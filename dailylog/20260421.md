## 0421-H｜相對原 spec 的事實校正

- `nx01_role` 實際 **8 個職務**（含 `HR_ADMIN` 人資主管），原 spec 寫 7 個
- `nx10_medal_level` 實際 **16 階**（4 tier × 4 rank：BRONZE/SILVER/GOLD/PLAT × IV~I），原 spec 寫 20 階
- Prisma 7 行為：`prisma migrate reset` **不再自動跑 seed**，必須手動 `pnpm tsx prisma/seed/index.ts --mode all --tier all`
- Prisma 7 AI Agent 安全機制：破壞性指令（如 `migrate reset --force`）即使 spec 授權仍要求當下設 `PRISMA_USER_CONSENT_FOR_DANGEROUS_AI_ACTION` 環境變數
- Prisma 7 的 unique 是 `CREATE UNIQUE INDEX`（不是 `ADD CONSTRAINT`），手寫 migration 用 `DROP INDEX` 才對
- Prisma 7 CLI flag 改名：`--from-schema-datasource` → `--from-config-datasource`；`--to-schema-datamodel` → `--to-schema`
