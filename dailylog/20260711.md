```

先以無 token 401 確認新端點已載）。

測試料號 NX01PART0023891（03L 115 561 機油芯：報價 2/對應料 2/車型 1 都有真資料）

登入：Y0005 TEMP 換雜湊（bcryptjs、nx-api 沒裝 bcrypt）→ POST /auth/login 取 token

四端點核對全過：
  sales-history    → TEMP SO 2 筆逐欄全對（日期新→舊/客戶/數量/單價/金額/狀態）
                     + 真報價 2 筆 + 建議售價 cost=383.08 / A=1297 / B=908
  purchase-history → TEMP RR 2 筆逐欄全對（含批號、INSPECTING/POSTED 狀態）
  related          → 真資料 2 筆（MAHLE/BOSCH 機油芯、庫存帶出）
  models           → 真資料 1 筆（VW T5 Transporter、1988–2017、fit=1 原廠）

還原全數確認：TEMP 單據刪除歸零；Y0005 雜湊還原＝快照原值逐字比對 t、
must_change_password 還原 true。
```

**驗證中三發現：**
1. ⚠️ **Y0005 雜湊曾被 0710 session 寫壞**：PowerShell 還原時 `$` 被塞反引號（60→63 字）、
   該帳號本機其實一直登不進去。本日修回快照原值（與 dump 逐字比對一致）。
   教訓：**含 $ 值（bcrypt 雜湊）一律走檔案傳遞（[IO.File]→psql stdin）、禁 shell 字串內插**。
2. ⚠️ **schema 觀察（純回報未動、轉 CTO）**：nx04_so / nx02_rr 的 currency_id
   預設值 'TWD' 是幣別代碼、但 FK 指向 nx01_currency.id（NX01CURR...）——
   預設值本身違反 FK、靠應用層每次明填才沒炸。
3. 插測試單據 tenant 別拿 nx99_tenant LIMIT 1（第一列 SYSTEM）；營運租戶=NX99TANT9900004。
