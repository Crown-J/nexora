### 關鍵技術決策：FadeInItem 用 Tailwind 原生而非 CSS keyframes
Alex spec 建議 `@keyframes fade-in` 寫 globals.css。我選擇：

```tsx
function FadeInItem({ delay, children }) {
  const [visible, setVisible] = useState(false);
  useEffect(() => {
    const t = setTimeout(() => setVisible(true), delay);
    return () => clearTimeout(t);
  }, [delay]);
  return (
    <div className={cx(
      'transition-all duration-300 ease-out',
      visible ? 'translate-y-0 opacity-100' : 'translate-y-1 opacity-0',
    )}>
      {children}
    </div>
  );
}
```

**理由**：
- 零跨檔 CSS 依賴，不污染 globals.css 避免波及其他頁
- 每個 item 獨立管理，可個別調 delay
- 純 Tailwind transition utilities，不引入 tailwindcss-animate plugin
- 代價：每 item 多一個 setState；15 item 以內可忽略
