# F2 報價工作台・逐環節調整清單（2026-07-12 執行長實走）

**工作模式**：純紀錄 → 流程 RUN 完 → 一次動工。動工前逐條回讀確認。

## ✅ 執行長定案（07/12、五題全回＋開工令）

1. **取貨方式**：客戶主檔**補「預設取貨方式」欄位**（後端小案：schema 加欄
   `default_delivery_type`、值域同銷貨單出貨方式 P自取/D配送/S寄送、nullable；
   DDL 記得進 pending-production.sql）
2. **階段③ Alt+D 加調貨**：**退場**、統一走④出貨倉庫屬性
3. **④移除鍵**：**定案 Alt+D**
4. **⑤編輯模式換行**：**Shift+Enter**（Enter＝回副容器）
5. **⑤手編 vs 設定卡**：**(a)** 設定卡變更即重生成、以最後動作為準

## S5-6・訊息格式（執行長 07/12 補充、定案）

同品名（同通用件群組）**分組顯示**：品名固定當組標題（取其中一個即可、
同群組品名相同）、組內每行＝識別（正廠 或 廠牌名）＋報價：

```
機油芯
正廠 報價 NT$ 200
BOSCH 報價 NT$ 320
```

- 設定卡新增「**廠牌**」選項；**品名固定顯示在組標題**（不再是每行開關）；
  既有：基準料號/副廠料號/數量恆顯 照舊為可選。

- [ ] **S4-2（修正版）・Enter 進副容器屬性面板**（執行長二稿、取代一稿的
