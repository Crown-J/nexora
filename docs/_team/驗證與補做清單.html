B. 查證（系統「有沒有」＋「該不該有」）

#項目模組優先動作
B1版本閘門殘留核心 §9.2高舊矩陣列的功能（多倉/部門層級/完整員工主檔/採購單/出口/KPI…）在 code 是否還有「依版本擋」的閘門？有 → 違反鐵則、要拆。
B2在途量／預進量NX02/03中採購「已核准未入庫」的在途量，系統是否記錄、是否計入「可用庫存」供下單參考。查現況＋判該不該有。
B3採購相關狀態重驗NX08中採購已串通，進貨報表/個人月報毛利/損益表成本 應已改善 → 重驗實際資料、更新報表手冊狀態。
B4安全庫存設定可用性NX08/01中低庫存警報依賴零件主檔「安全量」；核心主檔已列欄位 → 確認設定功能是否已可用（手冊原註建置中）。
B5零件主碼錨點NX01中是否有獨立於「零件料號」的系統內碼作永久錨點，或料號本身即不可改錨點。影響改號與歷史單據。
B6員編格式對齊NX01低手冊「Y＋4碼自動可覆寫」vs 產品方向「自由文字不強制格式」→ 確認現況以「自動給號為預設、可覆寫成任意唯一文字」對齊。
