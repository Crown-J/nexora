## §2. 六大報表（對齊 v1.2 §9.1）

```
報表
├─ 個人月報表
├─ 進貨報表
├─ 銷售報表
├─ 庫存報表
├─ 財務報表（本軌 = 損益表）
└─ 營運報表（負責人全公司 KPI dashboard）
```

### 2.1 個人月報表（§9.2）

```
─ 範圍切換：日報 / 月報
─ 日期選擇
─ 員工選擇：預設「我」、負責人可選其他員工
─ 內容：統計這人這時段做過的業務動作
  開單數（報價/銷貨/進貨各幾張）/ 出貨件數 / 撿貨件數 / 跑客戶家數
  ⭐ 完成業績 = 銷貨額 + 毛利（兩者都顯示、總經理拍板）
⚠️ LITE 沒打卡系統、月報不綁打卡、純統計業務動作
⚠️ 權限：員工只看自己、負責人看所有人（套既有角色權限、不寫死）
```

### 2.2 進貨報表

```
進貨維度分析：圖表 + 表格
（採購金額、供應商分布、品項分析等、依既有進貨資料能撈的維度）
```

### 2.3 銷售報表（§9.3）

```
─ 分析角度切換：產品 / 客戶 / 員工
─ 期間選擇
─ 銷售排行（依角度：產品排行 / 客戶排行 / 員工排行）
─ 趨勢圖
─ 匯出 Excel / 列印
```

### 2.4 庫存報表

```
庫存維度分析：庫存量、週轉、呆滯品、安全量警示等
（依既有庫存資料能撈的維度）
```

### 2.5 財務報表（本軌 = 損益表）

```
⭐ 本軌只做損益表（總經理拍板 B）：
  收入（銷貨淨額）− 銷貨成本 = 毛利
  毛利 − 營業費用 = 營業淨利
  （用既有財務/銷貨/採購資料能算的損益結構）

⚠️ 資產負債表 / 現金流量表 → 後續軌（需完整會計總帳科目系統、本軌不做）
   報表頁可預留這兩張的 Tab、標「需完整會計科目、後續啟用」
```

### 2.6 營運報表

```
負責人的全公司 dashboard：整合各模組 KPI
（銷售額/進貨額/庫存值/應收應付/毛利等綜合指標、卡片+圖表）
⚠️ 權限：通常只有負責人/高權限角色能看（套角色權限）
```
