🎮 NEXORA 情境攻略測試本 v1.0（2026-07-11）

像跑遊戲關卡一樣測系統。鍵位＝程式實掛、分支＝驗收實測撞過的業務閘。勾選會自動儲存在這台瀏覽器。
每一步都問自己四件事、對應四個勾：
①在＝功能真的存在　②清＝排版清楚不複雜　③鍵＝不碰滑鼠能完成　④手＝快捷鍵順手好按
③④只勾「這一步有按鍵」的項目；哪一步卡住就記下關卡編號-步驟號丟給 Hank。
🧰 準備：dev server 起著、用 Y0001 登入、硬重整一次（Ctrl+Shift+R）再開始。

關卡一｜客戶來電：黃金三十秒

角色：業務（櫃台接電話）
📞 「喂，我要 GOLF 的前輪軸承，多少錢？有貨嗎？」——客戶在線上等、你手不能離鍵盤。
  1. 任何頁面直接按 F2 開料號即時查詢窗
    預期：查詢窗彈出、游標已在搜尋框（不用點）
  2. 打料號或關鍵字 → ↑↓ 選料 → Enter 進主視窗
    預期：三欄主視窗（基本資料/庫存/價格）、看得到各倉庫存
  3. 按 F4 看這顆料的歷史報價、F8 看銷貨比價（建議售價列＝成本+A~D 價）
    預期：面板即開即關、客戶問「上次跟你們拿多少」馬上答得出
  4. 客戶問「有沒有替代品」→ 按 F3 可替代零件、F10 相關零件（對應料/適用車型兩頁籤）
    預期：F10 兩頁籤切換順、車型年份看得懂
  5. Esc 關查詢窗 → 回首頁按 1 直接開新報價
    預期：報價建單畫面、游標落在第一個要填的欄位
  6. 報價明細加行：選料、填量價、Enter 一路跳格到底
    預期：Enter 跳格鏈不斷、不用滑鼠點格子
💥 遭遇戰：報價低於底價
給熟客殺到底價以下 → 系統要求必填理由才放行。測：理由欄好不好找？填完流程順嗎？
💥 遭遇戰：第一次進頁跳出操作導覽
新頁面首次進入會有導覽浮層、此時背景鍵盤全鎖（設計行為）。按任意鍵焦點會跳到「我知道了」→ Enter 關閉。測：這體感能接受嗎？
💡 攻略提示
F2 窗內八快捷：F3 可替代 F4 報價 F5 周轉 F6 出入庫 F7 詢價 F8 銷貨比價 F9 進貨比價 F10 相關零件

關卡二｜成交！報價轉銷貨

角色：業務
📞 客戶回電：「好、就照你報的價，出貨吧。」
  1. Alt+W 開銷售選單 → ↓ 移到「報價單」→ Enter
    預期：選單開啟時焦點自動落第一項、↑↓ 會跳過「建置中」項目
  2. 報價列表 Alt+F 開搜尋（游標自動進框）→ 打客戶或單號 → ↑↓ 選單、Enter 開詳情
    預期：搜尋即打即找、Esc 可收搜尋條
  3. 把報價單「寄出」（狀態 草稿→已寄出）
    預期：找得到寄出按鈕/動作；⚠️ 草稿直接轉銷貨會被擋（業務閘、訊息要看得懂）
  4. 按「轉銷貨」→ 檢查明細**整批帶過去**、單價跟報價一字不差、銷貨單上看得到來源報價單號
    預期：不用重 key 任何一行
  5. 檢查出貨倉自動帶入（客戶有預設倉帶預設倉、沒有帶你的隸屬倉）
    預期：倉位欄已有值、不會叫你手選
💥 遭遇戰：這個客戶被凍結了
對授信凍結戶建銷貨 → 直接擋單、訊息含凍結原因。測：訊息清楚嗎？接著去 基本資料→往來對象 解凍再回來、流程斷點多不多？

關卡三｜沒庫存！打給同行調貨

角色：業務
😱 銷貨明細有一顆庫存 0。客戶等著要、恆迎日常：打給同行調。
  1. 明細行把補貨來源標成「同行調貨」
    預期：行狀態自動變「待補貨」、看得出這行在等調貨
  2. 先 F2 → F9 進貨比價、F7 詢價紀錄——決定打給哪家同行、大概什麼價
    預期：歷史進價一眼可比（實際成本欄有橘色強調）
  3. 銷貨單上的「待調貨行」開同行調貨單（選同行、勾行、一鍵建）
    預期：調貨單草稿生成、銷貨行自動連結調貨單並轉「補貨中」
  4. 去 銷售作業→同行調貨單（Alt+W 選單裡、7/11 剛搬過來的位置）確認單在、明細回連銷貨
    預期：調貨單在「銷售」選單找得到（不再是採購）、位置符合直覺
💡 攻略提示
調貨的「收貨」不在這裡——貨到時是倉管在 庫存管理→入庫作業→到貨驗收 收、單據歸業務、收貨歸倉管。

關卡四｜出貨收錢

角色：業務→會計
🚚 貨備好了。出貨、然後把錢收回來。
  1. 銷貨單狀態推進：確認 → 撿貨 → 出貨
    預期：每步都有明確按鈕/動作；出貨後量價鎖定不能改（試改一格、應被擋）
  2. Alt+Q → 應收帳款：出貨那張單的應收自動出現、金額含稅正確
    預期：不用手建應收
  3. 對應收建收款 → 過帳 → 餘額歸零、狀態變「已付清」
    預期：沖帳兩步內完成
💥 遭遇戰：不小心關過帳的月份
會計→月關帳 關掉上個月 → 回頭想塞一筆上月收款 → 被鎖、訊息會告訴你「誰可以解鎖回頭改」。測：解鎖流程（負責人 REOPEN）好不好走？

關卡五｜客戶退貨

角色：業務→倉管
📦 客戶：「這顆不合、退一顆。」（只有出過貨的單能退）
  1. 對已出貨的銷貨單開銷退、挑行、填退量、選退貨原因
    預期：⚠️ 對草稿單開退會被擋（正確）；退貨取件方式（自送/順路取/寄回）選項看得懂
  2. 倉管驗貨：每一行標「好品/壞品」——沒標完就過帳會被擋、訊息指名缺哪行
    預期：標記操作直覺、擋單訊息精確
  3. 過帳 → 好品庫存自動回倉、系統自動開折讓單
    預期：庫存和帳都不用手調

關卡六｜採購補貨

角色：採購
🛒 缺貨簿有一串要補的料。走正式採購。
  1. Alt+X → 國內採購工作台（選單第一位＝主入口）
    預期：工作台一眼看得到今天要處理什麼
  2. 建採購單（Alt+A）→ 走簽核鏈：送審 → 核准 → 寄出 → 廠商確認
    預期：每一步狀態清楚；廠商確認後 應付帳款自動產生（Alt+Q 去看）
  3. 母公司代付情境：採購單填「付款對象」→ 確認後應付帳款掛歸戶（列表有金色「歸戶」副行）、開付款單對象自動帶歸戶
    預期：7/11 新功能、欄位好找
  4. 貨到：採購單「轉進貨」（要指定收貨庫位）→ 驗收 → 過帳 → 庫存增加
    預期：庫位欄不會讓你猜、過帳後庫存立刻查得到（F2 → F6 出入庫）
  5. 來了一顆壞的：開進貨退回、處置選「走保固」→ 過帳後保固申請單自動生成（採購→保固申請）
    預期：7/11 修好的功能、保固單回連原退貨單

關卡七｜倉管的一天

角色：倉管
🏭 撿貨、包貨、調撥、盤點、有問題回報。
  1. Alt+U → 出貨作業 → 撿貨/包貨：清單照單撿、狀態逐步推
    預期：待撿清單清楚、鍵盤能選單操作
  2. 調撥：Z01 調兩顆去 Z02（挑庫位）→ 運送中 → 收貨 → 兩倉餘額互轉
    預期：LITE 也能用（7/11 拆掉的擋牆）、不會叫你升級方案
  3. 發現一顆壞品：誤差回報 → 送出 → 「一鍵開報廢單」→ 報廢過帳 → 回報單自動結案
    預期：異常鏈全程不用手動關單
  4. 條碼：零件主檔掛條碼、設預設 → 標籤列印（🖨 這步順便驗列印版面）
    預期：一料多條碼、重複條碼會告訴你撞到哪顆料

隱藏關｜拔掉滑鼠

難度：★★★
🖱️❌ 把滑鼠拔掉（或推到拿不到的地方）、重跑一次關卡一＋關卡二。這是「全鍵盤」的終極驗收。
  1. 選單全鍵盤：Alt+Y → ↓ 到「產品與廠牌」→ → 進子選單 → 選「零件基本資料」
    預期：→ 進子層、← 退回、左右換頂層選單、Esc 關閉焦點回選單列
  2. 主檔頁全鍵盤：↑↓ 選列、Home/End 首尾、Enter 開詳情、Alt+1/2 切列表詳情、Alt+E 編輯 → Enter 跳格 → Alt+S 存檔
    預期：整圈不碰滑鼠；焦點在哪永遠看得出來（金色高亮）
  3. 對話框全鍵盤：Alt+D 叫出停用確認 → 框上直接標 Esc 取消/Enter 確認 → 按 Esc 全身而退
    預期：框開著時背景熱鍵全部失效（按 Alt+A 不會穿透）
  4. 終極試煉：從 F2 查料 → 首頁 1 開報價 → 加行 → 存檔寄出 → 轉銷貨、全程零滑鼠
