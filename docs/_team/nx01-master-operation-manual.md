## 三、通用操作（鋼鐵星球範式，所有新範式主檔一致）

### 畫面結構（ASCII 示意）

```
┌─────────────────────────────────────────────┐
│ ← 返回   📁 系統設定 / 幣別主檔        12 筆幣別 │  ← 標題列
├─────────────────────────────────────────────┤
│ [資料瀏覽 Alt+1]  [詳細資料 Alt+2]            │  ← Tab
├─────────────────────────────────────────────┤
│ ◀ ◀ 1/3 ▶ ▶  A新增 E更正 F查詢 | D停用 匯出 R │  ← ERP 工具列
│                          顯示停用  選取  Q結束 │
├─────────────────────────────────────────────┤
│ 代碼   名稱      符號  小數  狀態              │  ← 列表
│ TWD    新台幣    NT$   0     ● 啟用            │
│ USD    美金      $     2     ● 啟用            │
│ JPY    日圓      ¥     0     ○ 停用            │
└─────────────────────────────────────────────┘
```

### 新增一筆
1. 按 **A**（或工具列「新增」）→ 自動跳到「詳細資料」Tab、出現空白表單。
2. 填欄位（標 `*` 為必填）。
3. 按 **S** 存檔 → 跳出確認框 → 確認 → 寫入。

### 編輯一筆
1. 在「資料瀏覽」用 **↑ ↓** 選列（或滑鼠點）。
2. 按 **E** 更正 → 進編輯模式（代碼類欄位鎖定不可改）。
3. 改完按 **S** 存檔。**改到一半想離開**會跳「存檔後離開 / 丟棄變更 / 取消」三選一，不會默默丟資料。

### 停用 / 啟用（軟刪除，系統不刪資料）
- 選一筆按 **D**：選到「啟用中」的 → 變停用；選到「已停用」的 → 變啟用。
- 停用的資料不會消失，按工具列「顯示停用」就看得到、可重新啟用。

### 查詢
- 按 **F** 開搜尋條，輸入代碼 / 名稱即時過濾（停 300 毫秒自動查），**ESC** 關閉。

### 批次
- 按「選取」→ 列表出現勾選框 → 勾多筆 → 「批次啟用 / 批次停用」。

## 四、鍵盤快捷鍵列表（全鍵盤、不用滑鼠也能跑完）

| 按鍵 | 動作 | 模式 |
|---|---|---|

| `Alt+Q` | 結束（返回） | 瀏覽 |

| `Alt+C` | 取消 | 編輯 |

## 五、手機操作

- 同一套畫面，手機自動變單欄：標題列 → Tab → 工具列（**可左右滑動**看到全部按鈕）→ 內容。
- 「資料瀏覽」「詳細資料」用上方 Tab 切換（手機沒鍵盤就用點的）。
- 表單在手機是單欄、電腦是兩欄，自動適應。
- ⚠️ 手機實際手感（按鈕大小、滑動順不順）請在實機驗收，我這邊沒辦法實機測。

### 🟡 待遷移（目前仍是舊範式、功能可用，尚未換鋼鐵星球）

> ⚠️ **重要真相**：我把剩下 21 個主檔的後端摸過，發現**後端介面約定不統一**，沒辦法用同一套通用畫面無腦套，必須分群處理（這也是我沒有硬遷的原因——硬遷會在實機上壞掉，但編譯檢查看不出來）：

| 主檔群 | 主檔 | 遷移障礙（需處理才能正確遷） |
|---|---|---|
| 簡易目錄 | 傳動方式、車體類型 | 後端「停用」走 `DELETE`、跟幣別那群的 `啟用切換` 不同 → 通用畫面要加「停用方式」設定 |
| 車型字典 | 引擎、變速箱 | 有**必填下拉**（燃料別 / 變速型式）+ 車廠外鍵 → 通用畫面要加「下拉 / 外鍵選擇」欄位 |
| 品牌類 | 車廠品牌、零件廠牌 | 有國家外鍵、Logo 網址 → 要加外鍵下拉 |
| 產品料號 | 零件、料件車型適配、零件關聯、品牌料號規則 | 欄位多、有版本/適配子表、外鍵多 → 各自客製 |
| 交易對象 | 客戶、客戶分級、往來對象 | 往來對象有地址子表 → 客製 |
| 組織 | 倉庫、據點 | 平面為主、但停用約定待確認 |
| 帳號權限 | 職務、職務權限視圖 | 職務權限視圖是權限矩陣 → 客製 |
| 公告 / 字典 | 公告、注音字典 | 公告有分類/附件 → 客製 |

### 🔒 系統管理員鎖定（已完成、後端層）

- 一般用戶在「職務」清單看不到系統管理員、在「使用者」清單看不到伊諾瓦後台帳號。
- 一般用戶不能指派系統管理員職務、也停用不了它。
- 做在後端最底層，所有畫面只要走 API 就自動擋住。

## 八、已知問題 / 限制（誠實揭露）

1. **我無法在此環境跑 app**：以上都通過 TypeScript 編譯檢查，但畫面實際長相、手機手感、鍵盤跑起來順不順、API 串接 runtime 是否正確，**需要實機驗收**。截圖也要實機補。
2. **剩 21 個主檔的後端約定不統一**（第六節）：要正確遷移需要先把通用畫面加上「停用方式設定 + 下拉/外鍵欄位」，再一群一群遷、且每群在實機驗過再上。這是多輪工作。
3. 舊範式畫面仍留著（沒刪），所以這 21 個主檔現在「還是能用」，只是還沒換成鋼鐵星球外觀。
