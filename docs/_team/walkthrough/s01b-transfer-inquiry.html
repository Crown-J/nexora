關卡一｜F5 清單：一卡一料、掛電話前心裡有底價

任何頁面 F5
📵 客戶電話掛了。換你打出去之前、先看清單。
  1. 任何頁面按 F5 開「即時調貨詢價」
    預期：瀏覽器不會整頁重新整理（F5 被視窗接管、真要重整用 Ctrl+R）；焦點直接在清單、不用點
  2. 看卡片：料號＋品名大字、加入時間、摘要行「詢價 N 筆・近5筆最低 X（同行名）」
    預期：皮帶卡顯示「詢價 2 筆・近2筆最低 398（鐙薪企業有限公司）」——還沒拿起電話就知道行情和最便宜那家
  3. ↑↓ 換選：選中卡金框＋展開近 5 筆明細（日期／同行／量／價）
    預期：換卡即展開即收合、清單自動捲動跟著走
  4. Alt+H 開引導精靈掃一眼 → Esc 關；Delete 試移除一顆再用入口加回來
    預期：精靈有全部鍵位＋「怎麼加料進來」說明；Delete 移除不影響已記的詢價紀錄

關卡二｜記詢價：連打三家不斷流（本本重頭戲）

電話夾肩膀上、單手操作
☎️ 「喂、復興嗎？025 260 849B 有貨嗎、多少？」——問到價、五個鍵存一筆。
  1. F5 清單選皮帶 → Enter 開「即時詢價」對話框
    預期：焦點直接在同行輸入框、拿起就打字；料號品名帶在框頂不用再選
  2. 打 復興（或 O0007）→ 下拉即出 → Enter 選定
    預期：選定自動跳數量欄（值全選、直接打新值）；注音首碼 F4 也通（同客戶欄）
  3. 數量 Enter → 價格欄打對方報的價 → Enter 存檔
    預期：對話框關閉、焦點回 F5 清單原料、卡片摘要「詢價 N 筆・最低…」即時+1 更新——不用重新整理
  4. 直接再 Enter → 記第二家（鐙薪）→ 存 → 再 Enter 記第三家
    預期：連打三家、手不用離開鍵盤；每存一筆、展開的近 5 筆明細多一列
  5. 加試單發入口：F1 搜任一顆料 → 主視窗 F7
    預期：同一個對話框、同一套鍵盤流（F7＝查庫存時順手記一筆、不用先進 F5 清單）
  6. 價格欄空著直接 Enter
    預期：擋下、提示「數量需大於 0、單價需填且不可負」——不會存出 0 元詢價

關卡四｜銷貨單標「同行調貨」：缺貨行標得了了

07/12 新功能
🤝 Line 上客戶＋同行都敲定了。回系統先開銷貨單（你拍板的順序 🅐）、缺貨那行標「同行調貨」。
  1. 銷售作業 → 銷貨單 → A 新增：C0049、走到編輯明細 → 加行打 025 260 849B 選定
    預期：黃字提示「本倉可用 0、下單 1、不足 1——單價按 Enter 後選補貨來源」
  2. 數量 Enter → 單價 Enter → 焦點自動跳到「補貨來源」下拉 → ↑↓ 選「同行調貨」→ Enter 存行
    預期：缺貨才會攔一手（庫存夠的料 Enter 直接存、不多這一步）；存完明細表新「狀態」欄顯示「等貨」徽章＋「同行調貨」小字
  3. 加驗：編輯這行、把補貨來源改回「本倉現貨」再改回來
    預期：改標即生效（狀態徽章跟著換：本倉現貨=等撿貨、同行調貨=等貨）；等到關卡五建完調貨單再回來改→會被擋「補貨中不可改」
  4. 免手標路線（F2 決策全自動接到這裡）：工具列「R 從報價紀錄」（Alt+R）→ 勾 07-12 那筆掛「調貨」徽章的 620 → Enter 帶入
    預期：行進來直接標好「同行調貨」（等貨徽章）、量價照紀錄；無徽章的紀錄帶入＝本倉現貨、倉別還跟著你在 F2 選的項目倉走
💡 兩條路都通
手動加行標來源（步驟 1~2）＝臨時來電沒走 F2 的情況；從報價紀錄拉入（步驟 4）＝F2 報過價的、調貨決策自動帶。挑順手的走。

關卡五｜一鍵補調貨單：成本自動帶、建單前先看到

單據純記錄、十秒補齊
📋 銷貨單存好了。工具列按「同行調貨」、把跟復興講好的那筆變成正式單據。
  1. 銷貨單詳情工具列「同行調貨」→ 同行欄打 復興 → Enter 選定
    預期：選定自動跳明細清單；每行「帶入成本」欄即時亮出該同行最近一筆詢價價（金色數字）、底部「勾選 N 行・成本合計」
  2. 把同行改成 品鑫（沒詢過這顆的）看成本欄
    預期：⚠️ 琥珀警示「查無詢價（成本 0）」——建下去成本 0、要進調貨單手動補；改回復興再繼續
  3. 明細清單 ↑↓ 選行、Space 勾/取消、Enter 建單
    預期：自動跳轉調貨單（TI）詳情；明細單價＝剛預覽的詢價價、表頭金額已算好——成本沒重 key 一次
  4. 回銷貨單看那行
    預期：狀態徽章轉「補貨中」、行上回連調貨單；這時再想改補貨來源會被擋（可讀訊息）
  5. Alt+W → 銷售作業 → 同行調貨單：確認單在銷售選單（不在採購）
    預期：後續狀態 草稿→發出→回覆→待驗收→完成、每一步看得懂

貨到是倉管在 庫存管理→入庫作業 收。單據歸業務、收貨歸倉管——跟 S01 尾聲同一句話。
