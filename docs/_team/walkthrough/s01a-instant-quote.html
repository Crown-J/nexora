關卡四｜④報價：卡片＋五列屬性面板（本本重頭戲）

左卡片、右屬性
📞 「上次跟你拿多少？」——每顆項目一張卡、Enter 進右欄調五個屬性、全程不碰滑鼠。
  1. 看左右「操作中」指示：左欄卡片區聚焦時、右欄整欄變暗＋標題掛「Enter 進來」；按 Enter 進右欄屬性面板後反過來（左暗＋「Esc 回這裡」）
    預期：一眼分得出現在控制哪一邊（07/12 你點名的切換不明顯已修）；「操作中」金徽章跟著焦點跑
  2. 屬性面板 ↑↓ 走五列：建議售價 → 報價/成交歷史 → 出貨倉庫 → 數量 → 報價；Esc 回左欄卡片
    預期：五列一屏放得下、選中列金框
  3. 「建議售價」Enter → 展開 ABCD 四級價 → 再 Enter 收合
    預期：A/B/C/D 四格、無值顯示 —
  4. 「報價/成交歷史」列直接顯示該客戶前價（例「報價 NT$ 315」、報價/成交取最近）→ Enter 開彈出視窗：表頭 日期/類別/客戶/數量/單價、客名金字＝該客戶、價差 ▲綠▼紅（對建議售價）
    預期：C0049 有 12 筆種好的歷史；↑↓ 選一筆 Enter → 價格直接帶進報價欄、視窗關閉、屬性自動跳到「出貨倉庫」讓你續編；Esc＝不帶價關閉
  5. 「出貨倉庫」Enter → 列出有可出量的倉（帶各倉可出數）＋最後一項「調貨（同行詢價）」→ 選一個倉
    預期：選完項目卡上的倉別徽章跟著換；選「調貨」時若公司有現貨會先跳確認防呆、確認後入 F5 調貨詢價清單、卡上掛橘色「調貨詢價（F5）」徽章
  6. 「數量」「報價」Enter 行內編輯 → 打字 → Enter 存回
    預期：編輯框自動全選、改完值即時反映在左欄卡片（× 數量、NT$ 價）
  7. Esc 回左欄 → Alt+2 回②搜尋、再挑一顆料加進來（跨搜尋輪累加）→ Alt+4 回報價看清單變長
    預期：先前的項目和量價都還在、一通電話報好幾顆不用重來
  8. 試 Alt+D 移除聚焦項目（有確認提示）→ Alt+S 結案 → 確認 → 進⑤發送訊息
    預期：Alt+S 會先告知有效筆數再確認；沒填量價的項目不算有效、不會進訊息
