## ➡ 目標：NX-MANUAL-PACKAGE-02（電子發票套件）

### 來自 §9.2 套件 A：電子發票套件

| 項目 | 說明 |
|---|---|
| **是什麼** | 系統幫客戶跟「加值中心」串接、能印出或寄電子發票給客戶 |
| **典型加值中心** | ezPay / 綠界 / 藍新 等財政部認證加值中心 |
| **沒買 = LITE 預設** | 客戶用發票機 / 自己另外用第三方開、再手動標 NEXORA 銷貨單為 INVOICED |
| **買了 = 加購版** | NEXORA 銷貨單 INVOICED 時、系統自動透過加值中心開發票、印出或寄給客戶 |
| **業務邊界** | 發票專用、不做其他事 |
| **目前實作狀態** | ⚠️ 套件範疇、後續再做 |

⚠️ **重要邊界**：電子發票套件**只負責**「跟加值中心串接、發發票」、不做物流通知、不做 LINE 訊息、不做催收、不做金流串接。

#### 對應的 LITE 流程接點（搬進套件後要寫的整合節）

- LITE 銷貨單 INVOICED 狀態手動標（NX-MANUAL-05 §6.10）→ 加購此套件後改自動觸發加值中心 API。
- LITE 銷退單 R / D 過帳後手動寄折讓單 → 加購後可選擇自動電子折讓。

## ➡ 目標：NX-MANUAL-PACKAGE-03（401 上傳套件）

### 來自 §9.2 套件 B：401 自動上傳套件

| 項目 | 說明 |
|---|---|
| **是什麼** | 系統自動把 401 TXT 兩檔送到財政部 API、自動標已上報 |
| **沒買 = LITE 預設** | 系統產 401 報表 + TXT、客戶自行到財政部網站上傳（NX-MANUAL-06 §7.7）|
| **買了 = 加購版** | TXT 直接傳檔、不用會計手動上傳 |
| **業務邊界** | 自動上傳國稅局、不做別的稅務功能 |
| **目前實作狀態** | ⚠️ 套件範疇、後續再做 |

⚠️ ⭐ **重要：401 預覽 + TXT 兩檔下載功能 LITE 內含**、就算不買套件、會計也能自己處理 401 申報。

#### 對應的 LITE 流程接點（搬進套件後要寫的整合節）

- LITE 雙月：月關帳 → 401 預覽 → TXT 兩檔下載 → 會計手動上傳 → 回標已上報。
- 加購此套件：TXT 自動上傳 + 自動回標、會計只要核對總數對不對。
- 接點 = NX-MANUAL-06 §7.8。

## ➡ 目標：NX-MANUAL-PACKAGE-07（第三方串接套件）

### 來自 §9.2 套件 C：第三方串接套件

| 項目 | 說明 |
|---|---|
| **是什麼** | 一籃子「跟外部 API 串接」的通用套件、含 LINE / Lalamove / 簡訊 / 催收訊息 / GPS / 金流自動偵測款項到帳 |
| **沒買 = LITE 預設** | 所有「給對方發訊息 / 同步對方系統」的動作都靠人工 |
| **買了 = 加購版** | 系統自動發 LINE / 派 Lalamove / 寄簡訊催收 / 即時 GPS 追蹤 / 自動匯入銀行流水沖銷票據 |
| **業務邊界** | 通用第三方 API、不含發票（電發走 PACKAGE-02）|
| **目前實作狀態** | ⚠️ 套件範疇、後續再做 |

⚠️ ⭐ **重要邊界**：

- 「催款訊息」（NX-MANUAL-06 §3.7）= **第三方串接套件範疇**（走 LINE / 簡訊）。
- 物流串接（Lalamove）= **第三方串接套件範疇**（NX-MANUAL-04 §9.5 已降指路）。
- GPS 即時追蹤 = **第三方串接套件範疇**（NX-MANUAL-04 §9.5 已降指路）。
- 金流自動串接銀行 = **第三方串接套件範疇**（未來可能分割成獨立金流套件、待總經理拍）。
- 電子發票串接（加值中心）= **電發套件範疇（PACKAGE-02）、不在這**。

#### 對應的 LITE 流程接點（搬進套件後要寫的整合節）

- 催客戶付款：LITE 純內部 log（NX-MANUAL-06 §3.7）→ 加購自動 LINE / 簡訊。
- 銀行對帳：LITE 會計人工核對月結單 + 手動更新自有帳戶餘額（NX-MANUAL-06 §8.5）→ 加購自動匯入流水。
- 配送：LITE 配送員手動「已派車 / 已送達」（NX-MANUAL-04 §9.5）→ 加購 GPS + Lalamove 自動串。
