## ➡ 目標：NX-MANUAL-PACKAGE-08（多據點模組）

### 來自 §11 出口（國外銷售）

⚠️ **此整個功能屬「多據點模組」、需加購**（PLUS / PRO 免費送、LITE 也可單買）：

#### 11.1 未加購時 LITE 看到什麼

- 銷售中心首頁桌機 hub 沒有「出口」卡（已收起、跟採購側 hub 不一樣）。
- 路由 `/dashboard/sale/export` 存在、進去顯示「需加購多據點模組、目前未開放」。

#### 11.2 加購多據點模組後開的功能

| 功能 | 說明 |
|---|---|
| 國外銷貨單 | 含外幣、貿易條件（FOB/CIF/EXW/DDP）|
| 商業發票 | 給海關用 |
| 裝箱單 | 給物流用 |
| 報關文件 | 給報關行用 |

國內為主的 LITE 客戶用不到、加購多據點模組後才開放完整國外流程。
