## ➡ 目標：NX-MANUAL-PACKAGE-08（多據點模組）

### 來自 §10.2 跨倉調撥單

⚠️ **此功能屬「多據點模組」、需加購**（PLUS / PRO 免費送、LITE 也可單買）：LITE 未加購時預設單倉、跨倉調撥沒有意義；加購後才有多倉可調。

#### 是什麼（加購後才能用）

公司內部「A 倉的貨搬到 B 倉」的單據。常見場景：

- A 倉爆滿、B 倉空、把賣不動的料件搬過去。
- A 倉某料件缺、B 倉有多、移過來救急。
- 自動補貨：系統依「倉別」（總倉 / 中間倉 / 自助倉 / 寄賣倉）規則自動產調撥單。

#### 入口

手機版工作站：「調撥」分頁、桌機路由 `/dashboard/inventory/transfer`。未加購多據點模組的 LITE 客戶進不去。

## ➡ 目標：NX-MANUAL-PACKAGE-07（第三方串接套件）

### 來自 §9.5 配送工作站

#### GPS 即時追蹤（加購後才能用）

司機開車送貨時、可在配送單詳情頁看到司機目前位置（即時 GPS 點），客戶亦可拿到追蹤連結。配送完成 / 簽收落地後自動清除位置資訊。

#### Lalamove API 整合（加購後才能用）

配送方式選「Lalamove」時、直接呼叫 Lalamove API 叫車、API 回傳司機資訊 + 預計到達時間自動回填、司機位置接 GPS 追蹤、客戶用 LINE 通知拿追蹤連結。免去人工聯絡 Lalamove 客服 / 自行貼司機資訊。
