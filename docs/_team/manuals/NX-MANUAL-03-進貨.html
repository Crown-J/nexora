通用操作（所有進貨單據共通）

進貨在 NEXORA 是一套有先後順序的流程：先有「採購需求」、再去「詢價」、選定供應商開「採購單」、貨到開「進貨單」驗收、發現問題開「退貨單」或「保固申請」。整套都集中在「採購中心」。

怎麼進到採購中心

按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「進貨」→ 進入採購中心。也可以從下方工具列（dock）的「進貨」項展開進入。採購中心首頁分三個分區：

  • 主檔管理（2 卡）：採購視角的「產品」「供應商」入口，可以直接在採購中心改進貨成本、付款條件，不必跑去主檔中心。
  • 國內採購（6 卡）：完整的國內進貨流程，從需求到退貨。本手冊主軸。
  • 特殊採購（3 卡）：掃貨／機會採購用，跳過詢價、直接開採購單。
【說明】本手冊每個畫面開頭都會標「選單位置」，照著點就能找到該畫面。

三種畫面版面

進貨畫面依用途分成三種：

A　單據列表＋詳細頁

大部分單據（詢價、採購、進貨、退貨、保固）都是這種。上半部「資料列表」（含狀態下拉過濾、單號／日期／供應商／金額／狀態欄），點「新增」進入空白表單、點某一列進入既有單詳細頁。詳細頁通常有「儲存草稿／送出／作廢」等動作按鈕。

B　工作台（流程聚合）

需求池、國內採購工作台、國外進貨追蹤頁屬這種。把「該處理的事」聚合到一個畫面，業務員一眼看到目前有哪些待辦、進到哪個階段。

C　設定頁

客套話設定屬這種。一個租戶 1 筆設定，沒有「新增／撤銷」，只有「修改」。

單據狀態流

進貨單據的狀態用單一英文字母代號：

單據狀態流
詢價單 RFQD 草稿 → S 已發出 → R 已回覆 → C 已關閉
採購單 POD 草稿 → S 已送出 → C 已關閉
進貨單 RRD 草稿 → P 已過帳（過帳即入庫＋產生應付帳）
退貨單 PRD 草稿 → P 已過帳（過帳即扣庫＋產生應付帳沖銷）
採購需求O 待處理 → P 處理中 → C 已完成 ／ I 已忽略
保固申請D 草稿 → S 已送出 → R 審核中 → C 已完成 ／ V 作廢
國外進貨（6 階段）1 備貨中 → 2 要求付款 → 3 待出貨 → 4 出貨上船 → 5 已到港 → 6 驗收完成
【提醒】已過帳的進貨單、退貨單不能直接刪除（會影響庫存平均成本與應付帳）；要更正必須開「反向單」沖銷。已關閉的詢價單／採購單可重開。

欄位標記說明

欄位後面會有徽章標示屬性：

  • 必填：空白無法存檔。
  • 建立後不可改：第一次存檔後就鎖定（例如單號、來源來源）。
  • 進階：列表預設不顯示，但詳細頁仍可填可看。
  • 系統自動寫：純顯示、業務員無法手動填（例如過帳人、入庫成本、最後進貨時間）。

版本門檻

本手冊涵蓋 LITE 版完整功能。少數進階功能屬加購套件，會在該單據開頭標 PLUS 徽章：

  • 自動補貨建議：依安全量／最高量自動排定補貨計畫（PLUS 起）。
  • SOP 精品示範：手機 9 步走完採購、防呆 UX（屬展示用、不綁版本）。

主檔管理（採購視角）

採購中心保留兩張主檔卡，方便採購人員不必跑去「主檔中心」就能改進貨成本與付款條件。欄位與「主檔中心」完全一樣（同一筆資料、同一張表）、只是入口和介面排版不同——本章只列「採購中心專屬視角」的重點，完整欄位請翻 NX-MANUAL-02 核心主檔。

產品管理（採購視角）
一般表格LITE
選單位置進貨 → 採購中心 → 主檔管理 → 產品管理

產品列表加上採購視角分區編輯：可改「進貨成本」「安全量／最高量／預設庫位」「保固月數」「退貨政策」等採購相關欄位，不影響「銷貨成本」「售價 ABCD」「規格／品名」等非採購欄位（那些走主檔中心或銷貨頁）。

【說明】採購頁編輯的零件欄位範圍由「產品分區」決定。完整欄位定義見 NX-MANUAL-02 §「零件基本資料」。

國內採購

國內採購流程從「採購需求」開始、經「詢價」「採購單」「進貨單」、可能走到「退貨單」。本章依採購中心「國內採購」分區的順序逐一說明 6 張卡。

採購需求
工作台LITE
選單位置進貨 → 採購中心 → 國內採購 → 需求

採購需求是「該採購但還沒開單」的待辦池。聚合三個來源、業務員一眼看到目前所有要採購的料件：

  • S 補貨自動：盤點低於安全量、系統自動建。
  • O 客訂：銷貨單下單時庫存不足、系統自動建（標客戶名）。
  • 手動：業務員主動新增（例如預期下個月會需要的料）。

操作步驟
  1. 看「來源」欄知道這筆是怎麼來的（補貨自動／客訂／手動）。
  2. 點「處理」進入詢價或採購單建立流程，狀態自動推到「處理中」。

操作步驟
  1. 在詢價列表點「新增詢價單」。
  2. 選日期、選供應商（可不指定，事後再加）、用搜尋框加料號／品名到明細。
  3. 點「儲存草稿」（狀態變 D）。
  4. 點「產生詢價文字」按鈕、系統依據「客套話設定」開頭結尾＋明細產生整段詢價文字，點「複製」貼到 LINE/Email。
  5. 狀態改「已發出」（S）。
  6. 供應商回報後，點「新增報價」逐家輸入單價／交期，狀態變「已回覆」（R）。
  7. 並排比較後點某筆報價的「採用」、系統自動把這筆改 A、其他標拒絕，並建一張草稿採購單帶過去。
  8. 採購單存檔後可關閉本詢價單（狀態 C）。
【重點】「採用」一筆報價會自動建草稿 PO，PO 帶供應商、料號、數量、單價過去，業務員只要檢查再送出即可，不必重新輸入。

操作步驟（手動新增）
  1. 點「新增採購單」。
  2. 選供應商（必填）、倉庫、幣別、付款條件。
  3. 用搜尋框加料號到明細，填採購量／單價。
  4. 點「儲存草稿」（狀態 D），檢查無誤點「送出」（狀態 S，正式對供應商下單）。
  5. 貨到時點「轉進貨」進入進貨單建立流程，系統把採購單的料號／已收 / 單價自動帶過去（見下節）。
  6. 整張採購單全部已收後可點「關閉」（狀態 C），未來不再從這張單轉進貨。
【說明】採購單可分批進貨（同一張 PO 開多張 RR）。每張 RR 過帳後 PO 的「已收」欄位累加，直到等於「採購量」為止。

操作步驟
  1. 點「新增進貨單」。
  2. 選「來源採購單」（推薦做法、明細自動帶）；或留空手動填（特殊採購／無 PO 進貨）。
  3. 檢查料號／庫位／數量／單價，數量可比 PO 少（缺料／壞品先退）。
  4. 國外進貨：填海運費／關稅／報關費／倉儲費／其他雜費＋當日匯率。系統自動把總費用按各料金額比例攤分到每料，並換匯產生「入庫成本」。
  5. 點「儲存草稿」（狀態 D），檢查無誤點「過帳」（狀態 P）。
  6. 過帳的瞬間系統做四件事：
    • 把每料件數量加到對應庫位的庫存。
    • 用入庫成本走「移動平均」更新該料件的平均成本。
    • 建立應付帳款（金額 = 進貨單總額、付款條件 = 供應商主檔的國內付款條件）。
    • 更新該料的「最後進貨時間」（見業績指標章節）。
【提醒】已過帳的進貨單不可改、不可刪。要更正請開「退貨單」沖銷或聯絡 IT。過帳前務必檢查單價、數量、庫位。

國外進貨比國內多兩個重點：6 階段時程追蹤（從備貨到到港）與進口費用攤分（海運／關稅／報關／倉儲攤到每料件成本）。

進口費用攤分（RR 國外版）

RR 國外進貨單裡填的海運費／關稅／報關費／倉儲費／其他雜費，系統會按各料件「金額（量 × 原幣單價 × 匯率）比例」攤分到每料件，再加上換匯後的單價，得到「入庫成本」寫入庫存帳本。

欄位計算公式
原幣小計數量 × 原幣單價
換匯後 TWD 小計原幣小計 × 匯率
本料攤分費用進口費用總額 × （本料換匯 TWD 小計 ÷ 整單換匯 TWD 總額）
入庫成本（單顆）（換匯後 TWD 小計 + 本料攤分費用） ÷ 數量
【重點】用「金額比例」攤分（不是「重量比例」或「件數比例」），對「貴的料攤多、便宜的料攤少」，符合實務上「重要進口品成本較高、應分擔較多費用」的原則。如要改攤分方式請聯絡 IT。

特殊採購

特殊採購＝跳過詢價、直接開採購單。常見場景：

  • 掃貨採購：路過供應商順手撿便宜貨，現場決定。
  • 機會採購：限時促銷、限量出清。
  • 緊急採購：客訂催料、來不及詢價。
  • 小額採購：金額太小不值得走詢價流程。
特殊採購（採購單／進貨單／退貨單）
一般表格LITE
選單位置進貨 → 採購中心 → 特殊採購（3 卡）

畫面與操作和「國內採購」三張單據完全一樣，只是 PO 的「來源」欄會自動標 B 特殊採購、跳過詢價／需求關聯。

【說明】特殊採購的單據與一般採購共用同一表（後端同套 API、加 purchaseType=B 旗標）。報表分析時可依此區分「正規採購 vs 特殊採購」的金額比例。

供應商修好還我們。系統不動帳、純記錄。
REJ 駁回
供應商認為非品質問題、不接受保固。要填駁回原因。

O 下次扣抵

A 折讓單
系統自動建草稿折讓單、財務核可後沖應付帳款。
R 直接退現
純記錄、業務員用收付款開「付款」沖應付。
操作步驟
  1. 進入保固申請單列表、點「新增」。
  2. 選類型（CUST／SELF）、選供應商、選零件、填問題描述、上傳附件（行照／問題照片／影片）。
  3. 點「送出」（狀態 S）對供應商主張保固。
  4. 供應商回覆要審核時點「進入審核」（狀態 R）。
  5. 審核結果出來時點「登記結果」、選 NEW／REF／RPR／REJ，REF 要填退錢金額＋方式。
  6. 登記完狀態自動推到 C（已完成）。
  7. 若整張單作廢，點「作廢」（狀態 V）保留紀錄。
【重點】客戶來反映壞掉時、業務員的標準動作是：(1) 先建「保固申請單」追供應商；(2) 同時看狀況決定要不要立刻換新給客戶（先換、等供應商賠）。退貨單「處置=走保固」會自動建保固單、是反過來的流程入口。

業績指標

進貨流程影響零件主檔的「最後進貨時間」「最後銷售時間」兩個業績指標欄位（02 第四批 P5 拍板加）。

最後進貨時間 / 最後銷售時間（指路 NX-MANUAL-02）
系統自動寫LITE
選單位置主檔 → 產品與料號 → 零件基本資料 → 採購分頁 / 銷貨分頁

每張進貨單過帳時、系統自動把「該料件最後進貨時間」更新為進貨單日期（取較新值，舊單不會覆蓋新單）。同樣的，銷貨單出貨過帳時更新「最後銷售時間」。

  • 最後進貨時間顯示在零件主檔的「採購分頁」、業務員看「久未進貨的料」用。
  • 最後銷售時間顯示在零件主檔的「銷貨分頁」、業務員看「呆滯料（最後賣很久了）」用。
  • 兩個搭配看可抓出「進得多、賣得少」的庫存風險料件。
