# H-W01｜出勤打卡作業

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

員工每日出勤的記錄與管理作業。支援 IP 打卡（辦公室）與 LINE 打卡（外出/外務）兩種方式。行政專員每日處理打卡異常，店長管理所轄人員出勤。

---

## 打卡方式

| 方式 | 適用對象 | 說明 |
|------|---------|------|
| IP 打卡 | 辦公室/倉庫人員 | 系統偵測 IP 位址，確認在指定網域內 |
| LINE 打卡 | 外務/外出人員 | LINE Bot 打卡，附 GPS 位置 |

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 員工上班 | H01 | 員工執行上班打卡 |
| 員工下班 | H02 | 員工執行下班打卡 |
| 系統偵測 | SYS-H01~ | 超過上班時間未打卡，系統自動通知 |

---

## 流程階段

### 階段一：員工打卡

**執行者：** 員工本人

**IP 打卡（辦公室/倉庫）：**

| 行為 | 說明 |
|------|------|
| H01 上班打卡 | 開啟系統，點擊「上班打卡」，系統記錄時間與 IP |
| H02 下班打卡 | 下班前點擊「下班打卡」，系統記錄時間 |

**LINE 打卡（外務/外出）：**

| 行為 | 說明 |
|------|------|
| H03 LINE Bot 上班打卡 | 傳送「上班」至 LINE Bot，系統記錄時間與 GPS 位置 |
| H04 LINE Bot 下班打卡 | 傳送「下班」至 LINE Bot，系統記錄時間與 GPS 位置 |

**忘記打卡處理：**

```
員工忘記打卡
  ↓
當日補登申請（需填補登原因）
  ↓
店長/直屬主管確認核准
  ↓
行政專員審核後登記
```

---

### 階段二：每日異常處理

**執行者：** 行政專員
**時機：** 每個工作日上午

| 行為 | 說明 |
|------|------|
| H05 查看打卡異常清單 | 系統列出：未打卡/遲到/早退/異常 IP |
| H06 確認異常原因 | 聯繫主管確認員工狀況 |
| H07 處理補登申請 | 審核員工補登申請，核准或退件 |
| H08 更新出勤記錄 | 依確認結果更新系統記錄 |

**異常類型：**

| 類型 | 說明 | 處理方式 |
|------|------|---------|
| 未打卡 | 無上班或下班打卡記錄 | 確認是否請假或補登 |
| 遲到 | 超過上班時間打卡 | 記錄遲到分鐘數 |
| 早退 | 未到下班時間打卡 | 確認是否有主管核准 |
| 異常 IP | 不在指定網域打卡 | 確認是否外出執行公務 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ H⊗01 出勤確認完成 | 所有異常處理完畢 | 流程結束 |

---

### 階段三：月底出勤彙整

**執行者：** 行政專員
**時機：** 每月最後一個工作日

| 行為 | 說明 |
|------|------|
| H09 產生月出勤報表 | 系統自動彙整當月所有員工出勤記錄 |
| H10 確認出勤天數/時數 | 核對每人實際出勤與應出勤 |
| H11 送薪資計算 | 出勤資料送交薪資計算，引用 [H-W03 薪資計算作業] |
