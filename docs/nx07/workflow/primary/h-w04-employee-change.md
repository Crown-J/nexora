# H-W04｜員工異動作業

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

處理員工入職、離職、調職、升職等人事異動的標準流程。每次異動都需更新系統員工主檔、帳號權限、薪資設定。

---

## 異動類型

| 類型 | 說明 | 觸發時機 |
|------|------|---------|
| 入職 | 新員工報到 | 報到日前完成設定 |
| 離職 | 員工離職 | 最後工作日前完成 |
| 調職 | 部門/職位異動 | 異動生效日前完成 |
| 升職 | 職稱/層級變更 | 異動生效日前完成 |

---

## 子流程一：入職

**執行者：** 行政專員

### 報到前準備

| 行為 | 說明 |
|------|------|
| E01 建立員工主檔 | 填入姓名/身分證/生日/學歷/緊急聯絡人/銀行帳號 |
| E02 設定職務/部門/組別 | 選擇對應的 role_id/department_id/team_id |
| E03 設定薪資結構 | 填入底薪/津貼/勞健保級距 |
| E04 建立系統帳號 | 依職務設定對應權限 |
| E05 設定打卡方式 | IP 打卡或 LINE Bot 打卡 |

### 報到當日

| 行為 | 說明 |
|------|------|
| E06 執行職前教育 | 說明公司規章/工作規則/勞動條件（1~3天）|
| E07 簽署勞動契約 | 員工了解工作規則後簽署 |
| E08 確認帳號可正常登入 | 確認員工可存取對應模組 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ H⊗04A 入職完成 | 員工主檔/帳號/薪資設定完成 | 流程結束 |

---

## 子流程二：離職

**執行者：** 行政專員（處理）、部門主管（確認）

| 行為 | 說明 |
|------|------|
| E09 收到離職申請 | 員工提交離職申請（需符合預告期）|
| E10 確認交接事項 | 通知直屬主管安排工作交接 |
| E11 計算離職薪資 | 計算至最後工作日的薪資/資遣費（若適用）|
| E12* 負責人確認離職 | 確認後續安排 |
| E13 最後工作日作業 | 停用帳號/收回資產/完成交接確認 |
| E14 更新員工主檔 | 填入離職日期/離職原因/離職狀態→停用 |
| E15 發放最終薪資 | 引用 [H-W03 薪資計算作業] 計算最終薪資 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ H⊗04B 離職完成 | 帳號停用/交接完成/薪資發放 | 流程結束 |

---

## 子流程三：調職/升職

**執行者：** 行政專員（執行）、部門主管（申請）

| 行為 | 說明 |
|------|------|
| E16 主管提交異動申請 | 填入員工/異動類型/生效日期/異動原因 |
| E16* 負責人審核 | 確認異動合理 |
| E17 更新員工主檔 | 更新部門/組別/職務/薪資（若有調薪）|
| E18 更新系統權限 | 依新職務調整模組存取權限 |
| E19 通知相關人員 | 通知新舊部門主管、當事員工 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ H⊗04C 異動完成 | 主檔/帳號/薪資更新完成 | 流程結束 |
