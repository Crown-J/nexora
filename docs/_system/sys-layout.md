## 三、TOP BAR 規格

```
┌────────────────────────────────────────────────────────────┐

## 四、KPI BAR 規格（PRO 限定）

```
所有模組共用規則：

1. PRO 版才顯示，LITE/PLUS 直接省略此區域
2. 依使用者角色自動顯示對應層級
   只有一個層級 → 直接顯示，不顯示 Tab
   兼任多個層級 → 顯示 Tab 切換
3. 統計週期：本月（固定，不可切換）
4. 右上角顯示：本月到結算還有 X 天

進度條規格：
  填充色：#E8A020 → #F5C842（金色漸層）
  底色：rgba(232,160,32,0.15)
  達標（≥目標）：綠色 #1D9E75
  警示（距目標差 10% 內）：橘色 #E8A020
  嚴重落後：紅色 #E24B4A
  反向指標（越低越好，如退貨率）：達標為綠，超標為紅

手機版 KPI BAR：
  預設收合，右上角收合/展開按鈕
  收合狀態顯示一行摘要（最重要的 2~3 個指標）
```

## 五、全域快捷鍵規格

### 層級一：模組層級

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+X` | 召喚/關閉功能選單 |
| `↑↓` | 選單內移動 |
| `Enter` | 進入選定模組 |
| `Esc` | 關閉選單 |

### 層級二：作業層級

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+←` | 切換到上一個子作業 |
| `Alt+→` | 切換到下一個子作業 |

子作業對照表：

| 模組 | 子作業順序 |
|------|-----------|
| 採購管理 | 國內 ← → 國外 ← → 特殊採購 ← → 產品管理 ← → 廠商管理 |
| 庫存管理 | 作業工作台 ← → 庫位管理 |
| 銷售管理 | 國內 ← → 國外 ← → 客戶管理 |

### 層級三：流程節點

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+1` ~ `Alt+9` | 切換對應節點或 Tab |

### 層級四：步驟

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+Q` | 聚焦步驟一 |
| `Alt+W` | 聚焦步驟二 |
| `Alt+E` | 聚焦步驟三 |
| `Alt+R` | 聚焦步驟四 |

### 層級五：動作

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+S` | 送出處置，產生單據 |
| `Alt+A` | 新增單據或品項 |
| `Alt+D` | 刪除單據或品項（需二次確認）|
| `Enter` | 確認 / 進入下一步 |
| `Esc` | 取消 / 返回上一步 |
| `Tab` / `Shift+Tab` | 欄位間前進/後退 |
| `↑↓` | 列表內上下移動 |
| `/` | 聚焦全域搜尋框（首頁）|

### 離開提醒機制

```
觸發時機：
  切換流程節點（Alt+1~9）
  切換子作業（Alt+←→）
  離開頁面（跳轉其他模組）

觸發條件：
  當前步驟有未確認的輸入
  或決策彙總區有未送出的項目

提醒對話框：
  「目前有未完成的操作，離開將會清空，確定要離開嗎？」
  [確定離開]  [留在此頁]

不觸發情況：
  步驟區完全空白
  已按 Alt+S 送出決策後
```

## 六、六種頁面版型

### 版型 A：模組首頁（卡片式）

```
適用：各模組的進入首頁
結構：
  卡片式功能入口（2~4 欄）
  每張卡片：圖示 + 功能名稱 + 說明 + 未完成數 badge
  點擊進入對應子作業

已使用：NX01 主檔首頁
```

### 版型 B：主檔列表（表格式）

```
適用：各種主檔資料的列表查閱
結構：
  頂部：搜尋框 + 篩選條件 + [+ 新增] 按鈕
  主體：表格列表（可排序）
  點擊列：右側展開詳情 或 進入詳情頁

已使用：NX01 使用者列表、客戶列表、廠商列表
```

### 版型 C：左右分欄設定（主從關係）

```
適用：有層級關係的設定頁面
結構：
  左側：分類/群組導覽（固定寬度 180~250px）
  右側：選中項目的詳細設定

已使用：NX01 職務設定、NX08 報表選單、NX09 文件庫
```

### 版型 D：矩陣設定（勾選表格）

```
適用：多對多的權限/設定矩陣
結構：
  橫軸：功能/模組
  縱軸：角色/職務
  交叉格：勾選框

已使用：NX01 職務權限矩陣
```

### 版型 E：作業工作台（主要版型）

```
適用：所有業務流程操作頁面
結構（桌面版）：
  頂部：KPI BAR（PRO）
  流程區：捷運圖式節點（固定高度 120~160px）
  作業區：依選中節點顯示

作業區兩種子版型：

E-1 有單據的節點：
  ┌──────────────┬──────────────────────┬────────────────┐
  │ 左側單據列表  │ 中間步驟區（三欄）    │ 右側決策彙總   │
  │ （固定 240px）│                      │ （固定 280px） │
  └──────────────┴──────────────────────┴────────────────┘

E-2 無單據的節點（查詢/列表）：
  ┌──────────────────────────────┬────────────────┐
  │ 全寬內容區（列表或步驟）      │ 右側統計/彙總  │
  │                              │ （固定 280px） │
  └──────────────────────────────┴────────────────┘

節點流程圖規格：
  實線（━）= 主線節點
  虛線（╎）= 支線節點（異常/退貨等）
  當前節點：金色填滿 + 放大
  有待處理：顯示 badge 數字（未完成單據數）
  完成節點：綠色
  無待處理：badge 不顯示

已使用：
  NX02 採購工作台（國內/國外）
  NX03 庫存工作台（入庫/出庫/盤點）
  NX04 銷售工作台（國內/國外）
  NX05 財務工作台（六個 Tab）
  NX06 物流工作台（四個 Tab）
  NX07 人資工作台（六個 Tab）
```

### 版型 F：報表分析（左側選單 + 右側圖表）

```
適用：分析報表類頁面
結構：
  左側：群組式選單（固定 220px）
        可展開/收合的群組
        依角色隱藏無權限項目
  右側：報表內容
        頂部：報表標題 + 匯出按鈕
        篩選條件列（期間/部門等）
        圖表區（Chart.js / Recharts）
        數據表格區

已使用：NX08 報表分析工作台
```

## 七、共用 UI 元件規格

### 7-1 單據列表（DocumentList）

```
共用於所有作業工作台左側單據清單

規格：
  每列：單據號 / 主要資訊 / 狀態 badge / 建立時間
  點擊列：高亮選中 + 右側步驟區更新
  [+ 新增] 按鈕固定在列表頂部

狀態 badge 顏色規範：
  草稿（D）：灰色
  進行中：橘色
  待審核：橘色 + ⚠️
  已完成：綠色 ✅
  異常：紅色 🔴
  已取消：灰色 刪除線
```

### 7-2 步驟區（StepPanel）

```
共用於所有作業工作台中間步驟區

三欄布局（Alt+Q/W/E/R 切換聚焦）：
  步驟一（Alt+Q）
  步驟二（Alt+W）
  步驟三（Alt+E）
  步驟四（Alt+R，若有）

步驟間以 Enter 推進
每個步驟完成後，系統自動聚焦下一步驟
```

### 7-3 決策彙總區（DecisionSummary）

```
共用於所有作業工作台右側決策彙總

固定寬度：280px
頂部：已選項目列表（每項可刪除）
中間：決策選項（單選或多選）
底部：[送出處置] Alt+S 按鈕（橘金色大按鈕）
      按鈕下方：備註說明

送出後：
  彙總區清空
  流程 badge 數字更新
  畫面停留（可繼續處理下一筆）
```

### 7-4 流程節點圖（FlowChart）

```
桌面版：捷運圖式水平排列
  各節點之間以連線連接
  虛線表示支線/可選路徑

手機版：底部 Dock 左右滑動
  各節點顯示名稱 + 未完成數 badge
  當前節點高亮
  左右滑動切換
```

### 7-5 KPI 進度條（KpiProgressItem）

```
共用於所有模組的 KPI BAR

結構：
  左側：KPI 名稱（12px）
  中間：進度條 + 百分比
  右側：目標值 / 達成狀態

進度條動畫：
  頁面載入時從 0 動態填充至實際值
  動畫時長：600ms
```

### 7-6 確認對話框（ConfirmDialog）

```
共用於所有需要二次確認的操作

類型：
  一般確認：白色背景，灰色框線
  警告確認（刪除/離開/關帳）：橘色邊框 + ⚠️
  危險確認（不可逆操作）：紅色邊框 + 🔴

結構：
  標題：說明要做什麼
  內容：詳細說明影響
  按鈕：[確認]（主色）[取消]（次要）
  危險操作：確認按鈕需輸入指定文字才能點擊
```

### 7-7 員工搜尋（EmployeeSearch）

```
共用於所有需要選擇員工的場景

輸入框：支援姓名/帳號/部門搜尋
結果列表：頭像（姓名縮寫）+ 姓名 + 部門 + 職務
多選模式：可勾選多位員工
單選模式：點擊即選定
```

### 7-8 客戶/廠商搜尋（PartnerSearch）

```
共用於採購/銷售的對象選擇

類型參數：C=客戶 / S=供應商 / T=物流 / V=一般廠商
輸入框：支援名稱/統編/代碼搜尋
結果顯示：名稱 + 等級 badge + 信用狀態
警示：凍結客戶顯示紅色警告
```

## 八、顏色系統

### 主色調（品牌色）

```
金色主色：#E8A020
金色漸層：#E8A020 → #F5C842
深色背景：#1A1A1A（深色模式）
```

### 語意色彩

```
成功/完成：#1D9E75（綠）
警示/注意：#E8A020（橘）
危險/錯誤：#E24B4A（紅）
資訊/一般：#378ADD（藍）
次要/停用：#888780（灰）
```

### 狀態顏色規範

```
單據狀態：
  草稿：灰色 #888780
  進行中：橘色 #E8A020
  已完成：綠色 #1D9E75
  異常：紅色 #E24B4A
  已取消：灰色 + 刪除線

KPI 進度條：
  達標：綠色 #1D9E75
  接近目標（差 10% 內）：橘色 #E8A020
  落後：紅色 #E24B4A
  反向指標（越低越好）：邏輯相反

關帳 Tab：
  未關帳：橘紅色底色 + ⚠️
  已關帳：綠色底色 + ✅
  解帳中：黃色底色 + 🔓

逾期警示：
  即將到期（7天內）：🟠 橘色
  逾期 1~14 天：🔴 紅色
  逾期 30 天+：🔴🔴 深紅 + 警示圖示
```

## 十一、存取控制規範

### 頁面層級控制

```
完全隱藏（模組不顯示）：
  NX05 財務：手機版完全隱藏
  NX07 人資：一般員工完全隱藏
  NX08 報表：一般員工完全隱藏

版本控制：
  LITE：基礎功能
  PLUS：進階功能（審核/多倉/國外）
  PRO：全功能（KPI/報表/遊戲化/人資）

角色控制：
  同一頁面依角色顯示不同視角
  例：NX03 倉管工作台
    一般員工：只看到自己的任務
    倉管組長：看到整體進度 + 待審核清單
```

### 財務安全限制

```
NX05 財務模組：
  行動裝置：完全封鎖（User-Agent 偵測）
  非公司 IP（PLUS+）：需 OTP 驗證
  緊急授權（PRO）：24 小時臨時授權 + 永久記錄
```

### 薪資保密規則

```
薪資明細：
  只有 NX07 行政專員 + 負責人 可在系統查看
  財務相關角色：完全無法存取 NX07
  一般員工：個人薪資單只能從加密 Email 查看
  出納匯款清單：加密 Email，不在系統介面留存
```

## 十二、通知系統規範

```
通知類型：
  系統通知（藍色）：版本更新/定期提醒
  業務通知（橘色）：需要處理的業務事項
  警示通知（紅色）：逾期/異常需緊急處理
  完成通知（綠色）：對方已完成，可繼續下一步

通知顯示位置：
  TOP BAR 通知鈴鐺（有未讀顯示數字 badge）
  點擊 → Dropdown 顯示最新 10 筆
  查看全部 → 通知中心頁面

跨部門通知（保固/需求回饋/安全量建議）：
  A 部門完成操作 → 系統推播通知給 B 部門
  點擊通知 → 直接跳至對應操作介面
  不需要透過口頭/LINE 通知

今日待辦：
  首頁 Dashboard + 各模組工作台頂部
  依角色顯示今日最重要的待處理事項
  點擊 [前往處理] → 直接跳至對應節點
```

## 十三、圖表技術規格

```
圖表庫：
  Recharts（React 原生，主要使用）
  Chart.js（複雜圖表，如瀑布圖）

各圖表類型：
  HPA 趨勢折線：Recharts LineChart（多年同月比較，多條線）
  業績橫條圖：Recharts BarChart horizontal
  分布圓餅圖：Recharts PieChart
  BCG/人才象限：Recharts ScatterChart（氣泡大小=金額）
  Porter 五力：Recharts RadarChart
  現金流瀑布：Chart.js（Recharts 無內建）
