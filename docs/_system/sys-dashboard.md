## 二、TOP BAR

> 維持現有風格，新增公告按鈕

### 版面結構（左 → 右）

```
[Logo] [租戶名稱] [版本Badge]    [日期時間]  [公告] [通知] [深淺] [使用者]
```

### 各元素規格

**Logo**
- NEXORA GRID 字樣 + 圓形 Logo 圖示
- 點擊跳轉 /dashboard

**租戶名稱 + 版本 Badge**
- 租戶名稱：`nx99_tenant.name`
- 版本 Badge：`LITE / PLUS / PRO`，金色外框樣式

**日期時間**
- 格式：`YYYY年M月D日 星期X / 下午HH:MM:SS`
- 即時更新（每秒）

**公告按鈕（新增）**
- 圖示：喇叭/廣播 icon
- 未讀數量 badge（紅色圓點數字）
- 資料來源：`nx01_bulletin`，`is_read = FALSE` 的筆數
- 點擊：展開下拉清單（dropdown）
- Dropdown 內容：
  - 標題列：「公告」+ 未讀數
  - 每則公告：`[緊急/公司/系統 badge]` + 標題 + 日期 + `>` 箭頭
  - 底部：「查看所有公告 →」→ 跳轉 `/dashboard/base/bulletin`
  - 最多顯示 5 則，依 `created_at` 倒序
- 鍵盤：`Alt+A` 開關公告 dropdown

**通知按鈕**
- 維持現有設計
- 鍵盤：`Alt+N` 開關通知 dropdown

**深淺模式切換**
- 維持現有設計
- 鍵盤：`Alt+T` 切換

**使用者按鈕**
- 頭像（姓名首字）+ 名稱 + 下拉箭頭
- Dropdown：個人設定 / 登出
- 鍵盤：`Alt+U` 開關

## 三、全鍵盤操作規格

## 全域快捷鍵規格（所有作業頁面共用）

### 層級一：模組層級
| 快捷鍵 | 功能 |
|--------|------|
| `Alt+X` | 召喚/關閉功能選單 |
| `↑↓` | 選單內移動 |
| `Enter` | 進入選定模組 |
| `Esc` | 關閉選單 |

### 層級二：作業層級
| 快捷鍵 | 功能 |
|--------|------|
| `Alt+←` | 切換到上一個子作業（如：國外採購→國內採購）|
| `Alt+→` | 切換到下一個子作業（如：國內採購→國外採購）|

### 層級三：流程節點層級
| 快捷鍵 | 功能 |
|--------|------|
| `Alt+1` | 切換到節點 1 |
| `Alt+2` | 切換到節點 2 |
| `Alt+3` | 切換到節點 3 |
| `Alt+4` | 切換到節點 4 |
| `Alt+5` | 切換到節點 5 |
| `Alt+6` | 切換到節點 6 |
| `Alt+7` | 切換到節點 7 |
| `Alt+8` | 切換到節點 8 |
| `Alt+9` | 切換到節點 9 |

### 層級四：步驟層級
| 快捷鍵 | 功能 |
|--------|------|
| `Alt+Q` | 聚焦步驟一 |
| `Alt+W` | 聚焦步驟二 |
| `Alt+E` | 聚焦步驟三 |
| `Alt+R` | 聚焦步驟四 |

### 層級五：動作層級
| 快捷鍵 | 功能 |
|--------|------|
| `Alt+S` | 送出處置，產生單據 |
| `Alt+A` | 新增單據或品項 |
| `Alt+D` | 刪除單據或品項（需確認）|
| `Enter` | 確認/進入下一步 |
| `Esc` | 取消/返回上一步 |
| `Tab` | 欄位間向前移動 |
| `Shift+Tab` | 欄位間向後移動 |
| `↑↓` | 列表內上下移動 |

### 離開提醒機制
```
觸發時機：
  - 切換流程節點（Alt+1~9）
  - 切換子作業（Alt+←→）
  - 離開頁面（跳轉其他模組）

觸發條件：
  當前步驟有未確認的輸入
  或決策彙總區有未送出的項目

提醒內容：
  「目前有未完成的操作，離開將會清空，確定要離開嗎？」
  [確定離開]  [留在此頁]

不觸發情況：
  步驟區完全空白
  已按 Alt+S 送出決策
```

## 四、EXP BAR（PRO 限定）

> 位於 TOP BAR 下方，全寬顯示
> LITE / PLUS 不顯示此區塊

### 版面結構（左 → 右）

```
[頭像+等級] [稱號 Lv.XX]  [經驗條（漸層）]  [數字 X,XXX / X,XXX]  [排位按鈕]
```

### 各元素規格

**頭像 + 等級圈**
- 圓形頭像（姓名首字），左下角顯示等級數字

**稱號 + 等級**
- 等級：`Lv.XX`
- 星星圖示（依勳章階級顯示顏色）

**經驗條**
- 漸層填色：`#E8A020 → #F5C842`
- 底色：`rgba(232,160,32,0.15)`（微金色，非灰色）
- 進度：`current_exp / next_level_exp * 100%`
- 條下方小字：「還需 X,XXX 經驗值升級」

**數字**
- 格式：`X,XXX / X,XXX`（當前 Exp / 本級滿級 Exp）

**排位按鈕（右側）**
- 樣式：金色圓角卡片
- 顯示：勳章圖示 + 稱號 + 等級
- 點擊：開啟「牌位、勳章與排行榜」Modal
- Modal 內容：
  - Tab 1「牌位勳章」：當前牌位 + 所有牌位解鎖進度
  - Tab 2「排行榜」：本週/本月/總榜 Tab + 排名列表
    - 每列：名次 + 頭像 + 姓名 + 部門 + XP + 排名變化（↑↓）
    - 我的排名固定置底顯示（金色高亮）

## 五、LEFT PANEL（PRO 限定）

> 固定寬度約 280px，由上至下排列
> LITE / PLUS 不顯示此區塊

### 5-1 今日簽到

**未簽到狀態：**
```
[綠色圓點] 今日簽到   [連續天數 badge] [獎勵按鈕]
            開始您的工作日
[簽到 按鈕]（橘金色大按鈕）
```

**已簽到狀態：**
```
[綠色圓點] 00:08:58   [7] [獎勵按鈕]
            下午04:52 簽到
```
- 計時器即時更新（每秒）

**獎勵按鈕（點擊）→ 開啟簽到獎勵 Modal：**
- 連續簽到週期獎勵（第1天 50XP / 第2天 100幣 / 第7天 獎品...）
- 額外成就勳章（新手達人7天 / 效率專家14天 / 堅持不懈21天 / 傳奇員工28天）

### 5-2 本日目標

```
[橘色圓圈] 本日目標    [70 / 125 XP]

[✓ 完成5項工作任務]         +50
[✓ 準時上班簽到]            +20
[ ] 參與一場會議  ⏰10:00   +30
[ ] 填寫工作日誌            +25

已完成 2 / 4 項
```

- 已完成：綠色打勾 + 刪除線
- 有截止時間：時鐘圖示 + 時間

### 5-3 本月目標

```
[橘色圓圈] 本月目標   [公司] [團隊] [個人]（Tab）

--- 公司 Tab ---
月營收目標      850/1000萬  ↑
客戶滿意度      92/95%      ↑
新客戶開發      45/60家

查看詳細目標 >
```

- Tab 切換：公司 / 團隊 / 個人
- 資料來源：`nx01_kpi_record`（達成）/ `nx01_kpi_target`（目標）
- 進度條：金色漸層，底色微金色
- 趨勢箭頭：vs 上月（↑綠色 / ↓紅色）
- 「查看詳細目標」→ 跳轉 `/dashboard/report/monthly-report`

### 5-4 填寫工作日誌

```
[橘金色大按鈕] 📄 填寫工作日誌
```
- 點擊：跳轉 `/dashboard/report/daily-report`
- 已填寫：按鈕變為「✓ 今日日誌已完成 +25 XP」（綠色）
- 填寫完成 = 今日下班打卡
- 資料來源：`nx08_daily_report`（當日是否已填）
