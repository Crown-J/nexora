# SYS-W01｜初始化作業流程

> 版本需求：所有版本
> 最後更新：2026-04-12

---

## 流程概述

新租戶首次啟用 NEXORA GRID 時的系統初始化流程。依客戶情況分為兩種路徑：
- **路徑 A：新公司（Green Field）**，從零開始建立資料
- **路徑 B：舊公司移轉（Data Migration）**，從既有 ERP/帳務系統匯入歷史資料

---

## 路徑 A：新公司（Green Field）

**適用對象：** 全新開業或從未使用 ERP 系統的客戶

### 階段一：系統建立租戶

**執行者：** Innova IT 系統管理員

| 行為 | 說明 |
|------|------|
| S01 建立租戶記錄 | 在 nx99_tenant 建立租戶（code/name/contact 等）|
| S02 建立訂閱記錄 | 在 nx99_subscription 建立對應方案與席次 |
| S03 執行預設資料 | seed.ts 依版本（LITE/PLUS/PRO）寫入 seed/default/ 所有 seed_type=ALL 的資料 |
| S04 依版本補寫 | PLUS → 補寫 seed_type=PLUS / PRO → 補寫 PLUS+PRO |
| S05 寄送開通通知 | 系統發送啟用 Email，含租戶代碼與管理員帳密 |

**seed.ts 執行順序：**
```
1. nx99_plan（方案，系統共用）
2. nx01_user（SYSADMIN + admin）
3. nx01_role（7個職務）
4. nx01_country / nx01_currency
5. nx01_car_brand / nx01_part_group / nx01_part_brand
6. nx01_brand_code_rule
7. nx01_customer_grade / nx01_discount_code
8. nx01_warehouse（依版本：ALL=MW1 / PLUS+=BW1 / PRO+=HW1+BW2~4）
9. [PLUS+] nx01_warehouse_type
10. [PLUS+] nx01_department（採購/銷售/倉管/財務）
11. [PRO+]  nx01_department（物流/人資）
12. nx05_account_code
13. [PRO+]  nx07_leave_type
15. system/ nx01_view（118個畫面）
16. system/ nx01_role_view（826筆權限）
```

---

### 階段二：客戶登入與基本設定

**執行者：** 客戶租戶管理員（admin）

| 行為 | 說明 |
|------|------|
| A01 首次登入 | 使用系統提供的 admin 帳號登入，強制修改密碼 |
| A02 確認公司資料 | 核對租戶名稱、聯絡資訊 |
| A03 建立使用者帳號 | 依員工人數建立各角色帳號（採購/業務/倉管/財務等）|
| A04 設定使用者權限 | 分配角色，調整各畫面的 canRead/canCreate 等 |
| A05 [PLUS+] 設定部門組別 | 調整預設部門架構，新增組別 |
| A06 [PLUS+] 設定使用者據點 | 指定各使用者可存取的倉庫 |

---

### 階段三：主檔建立

**執行者：** 各部門主管

**建議順序：**

```
1. 倉庫主檔確認       → 確認 MW1/BW1 等倉庫資訊正確
2. 庫位主檔建立       → 在 NX01 庫位主檔，依實際倉庫規劃建立庫位
3. 零件品牌確認       → 確認 VAG/Hella/Bosch 等預設品牌，可新增
4. 零件種類確認       → 確認 6 大種類，可新增自訂分類
5. 料號建立           → 在 NX01 零件主檔逐筆建立（或批量匯入）
6. 定價設定           → 在 NX01 產品定價作業設定 A~D 建議售價
7. 安全量設定         → 在 NX02 安全量設定，設定各料號各倉安全量/最高量
8. 交易對象建立       → 在 NX01 交易對象主檔建立廠商與客戶
9. 客戶等級設定       → 確認 A~D 等級毛利下限，分配客戶等級
10. 會計科目確認      → 確認費用科目，可新增自訂科目
```

---

### 階段四：期初庫存建立

**執行者：** 倉管組長

| 行為 | 說明 |
|------|------|
| B01 建立開帳存單 | NX03 → 開帳存 → 新增，選擇倉庫 |
| B02 填入料號與數量 | 逐筆填入料號/庫位/數量/均價 |
| B03 確認開帳金額 | 核對庫存總值與帳冊相符 |
| B04 執行過帳 | 點擊「執行過帳」，系統寫入 stock_ledger + stock_balance |
| B05 確認庫存餘額 | 到 NX03 庫存一覽確認各料號庫存正確 |

> ⚠️ 期初庫存過帳後，系統正式啟用日從此日期起算。
> 所有後續採購/銷售/財務單據日期須在開帳日期之後。

---

### 完成條件

```
✅ 所有使用者帳號建立完成
✅ 至少一個倉庫有庫位
✅ 至少一個廠商、一個客戶
✅ 至少一個料號
✅ 期初庫存過帳完成（若無庫存可跳過）
✅ 首筆採購單或銷貨單可正常建立
```

## 路徑 B：舊公司移轉（Data Migration）

**適用對象：** 從既有 ERP/帳務系統切換至 NEXORA GRID 的客戶

### 移轉策略

```
移轉範圍：
  ✅ 必移轉：料號主檔 / 廠商客戶主檔 / 期初庫存
  ⚠️ 選移轉：歷史採購單 / 歷史銷售單（建議只移近1年）
  ❌ 不移轉：舊系統的帳務流水（從切換日起重新累計）

切換日（Go Live Date）：
  → 建議選月初第一個工作日
  → 切換日前完成舊系統資料凍結
  → 切換日當天完成期初庫存過帳
```

---

### 階段一：移轉前準備

**執行者：** Innova IT 顧問 + 客戶負責人

| 行為 | 說明 |
|------|------|
| M01 確認切換日期 | 與客戶協議 Go Live Date |
| M02 匯出舊系統資料 | 客戶自行匯出：料號/廠商/客戶/庫存 |
| M03 資料清洗 | 顧問協助清洗：去除停用料號/重複廠商/負庫存 |
| M04 對應欄位 | 將舊系統欄位對應到 NEXORA 欄位格式 |
| M05 建立測試租戶 | 先在 STAGING 環境測試匯入 |
| M06 驗收測試匯入 | 客戶核對資料正確性 |

---

### 階段二：系統建立租戶（同路徑 A 階段一）

執行步驟同新公司路徑 S01~S05。

---

### 階段三：批量匯入主檔

**執行者：** Innova IT 系統管理員（執行）、客戶負責人（驗收）

**匯入順序（嚴格依照外鍵依賴）：**

```
Step 1. nx01_part_group（若有自訂分類）
Step 2. nx01_part_brand（若有自訂品牌）
Step 3. nx01_brand_code_rule（若有自訂規則）
Step 4. nx01_part（料號主檔）
         → 設定 A~D 售價
         → 設定退貨政策/保固月數
Step 5. nx01_partner（廠商+客戶）
         → 設定付款條件/信用額度/客戶等級
Step 6. nx01_location（庫位主檔）
Step 7. nx01_user（員工帳號）
         → 指派角色/倉庫授權
```

**匯入工具：**
```
系統提供 CSV 匯入功能（NX01 各主檔頁面右上角「批量匯入」）
匯入結果產生匯入報告：成功N筆/失敗N筆/警告N筆
```

---

### 階段四：期初庫存過帳

**時機：** 切換日前一天晚上（舊系統最後盤點完成後）

| 行為 | 說明 |
|------|------|
| M07 舊系統最終盤點 | 客戶在舊系統執行最後一次盤點，確認庫存數字 |
| M08 匯出庫存清單 | 匯出各料號各庫位最終庫存數量與平均成本 |
| M09 批量匯入期初庫存 | 在 NX03 開帳存批量匯入（每倉一張開帳單）|
| M10 核對庫存總值 | 確認 NEXORA 庫存總值與舊系統相符（誤差 < 0.1%）|
| M11 執行過帳 | 各倉開帳單逐一過帳 |
| M12 舊系統凍結 | 切換日起舊系統設為唯讀，禁止新增單據 |

---

### 階段五：歷史應收/應付移轉（選做）

**適用情況：** 客戶有未結清的 AR/AP 需繼承

| 行為 | 說明 |
|------|------|
| M13 匯出未結清 AR | 舊系統匯出截至切換日的未收款客戶清單 |
| M14 匯出未結清 AP | 舊系統匯出截至切換日的未付款廠商清單 |
| M15 在 NX05 手動建立 | 財務人員在應收/應付帳款手動建立移轉記錄 |
| M16 備註標記移轉來源 | remark 填入「移轉自舊系統 YYYY-MM-DD」|

---

### 完成條件

```
✅ 所有料號匯入完成，主檔正確
✅ 所有廠商/客戶匯入完成
✅ 期初庫存過帳完成，庫存總值核對無誤
✅ 未結清 AR/AP 移轉完成（若選做）
✅ 全員培訓完成，可正常使用系統
✅ 切換日起舊系統凍結
```
