# SYS-W04｜Onboarding Wizard 引導設定流程

> 版本需求：所有版本
> 最後更新：2026-04-12

---

## 流程概述

新租戶首次登入後，系統自動啟動 Onboarding Wizard 引導設定頁面。透過問卷式步驟引導客戶完成系統基礎設定，降低學習門檻，確保關鍵設定不漏填。

**觸發條件：**
```
租戶 onboarding_completed = FALSE 時（首次登入後自動跳轉）
管理員可在設定頁手動重啟 Wizard
```

**設計原則：**
```
1. 只問決策性問題，不問技術細節
2. 所有步驟均可「跳過」，跳過項目在 Dashboard 待辦清單提醒
3. 批量資料（料號/廠商/客戶）不在 Wizard 中填寫，改用 CSV 匯入
4. 完成後顯示摘要，讓客戶確認設定結果
5. 進度條顯示目前在第幾步
```

**整體步驟：**
```
Step 1 → 公司基本確認
Step 2 → 使用情境判斷
Step 3 → 倉庫設定
Step 4 → 建立第一批使用者
Step 5 → 零件基礎設定
Step 6 → 廠商與客戶
Step 7 → 期初庫存
Step 8 → 完成
```

## Step 1：公司基本確認

**頁面說明：** 「歡迎使用 NEXORA GRID！讓我們先確認您的公司基本資訊。」

### 問題

| # | 問題 | 類型 | 說明 |
|---|------|------|------|
| Q1 | 公司名稱 | 文字輸入（已預填）| 來自 nx99_tenant.name，可修改 |
| Q2 | 主要代理品牌 | 單選 | VAG 全系列 / 部分 VAG / 多品牌混合 |
| Q3 | 公司目前規模 | 單選 | 1~5人 / 6~10人 / 11~30人 / 31人以上 |

### 後續動作

```
→ 更新 nx99_tenant.name（若有修改）
→ 記錄 Q2/Q3 偏好（存入 wizard_meta，供後續步驟引導用）
→ Q3 回答與版本不符時顯示提示：
  「您選擇的人數超過目前版本上限，建議升級至 PLUS/PRO」
  （僅提示，不強制）
```

---

## Step 2：使用情境判斷

**頁面說明：** 「了解您的使用情境，我們可以提供更適合的引導。」

### 問題

| # | 問題 | 類型 | 選項 |
|---|------|------|------|
| Q1 | 您的公司之前有使用過 ERP 或倉管系統嗎？ | 單選 | 沒有，這是第一次 / 有，要從舊系統切換過來 |
| Q2 | [若有舊系統] 您需要將舊系統的資料移轉到 NEXORA 嗎？ | 單選 | 需要 / 不需要，從今天起重新開始 |

### 分流邏輯

```
Q1 = 沒有（Green Field）：
  → 顯示提示：「很好！我們會從零開始引導您建立資料。」
  → 繼續 Step 3

Q1 = 有舊系統 + Q2 = 需要移轉：
  → 顯示提示：
    「建議您先完成以下步驟後，再執行資料移轉：
     ① 完成 Wizard 基礎設定
     ② 下載 CSV 匯入範本（Step 5~7）
     ③ 準備好後至各主檔頁面執行批量匯入」
  → 繼續 Step 3

Q1 = 有舊系統 + Q2 = 不需要移轉：
  → 顯示提示：「了解！我們會從今天起開始記錄新資料。」
  → 繼續 Step 3
```

---

## Step 3：倉庫設定

**頁面說明：** 「設定您的倉庫，這是所有庫存管理的基礎。」

### 問題

| # | 問題 | 類型 | 說明 |
|---|------|------|------|
| Q1 | 您目前有幾個倉庫（據點）？ | 單選 | 1個 / 2~4個 / 5個以上 |
| Q2 | 各倉庫的名稱與代碼 | 動態填入 | 依 Q1 答案顯示對應數量的輸入欄位 |
| Q3 | 現在要設定庫位嗎？ | 單選 | 要，引導設定 / 之後再設 |

### Q2 預設值邏輯

```
Q1 = 1個：
  → 顯示 1 組輸入：
    代碼（預設 MW1）｜名稱（預設「主倉」）

Q1 = 2~4個：
  → 顯示 2~4 組輸入（可動態新增）：
    代碼（預設 MW1/BW1/BW2/BW3）｜名稱
  → 若版本為 LITE 選了 2 個以上，顯示警告：
    「LITE 版本僅支援 1 個倉庫，多倉功能需升級至 PLUS」

Q1 = 5個以上：
  → 顯示 5 組輸入（預設 HW1/MW1/BW1/BW2/BW3）：
  → 若版本非 PRO，顯示警告：
    「5 倉以上功能需升級至 PRO」
```

### Q3 分流

```
要設定庫位：
  → 每個倉庫下方展開庫位新增區塊
  → 提示：「庫位格式建議：{區}-{架號}-{層}，例：A-01-1」
  → 可新增多筆，也可之後到 NX01 庫位主檔補設

之後再設：
  → 系統自動建立每個倉庫的「TEMP-IN」和「TEMP-OUT」暫放區
  → 在 Dashboard 待辦清單顯示「建議設定庫位」
```

### 後續動作

```
→ 建立 nx01_warehouse（依填入的倉庫數）
→ [PLUS+] 建立 nx01_warehouse_type（H/M/W/S）
→ 若選擇設定庫位：建立 nx01_location
→ 若未設定：建立 TEMP-IN + TEMP-OUT 暫放庫位
```

## Step 4：建立第一批使用者

**頁面說明：** 「建立您的團隊帳號，讓大家可以開始使用系統。」

### 問題

| # | 問題 | 類型 | 說明 |
|---|------|------|------|
| Q1 | 您要現在建立使用者帳號嗎？ | 單選 | 是 / 稍後再建 |
| Q2 | [若是] 新增使用者 | 動態表格 | 帳號/姓名/角色/Email（可新增多筆）|
| Q3 | 各使用者可存取的倉庫 | 勾選 | [PLUS+] 顯示，LITE 跳過 |

### Q2 表格欄位

```
每一列：
  ┌────────────┬────────────┬────────────────────────────┬──────────────────┐
  │ 登入帳號   │ 姓名       │ 角色                        │ Email（選填）    │
  │ (必填)     │ (必填)     │ 採購/業務/倉管/財務/物流/HR │                  │
  └────────────┴────────────┴────────────────────────────┴──────────────────┘
  
角色選項依版本：
  LITE：採購人員 / 業務人員 / 倉管人員 / 財務人員
  PLUS：+ 物流人員
  PRO：+ 人資人員
```

### 密碼規則

```
初始密碼統一為：Nexora@1234
首次登入強制修改密碼
系統發送 Email 通知（若有填 Email）
```

### 後續動作

```
→ 建立 nx01_user（每一列一筆）
→ 建立 nx01_user_role（指派角色）
→ [PLUS+] 建立 nx01_user_warehouse（倉庫授權）
```

## Step 5：零件基礎設定

**頁面說明：** 「料號主檔是系統的核心，讓我們看看您怎麼建立。」

### 問題

| # | 問題 | 類型 | 說明 |
|---|------|------|------|
| Q1 | 您現在要建立料號資料嗎？ | 單選 | 三個選項 |

### Q1 選項分流

```
選項 A：「我有舊系統的料號資料，要批量匯入」
  → 顯示 CSV 範本下載按鈕（含欄位說明）
  → 顯示上傳區域（拖曳或點擊上傳）
  → 匯入完成後顯示：成功 N 筆 / 失敗 N 筆
  → 失敗的顯示原因，可下載錯誤報告

選項 B：「我要手動逐筆新增」
  → 跳轉至 NX01 零件主檔頁面
  → Wizard 記錄此步驟為「進行中」
  → 返回 Dashboard 可繼續下一步

選項 C：「先跳過，之後再建立」
  → 在 Dashboard 待辦清單顯示「尚未建立料號」（⚠️ 警告等級）
  → 未建立料號無法執行採購/銷售
```

### CSV 匯入範本欄位

```
必填：料號（code）、品名（name）、零件種類代碼（part_group_code）
選填：品牌代碼、副廠料號、規格、A~D 售價、退貨政策、保固月數
```

## Step 6：廠商與客戶

**頁面說明：** 「建立您的往來廠商與客戶資料。」

### 問題

| # | 問題 | 類型 | 說明 |
|---|------|------|------|
| Q1 | 您現在要建立廠商資料嗎？ | 單選 | 批量匯入 / 手動新增 / 跳過 |
| Q2 | 您現在要建立客戶資料嗎？ | 單選 | 批量匯入 / 手動新增 / 跳過 |

### 分流邏輯（廠商與客戶相同）

```
批量匯入：
  → 下載 CSV 範本（廠商/客戶各一份）
  → 上傳後系統自動判斷 partner_type（C=客戶 / S=廠商）
  → 匯入結果顯示成功/失敗明細

手動新增：
  → 跳轉至 NX01 交易對象主檔
  → Wizard 記錄為「進行中」

跳過：
  → Dashboard 待辦清單顯示提醒
```

## Step 7：期初庫存

**頁面說明：** 「如果您目前有庫存，我們需要建立期初庫存記錄。」

### 問題

| # | 問題 | 類型 | 說明 |
|---|------|------|------|
| Q1 | 您目前是否有庫存需要建立期初記錄？ | 單選 | 三個選項 |

### Q1 選項分流

```
選項 A：「有庫存，我有 Excel/CSV 資料可以匯入」
  → 下載期初庫存 CSV 範本
  → 範本欄位：料號（code）、庫位代碼、數量、平均成本
  → 上傳後系統：
      ① 建立 nx03_init（每倉一張單，status=D）
      ② 建立 nx03_init_item（逐筆明細）
      ③ 顯示：「期初庫存建立完成，請確認後執行過帳」
      ④ 提供「立即過帳」按鈕（過帳後 status=P，庫存生效）

選項 B：「有庫存，但我要手動逐筆輸入」
  → 跳轉至 NX03 開帳存，系統自動新增一張草稿開帳單
  → Wizard 記錄為「進行中」
  → 在 Dashboard 顯示：「您有 1 張期初庫存單待過帳」

選項 C：「沒有庫存，從零開始」
  → 跳過，直接進入 Step 8
  → Dashboard 不顯示提醒（確認沒有庫存）
```

### 過帳確認提示

```
過帳前系統顯示摘要：
  ┌────────────────────────────────────────┐
  │ 期初庫存摘要                           │
  │ 倉庫：MW1 主倉                         │
  │ 料號數：30 筆                          │
  │ 庫存總值：NT$ 3,500,000               │
  │                                        │
  │ ⚠️ 過帳後不可修改，請確認資料正確      │
  │ [取消] [確認過帳]                      │
  └────────────────────────────────────────┘
```

## Step 8：完成

**頁面說明：** 「🎉 恭喜！您的 NEXORA GRID 基礎設定已完成。」

### 完成摘要顯示

```
┌──────────────────────────────────────────────────────┐
│  ✅ 公司資訊      已確認                              │
│  ✅ 倉庫          MW1 主倉（1 個）                    │
│  ✅ 使用者        5 個帳號已建立                      │
│  ✅ 料號          30 筆已匯入                         │
│  ✅ 廠商客戶      5 家廠商 / 8 家客戶已建立           │
│  ✅ 期初庫存      MW1 已過帳，庫存總值 NT$3,500,000   │
└──────────────────────────────────────────────────────┘
```

### 待辦清單（若有跳過的項目）

```
建議完成（可點擊直接跳轉）：
  ⚠️ 尚未設定庫位    → [前往設定] → /dashboard/nx01/location
  ⚠️ 尚未設定安全量  → [前往設定] → /dashboard/nx02/stock-setting
  ℹ️ 建議設定定價    → [前往設定] → /dashboard/nx01/part/pricing
  ℹ️ 建議設定客戶等級→ [前往設定] → /dashboard/nx04/customer-grade
```

### 完成按鈕

```
[開始使用 NEXORA GRID]
→ 更新 nx99_tenant.onboarding_completed = TRUE
→ 跳轉至 Dashboard 首頁
```

## Dashboard 待辦提醒機制

Wizard 完成後，Dashboard 首頁右下角顯示「設定完成度」：

```
┌────────────────────────────────────┐
│ 系統設定完成度  ████████░░  80%   │
│                                    │
│ ⚠️ 尚未設定庫位（影響撿貨流程）    │
│ ⚠️ 尚未設定料號安全量              │
│ ℹ️ 建議完成售價設定                │
│                                    │
│ [查看全部待辦設定]                 │
└────────────────────────────────────┘
```

**提醒等級：**
```
⛔ 紅色（必要）：未完成會導致核心流程無法執行
⚠️ 黃色（建議）：影響部分功能
ℹ️ 藍色（選做）：最佳化設定，影響分析精準度
```

**消除條件（各項目）：**

| 待辦項目 | 消除條件 |
|---------|---------|
| 建立庫位 | nx01_location 有至少 1 筆非暫放庫位 |
| 建立料號 | nx01_part 有至少 1 筆 |
| 建立廠商 | nx01_partner（type=S）有至少 1 筆 |
| 建立客戶 | nx01_partner（type=C）有至少 1 筆 |
| 設定安全量 | nx02_part_stock_setting 有至少 1 筆 |
| 期初庫存過帳 | nx03_init 所有記錄 status=P |
| 設定售價 | nx01_part 至少 50% 的料號有 price_a > 0 |
