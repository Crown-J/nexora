# SYS-W03｜版本退版作業流程

> 版本需求：所有版本
> 最後更新：2026-04-12

---

## 流程概述

租戶從較高版本降至較低版本的完整作業流程。退版方向共三種：

| 退版路徑 | 說明 |
|---------|------|
| PRO → LITE | 一次降至基礎版（跳降）|
| PLUS → LITE | 關閉多倉/調撥/採購審核/部門架構 |

> ⚠️ **退版不刪資料**：已建立的歷史資料全部保留，但功能被鎖定無法繼續操作
> ⚠️ **退版前必須完成資料處理**：未結清的高階功能單據需先關閉或處理

---

## 退版前必須處理的項目

### 通用項目（所有退版路徑）

| 項目 | 說明 |
|------|------|
| D01 確認無未完成的採購單 | 所有 status=D/S 的 PO 必須先關閉或過帳 |
| D02 確認無未完成的銷貨單 | 所有 status=N/B/F 的 SO 必須先完成或取消 |
| D03 確認無未結清的 AR/AP | 未結清帳款需先收/付款或標記 |

### PLUS → LITE 額外項目

| 項目 | 說明 |
|------|------|
| D04 處理分倉庫存 | BW1 的庫存需調撥回 MW1，或在退版後凍結 |
| D05 完成所有待辦調撥單 | 所有 status≠C 的 ST 調撥單需先完成或作廢 |
| D06 處理缺貨簿 | 所有 OPEN 的 shortage 記錄需轉詢價或標記 IGNORED |
| D07 確認部門架構影響 | 退版後部門架構功能關閉，但資料保留不刪除 |

### PRO → PLUS 額外項目

| 項目 | 說明 |
|------|------|
| D08 處理 BW2~BW4 庫存 | 多餘分倉庫存需調撥回 MW1 或 BW1 |
| D09 完成本月薪資作業 | 若在月中退版，建議先完成當月薪資計算 |
| D10 匯出人資分析報表 | PRO 報表在退版後無法存取，建議先匯出 |
| D11 完成所有待辦轉職申請 | 所有 status=P 的轉職申請需先審核完畢 |
| D12 通知員工遊戲化暫停 | 告知員工 Exp/勳章功能將暫停 |

### PRO → LITE 額外項目

| 項目 | 說明 |
|------|------|
| 合併上述 D04~D12 | 跳降需同時處理 PLUS 和 PRO 的所有項目 |

## 路徑一：PLUS → LITE

### 功能關閉清單

```
倉庫層面：
  🔒 BW1 分倉功能關閉（資料保留，無法新增）
  🔒 warehouse_type 設定關閉
  🔒 user_warehouse 多倉授權關閉（僅保留 MW1）

採購層面：
  🔒 採購單（PO）建立功能關閉
  🔒 進口費用攤分關閉
  🔒 缺貨簿功能關閉
  🔒 自動調撥補貨關閉

庫存層面：
  🔒 調撥單（ST）建立功能關閉
  🔒 in_transit_qty 停止計算

組織層面：
  🔒 部門/組別設定功能關閉（資料保留）
```

### 退版執行步驟

**Step 1：退版前清單確認（D01~D07）**

**Step 2：更新訂閱記錄**
```
nx99_subscription：
  → 現有 ACTIVE 訂閱 status 改為 CANCELED（end_at = 退版日）
  → 建立新的 ACTIVE 訂閱（plan_id = LITE，start_at = 退版日）
```

**Step 3：鎖定 PLUS 功能**
```
JWT planCode 更新為 'LITE'
PlusPlanGuard 自動鎖定以下路由（回傳 HTTP 403）：
  /nx02/po（採購單）
  /nx03/transfer（調撥單）
  /nx03/shortage（缺貨簿）
  /nx03/auto-replenish（自動補貨）
  /nx05/rr-import（進口費用）
  /nx06/international（國際物流）
```

**Step 4：資料凍結說明**
```
以下資料保留但功能鎖定：
  ✅ BW1 的庫存資料完整保留（可在庫存台帳查看歷史）
  ✅ 歷史 PO 採購單完整保留（可查看，不可修改/新增）
  ✅ 歷史 ST 調撥單完整保留
  ✅ 部門架構資料保留（角色仍可存在，但部門管理頁關閉）
  ❌ 無法在 BW1 新增庫存/調撥
  ❌ 無法建立新的 PO 採購單
```

## 路徑二：PRO → PLUS

### 功能關閉清單

```
人資層面（NX07）：
  🔒 排班/打卡功能關閉
  🔒 請假/加班申請關閉
  🔒 薪資計算功能關閉
  🔒 績效考核關閉

倉庫層面：
  🔒 HW1 總倉功能關閉（資料保留）
  🔒 BW2~BW4 分倉功能關閉（資料保留）

分析層面（NX08）：
  🔒 NX08 所有分析報表關閉
  🔒 日報表/月報表關閉

知識管理（NX09）：
  🔒 KM 知識庫關閉
  🔒 文件庫關閉
  🔒 會議管理關閉

  🔒 所有遊戲化功能關閉
  🔒 Exp 不再計算，勳章凍結
```

### 退版執行步驟

**Step 1：退版前清單確認（D01~D03 + D08~D12）**

**Step 2：更新訂閱記錄**
```
nx99_subscription：
  → 現有 ACTIVE 訂閱 status 改為 CANCELED（end_at = 退版日）
  → 建立新的 ACTIVE 訂閱（plan_id = PLUS，start_at = 退版日）
```

**Step 3：鎖定 PRO 功能**
```
JWT planCode 更新為 'PLUS'
```

**Step 4：資料凍結說明**
```
以下資料保留但功能鎖定：
  ✅ 員工主檔（nx07_employee）資料保留
  ✅ 薪資歷史記錄完整保留
  ✅ 出勤打卡歷史保留
  ✅ KM 知識庫文章保留（無法新增/修改）
  ✅ Exp/勳章歷史記錄保留（凍結在退版當下的狀態）
  ✅ 日報表/月報表歷史保留
  ❌ 無法建立新的排班/請假/加班
  ❌ 無法計算新月份薪資
  ❌ 無法存取 NX08 分析報表
  ❌ Exp 不再累計，勳章等級凍結
```

## 路徑三：PRO → LITE（跳降）

跳降等同於依序執行：
1. PRO → PLUS 的所有步驟
2. PLUS → LITE 的所有步驟

**退版前清單：** 合併 D01~D12 所有項目

**Step 1：完成所有退版前準備項目**

**Step 2：更新訂閱記錄**
```
nx99_subscription：
  → 現有 ACTIVE 訂閱 status = CANCELED
  → 建立新訂閱（plan_id = LITE）
```

**Step 3：鎖定所有 PLUS/PRO 功能**
```
JWT planCode 更新為 'LITE'
PlusPlanGuard + ProPlanGuard 同時生效
```

## 退版後驗收

**執行者：** 客戶租戶管理員

| 驗收項目 | 說明 |
|---------|------|
| V01 確認版本顯示正確 | 系統設定頁確認目前版本為目標版本 |
| V02 確認功能已鎖定 | 嘗試存取已鎖定的功能，確認回傳 403 |
| V03 確認歷史資料保留 | 舊版本的歷史單據可在列表查看 |
| V04 確認基礎功能正常 | 採購需求→詢價→進貨→出貨主流程可正常執行 |
| V05 確認費用差額退款 | 若有預付費用，確認退款金額計算正確 |

## 重要說明

### 退版後可重新升級

```
退版後的資料不會刪除，重新升級後可繼續使用：
  → 歷史採購/銷售/庫存資料全部恢復可見
  → 人資資料（薪資/出勤/排班）在重升後繼續可見
  → Exp/勳章等級從退版時的狀態繼續累計
  → KM 知識庫文章恢復可存取與新增
```

### 不可逆操作提醒

```
以下操作在退版後不可恢復：
  ⚠️ 退版後建立的 LITE 資料（如 MW1 新採購單）
     在重升後仍然存在，但不影響升級功能使用
  ⚠️ 退版期間員工的出勤記錄無法補登
     （因打卡功能鎖定）
  ⚠️ 退版期間的 Exp 不補算
```
