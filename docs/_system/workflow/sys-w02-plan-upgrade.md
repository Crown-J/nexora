# SYS-W02｜版本升級作業流程

> 版本需求：所有版本
> 最後更新：2026-04-12

---

## 流程概述

租戶從較低版本升級至較高版本的完整作業流程。升級方向共三種：

| 升級路徑 | 說明 |
|---------|------|
| LITE → PLUS | 新增多倉/調撥/採購審核/部門架構 |
| LITE → PRO | 一次升至最高版本（跳升）|
| PLUS → PRO | 新增人資/遊戲化/經營分析 |

> ✅ 升級後：舊有資料完整保留，歷史單據不受影響
> ✅ 升級後：新功能立即解鎖，無需重新輸入資料

---

## 升級前確認事項

**執行者：** 客戶租戶管理員（確認）、Innova IT（執行）

| 確認項目 | 說明 |
|---------|------|
| U01 確認目標版本與級距 | 確認要升至哪個版本（LITE/PLUS/PRO）與人數級距（S/M/L/XL）|
| U02 確認繳費方式 | 月繳/季繳/年繳，確認差額計算 |
| U03 確認升級生效日 | 建議月初，避免跨月計費複雜化 |
| U04 備份確認 | 系統自動快照，確認備份完成 |

**費用差額計算：**
```
升級差額 = 新方案月費 - 舊方案月費
差額依剩餘訂閱天數比例計算
例：LITE-S(2,500) → PLUS-S(8,000)，差額 5,500/月
    若剩餘 15 天：差額 = 5,500 × 15/30 = 2,750
```

## 路徑一：LITE → PLUS

### 新增功能清單

```
倉庫層面：
  ✅ 新增 BW1 分倉（branch warehouse）
  ✅ 啟用 warehouse_type（H/M/W/S 分類）
  ✅ 啟用使用者據點授權（user_warehouse）

採購層面：
  ✅ 採購單（PO）啟用（需採購組長審核）
  ✅ 國外採購/進口費用攤分（RR_IMPORT）
  ✅ 缺貨簿（SHORTAGE）啟用
  ✅ 自動調撥補貨設定

庫存層面：
  ✅ 調撥單（ST）啟用
  ✅ 庫存在途量（in_transit_qty）追蹤

組織層面：
  ✅ 部門架構啟用（最多 2 層）
  ✅ 採購/銷售/倉管/財務 4 個預設部門
```

### 升級執行步驟

**Step 1：更新訂閱記錄**
```
nx99_subscription：
  → 將現有 ACTIVE 訂閱狀態改為 CANCELED（end_at = 升級日）
  → 建立新的 ACTIVE 訂閱（plan_id = PLUS，start_at = 升級日）
```

**Step 2：執行 seed_type=PLUS 補寫**
```
seed.ts upgrade(tenantId, 'LITE', 'PLUS') 執行：
  1. nx01_warehouse_type（4筆：H/M/W/S）
  2. nx01_warehouse（BW1 分倉 1 筆）
  3. nx01_department（採購/銷售/倉管/財務 4 個部門）
```

**Step 3：解鎖 PLUS 功能**
```
JWT planCode 更新為 'PLUS'
PlusPlanGuard 自動解鎖以下路由：
  /nx02/po（採購單）
  /nx03/transfer（調撥單）
  /nx03/shortage（缺貨簿）
  /nx03/auto-replenish（自動補貨）
  /nx05/rr-import（進口費用）
  /nx06/international（國際物流）
```

**Step 4：客戶自行設定（無強制要求）**
```
建議完成：
  □ 設定 BW1 分倉的庫位
  □ 設定各員工的倉庫授權
  □ 設定部門/組別架構
  □ 設定 BW1 的安全量
  □ [選做] 調撥部分庫存至 BW1
```

## 路徑二：PLUS → PRO

### 新增功能清單

```
人資層面（NX07）：
  ✅ 員工主檔（nx07_employee）
  ✅ 排班管理 / 出勤打卡（IP + LINE）
  ✅ 請假/加班申請
  ✅ 薪資計算
  ✅ 績效考核（台式 OKR）
  ✅ 教育訓練管理

倉庫層面：
  ✅ 新增 HW1 總倉（type=H，flow_mode=C）
  ✅ 新增 BW2~BW4 分倉（共 5 倉）

分析層面（NX08）：
  ✅ HPA 歷史路徑分析
  ✅ BCG 矩陣 / SWOT / PESTEL
  ✅ 日報表 / 月報表
  ✅ 銷售/採購/庫存/財務/人資分析報表

知識管理（NX09）：
  ✅ KM 知識庫（Q/A + RAG）
  ✅ 文件庫（SOP/章則）
  ✅ 會議管理

  ✅ 勳章等級系統（20階）
  ✅ KPI 任務 / Exp 系統
  ✅ 轉職申請流程
```

### 升級執行步驟

**Step 1：更新訂閱記錄**（同 LITE→PLUS）

**Step 2：執行 seed_type=PRO 補寫**
```
seed.ts upgrade(tenantId, 'PLUS', 'PRO') 執行：
  1. nx01_warehouse（HW1 + BW2 + BW3 + BW4 共 4 筆）
  2. nx01_department（物流部 + 人資部 共 2 筆）
  3. nx07_leave_type（特休/病假/事假/婚假/喪假/公假 6 筆）
```

**Step 3：解鎖 PRO 功能**
```
JWT planCode 更新為 'PRO'
```

**Step 4：客戶自行設定（建議完成）**
```
人資設定：
  □ 建立員工主檔（nx07_employee）
  □ 設定班別（早班/晚班）
  □ 設定打卡 IP 白名單
  □ 設定薪資結構（底薪/加班倍率）
  □ 設定假別餘額（特休依年資）

倉庫設定：
  □ 設定 HW1/BW2~BW4 的庫位
  □ 設定各倉庫的自動補貨規則

KPI 設定：
  □ 設定 KPI 指標範本（銷售/採購/倉管等）
  □ 設定各員工 KPI 目標值

遊戲化設定：
  □ 設定任務範本（每日簽到/KPI 任務等）
  □ 設定門市團隊任務
```

---

## 路徑三：LITE → PRO（跳升）

跳升等同於依序執行：
1. LITE → PLUS 的所有步驟
2. PLUS → PRO 的所有步驟

**seed.ts 執行：**
```
seed.ts upgrade(tenantId, 'LITE', 'PRO') 執行：
  → seed_type=PLUS 的所有資料
  → seed_type=PRO 的所有資料
```

## 升級後驗收

**執行者：** 客戶租戶管理員

| 驗收項目 | 說明 |
|---------|------|
| V01 確認版本顯示正確 | 系統設定頁確認目前版本為目標版本 |
| V02 確認新功能可存取 | 逐一確認新解鎖的畫面可正常開啟 |
| V03 確認舊資料完整 | 歷史採購/銷售/庫存單據全部保留 |
| V04 確認使用者權限 | 各角色對新功能的預設權限正確 |
| V05 確認 Seed 資料 | 新增的倉庫/部門/假別等資料正確 |
