# P-W07｜廠商管理作業

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

廠商管理作業涵蓋新廠商開發審核、廠商定期評鑑、付款條件談判記錄三個面向。目標是建立穩定的供應鏈，確保採購品質、交期與價格的競爭力。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 新廠商申請 | P01V | 採購專員找到新廠商，申請建立廠商主檔 |
| 定期評鑑 | P01V | 採購組長每季執行廠商評鑑 |
| 廠商條件異動 | P01V^ | 廠商主動提出付款條件/價格調整 |
| 廠商異常 | P-W03 | 退供應商後觸發廠商評鑑 |

---

## 廠商分級定義

| 等級 | 說明 | 對應條件 |
|------|------|---------|
| A 級 | 核心廠商 | 準時交貨率 > 95%、瑕疵率 < 1%、價格競爭力強 |
| B 級 | 一般廠商 | 準時交貨率 85~95%、瑕疵率 1~3% |
| C 級 | 觀察廠商 | 準時交貨率 < 85% 或瑕疵率 > 3% |
| D 級 | 停用廠商 | 重大異常、長期表現不佳、無法配合 |

---

## 子流程一：新廠商開發與審核

### 觸發：採購專員找到新廠商

**執行者：** 採購專員（建立）、採購組長（審核）

| 行為 | 執行者 | 說明 |
|------|--------|------|
| P01V 填寫新廠商資料 | 採購專員 | 填入廠商基本資料/聯絡人/付款條件/產品線 |
| P02V 提交樣品評估 | 採購專員 | 索取樣品，送倉管專員確認品質 |
| P03V 確認樣品品質 | 倉管專員 | 確認料號/規格/品質是否符合需求 |
| P04V* 審核新廠商 | 採購組長 | 確認廠商資格/付款條件/價格競爭力 |
| P05V 建立廠商主檔 | 採購專員 | 系統建立廠商主檔，初始等級 B 級 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ V⊗01 廠商建立 | 審核通過，主檔建立 | 可開始詢價採購 |
| ❌ 退件 | 資格不符/品質不佳 | 記錄原因，暫不建立 |
| ⊗ V⊗00 | 不符合需求 | 流程結束，記錄評估結果 |

---

## 子流程二：廠商定期評鑑

### 觸發：每季執行（建議每季第二個月）

**執行者：** 採購組長（主導）、採購專員（提供數據）

### 評鑑指標

| 指標 | 權重 | 計算方式 |
|------|------|---------|
| 準時交貨率 | 40% | 準時 RR / 總 RR × 100% |
| 進貨瑕疵率 | 30% | 瑕疵明細 / 總驗收明細 × 100% |
| 價格競爭力 | 20% | 採購組長主觀評分（1~5分）|
| 服務配合度 | 10% | 採購組長主觀評分（1~5分）|

### 評鑑流程

| 行為 | 執行者 | 說明 |
|------|--------|------|
| P01E 系統產生廠商績效數據 | 系統自動 | 匯整過去一季的 RR/PR 相關數據 |
| P02E 採購組長填寫主觀評分 | 採購組長 | 填入價格競爭力/服務配合度評分 |
| P03E 計算廠商綜合評分 | 系統自動 | 依權重計算，產出廠商等級建議 |
| P04E* 採購組長確認廠商等級 | 採購組長 | 確認或調整系統建議等級 |
| P05E 更新廠商主檔等級 | 系統自動 | 廠商等級更新，記錄評鑑歷史 |

**評分對應等級：**

| 綜合評分 | 廠商等級 |
|---------|---------|
| 90 分以上 | A 級 |
| 75~89 分 | B 級 |
| 60~74 分 | C 級（列入觀察）|
| 60 分以下 | D 級（建議停用）|

**廠商等級異動後的系統動作：**

| 等級異動 | 系統動作 |
|---------|---------|
| 升至 A 級 | 通知採購組長，可優先詢價 |
| 降至 C 級 | 系統標記「觀察中」，詢價時顯示警示 |
| 降至 D 級 | 系統標記「停用」，無法建立新詢價單 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ V⊗02 評鑑完成 | 所有廠商評鑑完成 | 記錄評鑑結果，下季繼續 |

## 子流程三：付款條件談判記錄

### 觸發：廠商主動提出條件調整 或 採購組長主動談判

**執行者：** 採購組長

| 行為 | 說明 |
|------|------|
| P01N 記錄談判內容 | 填入談判日期/對象/提出條件 |
| P02N 評估條件合理性 | 與現有條件比較，計算對公司影響 |
| P03N* 決定是否接受 | 採購組長決定接受/拒絕/繼續談判 |
| P04N 更新廠商主檔 | 接受後更新付款條件/Incoterm |
| P04N 記錄談判歷史 | 無論結果均記錄，作為日後參考 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ V⊗03 條件更新 | 接受新條件，主檔更新 | 流程結束 |
| ❌ 拒絕 | 條件不合理 | 記錄原因，維持現有條件 |
| ↩ 繼續談判 | 雙方尚未達成共識 | 下次談判時重複 P02N~P03N |

## 結束點總覽

| 代碼 | 結束原因 | 後續處理 |
|------|---------|---------|
| V⊗00 | 新廠商不符需求 | 記錄評估結果 |
| V⊗01 | 新廠商建立完成 | 可開始詢價採購 |
| V⊗02 | 季度評鑑完成 | 記錄結果，下季繼續 |
| V⊗03 | 付款條件更新 | 下次採購適用新條件 |

## 廠商評鑑月報表

每季評鑑完成後，系統自動產生廠商評鑑報表：

| 報表內容 | 說明 |
|---------|------|
| 廠商等級分布 | A/B/C/D 各級廠商數量 |
| 本季異動廠商 | 升降級的廠商清單 |
| 準時交貨率排行 | 前五名/後五名廠商 |
| 瑕疵率排行 | 前五名/後五名廠商 |
| C/D 級廠商清單 | 需要關注/停用的廠商 |
