# R-W07｜人資分析報表

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

提供管理部經理與總經理用於人力資源健康管理、績效分析的報表。整合台式 OKR 績效考核數據與 HPA 歷史路徑分析，追蹤人效、離職率、訓練完成率等人資 KPI。

---

## 理論框架

| 分析工具 | 用途 |
|---------|------|
| 台式 OKR 績效考核 | 全員 KPI 達成率分析 |
| HPA 歷史路徑分析 | 人資指標多年趨勢 |
| 人才象限圖 | 選才/留才/識別老狗員工 |
| BCG 矩陣（人才版）| 識別明星員工/老狗員工 |

---

## 報表區塊

### 一、人力總覽

| 指標 | 說明 | 目標值 |
|------|------|-------|
| 員工總人數 | 在職人員結構（部門/職級）| - |
| 月離職率 | 離職人數/平均在職人數 | < 3%/月 |
| 人均產值 | 月營業額/員工人數 | HPA 趨勢成長 |
| 薪資佔比 | 薪資總額/營業額 | 控管範圍內 |
| 招募達成率 | 實際招募/需求人數 | > 80% |

### 二、績效考核分析（台式 OKR）

| 指標 | 說明 |
|------|------|
| 全員 KPI 達成率分布 | 各分數區間人數比例 |
| 各部門平均達成率 | 部門排行 |
| 低達成率（< 80%）員工清單 | 需要輔導的人員 |
| 高達成率（> 120%）員工清單 | 潛在升職/加薪對象 |
| KPI 達成率 HPA 趨勢 | 近 3 年全員達成率變化 |

### 三、人才象限圖（選才/留才工具）

```
              高績效達成率
                    │
   明星員工         │    核心幹部
（短年資 × 高績效）  │（長年資 × 高績效）
────────────────────┼────────────────────
   觀察員工         │    老狗員工
（短年資 × 低績效）  │（長年資 × 低績效）
                    │
              低績效達成率
```

| 象限 | 對應策略 |
|------|---------|
| 明星員工 | 快速培養，提早賦予責任 |
| 核心幹部 | 留才，提供發展機會 |
| 觀察員工 | 給予輔導，3 個月改善期 |
| 老狗員工 | 評估是否調整職務或資遣 |

### 四、教育訓練分析（引用 H-W06）

| 指標 | 說明 | 目標 |
|------|------|------|
| 全員年訓練時數達成率 | 達成 100 小時/人的比例 | > 90% |
| 各訓練類型時數分布 | OST/OJT/Off-JT/DT 佔比 | 均衡發展 |
| 訓練費用 vs 績效改善 | 訓練投資報酬率 | 正相關 |
| TTQS 申請補助記錄 | 政府補助金額追蹤 | 最大化 |

### 五、人資結構 HPA 分析

| 指標 | 說明 |
|------|------|
| 年資結構分析 | 各年資區間人數比例趨勢 |
| 年齡結構分析 | 各年齡層比例趨勢 |
| 學歷結構分析 | 各學歷層比例趨勢 |
| 功能/層級結構 | 各部門職級分布趨勢 |
