# F-W05｜收付款作業

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

記錄所有實際金流動作的作業。所有收款、付款、費用支出都必須在系統登記，確保現金庫存餘額正確。出納專員負責每日金流登記，財務組長每日核對餘額。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 廠商付款 | F-W04 | 安排廠商付款後登記 |
| 客戶收款 | F-W02 | 月結客戶付款/現金客戶即時收款 |
| 客戶退款 | S-W03 | 銷退後退款給現金客戶 |
| 廠商退款 | P-W03 | 退供應商後廠商退款 |
| 日常費用 | X01 | 租金/水電/文具/油費等支出 |

---

## 收付款類型

| 類型 | 說明 | 對應 AP/AR |
|------|------|-----------|
| 廠商付款 | 公司付款給廠商 | AP 核銷 |
| 客戶收款 | 客戶付款給公司 | AR 核銷 |
| 廠商退款 | 廠商退款給公司 | AP 反向沖銷 |
| 客戶退款 | 公司退款給客戶 | AR 反向沖銷 |
| 日常費用 | 公司支出（無對應 AP/AR）| 費用登記 |

---

## 流程階段

### 階段一：登記收付款

**執行者：** 出納專員

| 行為 | 說明 |
|------|------|
| R01 開啟收付款新增頁面 | NX04 財務模組 → 收付款 → 新增 |
| R02 選擇收付款類型 | 廠商付款/客戶收款/廠商退款/客戶退款/費用 |
| R03 選擇對象 | 廠商或客戶名稱 |
| R04 關聯來源單據 | 選擇對應的 AP 或 AR（費用支出不需要）|
| R05 填入金額 | 本次實際收付金額 |
| R06 選擇付款方式 | 現金/匯款/支票/本票 |

**依付款方式執行：**

| 付款方式 | 後續動作 |
|---------|---------|
| 現金 | 現金庫存餘額自動更新 |
| 匯款 | 填入匯款帳號/匯款日期 |
| 支票 | 引用 [F-W06 票據管理作業] 建立票據記錄 |
| 本票 | 引用 [F-W06 票據管理作業] 建立票據記錄 |

| 行為 | 說明 |
|------|------|
| R07 Alt+S 儲存 | 系統自動核銷對應 AP/AR |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 登記完成 | AP/AR 自動核銷或更新 | 進入階段二核對 |

---

### 階段二：每日現金核對

**執行者：** 出納專員
**時機：** 每日下班前（關帳前）

| 行為 | 說明 |
|------|------|
| R08 查看系統現金庫存餘額 | 系統計算當日所有現金收付後的餘額 |
| R09 實際點算現金 | 出納實際點算保險箱/收銀機現金 |
| R10 比對差異 | 確認系統餘額與實際現金相符 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗11 相符 | 系統與實際現金一致 | 通知財務組長，流程結束 |
| ⚠️ 有差異 | 金額不符 | 進入階段三差異處理 |

---

### 階段三：差異處理

**執行者：** 出納專員（查找）、財務組長（決定）

| 行為 | 說明 |
|------|------|
| R11 查找差異原因 | 逐筆比對當日收付款記錄 |
| R12 找到原因 | 補登漏記的收付款或更正錯誤金額 |
| R12* 財務組長決定 | 若找不到原因，財務組長決定列入「現金差異」科目 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗11 差異解決 | 找到原因並修正 | 流程結束 |
| ⚠️ 找不到原因 | 列入現金差異，通知財務組長 | 後續追查 |
