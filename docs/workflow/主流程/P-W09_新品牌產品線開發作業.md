# P-W09｜新品牌產品線開發作業

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

評估並引進新汽車品牌或新產品線的標準流程。觸發來源可能是業務的客戶需求回饋，或是採購組長主動觀察市場機會。引進後需要建立廠商主檔、料號主檔、設定建議售價，並安排業務教育訓練。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 銷售回饋 | S-W06 | 業務組長提交客戶需求回饋，需求量足夠 |
| 市場觀察 | N01 | 採購組長主動發現市場機會（新品牌/競品分析）|
| 管理層指示 | N02 | 總經理/產品部經理決定拓展新品牌 |

---

## 流程階段

### 階段一：市場評估

**執行者：** 採購組長（主導）、業務組長（提供市場資訊）

| 行為 | 說明 |
|------|------|
| N01 收集市場資訊 | 目標品牌的市場規模/競爭狀況/保養廠需求 |
| N02 確認目標產品線 | 確定要引進的品牌/車型/產品類別 |
| N03 評估廠商可行性 | 確認台灣有無代理商/直接廠商/進口可行性 |
| N04 估算引進成本 | 首批進貨量/最低訂單量/資金需求 |
| N05 評估競爭優勢 | 我方引進後的差異化優勢為何 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 評估可行 | 市場有需求，廠商可配合 | 進入階段二 |
| ⊗ N⊗00 | 市場太小/廠商無法配合/成本不划算 | 記錄評估結果，通知業務，流程結束 |

---

### 階段二：提案審核

**執行者：** 產品部經理（建立提案）、總經理（審核）

| 行為 | 說明 |
|------|------|
| N06 建立引進提案 | 填入市場評估結果/預估進貨計畫/資金需求/預期效益 |
| N07* 總經理審核 | 確認是否符合公司發展方向，核准引進 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 核准引進 | 總經理同意 | 進入階段三 |
| ❌ 退件 | 不符合公司策略/時機不對 | 記錄原因，可下次重新提案 |
| ⊗ N⊗01 | 確定不引進 | 流程結束，通知業務 |

---

### 階段三：廠商開發

**執行者：** 採購組長（主導）、採購專員（執行）

| 行為 | 說明 |
|------|------|
| N08 尋找廠商/代理商 | 聯繫目標品牌的台灣代理商或原廠 |
| N09 索取樣品 | 請廠商提供樣品評估品質 |
| N10 確認樣品品質 | 倉管專員確認樣品規格/品質 |
| N11 談判價格與條件 | 確認進貨價格/最低訂單量/付款條件/保固政策 |
| N12 建立廠商主檔 | 引用 [P-W07 廠商管理作業] 建立新廠商 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 廠商確認 | 廠商條件可接受 | 進入階段四 |
| ⚠️ 條件不理想 | 採購組長決定是否繼續談判或換廠商 | 重複 N08~N11 |
| ⊗ N⊗02 | 找不到合適廠商 | 流程結束，通知總經理 |

---

### 階段四：料號建立與定價

**執行者：** 採購專員（料號建立）、採購組長（定價）

| 行為 | 說明 |
|------|------|
| N13 建立料號主檔 | 逐一建立新產品線的料號/規格/適用車型 |
| N14 設定建議售價 | 引用 [P-W05 產品定價作業] 設定 A~D 價 |
| N15 設定安全量/最高量 | 引用 [P-W06 安全量最高量設定] 設定各倉庫存水位 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 料號建立完成 | 所有料號/定價/安全量設定完成 | 進入階段五 |

---

### 階段五：首批採購

**執行者：** 採購專員

| 行為 | 說明 |
|------|------|
| N16 建立首批採購單 | 引用 [P-W01 國內採購] 或 [P-W02 國外採購] |
| N17 入帳上架 | 首批貨物驗收入帳 |

---

### 階段六：業務教育訓練

**執行者：** 採購組長（教學）、業務專員（學習）

> 對應 EMBA 課程：OST/OJT 在職訓練概念

| 行為 | 說明 |
|------|------|
| N18 準備產品知識資料 | 整理新品牌的技術規格/適用車型/競品比較 |
| N19 辦理內部教育訓練 | 採購組長向業務說明新產品線知識 |
| N20 業務實際操作練習 | 業務練習查詢料號/報價/解答客戶問題 |
| N21 確認業務學習成效 | 採購組長確認業務能正確回答客戶問題 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ N⊗03 新產品線上線 | 料號/廠商/定價/教育訓練全部完成 | 業務開始主動推廣，流程結束 |

---

## 結束點總覽

| 代碼 | 結束原因 | 後續處理 |
|------|---------|---------|
| N⊗00 | 市場評估不可行 | 記錄原因，通知業務 |
| N⊗01 | 總經理不核准 | 記錄原因，可下次重新提案 |
| N⊗02 | 找不到合適廠商 | 通知總經理，考慮其他方案 |
| N⊗03 | 新產品線上線完成 | 業務開始銷售，採購持續追蹤銷售狀況 |
