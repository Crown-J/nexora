# R-W00｜個人日月報表作業

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

依 EMBA 課程精神，全員每日填寫日報表、每月填寫月報表，達到自我考核與主管監控的雙重目的。日報表記錄當日執行進度，月報表彙整 KPI 達成率與下月目標。主管查看下屬報表（不需逐一查看所有員工），形成由下往上的彙整機制。

---

## 理論依據

```
EMBA 課程：
  日報表 = 執行進度追蹤（EIP 雲端平台概念）
  月報表 = KPI 達成率 + 差異分析（台式 OKR）

主管查看原則：
  業務專員日報表 → 業務組長查看
  業務組長月報表 → 銷售部經理查看
  銷售部經理月報表摘要 → 總經理查看
```

## 報表結構

### 日報表內容

| 區塊 | 內容 | 說明 |
|------|------|------|
| 今日完成事項 | 對應五大工作重點 | 逐條填寫實際完成的工作 |
| KPI 當日累計進度 | 五大 KPI 累計數字 | 系統自動帶入部分，人工補充 |
| 異常事項回報 | 遇到的問題/風險 | 需主管協助的事項 |
| 明日計畫 | 明日預計執行事項 | 對應五大工作重點 |

### 月報表內容

| 區塊 | 內容 | 說明 |
|------|------|------|
| 五大 KPI 達成率 | KR/O 百分比 | 員工自評，引用 [H-W05 績效考核作業] |
| 本月重要事項說明 | 達標/未達標原因 | 差異分析（HPA 邏輯）|
| 行政指標自評 | 出勤/日報表繳交率 | 系統自動統計 |
| 學習成長記錄 | 本月完成訓練/學習 | 引用 [H-W06 教育訓練作業] |
| 下月目標設定 | 下月 KPI 目標與計畫 | 員工自行填寫 |

## 流程階段

### 階段一：每日填寫日報表

**執行者：** 全員員工
**時機：** 每個工作日下班前

| 行為 | 說明 |
|------|------|
| D01 開啟日報表 | NX05 → 個人報表 → 今日日報表 |
| D02 填寫今日完成事項 | 逐條填寫，對應五大工作重點 |
| D03 確認 KPI 累計進度 | 系統自動帶入可量化數字，人工補充說明 |
| D04 填寫異常事項 | 若有問題需協助，填入說明 |
| D05 填寫明日計畫 | 預計明日執行事項 |
| D06 Alt+S 提交 | 系統記錄提交時間，通知直屬主管 |

**系統自動提醒：**
```
下班前 30 分鐘若未提交日報表
→ 系統發送提醒通知
→ 影響行政指標（日報表繳交率）
```

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 提交完成 | 日報表送出 | 直屬主管可查看 |
| ⚠️ 未提交 | 超過下班時間未填 | 記錄為未繳，影響行政指標 |

---

### 階段二：主管查看下屬日報表

**執行者：** 直屬主管
**時機：** 每日（隔日上班前或當日隨時）

| 行為 | 說明 |
|------|------|
| D07 查看下屬日報表清單 | 系統顯示所有直屬下屬的昨日日報表 |
| D08 確認異常事項 | 優先處理下屬標記的異常/需協助事項 |
| D09 選擇性給予回饋 | 若有重要事項，在系統留言 |

---

### 階段三：每月填寫月報表

**執行者：** 全員員工
**時機：** 每月最後一個工作日

| 行為 | 說明 |
|------|------|
| M01 開啟月報表 | NX05 → 個人報表 → 本月月報表 |
| M02 確認五大 KPI 達成率 | 系統自動彙整當月累計數字，確認計算正確 |
| M03 填寫達成/未達成原因 | 差異分析：說明達標或未達標的原因 |
| M04 確認行政指標 | 系統自動計算出勤率/日報表繳交率 |
| M05 填寫學習成長記錄 | 本月完成的 OST/OJT/外訓時數 |
| M06 填寫下月目標 | 依公司方向設定下月各 KPI 目標 |
| M07 Alt+S 提交 | 送出月報表，通知直屬主管審閱 |

---

### 階段四：主管確認月報表

**執行者：** 直屬主管
**時機：** 每月初（看上月月報表）

| 行為 | 說明 |
|------|------|
| M08 查看下屬月報表 | 確認 KPI 達成率是否合理 |
| M09 填入主管評分 | 行政指標/學習成長指標的主管評分（20%部分）|
| M10 給予月度回饋 | 填寫對員工表現的文字回饋 |
| M11 月報表轉入績效考核 | 引用 [H-W05 績效考核作業] |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ R⊗00 月報表完成 | 員工+主管均完成 | 資料送入績效考核模組 |

---

## 報表彙整機制（由下往上）

```
基層員工（每日日報 + 每月月報）
  ↓ 主管查看
組長/店長（查看組員日報，自己也填）
  ↓ 部門經理查看
部門經理（查看組長月報，自己也填）
  ↓ 總經理查看
總經理（查看各部門經理月報摘要）
```
