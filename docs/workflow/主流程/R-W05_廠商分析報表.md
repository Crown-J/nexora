# R-W05｜廠商分析報表

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

提供採購組長用於廠商關係管理與談判策略的分析報表。整合 Porter 五力中的供應商議價力分析，搭配廠商評鑑數據與 HPA 趨勢，協助採購組長制定廠商管理策略。

---

## 理論框架

| 分析工具 | 用途 |
|---------|------|
| Porter 五力（供應商議價力）| 廠商依賴度/集中度分析 |
| 廠商四象限（BCG 概念）| 廠商策略分類 |
| HPA 歷史路徑分析 | 廠商績效 3 年趨勢 |

---

## 廠商四象限分類

```
              高採購金額佔比
                    │
   核心夥伴         │    主力廠商
（少量 × 高金額）   │（多量 × 高金額）
────────────────────┼────────────────────
   備用廠商         │    觀察廠商
（少量 × 低金額）   │（多量 × 低金額）
                    │
              低採購金額佔比
```

---

## 報表區塊

### 一、廠商總覽

| 指標 | 說明 |
|------|------|
| 廠商等級分布（A/B/C/D）| 數量與採購金額佔比 |
| 前 10 大廠商採購金額 | 集中度風險評估 |
| 廠商依賴度 | 單一廠商佔總採購 > 30% 需警示 |
| 本季等級異動廠商 | 升降級清單 |

### 二、廠商績效 HPA 分析

| 指標 | 說明 |
|------|------|
| 準時交貨率趨勢 | 各廠商近 3 年準時率折線圖 |
| 進貨瑕疵率趨勢 | 各廠商近 3 年瑕疵率折線圖 |
| 採購成本趨勢 | 各廠商料號進貨成本 3 年比對 |
| 付款條件分析 | 各廠商付款條件結構 |

### 三、供應商議價力分析（Porter 五力）

| 指標 | 說明 | 風險等級 |
|------|------|---------|
| 廠商集中度 | TOP3 廠商佔總採購比例 | 高 > 50% |
| 獨家供應料號數 | 只有一家廠商可供應的料號 | 需備案 |
| 替代廠商可行性 | 各主力廠商的替代廠商評估 | 季度更新 |
| 廠商評分趨勢 | A 級廠商維持率 | 目標 > 60% |

### 四、廠商談判建議

```
依廠商四象限提供談判策略建議：

核心夥伴（少量高金額）：
  → 建立長期合約，確保優先供貨

主力廠商（多量高金額）：
  → 量大議價，要求延長付款天數
  → 建立 MOQ 優惠機制

觀察廠商（多量低金額）：
  → 評估是否轉為核心夥伴，或降低採購量

備用廠商（少量低金額）：
  → 維持關係，作為緊急備用來源
```
