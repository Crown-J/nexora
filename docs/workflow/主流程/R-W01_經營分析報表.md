# R-W01｜經營分析報表

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

提供總經理與各部門經理用於戰略規劃的整合性經營分析報表。整合 PESTEL 外部分析、SWOT/TOWS 戰略規劃、Ansoff 矩陣市場策略、Porter 五力競爭分析，搭配 HPA 歷史路徑數據，協助決策者掌握公司整體經營方向。

---

## 理論框架

| 分析工具 | 用途 | 數據來源 |
|---------|------|---------|
| PESTEL | 外部環境六力評估 | 外部輸入（人工填入）|
| SWOT/TOWS | 內外部交叉戰略規劃 | 內部 KPI + 外部評估 |
| Ansoff 矩陣 | 市場/產品發展策略 | 銷售數據 + 新品數據 |
| Porter 五力 | 競爭環境分析 | 外部輸入 + 廠商資料 |
| HPA 歷史路徑分析 | 3~5 年趨勢比對 | 系統歷史數據自動彙整 |

---

## 報表區塊

### 一、公司總覽儀表板

| 指標 | 說明 | 週期 |
|------|------|------|
| 月營業額 vs 去年同期 | HPA 趨勢折線圖 | 月 |
| 月毛利率 | 當月毛利率 + 3年趨勢 | 月 |
| 庫存週轉次數 | 月銷售成本/平均庫存（目標12次）| 月 |
| 應收帳款逾期率 | 逾期 AR/總 AR | 月 |
| 員工人均產值 | 月營業額/員工人數 | 月 |

### 二、PESTEL 外部環境評估

| 維度 | 說明 |
|------|------|
| 政治（P）| 政策/法規變化對汽車零件業的影響 |
| 經濟（E）| 市場景氣/匯率/油價趨勢 |
| 社會（S）| VAG/雙B 車輛保有量/保養廠數量趨勢 |
| 科技（T）| 電動車趨勢對傳統零件需求的影響 |
| 環境（En）| ESG 合規/碳稅影響 |
| 法律（L）| 進口規範/認證要求 |

> 每季由總經理/部門經理手動更新評估

### 三、SWOT/TOWS 戰略矩陣

```
          優勢（S）           劣勢（W）
機會（O） SO 拓展攻擊策略     WO 游擊策略
威脅（T） ST 迂迴取勝策略     WT 固守/退出策略
```

**系統提供：**
- 各象限 KPI 數據支撐（量化佐證）
- 主管手動填入戰略方向文字

### 四、Ansoff 矩陣業績分析

| 象限 | 說明 | 數據 |
|------|------|------|
| 現有市場 × 現有產品 | 既有客戶/既有料號業績 | 系統自動計算 |
| 現有市場 × 新產品 | 新引進料號/品牌的業績貢獻 | 引用 [P-W09] 新品追蹤 |
| 新市場 × 現有產品 | 新開發客戶業績 | 引用 [S-W04] 客戶開發 |
| 新市場 × 新產品 | 新客戶 × 新料號 | 系統交叉分析 |

### 五、Porter 五力評估

| 五力 | 系統數據支撐 | 人工評分（1~5）|
|------|------------|--------------|
| 現有競爭者威脅 | 市場佔有率趨勢 | 主管評分 |
| 新進入者威脅 | 新競爭者資訊 | 主管評分 |
| 供應商議價力 | 廠商評鑑分數/AP 付款條件 | 自動帶入 |
| 客戶議價力 | 客戶等級分布/折讓率 | 自動帶入 |
| 替代品威脅 | 電動車影響指標 | 主管評分 |
