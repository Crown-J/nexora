# F-W07｜折讓作業

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

因進貨或銷貨異常造成的金額調整作業。由會計專員建立折讓單，財務部經理/負責人審核後執行帳務調整。分為進貨折讓（廠商給我們）與銷貨折讓（我們給客戶）兩種類型。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 採購異常 | P-W03 | 退供應商決定不退貨，改以折讓處理 |
| 進貨瑕疵接受 | I-W01 | 驗收有瑕疵但決定接受，要求廠商折讓補償 |
| 銷貨異常 | S-W01/S-W03 | 少給客戶貨或客戶收到瑕疵品 |
| 財務主動 | F01AL | 財務部發現帳務需要調整 |

---

## 折讓類型與處置方式

| 類型 | 說明 | 來源 |
|------|------|------|
| 進貨折讓（進）| 廠商給我們折讓，減少應付金額 | 採購相關 |
| 銷貨折讓（銷）| 我們給客戶折讓，減少應收金額 | 銷售相關 |

| 處置方式 | 說明 |
|---------|------|
| 沖銷 AP/AR | 直接減少應付或應收金額 |
| 下次折抵 | 記錄折讓金額，下次交易自動扣除 |
| 現金退回 | 直接退現金，引用 [F-W05 收付款作業] |

---

## 流程階段

### 階段一：建立折讓單

**執行者：** 會計專員

| 行為 | 說明 |
|------|------|
| AL01 新增折讓單 | NX04 財務模組 → 折讓 → 新增 |
| AL02 選擇折讓類型 | 進貨折讓 或 銷貨折讓 |
| AL03 選擇來源單據 | 關聯對應的採購單（PO）或銷貨單（SO）|
| AL04 填入折讓金額 | 本次折讓金額 |
| AL05 選擇處置方式 | 沖銷 AP/AR / 下次折抵 / 現金退回 |
| AL06 上傳證明文件 | 廠商確認函/瑕疵照片（建議上傳，作為憑證）|
| AL07 Alt+S 儲存送審 | 折讓單狀態→待審核，通知審核人 |

**產出：** 折讓單（狀態：待審核）

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 建立完成 | 資料填寫完整 | 進入審核 |

---

### 階段二：審核

**執行者：** 財務部經理

| 行為 | 說明 |
|------|------|
| AL08* 審核折讓單 | 確認折讓原因/金額/處置方式合理 |
| AL09 確認證明文件 | 確認有對應憑證 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 核准 | 折讓合理 | 進入帳務執行 |
| ❌ 退件 | 資料有誤或金額不合理 | 回到會計重新建立 |

**特殊情況：金額超過門檻需總經理審核**

```
折讓金額超過設定門檻（建議 NT$ 10,000）
→ 財務部經理核准後再送總經理最終確認
```

---

### 階段三：帳務執行

**執行者：** 出納專員

| 處置方式 | 執行動作 |
|---------|---------|
| 沖銷 AP/AR | 系統自動減少對應 AP 或 AR 金額 |
| 下次折抵 | 系統記錄折讓金額至廠商/客戶帳戶，下次交易自動提示 |
| 現金退回 | 引用 [F-W05 收付款作業] 執行退款 |

| 行為 | 說明 |
|------|------|
| AL10 確認帳務執行 | 出納確認系統動作正確 |
| AL11 通知相關人員 | 通知採購/業務折讓已完成 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗15 折讓完成 | 帳務執行完成 | 流程結束 |
