# NX09-W02｜文件庫作業

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

公司章則彙編、SOP、工作說明書等制度文件的線上存放與閱覽平台。員工可隨時查閱規章，但正式簽名確認仍以紙本為準（入職時/人事命令發布時列印簽名）。

---

## 文件分類架構

```
文件庫
  ├── 公司制度
  │     ├── 組織章程
  │     ├── 工作規則
  │     ├── 薪資管理辦法
  │     ├── 獎金管理辦法
  │     └── 其他規章辦法
  ├── 標準作業流程（SOP）
  │     ├── 採購部 SOP
  │     ├── 銷售部 SOP
  │     ├── 倉管部 SOP
  │     ├── 財務部 SOP
  │     └── 人資/管理部 SOP
  ├── 工作說明書
  │     └── 各職務工作說明書
  └── 公告欄
        ├── 系統公告（NEXORA 更新）
        └── 人事公告（人事異動/公司通知）
```

---

## 流程階段

### 階段一：文件上傳維護

**執行者：** 行政專員（上傳）、各部門主管（提供內容）

| 行為 | 說明 |
|------|------|
| D01 準備文件 | PDF 格式為主 |
| D02 選擇分類 | 依架構選擇正確資料夾 |
| D03 填入文件資訊 | 文件名稱/版本號/生效日期/負責部門 |
| D04 上傳文件 | 系統儲存，帶入版本記錄 |
| D05 設定閱覽權限 | 全員可見/特定部門/主管以上 |
| D06 發布公告 | 新文件發布時系統通知相關人員 |

---

### 階段二：員工查閱

**執行者：** 全員員工

| 行為 | 說明 |
|------|------|
| D07 開啟文件庫 | NX09 → 文件庫 |
| D08 瀏覽分類或搜尋 | 關鍵字搜尋文件名稱 |
| D09 線上閱覽 | PDF 線上預覽，不需下載 |

---

### 階段三：入職/人事命令紙本簽名

**執行者：** 行政專員（列印）、員工（簽名）

```
紙本簽名時機：
  1. 新員工入職時：列印工作規則/勞動契約
  2. 規章更新時：列印更新條文，現有員工簽名確認
  3. 人事命令發布：列印任命書，當事人簽名

系統角色：
  提供最新版本供列印
  記錄哪個版本、何時列印、列印人
  紙本簽名後，行政專員在系統標記「已完成紙本簽名」
```

---

### 階段四：公告發布

**執行者：** 行政專員/管理部經理

| 行為 | 說明 |
|------|------|
| D10 新增公告 | 選擇公告類型（系統/人事/部門）|
| D11 填入公告內容 | 標題/內容/有效期限 |
| D12 選擇發送對象 | 全員/特定部門/特定人員 |
| D13 發布 | 系統通知收件對象，首頁顯示未讀公告數 |
