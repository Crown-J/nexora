# L01｜送貨作業

> 版本需求：LITE
> 所屬模組：NX07 物流模組
> 最後更新：2026-04-10

---

## 子流程概述

外務配送貨物的作業。物流組長將多種來源任務合併成一張送貨單（DN）指派給外務，外務透過手機版依序執行各停靠點任務。

---

## 觸發情境

| 情境代碼 | 觸發來源 | 說明 |
|---------|---------|------|
| S-L01 | S-W01/S-W02 配送出貨 | 送貨給客戶 |
| I-L01 | I02 調撥作業 | 送貨到目標倉 |
| S-L01R | S-W03 銷退取件 | 順路取回退貨 |
| P-L01 | L02 調貨取貨 | 去同行取調貨 |

---

## 停靠點任務類型

| 類型 | 代碼 | 說明 | 簽收方式 |
|------|------|------|---------|
| 配送 | D | 送貨給客戶 | 客戶電子簽名 |
| 調撥 | T | 送貨到目標倉 | 倉管掃包裹 QR Code |
| 取件 | C | 取回客戶退貨 | 外務確認取回 |
| 取貨 | K | 去同行取調貨 | 外務確認取回 |

---

## 流程階段

### 階段一：建立送貨單（物流組長，桌面版）

| 行為 | 說明 |
|------|------|
| L01 新增送貨單 | Alt+A 建立 DN |
| L02 加入待指派任務 | Alt+A 開啟任務清單，勾選要合併的任務 |
| L03 調整停靠點順序 | 地圖上拖曳或手動輸入序號 |
| L04 規劃路線 | 點擊「規劃路線」，Google Maps 計算最佳路線 |
| L05 指派外務 | 選擇外務人員 |
| L05* Alt+S 送出 | DN 狀態→待指派 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 指派完成 | 外務確認任務 | 進入配送 |

---

### 階段二：執行配送（外務，手機版）

| 行為 | 說明 |
|------|------|
| L06 查看今日任務清單 | 開啟 /driver，確認停靠點 |
| L07 點擊出發 | DN 狀態→配送中 |
| L08 依序執行停靠點 | 點擊「開啟導航」→ Google Maps 導航 |
| L09 到達後執行任務 | 依任務類型執行簽收 |

**簽收方式：**

| 任務類型 | 簽收行為 |
|---------|---------|
| 配送（D）| 客戶在手機螢幕電子簽名 |
| 調撥（T）| 倉管掃描包裹 QR Code |
| 取件（C）| 外務點擊「確認取回」|
| 取貨（K）| 外務點擊「確認取回」|

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 停靠點完成 | 簽收完成 | 進入下一停靠點 |
| ⚠️ 異常 | 客戶不在/拒收/地址錯誤 | 標記異常，通知物流組長 |

---

### 階段三：返回確認

**執行者：** 外務

| 行為 | 說明 |
|------|------|
| L10 所有任務完成後回報 | 點擊「今日任務完成」|
| L11 交付取回的退貨/調貨 | 口頭回報物流組長，交給倉管驗收 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ L⊗01 送貨完成 | 所有停靠點完成 | 子流程結束 |
