# F04｜票據管理作業

> 版本需求：LITE
> 所屬模組：NX04 財務模組
> 最後更新：2026-04-11

---

## 子流程概述

記錄所有支票與本票的開立、持有、兌現與退票狀況。分為應收票據（客戶開給我們）與應付票據（我們開給廠商）兩種方向。系統每日自動偵測即將到期的票據並通知出納專員。

---

## 觸發情境

| 情境代碼 | 觸發來源 | 說明 |
|---------|---------|------|
| P-F04 | F01 應付帳款作業 | 廠商付款選擇支票/本票時 |
| S-F04 | F05 應收帳款作業 | 客戶收款選擇支票/本票時 |

---

## 票據類型

| 類型 | 說明 |
|------|------|
| 支票（C）| 由銀行帳戶支付，有票號/銀行/帳號/到期日 |
| 本票（P）| 由開票人直接承諾支付，有票號/到期日 |

---

## 票據方向

| 方向 | 說明 | 來源 |
|------|------|------|
| 應收票據（R）| 客戶開票給我們，我們持有 | F05 收款時建立 |
| 應付票據（P）| 我們開票給廠商，廠商持有 | F01 付款時建立 |

---

## 狀態流

**應收票據：**
```
持有中 → 已兌現
       → 退票
       → 作廢
```

**應付票據：**
```
待兌現 → 已兌現
       → 退票
       → 作廢
```

---

## 流程階段

### 階段一：建立票據記錄

**觸發：** F01 或 F05 選擇支票/本票付款方式
**執行者：** 出納專員

| 行為 | 說明 |
|------|------|
| F01B 填入票據資訊 | 票號/銀行名稱/銀行帳號/票面金額/開票日/到期日 |
| F02B 選擇票據方向 | 應收（R）或應付（P）|
| F03B 關聯對應 AP 或 AR | 確保帳款與票據關聯正確 |

**產出：** 票據記錄（應收：狀態→持有中 / 應付：狀態→待兌現）

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 建立完成 | 資料填寫完整 | 進入追蹤 |

---

### 階段二：到期追蹤

**執行者：** 系統自動偵測 + 出納專員

| 行為 | 說明 |
|------|------|
| SYS-F04~ 每日偵測到期票據 | 7 天內到期顯示 🟠，已逾期顯示 🔴 |
| SYS-F04~ 通知出納專員 | 系統自動發送通知 |

**應收票據到期：**

| 行為 | 說明 |
|------|------|
| F04B 確認票據已存入銀行 | 確認銀行是否已兌現 |
| F05B 確認兌現 | 點擊「確認兌現」，對應 AR 自動核銷 |

**應付票據到期：**

| 行為 | 說明 |
|------|------|
| F06B 確認銀行帳戶餘額足夠 | 避免退票 |
| F07B 確認兌現 | 點擊「確認兌現」，對應 AP 自動核銷 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗04 兌現完成 | 銀行確認兌現 | 子流程結束 |
| ⚠️ 退票 | 銀行退票 | 進入退票處理 |

---

### 階段三：退票處理

**執行者：** 出納專員

**應收票據退票（客戶票據退票）：**

| 行為 | 說明 |
|------|------|
| F08B 標記退票 | 填入退票原因（存款不足/帳號有誤/其他）|
| SYS-F04~ 對應 AR 改回未收款 | 系統自動還原 AR 狀態 |
| F09B 通知銷售組長催收 | 業務跟進催收款項 |
| F10B 登記退票手續費 | 引用 [F03 收付款作業] 費用支出 |

**應付票據退票（我方票據退票）：**

| 行為 | 說明 |
|------|------|
| F08B 標記退票 | 填入退票原因 |
| SYS-F04~ 對應 AP 改回未付款 | 系統自動還原 AP 狀態 |
| F09B 立即通知會計/負責人 | 緊急處理，避免信用損失 |
| F10B 安排補開票據或改付款方式 | 重新引用 [F01 應付帳款作業] |
| F11B 登記退票手續費 | 引用 [F03 收付款作業] 費用支出 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗05 退票處理完成 | 重新安排付款 | 子流程結束 |

---

### 階段四：票據作廢

**觸發：** 開錯票或雙方合意取消
**執行者：** 出納專員（申請）、負責人（審核）

| 行為 | 說明 |
|------|------|
| F12B 申請作廢 | 填入作廢原因（必填）|
| F12B* 負責人審核 | 確認作廢原因合理 |
| SYS-F04~ 票據狀態→作廢 | 系統更新狀態 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗06 作廢完成 | 負責人核准 | 子流程結束 |
| ❌ 退件 | 作廢原因不合理 | 回到申請重新說明 |

---
