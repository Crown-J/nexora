# P-W06｜安全量最高量設定作業

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

安全量與最高量的設定是採購組長與倉管組長共同決策的作業。採購組長依產品急迫性與市場知識判斷，倉管組長提供庫存流動率數據，採購組長做最終決定。設定結果直接影響補貨觸發時機與各倉庫存上限。

---

## 核心決策邏輯

```
安全量：庫存低於此量時系統自動觸發補貨（SYS-I01~）
最高量：庫存不應超過此量，避免積壓資金與占用空間
```

**決策考量因素：**

| 因素 | 負責人 | 說明 |
|------|--------|------|
| 庫存流動率 | 倉管組長提供 | 歷史出貨頻率與數量 |
| 產品急迫性 | 採購組長判斷 | 客戶急用程度（馬上要 vs 可以等）|
| 廠商交貨週期 | 採購組長判斷 | 從下單到到貨需要多少天 |
| 倉庫坪效 | 倉管組長提供 | 體積大的零件需特別考量 |
| 產品特性 | 採購組長判斷 | 消耗品（高頻）vs 修復件（低頻）|

**汽車零件特殊考量：**

```
高安全量（急迫性高）：
  機油/濾芯/來令片/雨刷 → 保養必換，客戶急用
  → 安全量設高，確保不缺貨

低安全量（可等待）：
  大燈/板件/車身件 → 安裝順序在後，客戶可等
  → 安全量設低，減少庫存積壓

衛星倉優先（體積大）：
  大燈/板件 → 體積大影響坪效
  → 優先放衛星倉而非營業處
```

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 新品入帳後 | SYS-P02~ | 新料號首次入帳，系統提示未設定安全量 |
| 定期檢視 | P01 | 採購組長每季主動檢視 |
| 銷售異常 | SYS-P04~ | 料號銷售量大幅變動（> 30%），系統提示重新檢視 |
| 倉管申請 | P01W | 倉管組長發現安全量不合理，主動申請調整 |

## 流程階段

### 階段一：收集決策資料

**執行者：** 採購組長（主導）、倉管組長（提供數據）

| 行為 | 執行者 | 說明 |
|------|--------|------|
| P01S 查詢庫存流動率 | 倉管組長 | 查看過去 3 個月出貨頻率與平均出貨量 |
| P02S 查詢廠商交貨週期 | 採購組長 | 確認從下單到到貨平均天數 |
| P03S 確認產品急迫性 | 採購組長 | 依產品類型判斷客戶急用程度 |
| P04S 確認倉庫坪效 | 倉管組長 | 確認體積大的料號存放規劃 |

**產出：** 決策參考資料

---

### 階段二：計算安全量與最高量

**執行者：** 採購組長

**安全量計算公式：**

```
安全量 = 平均日出貨量 × （廠商交貨天數 + 緩衝天數）

例：
  平均日出貨量：3 件
  廠商交貨天數：7 天
  緩衝天數：3 天
  安全量 = 3 × (7 + 3) = 30 件
```

**最高量計算公式：**

```
最高量 = 安全量 × 倍數係數

急迫性高（消耗品）：× 3~4 倍
急迫性低（修復件）：× 1.5~2 倍

例（急迫性高）：
  安全量 30 件 × 3 = 最高量 90 件
```

**特殊狀況調整：**

| 狀況 | 調整方向 | 說明 |
|------|---------|------|
| 旺季（年底前）| 安全量 × 1.5 | 備貨應對需求高峰 |
| 廠商交貨不穩定 | 緩衝天數 +5 天 | 降低缺貨風險 |
| 體積大/坪效差 | 最高量降低 | 優先放衛星倉，營業處少量 |
| 新品（無歷史數據）| 保守設定低安全量 | 先觀察 1~3 個月再調整 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 計算完成 | 安全量/最高量確認合理 | 進入階段三 |
| ⚠️ 數據不足 | 新品無歷史資料 | 採購組長保守設定，3 個月後重新檢視 |

---

### 階段三：設定各倉安全量與最高量

**執行者：** 採購組長
**操作位置：** NX02 庫存模組 → 庫存分析 Tab

> 注意：每個倉庫可設定不同的安全量與最高量

| 倉庫類型 | 安全量設定原則 | 最高量設定原則 |
|---------|-------------|-------------|
| 總倉（H）| 各倉安全量加總 × 1.2 | 各倉最高量加總 |
| 集中站（C）| 所轄營業處安全量加總 | 所轄營業處最高量加總 |
| 營業處（S）| 依該區域銷售量設定 | 依坪效與銷售量設定 |

| 行為 | 說明 |
|------|------|
| P05S 選擇料號 | 搜尋料號，切換到庫存分析 Tab |
| P06S 依倉別設定安全量 | 逐一設定各倉安全量 |
| P07S 依倉別設定最高量 | 逐一設定各倉最高量 |
| P07S Alt+S 儲存 | 系統記錄更新時間與更新人 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ P⊗07 設定完成 | 各倉安全量/最高量儲存成功 | 系統啟動自動補貨偵測，流程結束 |

---

### 階段四：季度定期檢視

**執行者：** 採購組長
**時機：** 每季第一個月初

| 行為 | 說明 |
|------|------|
| P08S 查看安全量異常清單 | 系統列出：實際庫存長期低於安全量/長期超過最高量的料號 |
| P09S 查看銷售量變動清單 | 系統列出銷售量變動 > 30% 的料號 |
| P10S 逐一檢視調整 | 依清單重複階段一~三 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ P⊗08 檢視完成 | 所有異常料號已處理 | 記錄檢視結果，下季繼續 |

## 系統自動通知

| 觸發條件 | 通知對象 | 說明 |
|---------|---------|------|
| 新料號未設定安全量 | 採購組長 | 提醒設定 |
| 庫存低於安全量 | 採購組長 | 觸發 SYS-I01~ 補貨建議 |
| 庫存超過最高量 | 採購組長/倉管組長 | 提醒庫存過高，暫停補貨 |
| 銷售量變動 > 30% | 採購組長 | 提醒重新檢視安全量設定 |
