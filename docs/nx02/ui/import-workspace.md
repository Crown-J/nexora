```
Alt+← / Alt+→ 切換：
  國內採購作業（/dashboard/purchase/domestic）
  國外採購作業（/dashboard/purchase/import）  ← 本文件
```

## 二、流程圖差異

### 國內採購節點
```
需求─詢價─採購單─[審核]─驗收─退貨─入帳─完成
```

### 國外採購節點（多三個）
```
需求─詢價─採購單─[審核]─備貨付款─報關─驗收─退貨─費用攤分─入帳─完成
                                                  ╎
                                                退貨（虛線）
```

**新增節點說明：**

| 節點 | 說明 | Badge 數字 |
|------|------|-----------|
| 備貨付款 | 追蹤廠商備貨/填入船號ETA/依Incoterm確認付款 | 待確認付款或待廠商出貨的單數 |
| 報關 | 提供文件給報關行/確認清關/填入提單號碼 | 待清關的單數 |
| 費用攤分 | 填入進口費用/系統攤分/組長確認後入帳 | 待填入費用的單數 |

### 快捷鍵對應

| 快捷鍵 | 節點（PLUS）| 節點（PRO）|
|--------|------------|-----------|
| `Alt+1` | 需求 | 需求 |
| `Alt+2` | 詢價 | 詢價 |
| `Alt+3` | 採購單 | 採購單 |
| `Alt+4` | 審核 | 審核 |
| `Alt+5` | 備貨付款 | 備貨付款 |
| `Alt+6` | 報關 | 報關 |
| `Alt+7` | 驗收 | 驗收 |
| `Alt+8` | 退貨 | 退貨 |
| `Alt+9` | 費用攤分 | 費用攤分 |

> 入帳和完成在費用攤分確認後自動觸發，不設獨立節點快捷鍵

## 三、國內/國外採購單的差異欄位

### 採購單新增欄位（purchase_type = I）

| 欄位 | 說明 | 必填條件 |
|------|------|---------|
| 幣別 | USD / EUR / JPY 等 | 必填 |
| 匯率 | 建單當日匯率（可調整）| 必填 |
| 貿易條件（Incoterm）| FOB / CIF / EXW / DDP | 必填 |
| 付款條件 | TT / LC / DP / DA | 必填 |
| 船號 | 廠商提供 | 出貨後必填 |
| 貨櫃號 | 廠商提供 | 出貨後必填 |
| 預計到港日（ETA）| 廠商提供 | 出貨後必填 |
| 提單號（B/L）| 報關行提供 | 清關後必填 |

### Incoterm 對費用攤分的影響

| Incoterm | 我方需填入費用 |
|---------|-------------|
| FOB | 出口報關費 |
| CIF | 出口報關費 + 海運費 + 保險費 |
| EXW | 僅採購成本 |
| DDP | 全部費用（含進口關稅）|

## 四、差異作業節點詳細規格

---

### 4-A 採購單（國外版，差異處）

> 與國內採購單相同，但步驟二增加國外特有欄位

**步驟二：確認採購明細（國外額外欄位）**

```
一般欄位（同國內）：
  料號 / 數量 / 外幣單價 / 小計

國外額外欄位：
  幣別          [USD ▼]
  匯率          32.50（建單當日，可調整）
  折合台幣      自動計算
  貿易條件      [FOB ▼]（FOB/CIF/EXW/DDP）
  付款條件      [TT ▼]（TT/LC/DP/DA）
  預計出貨日    [日期選擇器]
  備註（英文）  （廠商溝通用）
```

**付款條件提示：**
```
選 TT：提示「需在出貨前確認收款或匯款」
選 LC：提示「需先請財務開立信用狀」
選 DP：提示「到港後付款才可領貨」
選 DA：提示「承兌後票據到期才付款」
```

---

### 4-B 備貨付款（新節點）

> 採購單廠商確認後，追蹤備貨進度並依付款條件處理

**進入節點後：**
```
左側：採購單列表
  單據號 / 廠商 / 幣別 / 金額 / 付款條件 / 狀態
  （待備貨 / 已出貨待確認 / 付款處理中）
```

**點選採購單 → 進入步驟區：**

```
┌──────────┬────────────────┬──────────────┬────────────────────┐
│ ① 確認   │ ② 填入出貨     │ ③ 付款條件   │ 狀態追蹤           │
│    廠商  │    資訊        │    確認      │                    │
│（已帶入）│                │              │                    │
└──────────┴────────────────┴──────────────┴────────────────────┘
```

**步驟二：填入出貨資訊（廠商提供後填入）**
```
船號        [____________]
貨櫃號      [____________]
預計到港日  [日期選擇器]（ETA）
出貨日期    [日期選擇器]
```

**步驟三：付款條件確認**

```
TT 電匯：
  → 若先付款：填入匯款日期，通知財務
  → 若後付款：確認收到廠商出貨通知後付款
  → 採購工作台只做「標記已通知財務」
  → 實際付款由 NX05 財務模組執行

LC 信用狀：
  → 顯示：「請財務開立信用狀」
  → [標記已通知財務開狀] 按鈕
  → 財務確認開狀後，此項目狀態自動更新

DP 付款交單：
  → 到港後才需處理
  → 此節點只需確認廠商已出貨

DA 承兌交單：
  → 到港後才需處理
  → 此節點只需確認廠商已出貨
```

**右側狀態追蹤：**
```
PO-I-202604-00003
廠商：德國汽車配件 GmbH
幣別：EUR  金額：€ 5,200
付款條件：TT
─────────────────
船號：EVER GOLDEN
貨櫃：EMCU1234567
ETA：2026-05-15
─────────────────
付款狀態：待通知財務
[標記已通知財務] 按鈕
```

**確認後：**
- 進入報關節點等待到港
- 財務模組產生 AP 預計付款記錄

---

### 4-C 報關（新節點）

> 貨物到港後，委託報關行清關

**進入節點後：**
```
左側：進口採購單列表（已到港或即將到港）
  單據號 / 廠商 / ETA / 狀態
  （待到港 / 已到港待報關 / 報關中 / 已清關）
```

**點選採購單 → 進入步驟區：**

```
┌──────────┬────────────────┬──────────────┬────────────────────┐
│ ① 確認   │ ② 填入報關     │ ③ 確認清關   │ 狀態追蹤           │
│    資訊  │    文件        │    填提單號  │                    │
│（已帶入）│                │              │                    │
└──────────┴────────────────┴──────────────┴────────────────────┘
```

**步驟二：填入報關文件**
```
報關行名稱    [____________]
聯絡人        [____________]
報關委託日    [日期選擇器]
附件上傳      [商業發票 PDF] [裝箱單 PDF]（報關行需要的文件）
```

**步驟三：確認清關，填入提單號**
```
清關完成日    [日期選擇器]
提單號（B/L） [____________]
關稅金額      [____________]（填入後帶入費用攤分）
報關費        [____________]（填入後帶入費用攤分）
其他費用      [____________]
備註          [____________]
```

**右側狀態追蹤：**
```
報關狀態：報關中
報關行：聯邦報關行
委託日：2026-05-15
─────────────────
⚠️ 若報關超過 3 天未完成
  系統自動提醒採購人員追蹤

[報關異常] 按鈕（若有問題）
  → 填入異常原因，通知採購組長
```

**清關完成後：**
- 進入驗收節點（安排提貨+驗收）
- 關稅/報關費自動帶入費用攤分節點

---

### 4-D 費用攤分（新節點，在驗收之後）

> 驗收正常後，填入所有進口費用並攤分到每個料號

**進入節點後：**
```
左側：待費用攤分的進貨單列表
  單據號 / 廠商 / 料號數 / 狀態
  （待填費用 / 攤分中 / 待組長確認 / 已確認）
```

**點選進貨單 → 進入步驟區：**

```
┌──────────┬────────────────┬──────────────┬────────────────────┐
│ ① 確認   │ ② 填入進口     │ ③ 確認攤分   │ 攤分結果預覽       │
│    資訊  │    費用        │    結果      │                    │
│（已帶入）│                │              │                    │
└──────────┴────────────────┴──────────────┴────────────────────┘
```

**步驟二：填入進口費用**

```
費用項目（依 Incoterm 自動判斷必填）：

海運費        NT$ [________]   必填（CIF/DDP）
進口關稅      NT$ [________]   必填（DDP）
報關費        NT$ [________]   必填（FOB/CIF/DDP，已從報關節點帶入）
保險費        NT$ [________]   選填（CIF/DDP）
倉儲費        NT$ [________]   選填
其他費用      NT$ [________]   選填
費用說明      [____________]

總費用：NT$ X,XXX（自動加總）
```

**步驟三：確認攤分結果**

```
攤分方式（系統預設）：
  ○ 依數量攤分（每個零件分到相同費用）
  ○ 依金額攤分（較貴的零件分到較多費用）
  ○ 依材積攤分（較大的零件分到較多費用）

攤分預覽：
  料號 A  採購成本 $8.50  攤分費用 $0.32  最終成本 $8.82
  料號 B  採購成本 $12.00 攤分費用 $0.48  最終成本 $12.48
  料號 C  採購成本 $5.00  攤分費用 $0.20  最終成本 $5.20
```

**右側攤分結果預覽（即時更新）：**
```
費用攤分預覽
─────────────────
總費用：NT$3,500
攤分方式：依金額

料號 A  → 最終成本 $8.82
料號 B  → 最終成本 $12.48
料號 C  → 最終成本 $5.20
─────────────────
[送組長審核]（Alt+S）
```

**組長確認後（採購組長操作）：**
```
採購組長看到費用攤分審核單
確認每個料號成本合理
[確認入帳] → 庫存增加（含攤分成本）
            AP 應付帳款更新
```
