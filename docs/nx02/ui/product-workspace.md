## 六、保固申請的三端視角整合

```
完整保固申請流程（三部門各自操作）：

【第一關】倉管組長（NX03 → 保固申請）
  初步判斷是否符合保固條件
  符合 → 通知業務進入第二關
  不符合 → 填寫原因，通知業務告知客戶

【第二關】業務（NX04 → 銷售工作台 → 保固節點）
  填寫保固申請單
  上傳客戶提供的文件（照片/行照/維修記錄）
  → 系統通知採購組長進入第三關

【第三關】採購組長（NX02 → 產品管理 → 保固申請）
  確認文件完整性
  審核是否符合廠商保固政策
  向廠商送出申請
  記錄廠商回覆結果
  → 系統通知業務轉告客戶

跨部門通知方式：
  各端完成操作後，系統推播通知給下一個負責人
  通知顯示在 TOP BAR 通知鈴鐺
  點擊通知可直接跳至對應的操作介面
```
