# NX10-W01｜遊戲化任務系統

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

透過遊戲化機制將員工每日工作任務轉化為可量化的經驗值（Exp），激勵員工積極執行 KPI。每日任務對應各職務的五大 KPI（與 H-W05 OKR 同一套目標），系統自動從各模組抓取數據計算達成率。

## Exp 來源

### 柱一：每日簽到

| 行為 | Exp | 觸發 |
|------|-----|------|
| 準時打卡 | +5 | H-W01 自動帶入 |
| 連續全勤 7 天 | +20 | 系統自動計算 |
| 連續全勤 30 天 | +100 | 系統自動計算，觸發全勤獎金 |

### 柱二：每日任務（五大 KPI）

**KPI 達成率 → 當日 Exp：**

| 達成率 | Exp | 備註 |
|-------|-----|------|
| ≥ 120% | +35 | 超越自我加成 |
| 100~119% | +20 | 完全達標 |
| 80~99% | +12 | 良好表現 |
| 60~79% | +5 | 基本貢獻 |
| < 60% | 0 | 無獎勵 |

> 五大 KPI 每個獨立計算，單日最高可得 35 × 5 = 175 Exp

**各職務 KPI 與數據來源：**

| 職務 | KPI | 數據來源 |
|------|-----|---------|
| 外務 | 里程/送單數/趟次/品項數/簽收率 | L01 自動帶入 |
| 業務專員 | 報價單數/成交金額/客戶聯繫/新客戶/日報表 | NX03 + R-W00 |
| 倉管專員 | 撿貨單數/準確率/入庫數/上架速度/日報表 | NX02 + R-W00 |
| 採購專員 | 詢價單數/準時入帳/瑕疵率/廠商追蹤/日報表 | NX01 + R-W00 |
| 出納 | 收付款筆數/AP到期處理/AR追蹤/日報表/現金核對 | NX04 + R-W00 |
| 主管職 | 部門 KPI 達成率/日報表/KM撰寫/下屬報表審核 | 各模組 + NX09 |

### 柱三：里程碑獎勵

| 里程碑 | Exp | 說明 |
|-------|-----|------|
| 帶新人通過試用期 | +500 | 每帶一人計一次 |
| 完成指定培訓課程 | +200 | H-W06 教育訓練記錄 |
| 連續 3 個月金牌以上 | +300 | 穩定高表現 |
| KM 撰寫（主管限定）| +10/篇 | NX09-W01 |
| 連續 30 天 KM 撰寫 | +200 | 主管限定加成 |

## 流程階段

### 階段一：系統每日自動計算

**執行者：** 系統自動
**時機：** 每日凌晨（當日資料鎖定後）

| 行為 | 說明 |
|------|------|
| G01 收集各模組當日數據 | 從 NX01/NX02/NX03/NX04/L01/R-W00 抓取 |
| G02 計算各員工 KPI 達成率 | 對比主管設定的目標值（H-W05 OKR）|
| G03 計算當日 Exp | 依達成率對應表計算 |
| G04 累加至員工 Exp 總計 | 更新 Exp 記錄 |
| G05 判斷是否升階 | Exp 達到門檻自動升階 |
| G06 通知升階員工 | 系統推播「恭喜晉升銀牌 III！」|

---

### 階段二：員工查看個人儀表板

**執行者：** 員工本人

| 行為 | 說明 |
|------|------|
| G07 開啟個人成長頁面 | NX10 → 我的成長 |
| G08 查看今日任務狀態 | 五大 KPI 當日進度（即時更新）|
| G09 查看 Exp 累積趨勢 | 近 30 天每日 Exp 折線圖 |
| G10 查看升階進度 | 距下一等級還需多少 Exp |
| G11 查看排行榜 | 同職務/門市/部門排行 |

---

### 階段三：每日簽到

**執行者：** 員工本人
**觸發：** 每日打卡後自動

```
準時打卡 → 系統自動觸發每日簽到任務
         → +5 Exp 立即入帳
         → 更新連續全勤天數計數器
```

## Exp 懲罰機制

### 輕微懲罰（系統自動）

| 觸發條件 | 扣除 Exp | 說明 |
|---------|---------|------|
| KPI 達成率 < 60% 連續 5 天 | -50 Exp | 系統自動 |
| 日報表連續未繳 3 天 | -30 Exp | 系統自動 |
| 遲到 | -5 Exp/次 | 系統自動（H-W01 連動）|
| 曠職 | -20 Exp/天 | 系統自動 |

### 重大懲罰（人工審核）

| 觸發條件 | 扣除 Exp | 審核流程 |
|---------|---------|---------|
| 客訴成立 | -100~-300 Exp | 主管填寫懲罰單 → 負責人核准 |
| 作業重大錯誤 | -100~-500 Exp | 主管填寫懲罰單 → 負責人核准 |
| 違反規章 | -200~-1000 Exp | 主管填寫懲罰單 → 負責人核准 |

**人工懲罰流程：**

| 行為 | 說明 |
|------|------|
| G12 主管建立懲罰申請 | 填入事由/建議扣除 Exp |
| G12* 負責人審核 | 確認扣除幅度合理 |
| G13 系統執行扣除 | Exp 減少，記錄原因（員工可查看）|
| G14 通知員工 | 系統通知扣除原因 |

### 降階保護機制

```
Exp 掉落不會立即降階

降階觸發條件：
  Exp 低於當前等級門檻
  且持續 14 天（保護期）
  系統才執行降階

保護期內提示：
  「您的 Exp 已低於 銀牌 IV 門檻
   剩餘 X 天保護期，請努力提升！」

目的：
  避免單次失誤造成打擊
  給予員工緩衝和恢復機會
```

## 進階激勵機制

### 一、限時衝刺任務（稀缺性動機）

```
每週限時衝刺任務：
  系統每週一早上自動發布本週衝刺目標
  例如：「本週業績達成率 ≥ 150% → 當週 Exp ×2」
  週日 23:59 截止，錯過就沒有

每月末衝刺：
  每月最後 3 天，全公司 KPI 達成率
  每超過目標 10% → 額外 +50 Exp
```

| 任務類型 | 週期 | 獎勵 | 說明 |
|---------|------|------|------|
| 週業績衝刺 | 每週 | 當週 KPI Exp ×2 | 業務/採購職務適用 |
| 週全勤衝刺 | 每週 | +50 Exp | 全員適用 |
| 月末衝刺 | 每月後 3 天 | +50 Exp/10% | 全員適用 |
| 季度排行獎 | 每季 | 前三名特別勳章 | 同職務排行前三 |

**季度排行獎特別勳章：**
```
同職務當季排行：
  第一名 → 🏆 季度冠軍勳章（永久顯示在個人頁面）
  第二名 → 🥈 季度亞軍勳章
  第三名 → 🥉 季度季軍勳章
```

### 二、驚喜寶箱（好奇心動機）

```
設計理念：
  讓員工對升級/里程碑產生期待感
  不只是固定 Exp，而是有「開寶箱」的驚喜
  避免遊戲化變成純粹例行公事

觸發時機：
  等級晉升時（例如銅牌 III → 銅牌 II）
  連續全勤 7/14/30 天
  帶新人通過試用期
  特定里程碑（累積 1000/5000/10000 Exp）
```

| 觸發條件 | 寶箱等級 | 獎勵範圍 |
|---------|---------|---------|
| 等級晉升 | 普通寶箱 | 隨機 30~100 Exp |
| 連續全勤 7 天 | 普通寶箱 | 隨機 30~100 Exp |
| 連續全勤 30 天 | 稀有寶箱 | 隨機 100~300 Exp |
| 等級大晉升（跨勳章）| 史詩寶箱 | 隨機 300~800 Exp |
| 帶新人通過試用期 | 稀有寶箱 | 隨機 100~500 Exp |

```
開寶箱 UI：
  員工點擊「開啟」→ 動畫效果 → 顯示獲得 Exp
  系統記錄每次寶箱獎勵歷程
  每日最多開 3 個（避免刷機制）
```

### 三、門市團隊任務（合作動機）

```
設計理念：
  避免純個人競爭導致「有人特別活躍，
  其他人退回參觀層級」
  讓門市整體一起努力，共同受益
  強化門市向心力與團隊精神
```

**每月門市團隊目標：**

| 目標 | 門檻 | 全員獎勵 |
|------|------|---------|
| 門市全勤率 | ≥ 95% | 全員 +100 Exp |
| 門市 KPI 平均達成率 | ≥ 90% | 全員 +150 Exp |
| 日報表繳交率 | 100% | 全員 +50 Exp |
| 零重大懲罰月 | 當月無 -200 Exp 以上懲罰 | 全員 +80 Exp |

**季度門市排行獎：**
```
每季統計各門市（Z01~Z04）平均 Exp
  第一名門市 → 全體員工獲得「最強門市」勳章
              + 全員額外 +500 Exp
  
門市 vs 門市 的良性競爭
讓倉管組長/店長有帶領團隊的動力
```

**帶新人的團隊效益：**
```
新人入職後第一個月：
  新人每日任務達成 → 帶新人的門市也獲得團隊 Exp
  強化「老員工願意帶新人」的誘因
```
