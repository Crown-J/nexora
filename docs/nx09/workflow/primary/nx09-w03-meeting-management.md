# NX09-W03｜會議管理作業

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

會議預約、出席確認、會議紀錄與追蹤的完整管理作業。支援定期會議（如每月產銷會議）與臨時會議，會議紀錄可轉為追蹤事項。

---

## 流程階段

### 階段一：預約會議

**執行者：** 會議發起人

| 行為 | 說明 |
|------|------|
| M01 新增會議 | NX09 → 會議管理 → 新增 |
| M02 填入會議資訊 | 主題/時間/地點/會議類型 |
| M03 選擇出席人員 | 從員工主檔選擇 |
| M04 填入會議議程 | 預計討論事項 |
| M05 發送邀請 | 系統通知出席人員，顯示在個人行事曆 |

**會議類型：**

| 類型 | 說明 | 建議週期 |
|------|------|---------|
| 產銷會議 | 庫存/業績/採購協調 | 每月第三週 |
| 部門週會 | 各部門內部例會 | 每週 |
| 主管月會 | 各部門主管彙報 | 每月月初 |
| 臨時會議 | 緊急議題 | 隨時 |
| 教育訓練 | OJT/DT 培訓 | 依排程 |

---

### 階段二：出席確認

**執行者：** 出席人員

| 行為 | 說明 |
|------|------|
| M06 確認出席 | 點擊「確認出席」或「請假」|
| M07 系統提醒 | 會議前 30 分鐘系統提醒 |

---

### 階段三：會議紀錄

**執行者：** 會議記錄人（發起人指定）

| 行為 | 說明 |
|------|------|
| M08 開啟會議紀錄 | 會議當日系統自動開啟紀錄頁面 |
| M09 記錄出席狀況 | 確認實際出席人員 |
| M10 填入討論內容 | 各議程討論結果 |
| M11 建立追蹤事項 | 決議事項 → 指派負責人 + 截止日期 |
| M12 發布會議紀錄 | 系統通知所有出席人員 |

---

### 階段四：事項追蹤

**執行者：** 追蹤事項負責人

| 行為 | 說明 |
|------|------|
| M13 查看待辦追蹤事項 | 個人待辦清單 |
| M14 更新完成狀態 | 完成後標記，通知會議發起人 |
| M15 逾期提醒 | 系統自動提醒逾期未完成事項 |
