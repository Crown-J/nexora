# NX09-W01｜知識管理作業（KM）

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

企業知識資產管理平台。主管每日撰寫 QA 知識條目，全員可搜尋查閱，解決 95% 的詢問問題，避免「人亡政息」。結構化資料設計，Phase 2 接入 RAG AI 自動解答。

---

## 模組功能架構

```
NX09 知識管理模組
  ├── KM 知識庫（QA 撰寫/搜尋）← 本 Workflow
  ├── 文件庫（章則/SOP 閱覽）
  └── 會議管理（紀錄/預約/活動）
```

---

## KM 知識庫資料結構

| 欄位 | 類型 | 必填 | 說明 |
|------|------|------|------|
| 部門 | 選單 | ✅ | 採購/銷售/倉管/財務/人資/全公司 |
| 分類標籤 | 多選 | ✅ | 系統操作/業務流程/規章制度/客戶處理/緊急狀況/其他 |
| 問題（Q）| 文字 | ✅ | 主要問題描述（RAG 向量化核心）|
| 答案（A）| 富文字 | ✅ | 詳細解答（支援圖片/步驟）|
| 適用情境 | 文字 | ✅ | 什麼時候會遇到這個問題（提升 AI 命中率）|
| 相關流程 | 連結 | ❌ | 對應的 SOP 或 Workflow 文件 |
| 建立人 | 系統帶入 | ✅ | 撰寫主管（知識責任歸屬）|
| 有效性 | 狀態 | ✅ | 有效 / 已過時（避免 AI 引用舊資訊）|
| 瀏覽次數 | 系統計算 | - | 熱門問題排行依據 |
| 解決率 | 員工回饋 | - | 「這篇解答了我的問題」按鈕統計 |

## 流程階段

### 階段一：主管每日撰寫 QA

**執行者：** 各部門主管（組長以上）
**時機：** 每個工作日（OST 早會後 10 分鐘內）
**對應 EMBA：** OST 在位訓練概念延伸

| 行為 | 說明 |
|------|------|
| K01 開啟 KM 撰寫介面 | NX09 → 知識庫 → 新增 QA |
| K02 選擇部門與分類標籤 | 確保搜尋分類正確 |
| K03 填入問題（Q）| 以員工實際會問的方式描述 |
| K04 填入答案（A）| 詳細解答，可附圖/步驟 |
| K05 填入適用情境 | 說明什麼情況下會遇到此問題 |
| K06 連結相關流程 | 選填：對應的 SOP 或 Workflow |
| K07 Alt+S 發布 | 系統記錄發布時間，全員立即可搜尋 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 發布完成 | QA 建立成功 | 全員可搜尋 |

---

### 階段二：員工搜尋查閱

**執行者：** 全員員工
**時機：** 遇到問題時，先查 KM，找不到才提問

| 行為 | 說明 |
|------|------|
| K08 開啟 KM 搜尋 | NX09 → 知識庫 → 搜尋 |
| K09 輸入關鍵字或選擇分類 | 全文檢索 + 分類篩選 |
| K10 查看搜尋結果 | 依相關度排序，熱門問題優先 |
| K11 閱讀答案 | 確認是否解決問題 |
| K12 回饋「已解決」| 按下「這篇解答了我的問題」，計入解決率 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 問題解決 | KM 有答案 | 流程結束 |
| ⚠️ 找不到答案 | KM 無相關 QA | 向主管提問，主管解答後補充 KM |

---

### 階段三：QA 維護與有效性管理

**執行者：** 各部門主管
**時機：** 系統/流程更新後，或每季檢視

| 行為 | 說明 |
|------|------|
| K13 查看過時 QA 清單 | 系統標示 6 個月未更新的 QA |
| K14 確認有效性 | 內容仍正確 → 確認有效；已過時 → 標記已過時或更新 |
| K15 更新答案 | 依最新流程/系統更新內容 |

## Phase 2：AI RAG 自動解答

```
技術架構（未來）：

KM 資料庫（PostgreSQL）
  ↓ 定期向量化
Vector DB（pgvector 或 Pinecone）
  ↓ 員工提問
RAG 檢索：問題 → 向量搜尋 → Top-K QA
  ↓
Claude API 生成答案
  ↓
回答附上來源 QA 連結

多租戶隔離：
  每筆 QA 帶 tenant_id
  向量搜尋時強制過濾 tenant_id
  A 公司 AI 絕不看到 B 公司資料
```

**Phase 2 觸發條件：**
- 員工搜尋 KM 無結果時，自動進入 AI 解答模式
- AI 答案旁顯示「由 AI 生成，非官方 QA」提示
- AI 答案被採用次數累積，可協助主管識別缺少的 QA
