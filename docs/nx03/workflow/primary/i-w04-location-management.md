# I-W04｜庫位管理作業

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

管理倉庫庫位的分配、異動與坪效優化作業。新品到貨前需指定庫位，定期檢視庫位使用狀況，將體積大的料號移至衛星倉，提升坪效。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 新品引進 | P-W09 | 新料號首次入庫，需分配庫位 |
| 新進貨量過大 | I-W01 | 進貨量超過現有庫位容量 |
| 定期檢視 | L01L | 倉管組長每月定期檢視庫位使用率 |
| 盤點後整理 | I-W03 | 盤點完成後順勢整理庫位 |
| 部門指示 | L02L | 倉管部長要求調整庫位配置 |

---

## 庫位分配原則

```
出貨頻率高的料號 → 放在靠近出貨區的庫位（減少撿貨距離）
體積大的料號    → 衛星倉或總倉，不放在營業處
重量重的料號    → 放在低層庫位（安全考量）
同類型料號      → 集中放置（撿貨效率）

特別規定：
  大燈/板件類 → 優先放衛星倉
  高週轉率零件（機油濾芯/來令片/雨刷）→ 放在出貨區附近
```

## 流程階段

### 階段一：新庫位分配

**觸發：** 新料號引進或進貨量超過現有庫位
**執行者：** 倉管組長

| 行為 | 說明 |
|------|------|
| L01L 確認料號特性 | 體積/重量/出貨頻率/類型 |
| L02L 查看現有庫位空間 | 系統顯示各庫位使用率 |
| L03L 選擇合適庫位 | 依分配原則選擇庫位 |
| L04L 在系統登記庫位 | 料號對應庫位寫入主檔 |
| L05L 貼上庫位標籤 | 實體庫位貼上料號標籤 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ L⊗01 分配完成 | 庫位登記完成 | 流程結束 |
| ⚠️ 庫位不足 | 現有庫位已滿 | 進入階段二（庫位優化）|

---

### 階段二：定期庫位檢視

**執行者：** 倉管組長
**時機：** 每月月初

| 行為 | 說明 |
|------|------|
| L06L 查看庫位使用率報表 | 系統顯示各庫位使用率/閒置庫位/超量庫位 |
| L07L 查看各料號出貨頻率 | 依近 3 個月出貨頻率排序 |
| L08L 標記需調整的庫位 | 列出需要搬移/合併/拆分的料號 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 無需調整 | 庫位使用合理 | L⊗02 檢視完成，流程結束 |
| ⚠️ 需要調整 | 發現不合理庫位 | 進入階段三 |

---

### 階段三：庫位異動

**執行者：** 倉管組長（規劃）、倉管專員（執行）

| 行為 | 說明 |
|------|------|
| L09L 規劃異動方案 | 決定哪些料號搬到哪個庫位 |
| L10L* 倉管部長確認 | 大規模調整需倉管部長核准 |
| L11L 執行搬貨 | 倉管專員依方案搬移貨物 |
| L12L 更新系統庫位 | 逐筆更新料號對應的新庫位 |
| L13L 更新庫位標籤 | 舊標籤撕除，貼上新標籤 |

**大燈/板件移至衛星倉的特殊處理：**

| 行為 | 說明 |
|------|------|
| L14L 建立調撥申請 | 引用 [I02 調撥作業] 將貨物移至衛星倉 |
| L14L^ 衛星倉確認收貨 | 調撥完成，庫存更新至衛星倉 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ L⊗03 異動完成 | 所有庫位更新完成 | 通知倉管部長，流程結束 |

---

## 結束點總覽

| 代碼 | 結束原因 | 後續處理 |
|------|---------|---------|
| L⊗01 | 新庫位分配完成 | 可執行入庫作業 |
| L⊗02 | 月度檢視無需調整 | 下月繼續 |
| L⊗03 | 庫位異動完成 | 通知倉管部長 |

## 庫位命名規則

```
格式：[倉別]-[走道]-[層]-[格]

範例：
  Z01-A-2-03  → Z01 倉，A 走道，2 層，第 3 格
  Z00-C-1-10  → Z00 總倉，C 走道，1 層，第 10 格
```
