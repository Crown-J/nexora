# I-W02｜出貨主流程

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

從倉管角度執行撿貨到出貨的完整流程。涵蓋配送、自取、寄貨三種出貨方式，以及調撥出貨情境。銷售視角的流程請見 S-W01/S-W02。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 銷貨出貨 | SYS-S01~ | SO 建立後系統自動產生撿貨單 |
| 調撥出貨 | SYS-I02~ | 調撥核准後系統自動產生撿貨單 |
| 保固補貨 | W-I03 | 廠商補發良品後，需配送給客戶 |

---

## 流程階段

### 階段一：查看待撿貨清單

**執行者：** 倉管專員

| 行為 | 說明 |
|------|------|
| I01O 開啟撿貨任務清單 | 系統顯示所有待撿貨的 PK 撿貨單 |
| I02O 依優先順序排列 | 依出貨急迫性（客戶要求時間）排序 |
| I03O 確認庫位 | 確認各料號庫位位置 |

---

### 階段二：執行撿貨

**執行者：** 倉管專員
**引用：** [I03 撿貨出貨作業]

| 行為 | 說明 |
|------|------|
| I04O 依庫位順序取出貨物 | 依系統路徑逐筆撿貨，減少走動距離 |
| I05O 確認貼紙狀態 | F/S：包裝貼紙；R：本體貼紙；W：QR Code |
| I06O 確認撿貨完成 | Alt+S 確認，系統依出貨方式自動分流 |

**找不到貨的處理：**

| 情況 | 通知對象 | 說明 |
|------|---------|------|
| 銷貨撿貨找不到 | 業務 | 業務決定改走調撥或調貨 |
| 調撥撿貨找不到 | 倉管組長 | 倉管組長通知申請方，決定處置 |

---

### 階段三：執行包貨

**執行者：** 倉管專員
**說明：** 所有出貨類型統一進入包貨環節

| 行為 | 說明 |
|------|------|
| I07O 執行包貨 | 引用 [I04 包貨作業]，依出貨方式選擇包裝類型 |

**包裝類型對應：**

| 出貨方式 | 包裝類型 | 說明 |
|---------|---------|------|
| 配送 | 正常包裝 | 完整封箱 + 出貨標籤，BOX 編號產生後自動產生 DN |
| 自取 | 簡易包裝 | 裝袋/箱但不封箱，BOX 編號通知業務，客戶到場核對後才封箱交付 |
| 寄貨 | 正常包裝 | 完整封箱 + 物流標籤，倉管組長聯繫第三方物流取件 |
| 調撥 | 正常包裝 | 完整封箱 + 調撥標籤，BOX 編號產生後自動產生 DN |

---

### 階段四：依出貨方式完成出貨

#### 路線 A：配送

**執行者：** 物流組長（合併 DN）、外務（執行）

| 行為 | 說明 |
|------|------|
| SYS-I04~ 自動產生 DN 送貨單 | 包貨完成後系統通知物流組長 |
| I08O 物流組長合併任務建立 DN | 可合併多筆包貨單到同一張 DN |
| I09O 指派外務配送 | 引用 [L01 送貨作業/S-L01] |
| I09O^ 客戶電子簽收 | 外務送達，客戶確認簽收 |
| SYS-I05~ 更新出貨狀態 | SO 明細狀態自動→已完成 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 簽收完成 | 客戶確認收貨 | 進入帳務觸發 |
| ⚠️ 配送異常 | 客戶不在/拒收/地址錯誤 | 外務回報，物流組長重新安排 |

#### 路線 B：自取

**執行者：** 倉管專員

| 行為 | 說明 |
|------|------|
| SYS-I04~ 產生 BOX 自取編號 | 格式：BOX-[年月]-[倉庫]-[流水] |
| I10O 通知業務 BOX 編號 | 業務聯絡客戶取貨 |
| I10O^ 客戶來取貨 | 客戶報 BOX 編號 |
| I11O 取出包裹，客戶現場核對 | 核對料號/數量，確認無誤後封箱交付 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 取貨完成 | 客戶取走貨物 | 進入帳務觸發 |
| ⚠️ 客戶遲未取貨 | 超過預定取貨日 | 通知業務聯絡客戶 |

#### 路線 C：寄貨

**執行者：** 倉管組長

| 行為 | 說明 |
|------|------|
| I12O 倉管組長確認包裹 | 確認 BOX 數量與編號 |
| I13O 聯繫第三方物流取件 | 安排物流公司取件 |
| I13O^ 物流取件，填入追蹤單號 | 記錄物流追蹤號碼 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 寄出完成 | 物流取件，填入單號 | 進入帳務觸發 |

#### 路線 D：調撥出貨

**執行者：** 物流組長（配送安排）、外務（執行）

| 行為 | 說明 |
|------|------|
| SYS-I04~ 自動產生調撥 DN | 包貨完成後系統通知物流組長 |
| I14O 引用 [L01 送貨作業/I-L01] | 外務送至目標倉 |
| I14O^ 目標倉倉管掃描 BOX 確認收貨 | 掃描 BOX QR Code 確認到貨數量 |
| SYS-I06~ 更新庫存 | 來源倉減少，目標倉增加 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 調撥完成 | 目標倉確認收貨 | I⊗02 子流程結束 |
| ⚠️ 數量異常 | 到貨數量不符 | 倉管組長決定補發或結案 |

---

### 階段四：帳務觸發

**觸發：** 出貨完成（配送簽收/自取交貨/寄貨寄出）
**執行者：** 系統自動

| 觸發 | 目標 | 說明 |
|------|------|------|
| 出貨→F | 財務模組 | [F05 應收帳款作業] 自動產生 AR |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ I⊗02 出貨完成 | AR 產生 | 流程結束 |
