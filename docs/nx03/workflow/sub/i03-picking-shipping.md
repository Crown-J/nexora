# I03｜撿貨出貨作業

> 版本需求：LITE
> 所屬模組：NX02 庫存模組
> 最後更新：2026-04-11

---

## 子流程概述

從庫位取出貨物的作業。系統自動產生撿貨單，倉管專員依庫位順序執行撿貨。撿貨完成後統一進入包貨環節（I04），再依出貨方式分流。

---

## 觸發情境

| 情境代碼 | 觸發來源 | 說明 |
|---------|---------|------|
| S-I03 | S-W01/S-W02 銷貨 | 銷貨單建立後有庫存，系統自動產生 |
| P-I03 | I02 調撥作業 | 調撥核准後，系統自動產生 |
| P-I03 | I01 分貨入庫 | 分貨後有待出貨 SO，系統自動產生 |
| W-I03 | P-W08 保固補貨 | 廠商補發良品後，配送給客戶 |

## 流程階段

### 階段一：執行撿貨

**執行者：** 倉管專員

| 行為 | 說明 |
|------|------|
| I01P 查看撿貨單 | 系統顯示庫位順序與待撿明細 |
| I02P 依庫位順序取出貨物 | 逐筆掃描或手動確認 |
| I03P 確認貼紙狀態 | F/S：包裝貼紙完整；R：本體貼紙完整；W：QR Code 完整 |
| I04P 確認撿貨完成 | 所有明細取出後按 Alt+S |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 撿貨完成 | 所有明細取出 | 系統依出貨方式分流 |
| ⚠️ 找不到貨 | 庫位無貨 | 標記找不到貨，通知相關人員 |

**找不到貨的處理：**

| 觸發來源 | 通知對象 | 處置方式 |
|---------|---------|---------|
| 銷貨（SO）| 業務 | 業務決定改走調撥或調貨 |
| 調撥（ST）| 倉管組長 | 倉管組長決定處置，通知申請方 |

---

### 階段二：產生包貨單

**執行者：** 系統自動

```
所有出貨方式統一進入包貨環節
  配送 → 正常包裝 + 貼出貨標籤
  自取 → 簡易包裝（客戶現場核對料號，不過度包裝）
  寄貨 → 正常包裝 + 物流標籤
  調撥 → 正常包裝 + 調撥標籤
```

| 行為 | 說明 |
|------|------|
| SYS-I03~ 自動產生包貨單 PL | 系統依出貨方式標記包裝類型，通知倉管執行包貨 |
