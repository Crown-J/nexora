### 3-1 待指派 Tab

**左側：待指派任務清單**

```
待指派任務                           共 12 個任務

[全部] [送貨] [調撥] [取件] [取貨]   篩選

□ D  SO-001  台北電子  大安區仁愛路  配送  1件
□ D  SO-002  新竹科技  新竹市光復路  配送  3件
□ T  ST-003  BW1→MW1  台北市內湖區  調撥  2件
□ C  SR-004  台北汽修  中山區民生東  取件  1件  [銷退]
□ K  TI-005  同行A     三重區重新路  取貨  5件
□ D  SO-006  高雄電機  高雄市前鎮區  配送  2件

[+ 新增 DN 送貨單] Alt+A
```

**任務類型顏色：**
```
D 配送：藍色
T 調撥：橘色
C 取件：綠色
K 取貨：紫色
```

**右側：地圖區**

```
地圖顯示所有待指派任務的地點 pin
未選取任何任務時：顯示所有 pin

勾選任務後：
  → pin 高亮顯示
  → 地圖右上角出現「建立 DN」按鈕
```

**建立 DN 流程：**

```
Step 1：勾選要合併的任務
  → 地圖上被選取的 pin 變為金色
  → 左側底部顯示「已選 5 個任務 / 共 8 件」

Step 2：點擊「規劃路線」
  → 系統呼叫 Google Maps API
  → 計算最佳停靠順序
  → 地圖顯示路線（藍色連線 + 編號）
  → 預估總里程 / 預估時間

Step 3：調整停靠順序（可選）
  → 左側列表可拖曳調整順序
  → 地圖路線即時更新

Step 4：指派外務
  → 下拉選擇外務人員
  → 顯示各外務今日已接任務數
  → 選擇後顯示外務目前位置（若在外勤中）

Step 5：送出指派 Alt+S
  → DN 建立，狀態：待出發
  → 外務手機收到通知
  → 該任務從待指派清單移除
```

**地圖右側控制欄：**
```
[規劃路線]（勾選任務後啟用）
[清除選取]

指派給：
  [王外務 ▼]  今日 2 張 DN
  [陳外務]    今日 1 張 DN
  [林外務]    今日 0 張 DN（可優先）

預估里程：42 公里
預估時間：2.5 小時

[送出指派] Alt+S
```

### 4-4 手機版 UX 設計原則

```
1. 大按鈕（主要操作按鈕高度 64px）
   外務可能戴手套或在移動中操作

2. 導航整合
   [開啟導航] → 直接開啟 Google Maps App
   不在系統內嵌地圖（節省手機資源）

3. GPS 追蹤
   出發後系統每 30 秒更新外務位置
   傳送給物流組長地圖

4. 離線容錯
   簽收記錄暫存本地，恢復連線後自動同步
   避免收訊不好的區域作業中斷

5. 震動回饋
   新任務通知：長震
   確認操作成功：短震
   異常警示：連續震動

6. 螢幕常亮
   進行中 DN 時，螢幕不自動關閉
   避免外務需要頻繁解鎖手機
```
