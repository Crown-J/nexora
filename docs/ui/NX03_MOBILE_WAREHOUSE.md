## 一、適用對象與使用情境

### 倉管專員（主要使用者）
```
在倉庫裡走動，手持手機操作
可能單手持機（另一手拿貨）
光線可能不均勻
需要快速看到「我現在要去哪裡拿什麼」
不需要複雜統計，只需要任務導向
```

### 倉管組長（次要使用者）
```
辦公室 + 倉庫兩種場景
需要看整體進度與異常
需要在手機上完成審核/入帳等操作
詳見第四章
```

### TOP BAR 右側掃描按鈕
```
[掃描] 圖示按鈕（相機 icon）
→ 點擊開啟手機相機掃描模式
→ 也支援外接藍牙掃描槍（自動觸發，不需點擊）
→ 掃描結果依當前情境判斷：
    未接單時掃單據條碼 → 接單
    已接單時掃料號條碼 → 填入料號
    填完料號後掃庫位條碼 → 填入庫位
```

## 三、接單機制

### 單據列表的狀態顯示

```
┌─────────────────────────────┐
│ 待驗收/上架                  │
│                             │
│ RR-202604-001               │
│ 德國汽配  3料號  到貨 10:30  │
│ [掃描接單] ← 橘金色按鈕     │
│                             │
│ RR-202604-002               │
│ 台北馬勒  2料號  到貨 11:00  │
│ 👤 陳倉管 進行中            │ ← 灰色，他人已接
│                             │
│ RR-202604-003               │
│ 台中汽修  1料號  到貨 11:30  │
│ 👤 王倉管（我）[釋出單據]   │ ← 我已接的單，可釋出
└─────────────────────────────┘
```

**狀態說明：**
```
待接單（橘金色）：掃描條碼或點擊「掃描接單」即接單
進行中-他人（灰色）：顯示接單人名稱，無法接單
進行中-自己（高亮）：顯示「釋出單據」按鈕
已完成（綠色）：顯示完成時間
```

### 接單流程

```
Step 1：掃描單據條碼（或點擊「掃描接單」）
  → 系統確認：「確認接單 RR-202604-001？」
  → [確認] [取消]

Step 2：確認後
  → 單據標記「進行中」，顯示接單人名稱
  → 系統記錄：接單人 / 開始時間（效率計算起點）
  → 明細區塊展開，顯示任務內容

Step 3：完成後
  → 點擊「完成此單」Alt+S
  → 系統記錄完成時間，計算效率 KPI
  → 單據移至「已完成」
  → 明細區塊清空，等待接下一張單
```

### 釋出機制

```
情境：倉管人員需要同事幫忙，或自己做不完

點擊「釋出單據」→ 確認對話框：
  「確定釋出 RR-202604-001？
   釋出後其他人可以接單繼續。」
  [確定釋出] [取消]

釋出後：
  → 單據回到「待接單」狀態
  → 系統記錄：原接單人 / 釋出時間 / 已完成項目
  → 同事掃描接單後繼續從未完成的項目做
  → 完成時系統記錄：原接人 + 接手人（兩人都計業績）
```

### 多張接單機制

```
可同時接多張單（自己分配工作）
已接的單在列表頂部顯示（高亮區）
未接的單在下方列表

切換進行中的單：
  點擊高亮區的任一張單 → 明細區塊切換顯示
```

## 八、掃描器支援規格

```
手機相機掃描：
  → 點擊 TOP BAR 掃描圖示開啟相機
  → 對準條碼自動識別（1D 條碼 + QR Code）
  → 識別成功震動 + 音效提示

藍牙掃描槍：
  → 系統自動偵測藍牙 HID 鍵盤輸入
  → 掃描結果自動填入當前聚焦欄位
  → 不需要額外設定，即插即用

條碼類型：
  單據條碼：Code 128（單據號）
  料號條碼：Code 128 / QR Code（料號）
  庫位條碼：QR Code（庫位代碼，貼在庫位標籤上）
  BOX 條碼：QR Code（BOX 編號）
```

## 九、手機版 UX 設計原則

```
1. 大按鈕優先
   主要操作按鈕高度至少 56px，避免誤觸

2. 單手操作友善
   重要按鈕放在畫面下半部（拇指易達區）
   確認按鈕固定在底部

3. 大字顯示關鍵資訊
   庫位代碼：24px 粗體
   料號：18px 粗體
   數量：20px 粗體
   確保在倉庫光線下易讀

4. 最少輸入原則
   能掃描就不用手動輸入
   數量有預設值，只需確認或修改
   庫位有系統建議，只需確認或掃描

5. 離線容錯
   若網路斷線，操作記錄暫存本地
   恢復連線後自動同步
   避免倉庫死角導致作業中斷

6. 震動 + 音效回饋
   掃描成功：短震 + 確認音
   確認操作：短震
   發現異常：長震 + 警示音
   避免在嘈雜倉庫環境依賴視覺回饋
```
