## 一、存取安全規則

### 裝置限制（所有版本）
```
行動裝置（手機/平板）：
  → 模組選單中完全隱藏 NX05 入口
  → 直接輸入網址嘗試進入時：
    系統偵測 User-Agent 為行動裝置
    → 顯示全螢幕提示：
      「財務模組不支援行動裝置
       請使用桌面電腦或筆記型電腦操作」
    → 無法繼續，無任何財務資料顯示
```

### IP 白名單限制（PLUS+）
```
系統設定 → 財務安全 → 允許 IP 清單
  → 管理員可新增/移除允許的 IP 位址
  → 最多 20 組 IP

非白名單 IP 存取 NX05：
  → 顯示 OTP 驗證頁面
  → 系統發送 6 位數 OTP 至財務組長手機
  → 財務組長輸入 OTP → 授予該 IP 本次存取權限
  → OTP 有效期：30 分鐘
  → 系統記錄：IP / 存取時間 / 授權人
```

### 緊急授權（PRO）
```
財務組長可在系統設定發出臨時授權：
  → 指定人員 + 指定時間（最長 24 小時）
  → 授權期間可從任何裝置（除手機/平板）存取
  → 授權到期自動失效
  → 所有異地存取記錄永久保存（稽核用）
```

## 五、Tab 功能區

### Tab 顏色規則（關帳狀態）
```
今日已關帳：
  [關帳] Tab 顯示綠色底色 + ✓ 圖示
  其他 Tab 正常顯示（但單據已鎖定）

今日未關帳：
  [關帳] Tab 顯示橘紅色底色 + ⚠️ 圖示（醒目警示）
  接近關帳時間（例如 17:00 後）Tab 閃爍提醒

已關帳後若有解帳：
  [關帳] Tab 顯示黃色底色 + 🔓 圖示
  記錄解帳原因與負責人
```

### 解除關帳流程

```
點擊 [申請解除關帳] →
  填入解除原因（必填）→
  系統通知負責人審核 →
  負責人：[核准解除] or [不核准]

核准後：
  → 🔓 黃色 Tab（解帳狀態）
  → 記錄：解除時間/原因/負責人（永久保存）
  → 修正完畢後重新執行關帳

不核准：
  → 建議改以新單據處理（SR 銷退/PR 退供應商）
```

