## 一、存取權限規則

```
NX08 整個模組：僅限主管級以上
  → 各部門組長/主管（限自己部門相關報表）
  → 部門經理（本部門 + 跨部門整合報表）
  → 負責人/總經理（全部報表）

一般員工：
  → NX08 在模組選單中完全隱藏
  → 個人日報表/月報表在 Dashboard 操作
  → 不可查看任何分析報表

各報表存取對照：

| 報表 | 組長 | 部門經理 | 財務組長 | 負責人 |
|------|------|---------|---------|--------|
| 個人報表管理 | ✅ 本部門 | ✅ 本部門 | ❌ | ✅ 全部 |
| 經營分析 | ❌ | ✅ | ✅ | ✅ |
| 銷售分析 | ✅ 業務組長 | ✅ 銷售經理 | ❌ | ✅ |
| 採購分析 | ✅ 採購組長 | ✅ 採購經理 | ❌ | ✅ |
| 庫存產品分析 | ✅ 倉管組長 | ✅ 倉管經理 | ❌ | ✅ |
| 廠商分析 | ✅ 採購組長 | ✅ 採購經理 | ❌ | ✅ |
| 財務分析 | ❌ | ❌ | ✅ | ✅ |
| 人資分析 | ❌ | ❌ | ❌ | ✅ |
```

```

沒有存取權限的群組：隱藏（不顯示）

  Alt+← / Alt+→ 收合/展開當前群組
  ↑↓ 在報表列表中移動
  Enter 開啟選中報表
```

## 三、共用報表介面規格

所有報表共用以下版面結構：

### 右側報表區結構

```
┌─────────────────────────────────────────────────────────┐
│ 報表標題  報表說明（一行摘要）          [匯出 Excel] [列印]│
├─────────────────────────────────────────────────────────┤
│ 篩選條件列                                               │
│ 期間：[本月 ▼] [2026-04 ▼]  部門：[全部 ▼]  [套用]     │
├─────────────────────────────────────────────────────────┤
│ 圖表區（Chart.js / Recharts）                            │
│ 高度約 300~400px                                         │
├─────────────────────────────────────────────────────────┤
│ 數據明細表格（可排序）                                   │
│ 高度可捲動                                               │
└─────────────────────────────────────────────────────────┘
```

### 期間篩選選項
```
快速選擇：本月 / 上月 / 本季 / 上季 / 本年 / 去年
自訂：起訖日期選擇器
HPA 比較：近 3 年同期 / 近 5 年同期
```

### 匯出規格
```
匯出 Excel：含原始數據 + 圖表截圖
列印：A4 橫向，優化排版
```

## 十三、圖表技術規格

```
圖表庫：Recharts（React 原生）+ Chart.js（複雜圖表）

各報表圖表類型：

折線圖（LineChart）：HPA 趨勢、KPI 達成率趨勢
  → Recharts <LineChart> + 多條線（不同年份不同顏色）

橫條圖（BarChart）：業務員業績比較、費用率比較
  → Recharts <BarChart horizontal>

散點圖（ScatterChart）：BCG 矩陣、人才象限、廠商四象限
  → Recharts <ScatterChart>（氣泡大小 = 金額）

圓餅圖（PieChart）：客戶等級分布、訓練類型佔比
  → Recharts <PieChart>

雷達圖（RadarChart）：Porter 五力、SWOT 評分
  → Recharts <RadarChart>

瀑布圖：現金流量（收款/付款/淨流量）
  → Chart.js（Recharts 無內建瀑布圖）

顏色規範（深色主題）：
  主色：#E8A020（金色，當前年/主要數據）
  比較色1：#378ADD（藍，去年）
  比較色2：#888780（灰，前年）
  成功：#1D9E75（綠）
  警示：#E8A020（橘）
  危險：#E24B4A（紅）

互動規範：
  hover → 顯示 tooltip（數值 + 說明）
  點擊數據點 → 展開明細
  圖例點擊 → 顯示/隱藏該數據線
```
