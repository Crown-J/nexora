## 一、與銷售作業的關係

```
Alt+← / Alt+→ 切換同模組子作業：
  國內銷售作業  /dashboard/sale/domestic
  國外銷售作業  /dashboard/sale/export
  客戶管理作業  /dashboard/sale/customer  ← 本文件

客戶管理是銷售模組的第三個子作業
主要使用者：業務專員 / 業務組長 / 銷售部經理
```

## 二、版面總覽

```
┌─────────────────────────────────────────────────────────┐
│ TOP BAR                                                  │
├─────────────────────────────────────────────────────────┤
│ KPI BAR（PRO 限定，與銷售作業共用同一套 KPI）            │
├─────────────────────────────────────────────────────────┤
│ Tab：[客戶開發] [客戶分級] [需求回饋]                    │
├─────────────────────────────────────────────────────────┤

```

### 快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+1` | 客戶開發 Tab |
| `Alt+2` | 客戶分級 Tab |
| `Alt+3` | 需求回饋 Tab |
| `Alt+A` | 新增（潛在客戶 / 等級申請 / 回饋單）|
| `Alt+S` | 送出/儲存 |
| `Alt+←` | 切換到上一個子作業（國外銷售）|
| `Alt+→` | 切換到下一個子作業（無，客戶管理是最後一個）|
