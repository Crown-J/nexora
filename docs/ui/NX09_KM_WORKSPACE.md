## 一、存取權限規則

```
NX09 整個模組：所有員工可進入（PRO 版）

各功能存取：
  KM 知識庫（搜尋閱覽）：全員
  KM 知識庫（撰寫發布）：組長以上主管
  文件庫（閱覽）：        全員（依文件權限設定）
  文件庫（上傳管理）：    行政專員 / 各部門主管
  公告發布：              行政專員 / 管理部經理
  會議管理（預約）：      全員
  會議管理（紀錄）：      會議發起人指定的記錄人
  追蹤事項：              全員（限自己被指派的事項）
```
