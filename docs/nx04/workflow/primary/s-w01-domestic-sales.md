# S-W01｜國內銷售主流程

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

國內銷售的標準作業流程，從客戶詢價到完成出貨與帳務的完整路徑。依庫存狀況自動分流，涵蓋有庫存、需調撥、需調貨三種備貨情境，以及配送、自取、寄貨三種出貨方式。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 客戶主動詢價 | S01 | 客戶電話/LINE/現場詢問 |
| 業務主動報價 | S02 | 業務查詢庫存後主動推薦 |

---

## 流程階段

### 階段一：詢價與報價

**觸發：** S01 或 S02
**執行者：** 銷售專員

| 行為 | 說明 |
|------|------|
| S01 查詢庫存與建議售價 | Alt+Q 查詢，顯示各倉庫存/A~D價/歷史成交價 |
| S02 建立報價單 | 選擇客戶，系統帶入客戶等級與毛利區間 |
| S03 填入報價明細 | 料號/數量/單價（低於最低售價需填原因）|
| S04 寄出報價單 | 匯出 Excel 或 PDF 傳給客戶 |
| S04^ 客戶確認報價 | 客戶回覆接受報價 |

**全公司無庫存時：**

| 行為 | 說明 |
|------|------|
| S05 向同行詢價 | Alt+Q → Alt+2，建立同行詢價單 RF |
| S05^ 同行回覆報價 | 同行確認有貨並回報價格 |
| S06 依同行報價加毛利回報客戶 | 填入報價單售價 |

**產出：** QT 報價單（狀態：已發出）

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ S04^ 客戶確認 | 客戶接受報價 | 進入階段二 |
| ↩ 重新報價 | 客戶要求調整價格 | 回到 S03 修改單價 |
| ⊗ S⊗01 | 客戶不接受報價 | QT 標記失效，流程結束 |

---

### 階段二：建立銷貨單

**觸發：** S04^ 客戶確認報價
**執行者：** 銷售專員

| 行為 | 說明 |
|------|------|
| S07 從報價單建立銷貨單 | 系統帶入料號/數量/單價 |
| S08 選擇出貨方式 | 配送（D）/ 自取（P）/ 寄貨（C）|
| S09 選擇出貨倉庫 | 依庫存選擇，可選他倉直接出貨 |
| SYS-S01~ 預留庫存 | 系統立即預留 reserved_qty |

**產出：** SO 銷貨單

**系統依庫存狀況自動設定明細狀態：**

| 庫存情況 | 明細狀態 | 系統動作 |
|---------|---------|---------|
| 本倉/他倉有庫存 | 待撿貨 | 自動產生 PK 撿貨單 |
| 本倉不足，他倉有 | 待調撥 | 自動在 NX02 建立待申請調撥項目 |
| 全公司無庫存 | 待調貨 | 業務按 Alt+T 發起調貨 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 有庫存 | 直接進入備貨 | 進入階段三 A |
| ⚠️ 需調撥 | 本倉不足，他倉有 | 進入階段三 B |
| ⚠️ 需調貨 | 全公司無庫存 | 進入階段三 C |
| ⊗ S⊗02 | 客戶取消訂單 | 釋放 reserved_qty，SO 標記取消，流程結束 |

---

### 階段三：備貨

#### 路線 A：本倉/他倉有庫存

**執行者：** 系統自動產生撿貨單，倉管專員執行

| 行為 | 說明 |
|------|------|
| SYS-S02~ 產生撿貨單 | 自動產生 PK（狀態：待撿貨）|
| I03 執行撿貨 | 引用 [I03 撿貨出貨作業/S-I03] |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 撿貨完成 | 所有明細取出 | 進入階段四（出貨）|
| ⚠️ 找不到貨 | 庫位無貨 | 通知業務，業務決定處置方式 |

#### 路線 B：需調撥（本倉不足，他倉有）

**執行者：** 倉管組長（NX02 調撥申請）

| 行為 | 說明 |
|------|------|
| I02 建立調撥申請 | 引用 [I02 調撥作業/S-I02] |
| I02^ 調撥完成，貨物到達本倉 | 倉管確認收貨後明細狀態自動更新 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 調撥完成 | 貨物到達，明細狀態→待撿貨 | 回到路線 A 執行撿貨 |
| ⊗ S⊗03 | 調撥失敗（他倉庫存不足）| 業務決定改走路線 C 調貨或取消 |

#### 路線 C：需調貨（全公司無庫存）

**執行者：** 銷售專員（發起）、物流組長（安排取貨）

| 行為 | 說明 |
|------|------|
| S10 勾選無庫存明細，按 Alt+T | 選擇同行廠商，系統產生調貨單 TI |
| L02 外務去同行取貨 | 引用 [L02 調貨取貨作業/S-L02] |
| L02^ 取貨完成，貨物入庫 | 倉管驗收入庫，明細狀態自動→待撿貨 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 調貨完成 | 貨物入庫，明細狀態→待撿貨 | 回到路線 A 執行撿貨 |
| ⊗ S⊗04 | 同行無貨/價格無法接受 | 業務決定取消或繼續詢問其他同行 |

---

### 階段四：出貨（依出貨方式分流）

#### 路線 A：配送

**執行者：** 倉管專員（包貨）、物流組長（安排）、外務（執行）

| 行為 | 說明 |
|------|------|
| I04 執行包貨 | 引用 [I04 包貨作業/S-I04D]，正常包裝 + 出貨標籤 |
| SYS-S03~ 包貨完成後自動產生 DN | 系統通知物流組長 |
| L01 物流組長指派外務配送 | 引用 [L01 送貨作業/S-L01] |
| L01^ 客戶電子簽收 | 外務送達，客戶在手機螢幕簽名 |
| SYS-S04~ 更新 SO 明細狀態 | 自動更新為已完成 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 簽收完成 | 客戶確認收貨 | 進入階段五 |
| ⚠️ 配送異常 | 客戶不在/拒收/地址錯誤 | 外務回報，物流組長重新安排 |

#### 路線 B：自取

**執行者：** 倉管專員（包貨）

| 行為 | 說明 |
|------|------|
| I04 執行簡易包貨 | 引用 [I04 包貨作業/S-I04P]，裝袋/箱但不封箱 |
| SYS-S05~ 產生 BOX 自取編號 | 格式：BOX-[年月]-[倉庫]-[流水] |
| S11 通知業務 BOX 編號 | 業務告知客戶 BOX 編號與取貨時間 |
| S11^ 客戶來取貨 | 客戶報 BOX 編號 |
| S12 客戶現場核對後封箱交付 | 倉管取出包裹，客戶核對料號/數量確認後封箱 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 取貨完成 | 客戶取走貨物 | 進入階段五 |
| ⚠️ 客戶遲未取貨 | 超過預定取貨日 | 業務聯絡客戶確認 |

#### 路線 C：寄貨

**執行者：** 倉管專員

**特殊情況（先付款客戶）：**
```
寄貨 + 先付款條件
  ↓
建立 SO 後先引用 [F05 應收帳款作業/S-F05]
  ↓
出納確認收款後才進入撿貨流程
```

| 行為 | 說明 |
|------|------|
| I04 執行包貨 | 引用 [I04 包貨作業/S-I04C]，正常包裝 + 物流標籤 |
| S13 聯繫第三方物流取件 | 安排物流公司取件 |
| S13^ 物流取件，填入追蹤單號 | 物流公司取件後填入系統 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 寄出完成 | 物流取件，填入單號 | 進入階段五 |

---

### 階段五：帳務處理

**觸發：** 出貨完成
**執行者：** 系統自動

| 出貨方式 | 付款條件 | AR 產生時機 |
|---------|---------|-----------|
| 自取 | 現金 | 取貨當下，AR 產生並立即核銷 |
| 配送 | 現金 | 外務收款，AR 產生並立即核銷 |
| 配送 | 月結 | DN 送達時自動產生 AR |
| 寄貨 | 先付款 | 確認收款後 AR 產生並核銷 |
| 寄貨 | 月結 | 寄出時自動產生 AR |

**跨模組觸發：**

| 觸發 | 目標 | 引用子流程 |
|------|------|-----------|
| S→F | 財務模組 | [F05 應收帳款作業/S-F05] |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ S⊗05 銷售完成 | AR 產生或核銷 | 主流程結束 |

## 結束點總覽

| 代碼 | 結束原因 | 後續處理 |
|------|---------|---------|
| S⊗01 | 客戶不接受報價 | QT 標記失效 |
| S⊗02 | 客戶取消訂單 | 釋放 reserved_qty，SO 標記取消 |
| S⊗03 | 調撥失敗 | 業務決定改走調貨或取消 |
| S⊗04 | 調貨失敗 | 業務決定取消或繼續詢問其他同行 |
| S⊗05 | 銷售完成 | AR 產生，觸發財務模組 |
