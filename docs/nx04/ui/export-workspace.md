## 二、流程圖差異

### 國內銷貨節點
```
查詢─詢價─報價─調貨─銷貨─出貨─完成
                              ╎    ╎
                           銷退  保固
```

### 國外銷貨節點（多三個）
```
查詢─詢價─報價─調貨─銷貨─付款確認─出口報關─國際物流─完成
                                                        ╎    ╎
                                                     銷退  保固
```

**新增節點說明：**

| 節點 | 說明 | Badge 數字 |
|------|------|-----------|
| 付款確認 | 依付款條件確認收款或信用狀，才能出貨 | 等待付款確認的單數 |
| 出口報關 | 準備出口文件/委託報關行/取得提單 | 報關中的單數 |
| 國際物流 | 依 Incoterm 安排物流/追蹤到貨 | 在途中的單數 |

### 快捷鍵對應

| 快捷鍵 | 節點 |
|--------|------|
| `Alt+1` | 查詢 |
| `Alt+2` | 詢價 |
| `Alt+3` | 報價 |
| `Alt+4` | 調貨 |
| `Alt+5` | 銷貨 |
| `Alt+6` | 付款確認 |
| `Alt+7` | 出口報關 |
| `Alt+8` | 國際物流 |
| `Alt+9` | 完成 |

## 三、國內/國外銷貨單的差異欄位

### 報價單/銷貨單新增欄位

| 欄位 | 說明 | 必填條件 |
|------|------|---------|
| 幣別 | USD / EUR / JPY 等 | 必填 |
| 匯率 | 建單當日匯率（可調整）| 必填 |
| 貿易條件（Incoterm）| FOB / CIF / EXW / DDP | 必填 |
| 付款條件 | TT / LC / DP / DA | 必填 |
| 客戶 PO 號碼 | 客戶的採購單號 | 選填 |
| 目的港/地 | 送達地點 | 必填 |
| 提單號（B/L）| 報關後取得 | 報關後必填 |

### 出口文件清單（出口報關節點需產出）

| 文件 | 說明 |
|------|------|
| Commercial Invoice | 商業發票（英文，含 Incoterm/幣別）|
| Packing List | 裝箱單（每箱料號/數量/重量/尺寸）|
| Certificate of Origin | 產地證明（視客戶要求）|

## 四、差異作業節點詳細規格

---

### 4-A 查詢（國外版，差異處）

> 與國內查詢相同，但顯示外幣售價

**步驟二：查詢庫存（差異欄位）**
```
料號 A  本倉 150  他倉 320  A 價 $11.50 TWD → $ 0.35 USD（依匯率換算）
```

**步驟三：選處置方式（差異）**
```
直接報價：顯示外幣建議售價
```

---

### 4-B 報價（國外版，差異處）

> 步驟三填入報價時，多了外幣相關欄位

**步驟三：填入報價（額外欄位）**
```
幣別          [USD ▼]
匯率          32.50（可調整）
外幣售價      [________]（主要填寫欄位）
折合台幣      自動計算（參考用）
貿易條件      [FOB ▼]
付款條件      [TT ▼]
目的港        [____________]
客戶 PO 號    [____________]（選填）
備註（英文）  [____________]
```

**付款條件提示：**
```
選 TT：「客戶需先匯款，確認收款後才出貨」
選 LC：「需確認信用狀有效後才出貨」
選 DP：「到港後客戶付款才能領貨」
選 DA：「到港後承兌，票據到期才收款」
```

---

### 4-C 銷貨（國外版，差異處）

**步驟三：填入出貨資訊（差異欄位）**
```
出貨方式：固定為「國際物流」（不提供配送/自取）
目的港    [____________]（已從報價帶入）
Incoterm  [FOB ▼]（已從報價帶入）
```

---

### 4-D 付款確認（新節點）

> 備貨完成後，依付款條件確認才能出貨

**進入節點後：**
```
左側：待確認付款的銷貨單列表
  單據號 / 客戶 / 幣別 / 金額 / 付款條件 / 狀態
  （待客戶付款 / 待 LC 確認 / 已確認可出貨）
```

**點選銷貨單 → 付款確認畫面：**

```
┌──────────────────────────────────────┬────────────────────┐
│ 銷貨單資訊（唯讀）                    │ 付款確認操作       │
│                                      │                    │
│ 客戶：Tokyo Auto Parts Ltd.           │ 付款條件：TT       │
│ 幣別：USD  金額：$3,500              │                    │
│ Incoterm：FOB                        │ [已收到客戶匯款]    │
│                                      │ 匯款日：[日期]      │
│                                      │ 匯款金額：[____]    │
│                                      │ 備註：[____]        │
│                                      │                    │
│                                      │ [確認可出貨] Alt+S  │
└──────────────────────────────────────┴────────────────────┘
```

**各付款條件的操作：**

```
TT 先付款：
  → 業務確認財務已收到匯款
  → [確認可出貨] → 進入出口報關節點

TT 後付款：
  → 直接 [確認可出貨]（出貨後收款）
  → 進入出口報關節點

LC 信用狀：
  → 顯示：「等待財務確認信用狀有效」
  → 財務在 NX05 確認 LC 後，此節點自動更新狀態
  → 業務只需等待狀態變更為「LC 已確認」
  → 狀態變更後業務收到通知，可繼續出貨

DP / DA：
  → 直接 [確認可出貨]（到港後處理）
  → 進入出口報關節點
```

---

### 4-E 出口報關（新節點）

> 撿貨包裝完成後，準備出口文件並委託報關行

**進入節點後：**
```
左側：待出口報關的銷貨單列表
  單據號 / 客戶 / 狀態
  （準備文件中 / 報關中 / 已清關取得提單）
```

**點選銷貨單 → 進入步驟區：**

```
┌──────────┬────────────────┬──────────────┬────────────────────┐
│ ① 確認   │ ② 建立出口     │ ③ 填入提單   │ 文件產出           │
│    資訊  │    文件        │    號碼      │                    │
│（已帶入）│                │              │                    │
└──────────┴────────────────┴──────────────┴────────────────────┘
```

**步驟二：建立出口文件**

```
系統自動產生：
  ✅ Commercial Invoice（商業發票）
     → 自動帶入：客戶/料號/數量/外幣單價/Incoterm/付款條件
     → 業務確認後可匯出 PDF

  ✅ Packing List（裝箱單）
     → 倉管填入的包裝資訊（每箱重量/尺寸）
     → 業務確認後可匯出 PDF

  ○ Certificate of Origin（產地證明）
     → 依客戶要求，選擇是否需要
```

**步驟三：填入提單號**
```
報關行名稱    [____________]
委託日        [日期選擇器]
提單號（B/L） [____________]（清關後填入）
清關完成日    [日期選擇器]
備註          [____________]
```

**右側文件產出：**
```
文件狀態
─────────────────
✅ Commercial Invoice  [下載 PDF]
✅ Packing List        [下載 PDF]
○  Certificate of Origin  [產出]
─────────────────
提單號：待填入
[已取得提單，確認出口完成] Alt+S
```

**確認後：**
- 進入國際物流節點
- 系統記錄出口完成時間

---

### 4-F 國際物流（新節點）

> 依 Incoterm 追蹤物流狀態

**進入節點後：**
```
左側：國際物流追蹤列表
  單據號 / 客戶 / Incoterm / 目的港 / 狀態
  （已出口 / 運輸中 / 已到港 / 客戶已簽收）
```

**各 Incoterm 的處理責任：**

```
FOB（我方負責到港口）：
  → 確認貨物已裝船
  → 之後由買方自理，我方只需追蹤客戶收貨確認
  → 操作：[客戶已確認收貨] → 完成

CIF（我方負責到目的港，含運費保險）：
  → 填入：船公司/航班/預計到港日
  → 追蹤到港狀態
  → 操作：[已到港，客戶確認] → 完成

EXW（買方到我方倉庫取貨）：
  → 最簡單，確認客戶已在倉庫取走
  → 操作：[客戶已取貨] → 完成

DDP（我方負責送到客戶倉庫，含關稅）：
  → 需安排目的地的配送
  → 填入：當地配送商/預計送達日
  → 確認客戶簽收
  → 操作：[客戶已簽收] → 完成
```

**物流追蹤畫面：**

```
┌──────────────────────────────────────┬────────────────────┐
│ 物流狀態                              │ Incoterm 責任說明  │
│                                      │                    │
│ 客戶：Tokyo Auto Parts               │ FOB                │
│ 目的港：橫濱港                        │ 我方負責到港口      │
│ 提單號：EVER12345                     │ 之後由買方自理      │
│                                      │                    │
│ ─── 物流時間軸 ───                    │ 當前狀態：運輸中    │
│ ✅ 2026-05-20 已出口清關              │                    │
│ ✅ 2026-05-21 已裝船                  │ 預計到港：         │
│ 🔄 運輸中（預計 2026-06-01 到港）     │ 2026-06-01         │
│                                      │                    │
│                                      │ [客戶已確認收貨]    │
│                                      │ Alt+S              │
└──────────────────────────────────────┴────────────────────┘
```

**客戶確認收貨後：**
- 進入完成節點
- AR 應收帳款依付款條件自動處理
