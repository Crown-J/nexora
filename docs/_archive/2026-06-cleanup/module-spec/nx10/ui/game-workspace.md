## 一、版面配置總覽

NX10 不是獨立模組，而是整合在首頁與個人資訊中：

```
1. 首頁 Dashboard EXP BAR（全寬橫條）
   → 勳章等級 + Exp 進度條
   → 右側「牌位大師」按鈕 → 開啟面板

2. EXP BAR 右側按鈕 → 「牌位、勳章與排行榜」面板
   → Tab 1：牌位勳章（所有等級一覽）
   → Tab 2：排行榜（本週/本月/總榜）

3. TOP BAR 使用者頭像 → Dropdown
   → 個人設定（密碼設定 + 個人成長頁面）
   → 系統設定（版面風格/語言）
   → 登出系統

4. 個人成長頁面（從個人設定進入）
   → 完整 Exp 趨勢圖
   → 寶箱開啟
   → 成就勳章

5. 轉職系統（從個人成長頁面進入）
   → 轉職條件進度
   → 申請轉職

6. 懲罰記錄（主管以上）
   → 從 NX07 人資模組進入
```

## 六、轉職系統（個人成長頁面內）

---

### 6-0 職位與勳章等級對應

```
各部門職位與勳章等級對應：

實習生  ← 銅牌（IV → III → II → I）
專員    ← 銀牌（IV → III → II → I）
副組長  ← 金牌（IV → III → II → I）
組長    ← 白金（IV → III → II → I）

晉升門檻：
  必須達到當前職位的最高階（X 牌 I）才可申請晉升
  例：實習倉管銅牌 I → 申請晉升倉管專員（銀牌 IV）
      倉管專員銀牌 I → 申請晉升倉管副組長（金牌 IV）

帶人門檻：
  新人需達到「申請人當前等級 -1 階」才算帶成功
  例：申請人銅牌 I → 新人需達到銅牌 III
      申請人銀牌 I → 新人需達到銀牌 III
```

---

### 6-1 兩種轉職類型

#### 類型 A：往上晉升（同部門）

```
條件：
  1. 當前職位達到最高階（X 牌 I）
  2. 帶新人達到「申請人當前等級 -1 階」

流程：
  員工 Exp 達到 X 牌 I
    ↓
  向直屬主管提出晉升申請
    ↓
  主管指派帶人對象（同部門新進員工）
  若當下無可帶新人：
    → 系統顯示「等待指派帶人對象」（等待招募）
    ↓
  員工帶新人，新人達到指定 Exp 等級
    ↓
  上報主管驗收確認
    ↓
  人資主管審核
    ↓
  完成晉升（引用 H-W04 異動作業）

審核：直屬主管 + 人資主管（共 2 人）
```

#### 類型 B：調部門（跨部門）

```
條件：無 Exp 要求，任何時候都可申請

Exp 狀態與調職結果：

  Exp 未滿（銅牌 IV~III~II）：
    實習倉管 → 實習業務
    排位歸零 → 銅牌 IV（同職位，最低階重來）

  Exp 已滿（達到 X 牌 I）：
    同職位，退一階開始
    實習倉管（銅牌 I）  → 實習業務（銅牌 II）
    倉管專員（銀牌 I）  → 業務專員（銀牌 II）
    倉管副組長（金牌 I）→ 業務副組長（金牌 II）

流程：
  員工提出調部門申請 + 填寫申請原因
    ↓
  原部門主管審核（同意放人）
    ↓
  目標部門主管審核（同意接收）
    ↓
  人資主管審核（人事合規確認）
    ↓
  目標部門考核（每月只能申請一次）
    → 填題：來自知識庫（KM QA）的相關題目
    → 操作測試：系統實際操作考核
    → 題目由人資主管 + 目標部門主管共同設計
    → 60 分及格（12/20 題）
    ↓
  考核通過 → 完成調部門（引用 H-W04 異動作業）
  考核未過 → 下個月才能重新申請

審核：原部門主管 + 目標部門主管 + 人資主管（共 3 人）

⚠️ 每月只能申請一次調部門考核
   本月未過 → 等下個月再申請
```
