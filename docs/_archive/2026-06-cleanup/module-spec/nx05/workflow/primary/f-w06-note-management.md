# F-W06｜票據管理作業

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

管理所有應收（客戶開給我們）與應付（我們開給廠商）票據，從建立記錄到兌現/退票的完整作業。每日自動偵測到期票據，確保不漏失任何票據處理。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 收付款選擇支票/本票 | F-W05 | 登記收付款時選擇票據付款方式 |
| 系統每日偵測 | SYS-F04~ | 每日早上自動偵測即將到期票據 |

---

## 票據方向與類型

| 方向 | 說明 | 建立時機 |
|------|------|---------|
| 應收票據（R）| 客戶開票給我們，我們持有 | F-W02 月結收款時建立 |
| 應付票據（P）| 我們開票給廠商，廠商持有 | F-W04 廠商付款時建立 |

| 類型 | 說明 | 注意事項 |
|------|------|---------|
| 支票（C）| 銀行帳戶支付，有票號/銀行/帳號/到期日 | 需確認帳戶餘額足夠 |
| 本票（P）| 開票人直接承諾支付，有票號/到期日 | 法律效力強，退票影響信用 |

---

## 流程階段

### 階段一：建立票據記錄

**觸發：** F-W05 收付款選擇支票/本票
**執行者：** 出納專員

| 行為 | 說明 |
|------|------|
| T01 填入票據資訊 | 票號/銀行名稱/銀行帳號/票面金額/開票日/到期日 |
| T02 選擇票據方向 | 應收（R）或應付（P）|
| T03 關聯對應 AP 或 AR | 確保帳款與票據正確對應 |
| T04 Alt+S 儲存 | 系統建立票據記錄 |

**產出：** 票據記錄（應收→持有中 / 應付→待兌現）

---

### 階段二：每日到期追蹤

**執行者：** 系統自動偵測 + 出納專員處理
**時機：** 每日早上

| 行為 | 說明 |
|------|------|
| SYS-F04~ 偵測到期票據 | 7 天內到期 🟠，已到期 🔴 |
| T05 出納查看票據到期清單 | 確認今日/近期需處理的票據 |

**應收票據到期（客戶開票給我們）：**

| 行為 | 說明 |
|------|------|
| T06 確認票據已存入銀行 | 確認銀行是否已兌現（登入網銀或電話確認）|
| T07 系統確認兌現 | 點擊「確認兌現」，對應 AR 自動核銷 |

**應付票據到期（我們開票給廠商）：**

| 行為 | 說明 |
|------|------|
| T08 確認銀行帳戶餘額充足 | 避免退票，需提前確認 |
| T09 系統確認兌現 | 銀行扣款後確認，對應 AP 自動核銷 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗12 兌現完成 | 正常兌現 | 流程結束 |
| ⚠️ 退票 | 兌現失敗 | 進入階段三 |

---

### 階段三：退票處理

**執行者：** 出納專員（處理）、財務組長（通報）

**應收票據退票（客戶票據退票）：**

| 行為 | 說明 |
|------|------|
| T10 標記退票 | 填入退票原因（存款不足/帳號有誤/其他）|
| SYS-F04~ 還原 AR | 對應 AR 狀態自動改回未收款 |
| T11 通知業務組長 | 請業務跟催客戶補款 |
| T12 登記退票手續費 | 引用 [F-W05 收付款作業] 費用登記 |
| T13 引用 [F-W01 催收作業] | 退票視同逾期帳款，啟動催收 |

**應付票據退票（我方票據退票）：**

| 行為 | 說明 |
|------|------|
| T10 標記退票 | 填入退票原因 |
| SYS-F04~ 還原 AP | 對應 AP 狀態自動改回未付款 |
| T11 立即通知財務組長/負責人 | 緊急處理，維護公司信用 |
| T12 安排補開票據或改付款方式 | 重新引用 [F-W04 應付帳款作業] |
| T13 登記退票手續費 | 引用 [F-W05 收付款作業] 費用登記 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗13 退票處理完成 | 重新安排付款/收款 | 流程結束 |

---

### 階段四：票據作廢

**觸發：** 開錯票或雙方合意取消
**執行者：** 出納專員（申請）、負責人（審核）

| 行為 | 說明 |
|------|------|
| T14 申請作廢 | 填入作廢原因（必填）|
| T14* 負責人審核 | 確認作廢原因合理 |
| SYS-F04~ 更新票據狀態→作廢 | 系統更新 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗14 作廢完成 | 負責人核准 | 流程結束 |
