# F-W03｜關帳作業

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

每日財務作業結束後執行關帳，鎖定當日所有單據確保財務資料完整性。分為每日關帳與月末關帳兩個層次。關帳由會計專員執行，解除關帳需負責人核准。

---

## 關帳層次

| 層次 | 說明 | 頻率 |
|------|------|------|
| 每日關帳 | 鎖定當日所有單據 | 每個工作日 |
| 月末關帳 | 月底結清，產出月報表 | 每月最後一個工作日 |

---

## 關帳後鎖定範圍

| 模組 | 鎖定內容 |
|------|---------|
| NX01 採購 | RR 進貨單、PR 退供應商單 |
| NX02 庫存 | ST 調撥單、SL 盤點單 |
| NX03 銷售 | SO 銷貨單、SR 銷退單 |
| NX04 財務 | AP、AR、收付款記錄、折讓單 |
| NX07 物流 | DN 送貨單 |

> 關帳後若需修正，只能建立新單據處理（SR 銷退/PR 退供應商），不得直接修改原始單據。

---

## 流程階段

### ▌每日關帳

#### 階段一：關帳前確認

**執行者：** 會計專員
**時機：** 每個工作日下班前

| 行為 | 說明 |
|------|------|
| A01 進入關帳作業頁面 | NX04 財務模組 → 關帳作業 |
| A02 確認待處理項目 | 系統自動顯示以下清單 |

**系統自動顯示待確認項目：**

| 項目 | 說明 |
|------|------|
| 未完成的 SO | 配送中/待配送，確認是否今日出貨 |
| 未入帳的 RR | 驗收完成但未入帳，確認是否今日入帳 |
| 未收款的現金 AR | 現金客戶取貨/配送但未登記收款 |
| 當日收付款記錄 | 確認是否完整登記 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 全部確認 | 無待處理項目 | 進入階段二 |
| ⚠️ 有待處理 | 有未完成項目 | 先處理完畢或備註原因後繼續 |

---

#### 階段二：產出 401 報表

**執行者：** 會計專員

| 方式 | 行為 | 說明 |
|------|------|------|
| 方式 A | 上傳 401 報表 | 使用外部工具產出 → 上傳系統 → 系統記錄上傳時間 |
| 方式 B | 系統列印 401 報表 | NX04 → 關帳作業 → 列印 → 系統記錄列印時間 |

> 401 報表的列印/上傳時間具法律效力，必須在關帳前產出，證明報表係關帳前產生。

---

#### 階段三：執行關帳

**執行者：** 會計專員

| 行為 | 說明 |
|------|------|
| A03 點擊「執行關帳」| 系統最後確認：「關帳後所有當日單據將鎖定，確認執行？」|
| A04 確認執行 | 系統執行關帳 |
| SYS-F07~ 鎖定當日單據 | 所有模組當日單據狀態鎖定 |
| SYS-F07~ 記錄關帳資訊 | 記錄關帳時間/執行人 |
| SYS-F07~ 通知全員 | 系統發送「今日已關帳」通知 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗08 關帳完成 | 關帳執行成功 | 流程結束 |

---

### ▌月末關帳

**執行者：** 財務組長（主導）、會計專員（執行）
**時機：** 每月最後一個工作日

#### 月末額外確認項目

| 項目 | 說明 |
|------|------|
| 所有月結客戶帳單已發送 | 引用 [F-W02 月結請款作業] 確認 |
| 本月 AP 全部處理 | 確認所有廠商應付帳款已登記 |
| 本月折讓單全部核准 | 未核准的折讓單須在月末前處理 |
| 票據到期確認 | 本月到期票據是否全部兌現/處理 |
| 費用支出登記完整 | 本月所有費用是否全部登記 |

| 行為 | 說明 |
|------|------|
| A05 月末確認清單 | 逐項確認上述項目 |
| A06 產出月報表 | 系統自動產生本月 AP/AR/損益摘要 |
| A07 財務組長審核月報表 | 確認數字無誤 |
| A08 執行月末關帳 | 與每日關帳相同步驟，但標記為「月末關帳」|

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗09 月末關帳完成 | 月末單據鎖定，月報表產出 | 流程結束 |

---

### ▌解除關帳（緊急修正）

**觸發：** 關帳後發現需要修改的錯誤
**執行者：** 會計專員（申請）、負責人（審核）

| 行為 | 說明 |
|------|------|
| A09 申請解除關帳 | 會計專員說明解除原因 |
| A09* 負責人審核 | 確認解除原因合理，核准解除 |
| SYS-F08~ 解除關帳 | 當日單據解除鎖定 |
| A10 修正錯誤 | 會計專員修正相關單據 |
| A11 重新執行關帳 | 修正完畢後重新走每日關帳流程 |
| SYS-F08~ 記錄解除歷程 | 解除時間/原因/負責人，永久保存不可刪除 |

> 解除關帳記錄永久保存，作為日後稽核依據。

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 重新關帳完成 | 修正後重新關帳 | 流程結束 |
| ❌ 不核准解除 | 負責人認為不需修改 | 改以新單據處理（SR/PR）|
