# H-W03｜薪資計算作業

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

每月依員工出勤、請假、加班記錄計算實領薪資，扣除應扣項目後產出薪資單，由負責人核准後交由出納發放。

---

## 薪資組成

| 項目 | 說明 |
|------|------|
| 底薪 | 月固定薪資 |
| 伙食津貼 | 固定金額（依公司規定）|
| 加班費 | 依加班時數計算 |
| 績效獎金 | 依 KPI 達成率（H-W05）|
| 全勤獎金 | 當月無請假則發放 |

| 扣除項目 | 說明 |
|---------|------|
| 事假扣薪 | 事假日數 × 日薪 |
| 勞保費（員工負擔）| 依薪資級距 |
| 健保費（員工負擔）| 依薪資級距 |
| 所得稅代扣 | 依薪資級距 |

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 月底固定執行 | H-W01 | 出勤資料彙整完成後觸發 |
| 行政專員手動執行 | S01 | 每月固定時間（建議 25 號前完成計算）|

---

## 流程階段

### 階段一：資料確認

**執行者：** 行政專員

| 行為 | 說明 |
|------|------|
| W01 確認出勤資料 | 引用 [H-W01] 月底出勤彙整結果 |
| W02 確認請假/加班記錄 | 引用 [H-W02] 當月請假/加班資料 |
| W03 確認績效獎金 | 引用 [H-W05] KPI 考核結果（PRO 版）|
| W04 確認人員異動 | 確認當月是否有入職/離職人員（引用 [H-W04]）|

---

### 階段二：系統計算薪資

**執行者：** 系統自動

| 行為 | 說明 |
|------|------|
| SYS-H03~ 計算各員工薪資 | 依底薪/津貼/加班/請假/獎金自動計算 |
| SYS-H03~ 計算勞健保/所得稅 | 依薪資級距自動計算應扣金額 |
| SYS-H03~ 產生薪資明細 | 每人一份薪資計算明細 |

---

### 階段三：行政專員確認

**執行者：** 行政專員

| 行為 | 說明 |
|------|------|
| W05 逐筆確認薪資明細 | 確認計算結果無誤 |
| W06 標記異常薪資 | 金額異常者（如比上月差異過大）需說明原因 |
| W07 送負責人審核 | 確認後送負責人核准 |

**產出：** 薪資計算清單（狀態：待核准）

---

### 階段四：負責人核准

**執行者：** 負責人（總經理）

| 行為 | 說明 |
|------|------|
| W08* 審核薪資清單 | 確認總薪資金額合理 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 核准 | 薪資合理 | 進入發放 |
| ❌ 退件 | 有疑問的薪資 | 行政專員確認後重送 |

---

### 階段五：薪資發放

**執行者：** 出納專員

| 行為 | 說明 |
|------|------|
| W09 執行匯款 | 依薪資清單匯款至各員工帳戶 |
| W10 發送薪資單 | 系統自動發送薪資單 Email，或列印紙本 |
| W11 登記費用 | 引用 [F-W05 收付款作業] 登記薪資費用支出 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ H⊗03 薪資發放完成 | 所有員工薪資匯出 | 流程結束 |
