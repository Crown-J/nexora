## 一、存取權限規則

### 模組存取
```
NX07 整個模組：僅限人資相關角色存取
  → 行政專員（ADMIN）
  → 負責人/總經理（全部）
  → 部門主管（僅出勤/請假加班/績效 Tab，限自己部門）

財務相關角色（出納/財務組長）：
  → NX07 完全不可存取
  → 薪資資訊嚴格保密，財務只收到薪資總額
  → 個別員工薪資明細不對財務部門揭露

一般員工：
  → NX07 在模組選單中完全隱藏
  → 薪資單統一以加密 Email 寄送，不在系統顯示
  → 請假/加班申請在自己的 Dashboard 操作
  → 月自評在自己的 Dashboard 操作
```

### 各 Tab 的角色存取對照

| Tab | 行政專員 | 部門主管 | 財務相關 | 負責人 |
|-----|---------|---------|---------|--------|
| 出勤 | ✅ 全部 | ✅ 本部門 | ❌ | ✅ 全部 |
| 請假加班 | ✅ 全部 | ✅ 本部門審核 | ❌ | ✅ 全部 |
| 薪資 | ✅ 計算 | ❌ | ❌ 嚴格禁止 | ✅ 核准 |
| 績效 | ✅ 彙整 | ✅ 本部門確認 | ❌ | ✅ 全部 |
| 訓練 | ✅ 全部 | ✅ 本部門 | ❌ | ✅ 全部 |
| 人事 | ✅ 全部 | ❌ | ❌ | ✅ 全部 |

### 薪資保密機制（嚴格執行）

```
人資與財務嚴格切割：

人資端（NX07 薪資 Tab）：
  → 行政專員看到每個人的薪資明細
  → 執行計算後送負責人核准
  → 負責人核准後，系統執行兩個動作：

動作 1：發送加密 Email（系統自動）
  收件人 A：各員工本人
    → 內容：個人薪資單明細
    → 加密，只有本人可開啟
  收件人 B：出納專員
    → 內容：完整匯款清單（姓名 + 帳號 + 個別金額）
    → 加密，只有出納可開啟
    → 此 Email 不在任何系統界面留存記錄

動作 2：推送至 NX05 財務模組
  → 只傳送薪資「總額」
  → 不包含任何個別員工薪資資訊
  → 財務端看到的只是一筆費用支出

系統技術規則：
  → 薪資明細資料加密儲存於 DB
  → 財務相關 role 對 nx07_payroll 表格零讀取權限
  → API 層級強制攔截，非授權角色查詢薪資明細回傳 403
```
