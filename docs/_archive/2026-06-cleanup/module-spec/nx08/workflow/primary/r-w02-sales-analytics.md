# R-W02｜銷售分析報表

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

提供銷售部經理與業務組長用於業績追蹤、客戶分析、市場開發的銷售分析報表。整合 HPA 歷史路徑分析與 Ansoff 矩陣，依區域別、業務別、客戶別、料號別進行多維度分析。

---

## 理論框架

| 分析工具 | 用途 |
|---------|------|
| HPA 歷史路徑分析 | 業績趨勢（月/季/年）多年比對 |
| Ansoff 矩陣 | 新舊客戶 × 新舊料號業績結構 |
| 客戶分級管理 | A~D 客戶等級業績貢獻分析 |
| 售價比率管理 | 實售價/定價比率控管 |

---

## 報表區塊

### 一、業績總覽（HPA 折線圖）

| 指標 | 說明 | 維度 |
|------|------|------|
| 月業績趨勢 | 近 3 年同月比較折線圖 | 公司/部門/業務 |
| 業績達成率 | 實際/目標 | 月/季/年 |
| 毛利率趨勢 | 毛利率變化曲線 | 公司/產品線 |
| 業績結構圖 | 各區域/各業務佔比 | 月 |

### 二、多維度業績分析

| 分析維度 | 說明 |
|---------|------|
| 區域別 | 各營業處業績比較 |
| 業務別 | 各業務員業績/達成率/KPI |
| 客戶屬性別 | 保養廠/車商/同行/直客 |
| 料號別 | 各料號/品牌銷售排行 |
| 月份交叉 | 淡旺季分析 |

### 三、客戶分析（引用 S-W05 客戶分級）

| 指標 | 說明 |
|------|------|
| A~D 等級客戶數量與業績佔比 | 等級分布結構 |
| 新客戶開發數（首次成交）| 引用 [S-W04] 客戶開發 |
| 客戶回購率 | 重複購買客戶 / 總客戶數 |
| 客戶流失率 | 去年有交易但今年未交易客戶 |
| 前 10 大客戶業績趨勢 | HPA 折線圖 |

### 四、Ansoff 矩陣業績結構

| 象限 | 計算方式 | 目標 |
|------|---------|------|
| 舊客戶 × 舊料號 | 既有業績基盤 | 維持/成長 |
| 舊客戶 × 新料號 | 新品導入貢獻 | 擴大份額 |
| 新客戶 × 舊料號 | 市場開發成果 | 開拓新市 |
| 新客戶 × 新料號 | 雙重創新 | 創造高毛利 |

### 五、售價管理分析

| 指標 | 說明 |
|------|------|
| 低於最低售價次數 | 業務別統計，影響 KPI |
| 平均售價比率 | 實售價/定價平均比率 |
| 折讓率 | 折讓金額/銷售金額 |
