# R-W06｜財務分析報表

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

提供財務部經理與總經理用於財務健康監控的分析報表。整合 Porter 價值鏈財務分析，搭配 HPA 歷史路徑分析，追蹤 AP/AR 健康度、費用率控管、現金流趨勢。

---

## 理論框架

| 分析工具 | 用途 |
|---------|------|
| Porter 價值鏈 | 各環節成本/利潤貢獻分析 |
| HPA 歷史路徑分析 | 財務指標 3~5 年趨勢 |
| 零基預算概念 | 費用率控管與預算差異分析 |

---

## 報表區塊

### 一、財務健康儀表板

| 指標 | 說明 | 目標值 |
|------|------|-------|
| 毛利率趨勢 | 近 3 年月度毛利率 HPA | 持續成長 |
| 費用率 | 營業費用/營業額 | 依預算控管 |
| 應收帳款逾期率 | 逾期 AR/總 AR | < 5% |
| 應付帳款準時率 | 準時付款 AP/總 AP | > 95% |
| 現金週轉天數 | 應收天數 + 庫存天數 - 應付天數 | 越短越好 |

### 二、Porter 價值鏈成本分析

```
主要活動成本佔比：
  採購成本（P-W01/P-W02）→ 進貨成本率
  倉儲成本（I-W01~I-W04）→ 倉儲費用率
  銷售成本（S-W01~S-W06）→ 銷售費用率
  物流成本（L01~L04）    → 物流費用率
  財務成本（F-W04~F-W07）→ 財務費用率

支援活動成本佔比：
  人資成本（H-W01~H-W06）→ 人力成本率（薪資佔比）
  行政成本（管理費用）   → 管理費用率
```

### 三、AP/AR 健康分析（HPA）

| 指標 | 說明 |
|------|------|
| AP 到期清單 | 7天內到期/逾期分布 |
| AR 逾期結構 | 逾期天數分布（0~30/30~60/60+ 天）|
| 應收帳款 HPA | 近 3 年 AR 總額/逾期率趨勢 |
| 票據到期行事曆 | 未來 30 天到期票據清單 |

### 四、費用率控管（零基預算概念）

| 費用類別 | 預算 | 實際 | 差異 | 差異率 |
|---------|------|------|------|-------|
| 薪資費用 | - | - | - | - |
| 物流費用 | - | - | - | - |
| 行政費用 | - | - | - | - |
| 其他費用 | - | - | - | - |

> 系統自動計算，每月與預算比對，差異 > 10% 顯示警示

### 五、折讓/退貨影響分析

| 指標 | 說明 |
|------|------|
| 銷貨折讓率 | 銷貨折讓/銷售金額 |
| 進貨折讓率 | 進貨折讓/採購金額 |
| 銷退率 | 銷退金額/銷售金額 |
| 退貨率趨勢 | 近 3 年 HPA |
