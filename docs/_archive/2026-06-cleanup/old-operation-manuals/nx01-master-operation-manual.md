## 三、通用操作（鋼鐵星球範式，所有新範式主檔一致）

### 畫面結構（ASCII 示意）

```
┌─────────────────────────────────────────────┐
│ ← 返回   📁 系統設定 / 幣別主檔        12 筆幣別 │  ← 標題列
├─────────────────────────────────────────────┤
│ [資料瀏覽 Alt+1]  [詳細資料 Alt+2]            │  ← Tab
├─────────────────────────────────────────────┤
│ ◀ ◀ 1/3 ▶ ▶  A新增 E更正 F查詢 | D停用 匯出 R │  ← ERP 工具列
│                          顯示停用  選取  Q結束 │
├─────────────────────────────────────────────┤
│ 代碼   名稱      符號  小數  狀態              │  ← 列表
│ TWD    新台幣    NT$   0     ● 啟用            │
│ USD    美金      $     2     ● 啟用            │
│ JPY    日圓      ¥     0     ○ 停用            │
└─────────────────────────────────────────────┘
```

### 新增一筆
1. 按 **A**（或工具列「新增」）→ 自動跳到「詳細資料」Tab、出現空白表單。
2. 填欄位（標 `*` 為必填）。
3. 按 **S** 存檔 → 跳出確認框 → 確認 → 寫入。

### 編輯一筆
1. 在「資料瀏覽」用 **↑ ↓** 選列（或滑鼠點）。
2. 按 **E** 更正 → 進編輯模式（代碼類欄位鎖定不可改）。
3. 改完按 **S** 存檔。**改到一半想離開**會跳「存檔後離開 / 丟棄變更 / 取消」三選一，不會默默丟資料。

### 停用 / 啟用（軟刪除，系統不刪資料）
- 選一筆按 **D**：選到「啟用中」的 → 變停用；選到「已停用」的 → 變啟用。
- 停用的資料不會消失，按工具列「顯示停用」就看得到、可重新啟用。

### 查詢
- 按 **F** 開搜尋條，輸入代碼 / 名稱即時過濾（停 300 毫秒自動查），**ESC** 關閉。

### 批次
- 按「選取」→ 列表出現勾選框 → 勾多筆 → 「批次啟用 / 批次停用」。

## 五、手機操作

- 同一套畫面，手機自動變單欄：標題列 → Tab → 工具列（**可左右滑動**看到全部按鈕）→ 內容。
- 「資料瀏覽」「詳細資料」用上方 Tab 切換（手機沒鍵盤就用點的）。
- 表單在手機是單欄、電腦是兩欄，自動適應。
- ⚠️ 手機實際手感（按鈕大小、滑動順不順）請在實機驗收，我這邊沒辦法實機測。

## 八、已知問題 / 限制（誠實揭露）

1. **我無法在此環境跑 app**：23 個都通過 TypeScript 編譯檢查，但畫面實際長相、手機手感、鍵盤順不順、API 串接 runtime 是否正確，**需要實機驗收**。截圖也要實機補。請特別點幾個有外鍵的（車型、零件、職務權限視圖）看下拉有沒有正確帶出選項。
2. **外鍵下拉目前一次載前 100 筆**：零件、車型資料量大時下拉只看得到前 100 筆，建議未來改「搜尋式挑選」。
3. **職務權限視圖的「畫面」下拉需要 seed**：畫面字典（views）目前可能沒資料、下拉會空 → 要先 seed 畫面清單（屬資料面、我沒做）。
4. **複雜主檔的進階功能先簡化**：零件的價格版本歷史、品牌料號規則用 JSON 貼分段定義、公告的發布流程 / 附件 / 已讀統計 —— 進階 UI 還沒做，但核心新增/編輯/停用都能用。
