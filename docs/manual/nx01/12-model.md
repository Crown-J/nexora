# 車型基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-13
> 適用版本：PLUS / PRO（LITE 灰階）
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理「車型字典」的主角——一台車的「車廠品牌 × 車系 × 年式」組合。每一筆代表一個具體車型（含適用年式範圍），可進一步掛上引擎、變速箱、傳動方式、車體類型。建好車型後，「料件車型適配」（第 10 頁）才能把零件對應到對應車款。
- **使用者角色**：建檔人員 / 系統管理員建立與維護；一般員工不會進到這頁。
- **使用時機**：新車款上市建檔、車型改款要拆新車型、或補登某車型的引擎 / 變速箱 / 傳動配置時。

> 車型是「車型字典」的核心，被「料件車型適配」引用，是料件對應車款的基礎。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 車型字典 → **車型基本資料**
（路徑：`/dashboard/base/model`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進入新增（編輯模式）。
2. 填 **車型代碼**（必填、鎖定）、**車型名稱**（必填）、**車廠品牌**（必填）、**年式(起)**（必填）。
3. 視需要補：年式(迄)、引擎、變速箱、傳動方式、車體類型、排序。
4. 按 `S` 存檔，跳確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入代碼或名稱關鍵字。
2. 要看已停用資料，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選（依車廠品牌、車體類型等）、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 車型代碼鎖定不可改，其餘欄位可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- 通則：**車型代碼同公司內唯一、建立後不可改、停用為軟刪除**（不真刪、可復原）。
- **改款處理走「拆 model」**：車型改款不在同一筆上覆寫，而是新增一個新車型、以年式（年式(起) / 年式(迄)）界定各自適用範圍。一個車系跨多個年式區間，就是多筆車型。
- **年式範圍**：以「年式(起)」「年式(迄)」表示適用年份；迄留空代表現行 / 未定。
- **與料件車型適配的關係**：「料件車型適配」（part_model）為純關聯——只記錄「哪個零件對應哪個車型」，**不在關聯上混入年份業務邏輯**；年份語意完全由本頁的車型年式區間承擔。
- 被「料件車型適配」引用中的車型建議只停用、勿視為可刪，以免破壞已建立的料件對應關係。
