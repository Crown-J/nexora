# 變速箱基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-15
> 適用版本：PLUS / PRO（LITE 灰階）
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理「變速箱字典」。每一筆是一具變速箱的基礎資料——代碼、名稱、變速型式（手排 / 自排…）、檔位數。建好之後，「車型基本資料」（第 12 頁）可以把變速箱掛上去，描述某車型搭載哪具變速箱。
- **使用者角色**：建檔人員 / 系統管理員建立與維護；一般員工不會進到這頁。
- **使用時機**：整理車型字典、新變速箱建檔、補登某具變速箱的型式與檔位數時。

> 變速箱是「車型字典」分區的一環，本身只是被「車型」引用的基礎清單，不直接連到單據。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 車型字典 → **變速箱基本資料**
（路徑：`/dashboard/base/transmission`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進入新增（編輯模式）。
2. 填 **代碼**（必填、鎖定）、**名稱**（必填）、**變速型式**（必填）。
3. 視需要補：檔位數、英文名稱、車廠品牌、排序。
4. 按 `S` 存檔，跳確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入代碼或名稱關鍵字。
2. 要看已停用資料，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 代碼鎖定不可改，其餘欄位可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- 標準字典主檔，無特殊計算或連動邏輯。通則：**代碼同公司內唯一、建立後不可改、停用為軟刪除**（不真刪、可復原）。
- **變速型式必填**：每具變速箱一定要指定型式（手排 / 自排 / 雙離合 / CVT / AMT / 其他）。
- **檔位數選填**：CVT 等無段變速可留空。
- **車廠品牌為選填關聯**，僅作標示，不影響車型掛載時的選擇。
- 被「車型」引用中的變速箱建議只停用、勿視為可刪，以免破壞已建立的車型關聯。
