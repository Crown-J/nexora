# 零件基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-05
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：整個系統最核心的主檔——所有要賣、要進、要管庫存的「料號」都在這裡建檔。一筆零件包含它的料號、品名、廠牌、規格、成本、四種售價，以及「正廠對應料號」（同一顆東西在原廠的料號）。後續採購、銷貨、庫存全靠這裡的料號。
- **使用者角色**：建檔人員 / 業務 / 系統管理員（後端限系統管理員 SYSADMIN 與負責人 OWNER 可寫）。
- **使用時機**：新料進廠建檔、調整售價、補正廠對應料號、把舊系統的舊料號接進來、料件停產時停用。

> 本頁是自訂頁（非泛型主檔），因為料號有「編碼規則分段輸入 + 即時預覽」「正廠對應子表」「售價自動計算」「三軌搜尋」等複雜互動。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 產品與料號 → **零件基本資料**
（路徑：`/dashboard/base/parts`）

## 3. 欄位定義

詳細頁分 6 區：基本 / 商品 / 正廠對應料號 / 規格 / 價格 / 系統。

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進編輯模式。
2. **決定料號方式**：
   - 想用規則 → 選「編碼規則」，下方出現 SEG1～5 分段輸入框，逐段填，料號自動組合並即時預覽。
   - 不用規則 → 編碼規則留「不套用」，直接在「料號」手動輸入。
3. 填品名（必填），視需要填舊料號。
4. 商品區選廠牌 / 群組 / 產地 / 料件類型 / 原廠。
5. 正廠對應：點「新增正廠對應」逐筆加（廠牌 + 正廠料號 + 備註）。
6. 規格區填規格 / 單位 / 保固。
7. 價格區填成本後按「依成本重算」自動帶 A/B/C/D，或手動填；可再微調。
8. `Alt+S` 存檔 → 確認 `Enter`。

### 5.2 查詢資料
1. `F` 開搜尋，輸入料號、舊料號、品名、或正廠料號任一片段。
2. 命中時列表料號旁標示「主料號」（綠）或「替代品」（藍，表示是靠正廠對應料號命中）。
3. 「顯示停用」可看已停用料件。

### 5.3 修改資料
1. 選到目標、`E`（會重新抓完整資料含正廠對應）。
2. 改任何欄位 / 增減正廠對應列 / 重算售價。
3. `Alt+S` 存檔。每次存檔系統自動留一筆版本快照（part_version）。

### 5.4 停用 / 啟用資料
1. 選到料件、`D`。啟用中→停用、已停用→啟用。`Enter` 確認。
2. 停用的料件預設列表隱藏，可由「顯示停用」找回。

## 6. 業務規則與特殊邏輯

### 編碼規則互動
- **選規則 → 分段輸入**：選了編碼規則，料號改由 SEG1～SEG5 分段輸入產生，每段字數受該規則的設定上限約束（見 [08 品牌料號規則](./08-brand-code-rule.md)）；料號欄變唯讀、顯示即時組好的預覽。
- **不選 → 手動輸入**：編碼規則留空時，直接手動打料號。
- ⚠️ **後端強制必填**：雖然前端允許「不套用」，後端 `codeRuleId` 為強制必填——必須先在「品牌料號規則」建好規則才能建零件（早期的「自動建規則 auto-vivify」已移除）。實務上請先建規則。

### 完整料號顯示格式（displayCode）
- 格式：`{零件品牌代碼} - {SEG1 SEG2 …（單空格）} #{產地代碼}`
- 範例：`VAG - 03H 115 562 H #DEU`
- 規則：SEG 各段一律以**單一空格**串接（分隔符欄位已移除）；品牌缺則省略品牌前綴、產地缺則省略 `#產地`。
- displayCode **不存資料庫**，列表 / 明細顯示時即時組合（有套規則才組完整格式，否則原樣顯示手動料號）。

### 售價 A/B/C/D 自動計算
- 「依成本重算」按 **成本 × 毛利率** 計算：**A = 成本 × 1.12（12%）/ B × 1.15（15%）/ C × 1.18（18%）/ D × 1.22（22%）**，對應客戶分級 A/B/C/D。
- 成本須 > 0 才能重算；重算後可再手動微調個別售價。
- ⚠️ 此自動計算是**前端 UI 行為**；後端不自動算售價，只原樣儲存填入的數字（任一售價有變更時，後端會自動記錄「售價更新時間 / 更新人員」）。

### 正廠對應料號子表
- 一顆零件（尤其副廠件）可對應多筆正廠料號。
- 存檔採「整批取代」：先清掉舊的、再依目前畫面逐筆寫入；空白的正廠料號列自動略過。

### 搜尋強化（多軌命中）
- 搜尋時系統把關鍵字與資料都**正規化**（去掉空白、`-`、`#` 並轉小寫）再比對，因此「VAG-03H」「VAG 03H」「03H 115 562」三種寫法都能命中同一顆。
- 命中來源涵蓋：主料號、舊料號、副廠料號、正廠對應料號（子表），品名則以原詞比對。
- 列表標示命中類型：命中主料號 / 品名等 → 標「主料號」；僅靠正廠對應料號命中 → 標「替代品」。

### 其他
- **欄位語意**：舊料號＝舊系統 / 客戶慣用料號（永遠可填）；成本＝進貨成本（小數 4 位）。
- **唯一性**：同公司內（料號 + 產地）不可重複。
- **UNK 保留值**：零件廠牌 / 產地不可選代碼為 `UNK` 的保留值。
- **版本快照**：每次修改都會寫一筆版本記錄（part_version），保留異動軌跡。
- **權限**：後端限系統管理員（SYSADMIN）與負責人（OWNER）可新增 / 修改 / 停用。
- **軟刪除**：停用＝`isActive=false`，不真刪、可復原。
