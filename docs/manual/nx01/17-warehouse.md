# 倉庫基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-06
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理公司的倉庫。倉庫掛在「據點」（第16頁）底下，倉庫底下再分「庫位」（第18頁）。所有庫存的進、出、調撥都以倉庫為單位。
- **使用者角色**：系統管理員 / 公司負責人 / 倉管主管。
- **使用時機**：開新倉、調整倉別、倉庫停用時。各版本預設倉庫數不同：LITE 1 倉、PLUS 2 倉、PRO 6 倉。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 組織架構 → **倉庫基本資料**
（路徑：`/dashboard/base/warehouses`）

## 3. 欄位定義

| 欄位名稱 | 型別 | 必填 | 預設值 | 限制 | 業務語意 |
|---------|------|------|--------|------|---------|
| 倉庫代碼 | 文字 | 是 | — | 自動轉大寫；建立後不可改；同公司內不可重複 | 倉庫代碼（如 MW1、BW1）|
| 倉庫名稱 | 文字 | 是 | — | — | 倉庫名稱（如 主倉 MW1）|

## 4. 按鈕與功能

config-driven 泛型主檔，沿用共通工具列（見 [index.md](./index.md)）：A 新增 / E 更正 / F 查詢 / D 停用-啟用 / P 匯出 / R 重新整理 / L 欄位 / T 篩選 / Q 結束；編輯模式 S 存檔 / C 取消。

| 按鈕 | 快捷鍵 | 功能 |
|------|--------|------|
| A 新增 | `Alt+A` | 新增倉庫 |
| E 更正 | `Alt+E` | 編輯選取倉庫 |
| F 查詢 | `Alt+F` | 搜尋代碼 / 名稱 |
| D 停用 / 啟用 | `Alt+D` | 軟停用 / 啟用 |
| P / R / L / T / Q | `Alt+R/L/T/Q` | 匯出 / 重新整理 / 欄位 / 篩選 / 結束 |
| S / C | `Alt+S/C` | 存檔 / 取消 |

## 5. 操作流程

### 5.1 新增資料
1. 先確認已有「據點」（沒有據點無法建倉庫，見 §6）。
2. 按 `A` 進編輯模式。
3. 填倉庫代碼（必填、轉大寫）、倉庫名稱（必填）。
4. 選所屬據點（必填；不選會自動帶主據點）、視需要選倉別。
5. `Alt+S` 存檔 → 確認。

### 5.2 查詢資料
1. `F` 搜尋代碼 / 名稱；「顯示停用」看已停用倉庫。

### 5.3 修改資料
1. 選到倉庫、`E`。倉庫代碼鎖定不可改，可改名稱 / 所屬據點 / 倉別 / 備註。
2. `Alt+S` 存檔。

### 5.4 停用 / 啟用資料
1. 選到倉庫、`D`。`Enter` 確認。
2. ⚠️ 停用前確認底下沒有還在用的庫位、也沒有未結的庫存。

## 6. 業務規則與特殊邏輯

- **所屬據點必填**：每個倉庫一定屬於一個據點。新增時若沒指定，系統自動帶「主據點優先」的第一個據點；若整家公司還沒有任何據點，會擋下並提示「請先建立據點再建倉庫」。
- **倉別型錄（系統預設、不可自建）**：倉別是全系統共用型錄，分總倉（H）/ 主倉（M）/ 分倉（W）/ 衛星倉（S），由系統預設、不可自行新增。
- **流向模式（flowMode，C / D）**：⚠️ 此設定**在「倉別」型錄上、不在倉庫本身**——`C = 集中管理`、`D = 分倉管理`，用來控制「進貨後是否自動調撥」的觸發邏輯。系統種子預設：總倉（H）為 C、主倉 / 分倉 / 衛星倉（M/W/S）為 D。倉庫頁本身不直接編輯 flowMode。
- **各版本預設倉庫數**：LITE 1 倉（主倉 MW1）、PLUS 2 倉（MW1 + 分倉 BW1）、PRO 6 倉（總倉 HW1 + 主倉 MW1 + 分倉 BW1～BW4）。⚠️ 此為種子配置；後端 service 未對倉庫數量上限做檢查（數量天花板屬版本設計、非後端硬限制）。
- ⚠️ **主倉旗標 / 倉管主管欄位**：資料庫已備「is_main（主倉）」「倉管主管」「結構化地址」等欄位，但目前倉庫的新增 / 編輯介面與後端 service **尚未維護這些欄位**（與據點的主據點互斥處理不同）；屬已備未用，待後續軌補。
- **代碼唯一**：倉庫代碼同公司內不可重複（不分大小寫）。
- **軟刪除**：停用＝`isActive=false`，不真刪、可復原。

## 7. 鍵盤快捷鍵總表

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+1` / `Alt+2` | 切資料瀏覽 / 詳細資料 |
| `↑` `↓` / `Enter` | 切換選取列 / 進詳細（或表單跳格）|
| `Alt+A` / `Alt+E` / `Alt+F` / `Alt+D` | 新增 / 更正 / 查詢 / 停用-啟用 |
| `Alt+R` / `Alt+L` / `Alt+T` / `Alt+Q` | 重新整理 / 欄位 / 篩選 / 結束 |
| `Alt+S` / `Alt+C` | 存檔 / 取消（編輯模式）|
| `Enter` / `Esc` / `D` | 確認視窗：確認 / 取消 / 丟棄變更 |
