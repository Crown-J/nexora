# 引擎基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-14
> 適用版本：PLUS / PRO（LITE 灰階）
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理「引擎字典」。每一筆就是一具引擎的基礎資料——它的代碼、名稱、燒什麼油、排氣量多少、用什麼進氣方式。建好之後，「車型基本資料」（第 12 頁）可以把引擎掛上去，描述一台車搭載的是哪具引擎。
- **使用者角色**：建檔人員 / 系統管理員建立與維護；一般員工不會進到這頁。
- **使用時機**：整理車型字典、新引擎上市要建檔、或某具引擎的規格（排氣量、進氣方式）要補登時。

> 引擎是「車型字典」分區的一環，本身只是被「車型」引用的基礎清單，不直接連到單據。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 車型字典 → **引擎基本資料**
（路徑：`/dashboard/base/engine`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進入新增（編輯模式）。
2. 填 **引擎代碼**（必填、建立後不可改）、**引擎名稱**（必填）、**燃料別**（必填）。
3. 視需要補：排氣量、進氣方式、車廠品牌、排序。
4. 按 `S` 存檔，跳確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入代碼或名稱關鍵字。
2. 要看已停用資料，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 引擎代碼鎖定不可改，其餘欄位可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- 標準字典主檔，無特殊計算或連動邏輯。通則：**引擎代碼同公司內唯一、建立後不可改、停用為軟刪除**（不真刪、可復原）。
- **燃料別必填**：每具引擎一定要指定動力別（汽油 / 柴油 / 油電 / 純電）。
- **進氣方式選填**：純電 EV 通常無進氣 / 增壓概念，可留空。
- **車廠品牌為選填關聯**：用來標示這具引擎屬於哪個車廠，不影響車型掛載時的選擇。
- 被「車型」引用中的引擎建議只停用、勿視為可刪——軟刪除即為此設計，避免破壞已建立的車型關聯。
