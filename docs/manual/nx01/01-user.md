# 使用者基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-01
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理公司內部「誰可以登入系統」。每一筆就是一位員工的登入帳號，連同他的姓名、聯絡方式、擔任的職務、負責的倉庫，以及帳號是否還在用。
- **使用者角色**：系統管理員 / 公司負責人（OWNER）建立與維護；一般員工不會進到這頁。
- **使用時機**：新人報到開帳號、員工離職停用帳號、調整某人職務或負責倉庫、員工忘記聯絡方式要更新時。

> 這頁是自訂頁（非泛型主檔），因為使用者牽涉「擔任職務」「隸屬倉庫」兩個關聯子表，比一般主檔複雜。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 帳號與權限 → **使用者基本資料**
（路徑：`/dashboard/base/users`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A`（或點「新增」），跳出「新增使用者」視窗。
2. 填 **帳號**（必填）、**姓名**（必填）；可選填啟用狀態 / 信箱 / 電話。
3. 系統提示初始密碼為 `nexora@2026`，使用者首次登入會被要求修改。
4. 點「建立」（或 `Esc` 取消）。建立成功後回列表。
5. 新帳號的職務 / 倉庫：先選到該筆 → `E` 進編輯 → 用「設定職務 / 設定據點」指派。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入帳號或姓名關鍵字。
2. 需要看已停用帳號時，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選（依職務、倉庫、啟用狀態等）、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好後按 `E`。
2. 基本資料可改：**姓名 / 啟用狀態 / 信箱 / 電話**（帳號、職務、倉庫不在此直接改）。
3. 調整職務：「設定職務」勾 / 反勾；用子表上「設為主要」改主要職務。
4. 調整倉庫：「設定據點」勾 / 反勾。
5. 以上變更都先暫存（畫面顯示「待存檔」），按 `S` 一次寫入、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標帳號，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。
4. ⚠️ 不能停用自己（會提示「Cannot deactivate self」）。

## 6. 業務規則與特殊邏輯

- **首次登入強制改密碼**：所有新建帳號一律用預設密碼 `nexora@2026` 建立，使用者首次登入時系統要求修改。（前端新增視窗明示；⚠️ `mustChangePassword` 旗標未在 `Nx01User` schema 證實，強制改密碼流程由 auth 模組處理。）
- **軟停用、不可硬刪**：停用＝`isActive=false`，資料保留可復原。**不能停用自己**。
- **系統管理員（SYSADMIN）鎖定**：
  - 非系統管理員的操作者，看不到、也不能編輯 / 停用「擁有系統管理員職務」的帳號（後端直接當「查無此人」）。
  - 帳號本身含 SYSADMIN 職務者，「擔任職務 / 隸屬倉庫」區塊唯讀灰掉——系統管理員預設擁有所有權限、無需設定。
  - 職務指派視窗永遠不會出現 SYSADMIN（前後端雙重過濾）。
- **唯一性**：同一公司內「帳號」不可重複（不分大小寫）、「信箱」不可重複。
- **多職務 + 主要職務**：一人可擔任多個職務，其中一個為「主要」（列表顯示的就是主要職務）。**主要職務不可直接撤銷**，要先把另一個職務設為主要、再撤銷原本的。
- **多倉指派（PLUS+）**：一人可隸屬多個倉庫據點；倉庫無「主要」概念，只能新增 / 撤銷。
- **暫存批次寫入**：編輯模式下所有職務 / 倉庫變更都先暫存，按 `S` 才一次送出（避免「按取消卻已寫入」）；按 `C` 全部放棄。
- ⚠️ **已知後端待辦**：目前撤銷職務 / 倉庫為「軟刪除」（`isActive=false`），Crown 需求是改為真刪除（避免再次指派同一職務撞唯一鍵）。前端介面不受影響，待後端調整。
- **帳號鎖定**：連續登入失敗次數 / 鎖定到期（`failedLoginCount` / `lockedUntil`）邏輯在登入（auth）模組處理，不在本頁。
