## 模組總覽

NX01 主檔管理是 NEXORA GRID 的基礎模組，提供所有後續業務模組（採購 NX02 / 銷貨 NX03 / 庫存 / 財務 NX05 / 物流 NX06 / 人資 NX07）所需的基礎資料。每一個主檔頁都是「先把基礎資料建好，後面的單據才有東西可選」的源頭。

所有主檔頁採同一套「鋼鐵星球」操作範式：暗色介面 + 琥珀色（#E8A020）重點色、全鍵盤操作、列表/詳細雙頁籤、軟刪除（停用而非真刪）。學會一頁，其餘 23 頁的操作邏輯完全相同，差別只在「欄位」與「業務規則」。

## 共通操作慣例（讀一次，各頁不重複）

整個 NX01 模組共用以下操作慣例。各頁的「§4 按鈕」「§5 操作流程」「§7 快捷鍵」皆以此為基準，只在有差異時額外標註。

### A. 介面結構

- **置頂列**：返回 · 模組選單 · 頁面標題 · 資料筆數 · 公告 · 通知 · 使用者。
- **雙頁籤**：
  - 「資料瀏覽」（`Alt+1`）：列表，整頁顯示所有資料列。
  - 「詳細資料」（`Alt+2`）：單筆的完整欄位（瀏覽 / 編輯）。
- **工具列**：在頁籤下方，依模式（瀏覽 / 編輯）顯示不同按鈕。

### B. 工具列按鈕（瀏覽模式）

| 按鈕 | 字母 | 快捷鍵 | 功能 |
|------|------|--------|------|
| 新增 | A | `Alt+A` | 開新增、進入編輯模式 |
| 更正 | E | `Alt+E` | 編輯目前選取列（需先選列） |
| 查詢 | F | `Alt+F` | 開 / 關搜尋列（關鍵字搜代碼 / 名稱） |
| 停用 / 啟用 | D | `Alt+D` | 軟刪除：啟用列→停用、停用列→啟用 |
| 匯出 | P | （點選）| 下拉：CSV / PDF / 列印（目前僅 **CSV** 真正匯出，PDF / 列印顯示「尚未開放」）。匯出「所見即所得」：只含目前可見欄位 + 篩選後資料列。**P 為顯示字母、未綁 `Alt+P`，需滑鼠點開下拉** |
| 重新整理 | R | `Alt+R` | 重新載入列表 |
| 欄位 | L | `Alt+L` | 欄位設定（隱藏 / 顯示欄位） |
| 篩選 | T | `Alt+T` | 進階篩選（多條件，就本頁已載入資料套用） |
| 顯示停用 | — | （點選）| 切換是否一併顯示已停用資料（預設只看啟用） |
| 選取 | — | （點選）| 進入多選模式，可批次啟用 / 停用 |
| 結束 | Q | `Alt+Q` | 回到儀表板 |

### C. 工具列按鈕（編輯模式）

| 按鈕 | 字母 | 快捷鍵 | 功能 |
|------|------|--------|------|
| 存檔 | S | `Alt+S` | 跳確認視窗，確認後寫入 |
| 取消 | C | `Alt+C` | 離開編輯（若有未存變更，跳 3 選 1 確認） |

### D. 鍵盤導航

- 列表頁：`↑` `↓` 切換選取列（自動鎖定第一列，進頁面就能用）、`Enter` 進入該列「詳細資料」。
- 編輯表單：`Enter` 跳下一格，最後一格 `Enter` = 跳存檔確認；多行欄位（內容 / 說明）的 `Enter` 為換行、不跳格。
- 下拉欄位（職務、廠牌等）：`Enter` 展開 → `↑↓` 選 → `Enter` 確認並跳格 → `Esc` 收合。
- `Esc`：搜尋列開啟時關閉搜尋；編輯模式中等同「取消」。

### E. 確認視窗（存檔 / 停用 / 丟棄變更）

所有寫入動作都先跳確認視窗，鍵盤對應固定：

| 鍵 | 動作 |
|----|------|
| `Enter` | 確認（預設動作，視窗開啟即聚焦此鈕） |
| `Esc` | 取消（不執行、留在原處） |
| `D` | 丟棄變更（僅「尚有未儲存變更」的 3 選 1 視窗才有） |

編輯中若有未存變更要離開（按 C / 切頁籤 / 點模組選單），會跳「存檔後離開 / 丟棄變更 / 取消」3 選 1。

### F. 軟刪除（系統不刪資料）

NEXORA **不提供真正刪除**。所有「D」鍵都是「停用」（`isActive=false`），避免破壞已被單據引用的關聯資料。停用的資料：

- 預設列表看不到，打開工具列「顯示停用」即可看到。
- 選中已停用列，「D」鍵會變成「啟用」，可隨時復原。

### G. 新增 / 修改 / 系統欄位

- 多數主檔的「代碼」欄位**建立後不可改**（鎖定），其餘欄位可改。
- 必填欄位標紅色 `*`，留空存檔會被擋下並提示「『○○』為必填」。
- 每筆資料都記錄並顯示 **建立時間 / 建立人員 / 修改時間 / 修改人員**（唯讀），系統內碼（id 等）不顯示給使用者。
- 時間一律中文化顯示（如 `2026-05-28 14:30`）。

### H. 版本可見性

LITE / PLUS / PRO 三版本。標示 PLUS / PRO 的主檔，LITE 用戶在「主檔總覽」會看到卡片但呈灰階 + 升級提示。此為前端引導，正式路由守門於後續軌（TASK-NX99-PLAN-MIDDLEWARE）才上。
