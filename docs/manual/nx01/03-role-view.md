# 職務權限設定

> 模組：NX01 主檔管理
> 頁面代碼：NX01-02（職務權限矩陣，職務基本資料的延伸設定頁）
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28
>
> ⚠️ 本頁為「設定頁」、非帶「基本資料」後綴的標準主檔，但操作獨立、互動最複雜（雙欄矩陣 + 全鍵盤），故單獨成冊。

## 1. 頁面說明

- **業務語意**：設定「哪個職務能對哪個畫面做什麼」。把職務（業務、倉管、財務…）與系統各畫面排成一張矩陣，逐格勾選「瀏覽 / 新增 / 修改 / 停用 / 匯出」五種權限。這張表決定員工登入後看得到、改得動哪些功能。
- **使用者角色**：系統管理員設定（一般職務碰不到此頁）。
- **使用時機**：公司導入時依種子預設微調；新增職務後設定其權限；組織調整要收緊 / 放寬某職務的權限時。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 帳號與權限 → **職務權限設定**
（路徑：`/dashboard/base/role-view`）

## 3. 畫面結構與欄位定義

本頁不是逐筆表單，而是一張「職務 × 畫面 × 權限」矩陣。

### 上方：職務選擇

| 元件 | 說明 |
|------|------|
| 職務下拉 | 選一個職務後，下方矩陣顯示該職務的權限。**系統管理員（SYSADMIN）與負責人（OWNER）不會出現在下拉**——這兩個職務預設全通行、無需設定 |
| 存檔 (Alt+S) | 把矩陣上的所有變更一次寫入；有未存變更時顯示「● 有未存檔變更」|

### 下方：權限矩陣

- **列（畫面）**：所有系統畫面，依模組分群成手風琴（一次只展開一個模組）。模組以中文顯示：主資料中心（NX01）/ 進貨作業（NX02）/ 銷貨作業（NX03）/ 庫存管理（NX04）/ 財務管理（NX05）/ 物流配送（NX06）/ 人資管理（NX07）/ 報表分析（NX08）/ 知識中心（NX09）/ 員工激勵（NX10）/ 系統管理（NX99）。
- **欄（5 種權限）**：

| 權限欄 | 內部旗標 | 業務語意 |
|--------|---------|---------|
| 瀏覽 | canRead | 能進入並查看此畫面（預設值：新建一格時為「開」）|
| 新增 | canCreate | 能在此畫面新增資料 |
| 修改 | canUpdate | 能編輯此畫面的資料 |
| 停用 | canDelete | 能停用（軟刪除）此畫面的資料 |
| 匯出 | canExport | 能匯出此畫面的資料 |

- **格子**：每個「畫面 × 權限」交叉點是一個可勾選方格（✓ = 有權限）。

## 4. 按鈕與功能

> 本頁為自訂矩陣頁，**沒有**標準主檔的 A/E/F/D 工具列。操作集中在矩陣勾選與三層全選。

| 按鈕 | 快捷鍵 | 功能 | 行為 |
|------|--------|------|------|
| 職務下拉 | `Alt+↑` / `Alt+↓` | 切換設定中的職務 | 切換後載入該職務權限 |
| 權限格 | `空白鍵` | 勾選 / 取消單一權限 | 切換該格 ✓ |
| 整列全選 / 清除 | `A`（焦點在畫面列時）| 該畫面 5 種權限一次全勾 / 全清 | 已全勾→清空、否則全勾 |
| 整模組全選 / 清除 | （點選模組標題列的按鈕）| 該模組所有畫面 × 5 權限一次全勾 / 全清 | 同上邏輯 |
| 模組展開 / 收合 | `→` 展開 / `←` 收合 / `Enter` 切換（焦點在模組標題列時）| 手風琴單展開 | 展開一個會自動收起其他 |
| 存檔 | `Alt+S` | 批次寫入所有變更 | 跳結果提示（成功 N 項 / 部分失敗）|
| 結束 | `Alt+Q` | 離開回儀表板 | 有未存變更會先跳確認 |

## 5. 操作流程

### 5.1 設定某職務的權限（本頁的核心流程，取代「新增 / 修改」）
1. 在上方下拉選擇要設定的職務（或 `Alt+↑↓` 切換）。
2. 下方矩陣載入該職務目前的權限。
3. 用 `→` / `Enter` 展開要設定的模組（如「進貨作業」）。
4. `↑↓` 移到目標畫面列、`←→` 移到目標權限欄、`空白鍵`勾選 / 取消；或按 `A` 對整列一次全開 / 全關；或點模組標題的「整模組全選」一次設定整個模組。
5. 完成後 `Alt+S` 存檔，跳出「已存檔 N 項權限變更」。

### 5.2 查詢（查看某職務有哪些權限）
1. 選職務 → 展開各模組即可檢視目前的勾選狀態（✓ 即有權限）。

### 5.3 修改
1. 同 5.1：改勾選後 `Alt+S`。系統自動判斷每一格：原本無、現在有勾 → 新增權限；原本有、現在改動 → 更新；原本有、現在全清 → 移除該畫面的權限記錄。

### 5.4 停用 / 啟用
- 本頁無獨立「停用」概念。取消某畫面的所有勾選並存檔，等同移除該職務對該畫面的權限。

## 6. 業務規則與特殊邏輯

- **預設 826 筆權限（7 職務 × 118 畫面）**：系統種子（seed）為每個租戶建立 7 個職務 × 118 個畫面 = **826** 筆權限預設值，導入即有合理基礎、再依需求微調。
- **系統管理員 / 負責人全通行、不進矩陣**：SYSADMIN 與 OWNER 預設擁有全部畫面的全部權限（由後端 RolesGuard 直接放行、不查矩陣明細）。因此這兩個職務**不出現在職務下拉**，矩陣實際可編輯的是其餘 5 個職務（業務 / 倉管 / 財務 / 人資 / 採購）× 118 畫面。前後端雙重過濾，避免誤改系統角色權限。
- **暫存批次寫入**：所有勾選都先在本機累積（顯示「● 有未存檔變更」），按 `Alt+S` 才一次比對差異送後端。離開前若有未存變更會跳確認。
- **三層全選**：單格（空白）→ 整列（A，一個畫面的 5 權限）→ 整模組（按鈕，一個模組所有畫面）。設定大模組時由粗到細很省事。
- **手風琴單展開**：一次只展開一個模組，畫面不會被一長串清單淹沒。
- **新建格預設**：新勾選一個畫面時，後端建立的權限預設「瀏覽=開、其餘=關」（先給看、再逐項放開）。
- ⚠️ 矩陣需要「畫面字典（nx01_view）」已 seed 才有畫面可設；若顯示「尚無畫面字典」，需先匯入畫面清單。
- ⚠️ 本頁後端 service 目前未寫稽核日誌（與其他主檔不同），權限異動不留 audit log。

## 7. 鍵盤快捷鍵總表

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+↑` / `Alt+↓` | 切換上 / 下一個職務 |
| `↑` `↓` | 矩陣換列（畫面 / 模組標題）|
| `←` `→` | 換權限欄；焦點在模組標題列時為收合 / 展開 |
| `Enter` | 焦點在模組標題列時：切換展開 / 收合 |
| `空白鍵` | 勾選 / 取消目前焦點權限格；焦點在模組標題列時切換展開 |
| `A` | 焦點在畫面列時：整列 5 權限全勾 / 全清 |
| `Alt+S` | 存檔（批次寫入）|
| `Alt+Q` | 結束（有未存變更先確認）|
