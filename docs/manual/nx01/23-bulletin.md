# 公告基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-08
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理公司 / 系統公告。每一筆就是一則公告，發布後會顯示在系統置頂列（鈴鐺通知）給全公司員工看。
- **使用者角色**：系統管理員 / 主管發布；一般員工只在置頂列被動看到，不進到這頁。
- **使用時機**：要發布公司通知、系統維護預告、重要事項提醒，或要把過期 / 失效的公告收掉時。

> 公告屬「系統設定」分區，是少數會主動推播給全員看的主檔。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 系統設定 → **公告基本資料**
（路徑：`/dashboard/base/bulletins`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進入新增（編輯模式）。
2. 填 **標題**（必填）。
3. 視需要補：內容、重要性（一般 / 重要 / 緊急）、是否置頂、到期日。
4. 按 `S` 存檔，跳確認後寫入；公告隨即顯示在置頂列。

> 內容為多行欄位，輸入時 `Enter` 為換行、不跳格（見 index.md §D）。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入標題關鍵字。
2. 要看已停用 / 過期公告，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選（如依重要性篩）、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 標題、內容、重要性、置頂、到期日皆可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後不再於置頂列顯示，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- **置頂公告優先顯示**：開啟「置頂」的公告會被排到置頂列最上方，優先被員工看到。
- **重要性影響呈現樣式**：一般 / 重要 / 緊急會以不同視覺強度（如顏色 / 標記）呈現，提醒員工注意程度。
- **到期日後自動隱藏**：超過到期日的公告不再顯示給員工（資料仍保留，可在本頁查到）。到期日為選填，留空代表不自動下架。
- ⚠️ **公告附件子表（NX01-08 軌 3 建立）**：公告另有「附件」功能（檔案上傳 / 下載），但附件管理 **不在本主檔頁的泛型表單內**，屬於另一個介面。本頁只管公告本文。
- 通則：**停用為軟刪除**（不真刪、可復原）。
