# 國家基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-09 相關（⚠️ 國家型錄內碼待確認）
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理「國家代碼型錄」。每一筆就是一個國家，給其他欄位當下拉選項用——例如零件的「產地」、車廠品牌的「國別」、零件廠牌的「國別」都會參照這張清單。
- **使用者角色**：系統管理員 / 建檔人員維護。
- **使用時機**：需要新增一個尚未建檔的國家、或調整國家顯示名稱 / 排序時。

> 這是「系統設定」分區的基礎型錄，本身只是被其他主檔引用的清單，不直接連到單據。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 系統設定 → **國家基本資料**
（路徑：`/dashboard/base/country`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進入新增（編輯模式）。
2. 填 **國家代碼**（必填、三碼、會自動轉大寫、建立後不可改）、**國家名稱**（必填）。
3. 視需要設定排序。
4. 按 `S` 存檔，跳確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入代碼或名稱關鍵字。
2. 要看已停用資料，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 國家代碼鎖定不可改，其餘欄位可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- **國家代碼採 ISO alpha-3 三碼**：例如 TWN（台灣）、DEU（德國）、JPN（日本）、USA（美國）、CHN（中國）、KOR（南韓）。輸入小寫會自動轉大寫。
- ⚠️ **新增框 placeholder 為過時範例**：目前新增框的提示文字仍顯示舊的兩碼範例「TW」（屬 A033 family 待修），**請忽略該範例、實際請填三碼**（如 TWN）。
- 通則：**國家代碼同公司內唯一、建立後不可改、停用為軟刪除**（不真刪、可復原）。被其他主檔（產地 / 國別）引用中的國家建議只停用、勿視為可刪。
