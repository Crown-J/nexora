# 車廠品牌基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-12
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理汽車製造商品牌（例：Toyota、VW、BMW、Audi…）。這是「車型」「引擎」往上歸屬的源頭，也用來判斷某個零件適用哪一個車廠。
- **使用者角色**：由建檔人員 / 主管維護；建好後給其他主檔（車型、引擎）與零件當下拉選項用。
- **使用時機**：公司開始經手某個新品牌的車、要在系統裡建立該品牌的車型 / 引擎之前，先把品牌建好。

> 本頁是設定驅動的泛型主檔，操作邏輯與其他主檔完全一致，差別只在欄位與業務規則。共通的按鈕 / 流程 / 快捷鍵見 [index.md 共通操作慣例](./index.md)。

## 2. 進入路徑

## 5. 操作流程

### 5.1 新增資料
1. 按 `A`（或點「新增」），進入編輯模式。
2. 填 **品牌代碼**（必填、建立後不可改）、**品牌名稱**（必填）。
3. 可選填英文名稱、國別、Logo 網址、排序。
4. 按 `S` 存檔，跳確認視窗、`Enter` 確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入品牌代碼或名稱關鍵字。
2. 要看已停用品牌時，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好後按 `E`。
2. 除「品牌代碼」鎖定外，其餘欄位都可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標品牌，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- **代碼建立後不可改**：品牌代碼一旦建立就鎖定，避免下游的車型 / 引擎指向錯亂。
- **軟停用、不可硬刪**：停用＝資料保留可復原（`isActive=false`）。若已有車型 / 引擎掛在此品牌下，停用品牌不會影響既有資料，但建檔時下拉預設只看得到啟用中的品牌。
- **被誰引用**：車型基本資料、引擎基本資料都以「車廠品牌」為必填 / 選填上層；零件也用品牌資訊判斷適用車廠。
- **國別下拉**：來源是「國家基本資料」，一次載入前 100 筆啟用資料（⚠️ 資料量大時未來改搜尋式 picker）。
