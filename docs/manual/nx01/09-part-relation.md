# 零件關聯基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-17
> 適用版本：PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：記錄零件之間的關係——這顆改號變成那顆、兩顆功能相同可互換、舊版升級成新版、套包與組成料件、原件與拆出料件。讓系統能查替代料、組合料、拆解料。
- **使用者角色**：採購 / 業務維護（業務日常高頻使用）；建檔人員 / 主管亦可。
- **使用時機**：廠商料號改編、要登記替代品、建立保養套包或拆解規則時。

> 本頁是設定驅動的泛型主檔，操作邏輯與其他主檔完全一致。共通的按鈕 / 流程 / 快捷鍵見 [index.md 共通操作慣例](./index.md)。

## 5. 操作流程

### 5.1 新增資料
1. 按 `A`（或點「新增」），進入編輯模式。
2. 選 **來源零件**（必填）、**目標零件**（必填，不可與來源相同）。
3. 選 **關聯類型**（必填）：改號 / 同款 / 改版 / 組合 / 拆解。
4. 可選填排序。
5. 按 `S` 存檔，跳確認視窗、`Enter` 確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，依來源 / 目標零件搜尋。
2. 要看已停用關係時，點工具列「顯示停用」。
3. 可用 `Alt+T` 依關聯類型進階篩選。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好後按 `E`。
2. 調整來源 / 目標零件、關聯類型、排序。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標關係，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後查替代料 / 套包時不再顯示，但歷史保留。

## 6. 業務規則與特殊邏輯

五種關聯類型的白話意思：

| 關聯類型 | 白話解釋 | 例子 |
|---------|---------|------|
| 改號 | 舊料號被廠商改編成新料號，後續用新料號 | 8K0 819 439 → 8K0 819 439 A |
| 同款 | 兩顆功能等同、可互換（料號不同、品牌可能不同）| 原廠濾芯 ⇄ 副廠等效濾芯 |
| 改版 | 同一料件的版本演進，新版取代舊版 | 舊版 → 改良版 |
| 組合 | 來源是套包、目標是組成料件 | 機油保養套包 → 機油 / 濾芯 / 墊圈 |
| 拆解 | 來源是整組原件、目標是拆出的料件 | 原廠氣壓計組 → 計頭 + 管線組 |

- **不可自我關聯**：來源零件與目標零件不可是同一顆。
- **不可重複建**：相同「來源 + 目標 + 關聯類型」的關係不可重複建立。
- **同款建議雙向**：建立「同款」關係時，因 A 等同 B、B 也等同 A，系統會提示是否同時建立反向關係（B→A 同款）；由使用者自行決定，不強制。其餘四種（改號 / 改版 / 組合 / 拆解）為單向、無此提示。
- **兩端零件需啟用**：來源 / 目標零件都必須是啟用中的零件，不能對停用零件建新關係。
- **軟停用、不可硬刪**：停用＝資料保留可復原（`isActive=false`）；停用後查替代料 / 套包查詢隱藏該筆、歷史保留。
- **零件下拉**：來源是「零件基本資料」，一次載入前 100 筆啟用資料（⚠️ 零件資料量大，未來應改搜尋式 picker）。
