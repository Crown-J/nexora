# 職務基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-02
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理公司內的「職務」（角色頭銜），例如業務、倉管、財務、採購。職務是兩件事的基礎：① 指派給使用者（一個人擔任哪些職務）；② 設定權限（哪個職務能看 / 能改哪些畫面，見 [03 職務權限設定](./03-role-view.md)）。
- **使用者角色**：系統管理員 / 公司負責人維護。
- **使用時機**：通常在公司初次導入時由系統種子建好標準職務，少需新增；偶爾調整職務名稱或說明。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 帳號與權限 → **職務基本資料**
（路徑：`/dashboard/base/roles`）

## 4. 按鈕與功能

config-driven 泛型主檔，沿用共通工具列（見 [index.md §共通操作慣例](./index.md)）：A 新增 / E 更正 / F 查詢 / D 停用-啟用 / P 匯出 / R 重新整理 / L 欄位 / T 篩選 / Q 結束；編輯模式 S 存檔 / C 取消。

| 按鈕 | 快捷鍵 | 功能 |
|------|--------|------|
| A 新增 | `Alt+A` | 新增職務（進編輯模式）|
| E 更正 | `Alt+E` | 編輯選取職務 |
| F 查詢 | `Alt+F` | 搜尋代碼 / 名稱 |
| D 停用 / 啟用 | `Alt+D` | 軟停用 / 啟用 |
| P 匯出 | （點選）| CSV 匯出（所見即所得）|

## 5. 操作流程

### 5.1 新增資料
1. 按 `A`，切到詳細資料編輯模式。
2. 填職務代碼（必填、會轉大寫）、職務名稱（必填），可補說明 / 排序。
3. `Alt+S` 存檔 → 確認視窗 `Enter` 完成。

### 5.2 查詢資料
1. `F` 開搜尋，輸入代碼或名稱。
2. `Alt+T` 進階篩選、`Alt+L` 調整欄位、「顯示停用」看已停用職務。

### 5.3 修改資料
1. 選到目標、`E` 進編輯。職務代碼鎖定不可改，其餘可改。
2. `Alt+S` 存檔。

### 5.4 停用 / 啟用資料
1. 選到職務、`D`。啟用中→停用、已停用→啟用。`Enter` 確認。
2. ⚠️ 停用職務前請確認沒有使用者還掛著此職務、也沒有權限矩陣依賴它。

## 6. 業務規則與特殊邏輯

- **7 種精煉職務**：系統預設 7 種職務——系統管理員（SYSADMIN）、負責人（OWNER）、業務（SALES）、倉管（WAREHOUSE）、財務（FINANCE）、人資（HR）、採購（PURCHASING）。早期的「物流（LOGISTICS）」已移除（改由往來對象的運輸商類型承接）、「人資管理員（HR_ADMIN）」併入人資（HR）。
- **系統管理員 / 負責人預設全權限**：SYSADMIN 與 OWNER 兩個職務在系統中**預設擁有所有權限、全畫面通行**，不需也不會出現在職務權限矩陣（見 [03 職務權限設定](./03-role-view.md)）。
- **職務 vs 部門解耦**：職務（role）與部門（department）是兩套概念、命名不綁定（例如採購職務代碼為 PURCHASING、產品部門代碼為 PRODUCT，刻意不同步）。
- **標準型錄**：代碼同公司內唯一、軟刪除；多數情境用系統種子建好即可，少需手動新增。
