# 料件車型適配基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-16
> 適用版本：PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：把「零件」對應到「車型」，並標明適配程度。讓櫃台能反查「某台車能用哪些料」，也能查「某顆料能裝哪些車」。
- **使用者角色**：採購 / 業務維護（業務日常高頻使用）；建好後成為「客戶問適配」時的查詢依據。
- **使用時機**：建好一顆零件後，登記它適用哪些車型；或客戶問某車該用哪顆料時查詢。

> 本頁是設定驅動的泛型主檔，操作邏輯與其他主檔完全一致。共通的按鈕 / 流程 / 快捷鍵見 [index.md 共通操作慣例](./index.md)。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 產品與料號 → **料件車型適配基本資料**
（路徑：`/dashboard/base/part-model`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A`（或點「新增」），進入編輯模式。
2. 選 **零件**（必填）、**車型**（必填）。
3. 選 **適配等級**（必填）：原廠 / 副廠等效 / 通用。
4. 可選填排序。
5. 按 `S` 存檔，跳確認視窗、`Enter` 確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，依零件或車型搜尋。
2. 要看已停用適配時，點工具列「顯示停用」。
3. 可用 `Alt+T` 依適配等級進階篩選。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好後按 `E`。
2. 調整零件 / 車型 / 適配等級 / 排序。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標適配，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後查適配時不再顯示，歷史保留。

## 6. 業務規則與特殊邏輯

- **一料 + 一車 = 一行**：同一顆零件對同一個車型只能有一筆適配記錄，不可重複建。要改適配等級就編輯既有那筆。
- **適配等級的語意**（業務查替代料時的決策依據）：

  | 適配等級 | 語意 | 業務取捨 |
  |---------|------|---------|
  | 原廠 | 原廠 OEM 件，最高適配 | 優先推薦 |
  | 副廠等效 | 副廠生產、功能等效 | 次選，業務自行確認 |
  | 通用 | 通用替代品 | 慎選，需確認規格 |

- **改款 / 年份不在此處混**：同一車的不同改款 / 年份要在「車型基本資料」那邊拆成不同車型（例：前期 2017~2019、後期 2020~2024），本頁只負責「一料對一車」的純關聯。
- **兩端需啟用**：零件與車型都必須是啟用中的，不能對停用的料或車建適配。
- **軟停用、不可硬刪**：停用＝資料保留可復原（`isActive=false`）；停用後查適配查詢隱藏該筆、歷史保留。
- **零件 / 車型下拉**：來源分別是「零件基本資料」「車型基本資料」，各一次載入前 100 筆啟用資料（⚠️ 零件資料量大，未來應改搜尋式 picker）。
