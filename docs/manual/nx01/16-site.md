# 據點基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-06 相關（據點；⚠️ 確切 spec 內碼待確認，與倉庫同軌）
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：公司的「物理分點」——例如台北倉、台中倉、總公司。據點是倉庫的上一層：先有據點，據點底下才掛倉庫（第17頁），倉庫底下再分庫位（第18頁）。一個分點的地址、電話也記在這裡。
- **使用者角色**：系統管理員 / 公司負責人。
- **使用時機**：公司開新分點、搬遷、調整主據點時。LITE 版預設只有一筆「總公司」。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 組織架構 → **據點基本資料**
（路徑：`/dashboard/base/site`）

## 3. 欄位定義

| 欄位名稱 | 型別 | 必填 | 預設值 | 限制 | 業務語意 |
|---------|------|------|--------|------|---------|
| 據點代碼 | 文字 | 是 | — | 自動轉大寫；建立後不可改；同公司內不可重複 | 據點的代碼（如 HQ、TPE）|
| 據點名稱 | 文字 | 是 | — | — | 據點名稱（如 總公司、台北倉）|
| 設為主據點 | 開關 | — | 否 | 每家公司只能有一筆主據點（見 §6）| 是否為公司主要據點 |
| 地址（自由文字）| 文字 | 否 | 空 | — | 據點地址（目前為自由文字輸入）|
| 聯絡電話 | 文字 | 否 | 空 | — | 據點聯絡電話 |
| 排序 | 數字 | 否 | 0 | 列表不顯示 | 控制顯示順序 |
| 建立時間 / 建立人員 | 時間 / 文字（唯讀）| — | — | — | 何時、由誰建立 |
| 修改時間 / 修改人員 | 時間 / 文字（唯讀）| — | — | — | 最後何時、由誰修改 |

> ⚠️ **結構化地址欄位（縣市 / 區 / 街道）現況揭露**：資料庫已預留結構化地址欄位（cityId / districtId / streetId，對齊倉庫的地址範式並存），但對應的「縣市 → 區 → 街道」三級下拉選擇器（picker）**尚未接上 UI**（待 NX01-04 地址型錄 UI 軌，已登架構債 **A076**）。目前畫面只提供「地址（自由文字）」一欄，不影響資料正確性。

## 4. 按鈕與功能

config-driven 泛型主檔，沿用共通工具列（見 [index.md](./index.md)）：A 新增 / E 更正 / F 查詢 / D 停用-啟用 / P 匯出 / R 重新整理 / L 欄位 / T 篩選 / Q 結束；編輯模式 S 存檔 / C 取消。

| 按鈕 | 快捷鍵 | 功能 |
|------|--------|------|
| A 新增 | `Alt+A` | 新增據點 |
| E 更正 | `Alt+E` | 編輯選取據點 |
| F 查詢 | `Alt+F` | 搜尋代碼 / 名稱 |
| D 停用 / 啟用 | `Alt+D` | 軟停用 / 啟用 |
| P / R / L / T / Q | `Alt+R/L/T/Q` | 匯出 / 重新整理 / 欄位 / 篩選 / 結束 |
| S / C | `Alt+S/C` | 存檔 / 取消 |

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進編輯模式。
2. 填據點代碼（必填、會轉大寫）、據點名稱（必填）。
3. 視需要打開「設為主據點」、填地址 / 電話。
4. `Alt+S` 存檔 → 確認。

### 5.2 查詢資料
1. `F` 搜尋代碼 / 名稱；「顯示停用」看已停用據點。

### 5.3 修改資料
1. 選到據點、`E`。據點代碼鎖定不可改，其餘可改。
2. 把某據點設為主據點 → 存檔後，原本的主據點會自動變回非主（見 §6）。

### 5.4 停用 / 啟用資料
1. 選到據點、`D`。`Enter` 確認。
2. ⚠️ 停用據點前，確認底下沒有還在用的倉庫（倉庫的「所屬據點」指向據點）。

## 6. 業務規則與特殊邏輯

- **主據點互斥（每家公司只能一筆）**：同一家公司同時只能有一筆「主據點」。當你把某據點設為主據點並存檔時，系統會自動把原本的主據點改回「非主」——永遠保持唯一。（資料庫以局部唯一索引強制；⚠️ 該索引的 DB 落地細節於 reinforce migration，本手冊未逐一展開確認。）
- **倉庫掛在據點底下**：倉庫（第17頁）的「所屬據點」指向據點。建倉庫時若沒指定據點，系統會自動帶「主據點優先」的據點。
- **LITE 預設一筆**：LITE 版初始化時預設建一筆主據點（總公司 / 主要倉庫）。
- **代碼處理**：據點代碼存檔時自動去空白並轉大寫；同公司內不可重複。
- ⚠️ **結構化地址待接**：見 §3 的 A076 揭露——schema 已備 city/district/street 欄位、與舊的自由文字地址並存，但 picker 尚未接上 UI；觸發時機為 NX01-04 地址型錄 UI 軌。
- **軟刪除**：停用＝`isActive=false`，不真刪、可復原。

## 7. 鍵盤快捷鍵總表

| 快捷鍵 | 功能 |
|--------|------|
| `Alt+1` / `Alt+2` | 切資料瀏覽 / 詳細資料 |
| `↑` `↓` / `Enter` | 切換選取列 / 進詳細（或表單跳格）|
| `Alt+A` / `Alt+E` / `Alt+F` / `Alt+D` | 新增 / 更正 / 查詢 / 停用-啟用 |
| `Alt+R` / `Alt+L` / `Alt+T` / `Alt+Q` | 重新整理 / 欄位 / 篩選 / 結束 |
| `Alt+S` / `Alt+C` | 存檔 / 取消（編輯模式）|
| `Enter` / `Esc` / `D` | 確認視窗：確認 / 取消 / 丟棄變更 |
