# 零件廠牌基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-12（相關；⚠️ 零件廠牌對應 spec 內碼待確認）
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理零件的製造 / 供應品牌（例：VAG、Bosch、MANN、MAHLE…）。這是零件往上歸屬的「廠牌」來源，也是「品牌料號規則」（第 8 頁）綁定的對象。
- **使用者角色**：由建檔人員 / 採購維護；建好後給零件建檔與品牌料號規則當下拉選項用。
- **使用時機**：要開始建某個新廠牌的零件、或要替某廠牌設定料號編碼規則之前，先把廠牌建好。

> 本頁是設定驅動的泛型主檔，操作邏輯與其他主檔完全一致。共通的按鈕 / 流程 / 快捷鍵見 [index.md 共通操作慣例](./index.md)。
> ⚠️ 「零件廠牌」與「車廠品牌」是兩個不同主檔：車廠品牌是汽車製造商（給車型用），零件廠牌是零件的製造 / 供應商（給零件用）。

## 5. 操作流程

### 5.1 新增資料
1. 按 `A`（或點「新增」），進入編輯模式。
2. 填 **廠牌代碼**（必填、自動轉大寫、建立後不可改）、**廠牌名稱**（必填）。
3. 可選填國別、是否原廠、排序。
4. 按 `S` 存檔，跳確認視窗、`Enter` 確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入廠牌代碼或名稱關鍵字。
2. 要看已停用廠牌時，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好後按 `E`。
2. 除「廠牌代碼」鎖定外，其餘欄位都可改（含切換「是否原廠」）。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標廠牌，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- **代碼自動轉大寫、建立後不可改**：輸入小寫會自動轉大寫存檔；代碼一旦建立就鎖定，避免下游的零件 / 料號規則指向錯亂。
- **「是否原廠」的意義**：開啟代表此廠牌是原廠件廠牌（OEM），關閉代表副廠 / 通用廠牌。此旗標供業務判斷與報表分類用。
- **與品牌料號規則的關係**：品牌料號規則（第 8 頁）是「依零件品牌」設定的——其「零件品牌」欄位對應的是**本頁的零件廠牌**（軸翻轉後，非車廠品牌）。要先建好零件廠牌，才能替它建料號編碼規則。
- **與零件的關係**：零件建檔時透過「零件廠牌」欄位掛上本頁的廠牌。
- **軟停用、不可硬刪**：停用＝資料保留可復原（`isActive=false`）。已被零件 / 料號規則引用的廠牌停用後不影響既有資料，但建檔下拉預設只看啟用中。
- **國別下拉**：來源是「國家基本資料」，一次載入前 100 筆啟用資料（⚠️ 資料量大時未來改搜尋式 picker）。
