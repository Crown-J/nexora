# 品牌料號規則基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-11
> 適用版本：PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：定義「某個零件品牌的料號要怎麼分段」。汽車零件的料號通常有固定結構（例如前 3 碼、中 3 碼、後 3 碼再加 1 碼），這頁就是替每個零件品牌設定「每一段最多幾個字」。設好規則後，建零件（第4頁）時選這條規則，就能用分段方式輸入、系統自動組出標準料號。
- **使用者角色**：建檔人員 / 系統管理員。
- **使用時機**：導入新零件品牌、或某品牌的料號結構需要調整時。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 產品與料號 → **品牌料號規則基本資料**
（路徑：`/dashboard/base/brand-code-rule`）

## 3. 欄位定義

| 欄位名稱 | 型別 | 必填 | 預設值 | 限制 | 業務語意 |
|---------|------|------|--------|------|---------|
| 規則名稱 | 文字 | 是 | — | 同一品牌下不可重複 | 規則的識別名稱（如「VAG 標準料號」）|
| 零件品牌 | 下拉參照 | 是 | — | 須對應已存在的零件品牌 | 這條規則適用哪個零件品牌 |
| 說明 | 多行文字 | 否 | 空 | — | 規則用途補充 |
| SEG1 最大字數 | 數字 | 是 | 3 | 1～20 | 第 1 段最多幾個字 |
| SEG2 最大字數 | 數字 | 是 | 3 | 1～20 | 第 2 段最多幾個字 |
| SEG3 最大字數 | 數字 | 是 | 3 | 1～20 | 第 3 段最多幾個字 |
| SEG4 最大字數（0=不使用）| 數字 | 否 | 1 | 0～20 | 第 4 段；填 0 表示不使用此段 |
| SEG5 最大字數（0=不使用）| 數字 | 否 | 0 | 0～20 | 第 5 段；填 0 表示不使用此段 |
| 分段預覽 | 計算（唯讀）| — | — | — | 依各段字數即時組出料號樣式（SEG 單空格），如 `XXX XXX XXX X` |
| 建立時間 / 建立人員 | 時間 / 文字（唯讀）| — | — | — | 何時、由誰建立 |
| 修改時間 / 修改人員 | 時間 / 文字（唯讀）| — | — | — | 最後何時、由誰修改 |

> 「分段預覽」用 `X` 重複各段字數、以單一空格分隔顯示。例：SEG 設 3·3·3·1 → 預覽 `XXX XXX XXX X`；SEG4/5 為 0 的段不顯示。

## 4. 按鈕與功能

config-driven 泛型主檔，沿用共通工具列（見 [index.md](./index.md)）：A 新增 / E 更正 / F 查詢 / D 停用-啟用 / P 匯出 / R 重新整理 / L 欄位 / T 篩選 / Q 結束；編輯模式 S 存檔 / C 取消。

| 按鈕 | 快捷鍵 | 功能 |
|------|--------|------|
| A 新增 | `Alt+A` | 新增規則 |
| E 更正 | `Alt+E` | 編輯選取規則 |
| F 查詢 | `Alt+F` | 搜尋規則名稱 |
| D 停用 / 啟用 | `Alt+D` | 軟停用 / 啟用 |
| P / R / L / T / Q | `Alt+R/L/T/Q` | 匯出 / 重新整理 / 欄位 / 篩選 / 結束 |
| S / C | `Alt+S/C` | 存檔 / 取消 |

> 「分段預覽」會隨 SEG 字數輸入即時更新（編輯時讀草稿、瀏覽時讀資料）。

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進編輯模式。
2. 填規則名稱、選零件品牌（必填）。
3. 設定 SEG1～SEG3 字數（必填，預設 3）、視需要設 SEG4 / SEG5（0 = 不使用）。
4. 看「分段預覽」確認料號樣式對不對。
5. `Alt+S` 存檔 → 確認。

### 5.2 查詢資料
1. `F` 搜尋規則名稱；「顯示停用」看已停用規則。

### 5.3 修改資料
1. 選到規則、`E`，調整 SEG 字數或名稱、`Alt+S` 存檔。
2. ⚠️ 調整字數不會回頭改已建零件的既有料號，只影響之後用此規則新建 / 編輯的料號。

### 5.4 停用 / 啟用資料
1. 選到規則、`D`。`Enter` 確認。
2. ⚠️ 停用前確認沒有零件還靠這條規則建料號。

## 6. 業務規則與特殊邏輯

- **SEG 分段字數**：SEG1～SEG5 各設「最多幾個字」，SEG1～3 必填（1～20）、SEG4／SEG5 可填 0 表示不使用。建零件時，料號就照這幾段分開輸入，每段不能超過設定字數。
- **同一品牌可建多條規則**：同一個零件品牌可以有多條規則（以「規則名稱」區分），對應不同產品線的料號結構。
- **規則被零件引用**：零件（第4頁）建檔時選一條規則（`codeRuleId`），就用該規則的分段方式產生料號。
- **與完整料號的關係**：本頁只決定「SEG 怎麼分段」。零件實際顯示的完整料號（`{品牌} - {SEG 單空格} #{產地}`）由零件頁組合，品牌前綴與產地後綴不在這條規則內（見 [04 零件](./04-part.md) §6）。
- **預設規則（種子）**：系統初始化時，會替每個零件品牌自動建一條「{品牌代碼} 標準料號」的預設規則（SEG 3·3·3·1），可再調整。
- **唯一性**：同一公司、同一零件品牌下，規則名稱不可重複。
- ⚠️ **軸翻轉**：本規則對應的是「**零件品牌**」（非車廠品牌）——這是下半場改版後的設計。早期版本曾用 JSON 段定義 / 分隔符欄位，皆已移除，改為 SEG1～5 字數 + 即時預覽。
- ⚠️ 規格書 NX01-11 的 §3～§5 仍保留 v1.0 舊內文（車品牌 / JSON / 分隔符），文件頂部已聲明被 v1.1 取代；本手冊以實際程式為準。
- **軟刪除**：停用＝`isActive=false`，不真刪。
