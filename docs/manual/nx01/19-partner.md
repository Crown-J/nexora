# 往來對象基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-03
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：把所有跟公司有往來的對象——客戶、供應商、運輸商、廠商、銀行——集中在同一個主檔管理。每一筆就是一個外部對象的完整資料（聯絡方式、統編、付款條件、信用狀態等），供採購、銷貨、財務等單據開單時挑選。
- **使用者角色**：業務 / 採購 / 財務人員 / 系統管理員建立與維護。
- **使用時機**：新客戶或新供應商上線建檔、聯絡方式異動、調整某對象的信用額度 / 付款條件、或要把某對象凍結交易時。

> 這是「交易對象」分區的核心主檔。一個對象可同時是客戶又是供應商（用「客戶兼供應商」類型）。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 交易對象 → **往來對象基本資料**
（路徑：`/dashboard/base/partners`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進入新增（編輯模式）。
2. 填 **對象代碼**（必填、建立後不可改）、**對象名稱**（必填）、**對象類型**（必填）。
3. 視需要補：聯絡人 / 電話 / 手機 / Email / 統編 / 地址，以及財務相關的客戶分級、信用狀態、信用額度、付款條件、貿易條件。
4. 按 `S` 存檔，跳確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入代碼或名稱關鍵字。
2. 要看已停用資料，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選（如依對象類型、信用狀態篩）、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 對象代碼鎖定不可改，其餘欄位可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- **對象類型語意（Crown 2026-05-26 定案）**：
  - **客戶**：會跟我們買東西的對象。
  - **供應商**：我們跟他進貨的對象。
  - **運輸商**：負責運送的物流業者。
  - **廠商**：一般往來廠商（非主要進銷貨對象）。
  - **銀行**：金流往來的銀行。
  - **客戶兼供應商**：同時既向我們買、也賣給我們的對象。
- **舊碼相容（新增不建議再用）**：「客戶（舊碼）」「供應商（舊碼）」是為了相容過去匯入的舊資料而保留的類型代碼。新建對象時請改用上面正規的「客戶 / 供應商」，**不要再選舊碼**。
- **客戶分級影響定價與付款條件**：對象掛上客戶分級後，會連動售價加成（見第 04 頁零件 §6 的售價 A/B/C/D 概念）與適用的付款條件談判基礎。
- **信用狀態為交易閘門**：標為「凍結」的對象，後續單據開單時應據此提示 / 阻擋（實際阻擋邏輯於各交易模組）。
- 通則：**對象代碼同公司內唯一、建立後不可改、停用為軟刪除**（不真刪、可復原）。被單據引用中的對象建議只停用、勿視為可刪。
