# 零件群組基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-07
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理零件的族群分類（例：煞車系統、引擎零件、電系、懸吊…）。給零件歸類，方便分群查找與報表統計。
- **使用者角色**：由建檔人員 / 採購維護；建好後給零件建檔當「零件群組」下拉選項用。
- **使用時機**：規劃零件分類體系時、或新增一類零件之前，先把族群建好。

> 本頁是設定驅動的泛型主檔，操作邏輯與其他主檔完全一致。共通的按鈕 / 流程 / 快捷鍵見 [index.md 共通操作慣例](./index.md)。

## 2. 進入路徑

## 5. 操作流程

### 5.1 新增資料
1. 按 `A`（或點「新增」），進入編輯模式。
2. 填 **族群代碼**（必填、建立後不可改）、**族群名稱**（必填）。
3. 可選填排序。
4. 按 `S` 存檔，跳確認視窗、`Enter` 確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入族群代碼或名稱關鍵字。
2. 要看已停用族群時，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好後按 `E`。
2. 除「族群代碼」鎖定外，其餘欄位都可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標族群，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- **標準型錄主檔**：本頁屬「標準型錄」型主檔——族群代碼在同一公司內唯一、建立後不可改、停用採軟刪除（資料保留可復原）。
- **代碼建立後不可改**：避免已歸類的零件失去對應。
- **被誰引用**：零件建檔時透過「零件群組」欄位歸類；報表也用群組做分群統計。
- ⚠️ 零件頁載入「零件群組」下拉時走 `/part-group` 端點（對應本頁資料）。
- **軟停用、不可硬刪**：停用＝資料保留可復原（`isActive=false`）。已被零件引用的族群停用後不影響既有資料，但建檔下拉預設只看啟用中。
