# 幣別基本資料

> 模組：NX01 主檔管理
> 頁面代碼：⚠️ 幣別 spec 內碼待確認
> 適用版本：LITE / PLUS / PRO
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理「幣別型錄」。每一筆就是一種貨幣，給金額類欄位（售價、信用額度、單據金額等）標示是用哪種幣別計價。
- **使用者角色**：系統管理員 / 財務人員維護。
- **使用時機**：需要新增一種尚未建檔的幣別、或調整幣別名稱 / 符號 / 小數位數時。

> 這是「系統設定」分區的基礎型錄，本身只是被其他欄位引用的清單，不直接連到單據。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 系統設定 → **幣別基本資料**
（路徑：`/dashboard/base/currency`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進入新增（編輯模式）。
2. 填 **幣別代碼**（必填、建立後不可改，例：TWD）、**幣別名稱**（必填，例：新台幣）。
3. 視需要補：幣別符號（例：NT$）、小數位數（預設 2）、排序。
4. 按 `S` 存檔，跳確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入代碼或名稱關鍵字。
2. 要看已停用資料，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 幣別代碼鎖定不可改，其餘欄位可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- 標準型錄主檔，無特殊計算或連動邏輯。
- **小數位數預設 2**：多數幣別（如新台幣、美元）取兩位小數；若幣別不使用小數（如日圓）可改為 0。
- 通則：**幣別代碼同公司內唯一、建立後不可改、停用為軟刪除**（不真刪、可復原）。被金額欄位引用中的幣別建議只停用、勿視為可刪。
