# 注音字典基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-10
> 適用版本：PRO 限定
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理「漢字 ↔ 注音」對照字典。每一筆記錄一個漢字對應的注音與聲母，用來加速櫃台 F4 快搜——讓使用者打注音就能找到客戶 / 料件，不必逐字打全名。
- **使用者角色**：系統管理員 / 資料維護人員；一般員工不會進到這頁（但人人受惠於它帶來的快搜）。
- **使用時機**：補登字典缺漏的字、調整某字的主注音 / 主聲母對照、或維護快搜索引基礎時。

> ⚠️ **PRO 限定**：本主檔僅 PRO 版可用。LITE / PLUS 在「主檔總覽」會看到卡片但呈灰階。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 系統設定 → **注音字典基本資料**
（路徑：`/dashboard/base/phonetic-dictionary`）

## 5. 操作流程

### 5.1 新增資料
1. 按 `A` 進入新增（編輯模式）。
2. 填 **字**（必填）、**主注音**（必填）、**主聲母**（必填）。
3. 視需要補：使用頻率。
4. 按 `S` 存檔，跳確認後寫入。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入字或注音關鍵字。
2. 要看已停用資料，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 字 / 主注音 / 主聲母 / 使用頻率皆可改。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- **快搜索引基礎**：本字典是櫃台 F4 注音快搜的對照基礎，建得越完整、快搜越準。
- **PRO 限定**：僅 PRO 版開放使用。
- **資料量大**：注音字典筆數龐大，正式建檔多以批次匯入處理（屬資料運營軌的工作），本頁主要用於零星補登 / 校正單筆。
- 通則：**停用為軟刪除**（不真刪、可復原）。
