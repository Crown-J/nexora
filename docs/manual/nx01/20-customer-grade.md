# 客戶分級基本資料

> 模組：NX01 主檔管理
> 頁面代碼：NX01-07
> 適用版本：PLUS / PRO（LITE 灰階）
> 最後更新：2026-05-28

## 1. 頁面說明

- **業務語意**：管理「客戶分級」（例如 A / B / C / D 級）。公司依交易額或信用條件把客戶分等級，把等級掛在「往來對象」上，藉此影響售價加成（不同級別賣不同價）。每一筆就是一個等級的設定。
- **使用者角色**：系統管理員 / 財務主管維護。
- **使用時機**：調整某個等級的名稱或加成率、或暫時停用某個不再使用的等級時。

> ⚠️ **特殊主檔——不可新增**：客戶分級是系統預設的等級資料，本頁 **不開放新增**（`canCreate=false`）。只能編輯既有等級的名稱 / 加成率，或停用 / 啟用。

## 2. 進入路徑

主檔管理 → 主檔總覽 → 交易對象 → **客戶分級基本資料**
（路徑：`/dashboard/base/customer-grade`）

## 5. 操作流程

### 5.1 新增資料
⚠️ 本頁 **不可新增**。客戶分級為系統預設等級，按 `A` 會提示「為系統設定、不可新增」。若需要調整級別內容，請改用 5.3 修改。

### 5.2 查詢資料
1. 按 `F` 開搜尋列，輸入代碼或名稱關鍵字。
2. 要看已停用資料，點工具列「顯示停用」。
3. 可用 `Alt+T` 進階篩選、`Alt+L` 調整顯示欄位。

### 5.3 修改資料
1. `↑↓` 選到目標、`Enter` 進詳細，或選好按 `E`。
2. 分級代碼鎖定不可改；可改 **分級名稱 / 加成率 / 排序**。
3. 按 `S` 存檔、跳確認後完成。

### 5.4 停用 / 啟用資料
1. 選到目標，按 `D`。本頁刪除模式為「切換啟用」。
2. 啟用中→跳「停用」確認；已停用→跳「啟用」確認。
3. `Enter` 確認。停用後預設列表隱藏，可由「顯示停用」找回再啟用。

## 6. 業務規則與特殊邏輯

- **不可新增（系統預設）**：客戶分級的代碼為系統內建，本頁只能編輯與啟用 / 停用，無法新增新等級。
- **加成率的用途**：加成率對應零件售價 A / B / C / D 的「毛利率」概念——等級越高（或越優惠）對應不同的售價。
- **實際售價計算在前端**：售價是由前端依「成本 × 毛利率」自動計算呈現，後端不自動算。詳細的售價 A/B/C/D 算法見第 04 頁零件 §6。
- 通則：**分級代碼建立後不可改、停用為軟刪除**（不真刪、可復原）。
