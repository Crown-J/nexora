# F-W02｜月結請款作業

> 版本需求：LITE
> 最後更新：2026-04-11

---

## 流程概述

依各客戶設定的切帳週期，定期彙整 AR 應收帳款並發送帳單。支援月底結帳與固定日切帳兩種週期，帳單發送方式支援 Email、紙本列印或兩種並行。

---

## 切帳週期定義

| 類型代碼 | 名稱 | 說明 | 觸發時機 |
|---------|------|------|---------|
| M | 月底結帳 | 本月 1~31 日出貨計入本月帳 | 每月最後一天 |
| D | 固定日切帳 | 依設定日（如 25 號）切帳，之後出貨計入下月 | 每月設定日當天 |

**帳單發送方式：**

| 類型代碼 | 說明 |
|---------|------|
| E | Email 自動寄送 |
| P | 列印紙本（業務或外務送達）|
| B | Email + 列印（兩種並行）|

> 以上設定均在客戶主檔（nx00_partner）的 billing_cycle_type / billing_day / billing_send_type 欄位設定。

---

## 觸發條件

| 來源 | 代碼 | 說明 |
|------|------|------|
| 系統自動 | SYS-F06~ | 每日偵測是否有客戶到達切帳日 |
| 手動執行 | B01 | 出納/財務組長手動觸發（補單或特殊情況）|

---

## 流程階段

### 階段一：系統偵測切帳日

**執行者：** 系統自動
**時機：** 每日凌晨自動執行

| 行為 | 說明 |
|------|------|
| SYS-F06~ 偵測今日切帳客戶 | 比對所有客戶的 billing_cycle_type 和 billing_day |
| SYS-F06~ 產生待請款清單 | 列出今日需要發送帳單的客戶 |
| SYS-F06~ 通知出納 | 系統通知出納今日有 N 家客戶需要請款 |

**切帳日判斷邏輯：**

```
月底結帳（M）：
  當日 = 當月最後一天 → 觸發

固定日切帳（D）：
  當日 = billing_day → 觸發
  例：billing_day = 25，每月 25 號觸發
  
  特殊情況：2 月只有 28/29 天
  → 若 billing_day > 28，改為 2 月最後一天觸發
```

---

### 階段二：彙整帳單

**執行者：** 出納專員

| 行為 | 說明 |
|------|------|
| B02 開啟待請款清單 | 系統顯示今日待請款客戶清單 |
| B03 確認各客戶 AR 明細 | 查看每家客戶的本期出貨明細/金額 |
| B04 確認異常 AR | 檢查是否有未完成的銷退/折讓需先處理 |
| B05 產生帳單 | 系統依 AR 明細自動產生帳單 |

**帳單內容：**

```
客戶名稱/統編
帳單期間（起訖日）
出貨明細（日期/料號/數量/單價/金額）
折讓/銷退明細（若有）
本期應付總金額
付款截止日
匯款帳號資訊
聯絡人電話
```

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 帳單確認 | 金額正確，無異常 | 進入階段三發送 |
| ⚠️ 有異常 | 有未處理的銷退/折讓 | 先處理完成，再回到 B05 |

---

### 階段三：發送帳單

**執行者：** 出納專員

**依客戶 billing_send_type 分流：**

#### 路線 E：Email 發送

| 行為 | 說明 |
|------|------|
| B06E 系統自動寄送 Email | 附上帳單 PDF，寄至客戶 Email |
| B06E 記錄發送時間 | 系統記錄寄送時間與收件人 |
| B07E^ 客戶確認收到 | 部分客戶會回覆確認（非必要）|

#### 路線 P：列印紙本

| 行為 | 說明 |
|------|------|
| B06P 列印帳單 | 出納列印紙本帳單 |
| B07P 交給業務/外務送達 | 業務下次拜訪時帶給客戶，或外務順路送達 |
| B07P^ 客戶簽收 | 客戶確認收到帳單（若有簽收單） |

#### 路線 B：Email + 列印並行

| 行為 | 說明 |
|------|------|
| 同時執行路線 E 和路線 P | 確保客戶一定收到 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 發送完成 | 帳單已送出 | 進入階段四追蹤 |

---

### 階段四：付款追蹤

**執行者：** 出納專員

**付款期限設定：**

```
帳單發送後 N 天為付款期限
N 天由客戶主檔的付款條件決定
  NET30 = 帳單後 30 天
  NET60 = 帳單後 60 天
  NET90 = 帳單後 90 天
```

| 行為 | 說明 |
|------|------|
| B08 追蹤付款進度 | 系統自動提醒接近到期的帳款 |
| B09 登記客戶付款 | 收到付款後引用 [F03 收付款作業] 登記 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗07 請款完成 | 客戶付款，AR 核銷 | 流程結束 |
| ⚠️ 逾期未付 | 超過付款期限 | 引用 [F-W01 應收帳款催收作業] |
