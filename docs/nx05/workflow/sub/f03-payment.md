# F03｜收付款作業

> 版本需求：LITE
> 所屬模組：NX04 財務模組
> 最後更新：2026-04-11

---

## 子流程概述

記錄所有實際金流動作，包含客戶收款、廠商付款、退款處理與日常費用登記。所有金流必須在系統登記，不得有未記錄的現金收付。

---

## 觸發情境

| 情境代碼 | 觸發來源 | 說明 |
|---------|---------|------|
| P-F03 | F01 應付帳款作業 | 廠商付款登記 |
| P-F03R | P01 退供應商/F01 | 廠商退款追收 |
| S-F03 | F05 應收帳款作業 | 客戶收款登記 |
| S-F03R | 銷售退貨 | 退款給客戶 |
| X-F03 | 日常費用 | 租金/水電/文具等支出 |
| F-F03 | F-W05 收付款作業 | 財務部出納操作視角 |

---

## 收付款類型

| 類型 | 說明 |
|------|------|
| 客戶收款 | 客戶付款，AR 核銷 |
| 廠商付款 | 公司付款給廠商，AP 核銷 |
| 客戶退款 | 退款給客戶（現金客戶銷退）|
| 廠商退款 | 廠商退款給公司（退供應商後）|
| 費用支出 | 日常營運費用 |

---

## 流程階段

### 階段一：登記收付款

**執行者：** 出納專員

| 行為 | 說明 |
|------|------|
| F01PM 新增收付款記錄 | 選擇類型/對象/關聯單據/金額/付款方式 |

**付款方式：**

| 方式 | 後續動作 |
|------|---------|
| 現金 | 現金庫存餘額自動更新 |
| 匯款 | 填入匯款帳號，記錄完成 |
| 支票 | 引用 [F04 票據管理作業] 建立票據記錄 |
| 本票 | 引用 [F04 票據管理作業] 建立票據記錄 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ 登記完成 | 資料填寫完整 | 對應 AP/AR 自動核銷或更新 |

---

### 階段二：AP/AR 自動核銷

**執行者：** 系統自動

| 行為 | 說明 |
|------|------|
| SYS-F03~ 更新 AP/AR 狀態 | 全額→已付/收款；部分→部分付/收款 |
| SYS-F03~ 更新現金庫存 | 現金收付時自動計算餘額 |

| 結果 | 條件 | 下一步 |
|------|------|--------|
| ✅ F⊗03 完成 | 核銷完成 | 子流程結束 |
| ⚠️ 部分付款 | 未全額付清 | 等待下次付款 |
