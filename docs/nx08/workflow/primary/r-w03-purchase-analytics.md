# R-W03｜採購分析報表

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

提供產品部經理與採購組長用於採購績效追蹤、成本分析、廠商管理的採購分析報表。整合 HPA 歷史路徑分析，追蹤採購成本變化、到貨率、瑕疵率趨勢。

---

## 理論框架

| 分析工具 | 用途 |
|---------|------|
| HPA 歷史路徑分析 | 採購成本/到貨率/瑕疵率多年趨勢 |
| 廠商評鑑（Porter 供應商議價力）| 廠商等級分布/績效排行 |

---

## 報表區塊

### 一、採購績效總覽

| 指標 | 說明 | 週期 |
|------|------|------|
| 採購金額趨勢 | HPA 折線圖，近 3 年比較 | 月 |
| 平均到貨天數 | PO 確認到 RR 入帳平均天數 | 月 |
| 進貨瑕疵率 | 瑕疵明細/總驗收明細 | 月 |
| 採購成本降低率 | 與去年同期相比 | 季 |

### 二、廠商績效分析（引用 P-W07）

| 指標 | 說明 |
|------|------|
| 廠商等級分布（A/B/C/D）| 各等級廠商數量與採購金額佔比 |
| 準時交貨率排行 | 前 5 名/後 5 名廠商 |
| 進貨瑕疵率排行 | 前 5 名/後 5 名廠商 |
| C/D 級廠商清單 | 需要關注/停用的廠商 |

### 三、料號採購成本 HPA

| 指標 | 說明 |
|------|------|
| 各料號進貨成本趨勢 | 近 3 年同月比較 |
| 成本異動超過 5% 料號清單 | 觸發定價檢視 |
| 進口費用佔比趨勢 | 進口採購各費用佔比（海運/關稅/報關）|

### 四、退供應商分析

| 指標 | 說明 |
|------|------|
| 退貨金額/退貨率 | 引用 [P-W03] 退供應商流程 |
| 退貨原因分布 | QTY/DEF-A/DEF-F/DEF-S/OTHER |
| 折讓金額趨勢 | 引用 [F-W07] 折讓作業 |
