# R-W04｜庫存產品分析報表

> 版本需求：PRO
> 最後更新：2026-04-11

---

## 流程概述

提供產品部經理與倉管部經理用於庫存健康管理、產品壽命週期評估的分析報表。核心工具為 BCG 矩陣（產品壽命週期），搭配 HPA 歷史路徑分析與產銷管理流程，協助識別明星/金牛/老狗產品，清理呆滯庫存。

---

## 理論框架

| 分析工具 | 用途 |
|---------|------|
| BCG 矩陣 | 料號四象限分類（問題/明星/金牛/老狗）|
| HPA 歷史路徑分析 | 銷售趨勢/庫存變化 3~5 年比對 |
| 產銷管理流程 | 庫存週轉次數（目標 12 次/年）|

---

## BCG 矩陣定義

```
問題產品（新品）：
  新引進料號，毛利率最高，但銷售量仍不穩定
  → 重點推廣，觀察 3~6 個月

明星產品：
  毛利率 40% 以上，銷售量持續成長
  → 確保庫存充足，優先補貨

金牛產品：
  毛利率 40% 以下但業績佔比高（佔總業績 70% 以上）
  → 穩定供貨，維持利潤主力

老狗產品：
  毛利率低於 15%，銷售量下滑
  → 出清策略（展會促銷/組合銷售）
  → 停止採購，清空庫存
```

## 報表區塊

### 一、BCG 矩陣圖（料號四象限）

| 指標 | 說明 |
|------|------|
| 橫軸 | 銷售量成長率（近 6 個月 vs 去年同期）|
| 縱軸 | 毛利率 |
| 氣泡大小 | 銷售金額 |
| 各象限料號清單 | 可點擊查看詳細資料 |

### 二、庫存健康分析

| 指標 | 說明 | 目標值 |
|------|------|-------|
| 庫存週轉次數 | 月銷售成本/平均庫存值 × 12 | ≥ 12 次/年 |
| 呆滯庫存金額 | 超過 90 天未出貨的庫存 | 趨近 0 |
| 安全量達成率 | 低於安全量的料號比例 | < 5% |
| 超過最高量料號數 | 庫存超過最高量的料號 | 趨近 0 |

### 三、HPA 庫存趨勢分析

| 指標 | 說明 |
|------|------|
| 各倉庫存量趨勢 | 近 3 年月度庫存量折線圖 |
| 庫存金額趨勢 | 近 3 年月度庫存總值 |
| 各倉周轉率比較 | 各倉庫存週轉次數比較 |

### 四、老狗產品出清追蹤

| 指標 | 說明 |
|------|------|
| 老狗料號清單 | 毛利 < 15% 且成長率下滑 |
| 已停止採購料號 | 確認不再補貨 |
| 出清進度 | 老狗庫存消化進度追蹤 |

### 五、產銷管理分析

```
產銷會議建議：每月第三週召開（EMBA 課程）

報表提供：
  銷售預估 vs 實際業績 差異
  庫存水位 vs 安全量 比較
  補貨建議清單（低於安全量料號）
  超量庫存清單（超過最高量料號）
```
