# NEXORA 資料表歸循環對照

> **分類原則（Crown 2026-07-25 拍板）**：主檔自成一層、只出現一次、被所有循環共用；循環層每一環只放它「產生的單據表」；兩本帳（庫存／現金）獨立擺。
> 資料表總數＝192（grep schema.prisma 實數）。⚠️＝待執行長裁的語意疑點。

## ⚠️ 待執行長裁的語意疑點
1. **訂單(Nx04Order) vs 銷貨單(Nx04So)**：兩張並存、Order 帶 legacyDocNo，疑為偉盟匯入舊資料。要合併、保留、還是標「歷史匯入」？
2. **保固理賠(Nx02WarrantyClaim)**：目前掛採購循環（向供應商索賠），但也涉客戶售後。歸採購 or 另立售後段？
3. **報廢(Nx03Disposal)/異常(Nx03IssueReport)**：單獨列「庫存調整」，或併入某一環？
4. **會計科目表(Nx05AccountCode)**：現放 A4 字典，若之後補總帳，是否升為「現金水位帳」的一員？
