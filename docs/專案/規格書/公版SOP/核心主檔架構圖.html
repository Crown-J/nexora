兩層讀法：四域圓＝NEXORA GRID 跨產業核心（任何行業都要：公司／產品／供應商／客戶）；黃色節點＝汽車零件零售產業套件，箭頭＝「行業具體化 → 掛進核心」。

產品↔零件真相：兩層今天已存在、但壓在同一張零件表裡——code＝基準料號（產品識別、基準＋產地唯一）、secCode＝廠牌料號（零件識別）。圖上的兩層＝把這兩欄攤開的目標視角；現況＝合併實作，將來跨產業才需決定是否正規化拆表（schema 設計決定、需執行長 review）。

同表範式：供應商＋客戶＝一張往來對象表六分類；兩個廠牌＝一張廠牌表雙開關——「一個對象一張表、身分用開關」是既有拍板，圖上分開畫＝權責視角、底層同表。

⚠ 5 個待裁：
  1. 「通銷件」＝系統的「通用件」（屬性欄位）？還是另一種分類？用詞待對齊。
  2. 車身號碼（VIN）現在放知識模組（加購）→ 要不要搬進核心主檔層？
  3. 貿易商：六分類沒有此類 → S 供應商細分？or 新增分類？
  4. 職務：現為員工表自由文字欄位 → 要不要升獨立主檔（封閉值域）？
  5. 公司基本資料：現放平台層租戶表 → 要不要在租戶內立主檔（報表抬頭／發票用）？
