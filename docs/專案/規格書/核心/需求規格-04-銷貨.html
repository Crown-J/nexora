需求規格 04 — 銷貨

說明：銷貨模組「該做成怎樣」的施工級需求——逐單據列欄位、定價、信用管控、規則、關聯。操作步驟見《操作手冊-05》；工程慣例見《核心系統規格》。

銷貨模組涵蓋：報價單 → 銷貨單 → 銷貨退回，外加優惠價子系統（促銷規則／折扣代碼／組合套餐）與三層定價、信用管控。銷貨單出庫連動庫存、過帳連動財務應收；並接收庫存「特價售出」產生的特價銷貨單。

通用操作

銷貨是「把貨賣給客戶」的完整流程，從報價到收款，再加上退貨。這一章先講共通操作。

怎麼進到銷貨作業

按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「銷貨」，或從下方工具列（dock）的「銷貨」項展開進入。銷貨底下有：報價單、銷貨單、銷貨退回，以及一組「定價工具」（折扣代碼、促銷規則、組合套餐）。

【說明】 銷貨沒有中間的「銷貨中心」頁；各項作業從星球選單或 dock 直接進。

銷貨主流程

目前只做內銷（外銷尚未開始）。一筆內銷生意從客戶來電查貨開始，到送達簽收、銷貨單顯示「已完成」。

【說明】 從「撿貨單」起（撿貨／包貨／配送／送達）屬庫存模組的撿包送＋配送，詳見《庫存》；銷貨單狀態會隨進度更新。開發票與收款屬財務、詳見《財務》。

信用管控

開銷貨單時，系統自動檢查四件事，避免賣給有風險的客戶：

信用管控四道把關
欄位性質規則／來源／說明
黑名單系統自動客戶被列黑名單 → 擋。
信用額度系統自動超過客戶的信用額度 → 擋／警示。
逾期帳款系統自動客戶有逾期未收的帳 → 擋／警示。
付款條件系統自動依客戶付款條件判斷。
【說明】 信用管控是開單時即時檢查，銷貨單上沒有「信用狀態」欄；客戶的信用狀態與額度在客戶主檔（見《核心主檔》）。確認銷貨單會產生應收帳款。發票相關（稅則／發票類型、應稅金額、稅額、含稅總額、發票號、發票日期、抬頭備註）屬財務、詳見《財務》。

銷貨退回

客戶退貨有兩種方式：業務先接到、建單再派人取回（計畫性）；或送貨員當場被告知、直接帶回檢查（臨時）。兩種最後都走「檢查能不能退 → 核准 → 過帳」。

方式 A：業務發起（計畫性退貨）

業務接到客戶要退貨 → 建銷退單 → 由庫存指派送貨員去取回（送貨員可能待命中、或正在配送中，屬庫存配送）→ 取回後檢查、核准、過帳。

方式 B：送貨員當場（臨時退貨）

客戶當場直接跟送貨員說這個要退 → 送貨員先把貨帶回 → 交給倉管或業務檢查能不能退 → 可退就建銷退單、核准、過帳。

【說明】 取回的送貨員調度、退貨配送屬庫存配送，詳見《庫存》；財務沖帳詳見《財務》。

優惠價子系統

優惠價是「針對特定商品（或套餐）給特定售價」，不是整張單打折。開銷貨單／報價時，系統會逐項商品算出該給的價、自動帶入。

定價分三層

商品的價分三層：基準價（商品本身的建議售價＋客戶等級）、促銷規則（臨時優惠：促銷／出清／即期）、個案特價（瑕疵／中古件個案，見《庫存》的特價售出）。系統開單時，把所有適用的價放進「候選價池」、取最低，就是這個商品給這個客戶的最終價。

第 1 層：基準售價

基準售價（既有，見《核心主檔》）
欄位性質規則／來源／說明
四級建議售價選填每個料件有 A／B／C／D 四級建議價。
客戶分級選填客戶分 A／B／C／D 級，對應挑哪一級建議價。
個別折數選填個別客戶可覆寫分級、設專屬折數。

第 2 層：促銷規則

促銷規則 詳細頁（表頭＋範圍） LITE

選單位置 銷貨 → 定價工具 → 促銷規則

一條規則 = 在某段時間、對某範圍的商品、給一個優惠價。促銷、出清、批量折扣都用這一個引擎設。

促銷規則欄位
欄位性質規則／來源／說明
代碼 / 名稱必填規則代碼與名稱。
生效時段必填起迄日期；只在這段時間內套用。
商品範圍必填指定料件（可多選）／品牌／料件族群（三選一範圍類型）。
優惠價必填這個範圍的商品在此時段賣多少（絕對單價）。
出清旗標選填標為出清；出清價只套在即期批、不套新鮮批。
買 N 件以上選填批量折扣：買到一定數量才套。
啟用選填開／關這條規則。
【說明】 按「車型」促銷需要車型字典，屬「汽車資料庫套件」，詳見套件手冊；LITE 的促銷範圍是料件／品牌／族群。

即期自動

系統會看每個批號快不快到期：批號的保固到期日距今小於「即期門檻天數」時，自動把它列為即期、套用即期類（出清）優惠價。新鮮的批不會被套出清價。

即期判定
欄位性質規則／來源／說明
即期門檻天數系統自動全域設定（預設 30 天）：到期前幾天算即期。
到期日來源系統自動優先用批號驗收時填的保固到期日；沒填時用「進貨日＋建議保存期限」推算（建議保存期限見《核心主檔》、族群設預設、零件可覆寫）。

組合套餐

組合套餐 詳細頁（表頭＋組成） LITE

選單位置 銷貨 → 定價工具 → 組合套餐

把多個商品綁成一組、賣一個打包價（例如 a+b 賣 100）。開單選套餐時，系統帶出組成料件（各自出庫扣庫存），總價就是套餐價。

組合套餐欄位
欄位性質規則／來源／說明
代碼 / 名稱必填套餐代碼與名稱。
套餐價必填整組打包賣多少。
生效時段選填套餐有效期間。
組成料件必填套餐裡有哪些料件、各幾個。
【說明】 選了套餐，組內商品「不再各自套促銷」——套餐價就是整組的最終價（避免重複折）。套餐價會按各料件比例分攤回各明細、確保總和等於套餐價。

取最低與低於成本警示

開單時每個商品把候選價（客戶分級價＋所有適用的促銷／出清／即期）放一起，取最低，就是最終單價。

【說明】 VIP 若分級價本來就比促銷低，他保有自己的低價（不會被促銷拉高）——客戶永遠拿到對他最划算的價。
【注意】 最終單價低於成本（虧本賣，例如出清、即期）→ 系統警示、必填原因後放行（出清／即期本來就可能認賠）。

客戶與定價設定

這裡講銷貨視角的客戶設定；客戶主檔的完整欄位見《核心主檔》的交易對象。

銷貨視角的客戶設定
欄位性質規則／來源／說明
客戶分級選填A／B／C／D 級，決定挑哪一級建議價、最低毛利率守則。
個別折數選填覆寫客戶分級、設這個客戶專屬的折數。

【說明】 客戶分級主檔（各級的最低毛利率）也在主檔維護，詳見《核心主檔》。

待釐清 / 待驗證

  • ① 特價售出銷貨單分流：庫存「特價售出」會產生一張特價銷貨單，售價脫離客戶分級毛利、低於成本屬正常。此單須與正常銷貨分流、不跳低於成本警示、且不污染毛利報表。須與《需求規格-03 庫存》《財務》對齊。
  • ② 三層定價取最低：基準售價／促銷規則／折扣代碼三層「取最低」的優先序與計算，以及「低於成本警示」觸發條件（含對特價售出的豁免）須明確。
  • ③ 信用管控：依客戶信用額度與信用狀態（N 正常／W 警示／F 凍結）擋單／放行的觸發點、誰能覆寫，連動核心主檔客戶設定。
  • ④ 銷退兩方式回沖：方式 A（業務發起、派送貨員取回）與方式 B（送貨員當場帶回）的庫存回沖與財務沖帳時點差異。
