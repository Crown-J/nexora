需求規格 02 — 進貨

檔案位置：docs/專案/規格書/核心/需求規格-02-進貨.html　|　版本：v1.0　|　維護：CTO（Alex）　|　NX 碼：NX02（核心 / LITE）
說明：進貨模組「該做成怎樣」的施工級需求——逐單據列欄位、狀態流轉、規則、關聯。操作步驟見《操作手冊-03》；工程慣例見《核心系統規格》。

進貨模組涵蓋採購全流程：採購需求單 → 詢價比價 → 採購單 → 進貨單（驗收入庫），外加退貨單、國外進貨追蹤（六階段）、特殊採購、保固申請。單據引用核心主檔（產品/供應商/供貨對應），驗收入庫連動庫存，廠商確認與驗收連動財務應付。

通用操作

進貨在 NEXORA 是一套有先後順序的流程：先看「採購需求」、再去「詢價」比價、選定供應商開「採購單」、送主管核准、寄給廠商確認、貨到開「進貨單」驗收入庫，過程中可能開「退貨單」或「保固申請」。這一章先講所有進貨作業共通的操作。

怎麼進到進貨作業

按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「進貨」，或從下方工具列（dock）的「進貨」項展開進入。進貨底下分四類作業：採購需求、詢價單、採購單、進貨單；另有退貨單、保固申請、國外進貨追蹤。

【說明】 進貨沒有「採購中心」這種中間頁；每一種單據都是獨立入口，從星球選單或 dock 直接進。

三種畫面版面

進貨的畫面分三種版面，看到時就知道怎麼操作：

三種版面
欄位性質規則／來源／說明

主檔管理（採購視角）

採購作業會用到三張主檔：產品、供應商、供應商供貨對應。它們和主檔中心是同一筆資料（同一張表），這裡只列「採購人員會用到、看得到」的欄位，方便不必跑去主檔中心就能維護進貨相關資料。完整欄位請見《核心主檔》操作手冊。

【說明】 採購視角只露採購相關欄位（進貨成本、付款條件、廠牌料號等），不會顯示售價、客戶分級加成率這類銷售敏感資料。要不要讓某職務看得到，由「職務權限設定」控制。

國內採購

國內採購是一條從「需求」到「驗收入庫」的流程。先看全貌：

第 1 步：採購需求單 清單頁＋詳細頁 LITE

選單位置 進貨 → 採購需求

先看哪些料件需要進貨。系統會依各料件的安全量，自動把低於安全量的缺料列進缺貨簿；也可能是客戶要的、或臨時手動要進的。

採購需求欄位
欄位性質規則／來源／說明
來源選填缺貨補貨（系統依安全量）／客戶要的（從銷貨來）／手動新增，三種來源用顏色區分。
料件必填要詢價進貨的料件。
需求數量必填要進多少。
備註選填說明用途、急不急。

第 2 步：詢價單・比價 詳細頁（並排比價） LITE

選單位置 進貨 → 詢價單

針對要進的料件，跟「可供貨的廠商」詢價，多家報價並排比較，選最好的一家直接帶出採購單。

詢價單表頭欄位
欄位性質規則／來源／說明
單號系統自動詢價單號。
開單日期 / 開單人員系統自動建立的日期與人。
狀態系統自動草稿 → 已發出 → 已回覆 → 已關閉。
詢價明細與比價欄位
欄位性質規則／來源／說明
料件必填要詢價的料件；系統依「供應商供貨對應」帶出可詢價的廠商。
數量必填詢價數量。
各家報價選填每家供應商一欄，填單價、交期，並排比較。
【重點】 「採用」一鍵就把比價結果變成採購單草稿，料件、數量、單價自動帶過去，不用重打。

第 3 步：採購單 詳細頁（表頭＋明細） LITE

選單位置 進貨 → 採購單

採購單是向廠商正式下單的單據。表頭記下單對象、付款與交貨安排，明細記要買的料件。建立後走「送審 → 核准 → 寄廠商 → 廠商確認」流程。

採購單表頭欄位
欄位性質規則／來源／說明
單號系統自動採購單號。
開單日期 / 開單人員系統自動建立的日期與人。
供應商必填向哪家廠商採購。
付款對象選填錢付給誰；留空＝跟供應商同（例如集團採購：母公司付款）。
指送對象選填貨送給誰；留空＝跟供應商同（例如分店收貨）。
收貨地址選填送到哪個地址（依指送對象或供應商的地址挑選）。
交貨地點選填自由填的地址，直送客戶現場、不進倉時用。
預計到貨日選填預估到貨日（草稿階段可改）。
帳款年月選填這筆算哪個月的帳（月結用，例如 5 月帳 vs 6 月帳）。
付款條件選填可逐單覆寫供應商的預設付款條件。
國內物流追蹤編號選填出貨後填物流單號（黑貓／嘉里／大榮），用來估到貨。
國內付款里程碑選填記「廠商通知付款 / 已付」的狀態。
總金額系統自動明細加總（含稅）。
備註選填備註。
採購單明細欄位（逐筆料件）
欄位性質規則／來源／說明
項次系統自動明細順序。
我方料號 / 廠牌料號選填料件的我方料號（主碼）與廠牌料號並列顯示。
品名系統自動料件名稱（帶自主檔）。
數量必填採購數量。
已進量 / 取消量系統自動已收多少、取消多少（分批進貨時追蹤；缺貨剩餘可取消）。
單價 / 金額選填單價與小計。
預交貨日選填這一筆料件的預計到貨日（可逐筆設）。
【注意】 「核准／退件」要有「核准」權限的職務才能按（在職務權限設定的「核准」欄開放）。這樣就能做到「採購員送審、主管才能核准」。

第 4 步：進貨單・驗收入庫 詳細頁（表頭＋明細） LITE

選單位置 進貨 → 進貨單

貨到後開進貨單驗收，狀態經過「草稿 → 驗收中 → 過帳完成」。系統從採購單帶出料件與數量，驗收人填實收、瑕疵等，過帳後庫存就增加。

進貨單表頭欄位
欄位性質規則／來源／說明
單號系統自動進貨單號。
供應商 / 對應採購單系統自動從採購單帶來。
提貨單號選填進口時填報關行給的提貨單號（D/O No）。
總金額系統自動明細加總。
進貨單明細欄位（逐筆驗收）
欄位性質規則／來源／說明
我方料號 / 廠牌料號選填料件的我方料號與廠牌料號並列。
目前庫存系統自動旁邊用燈號顯示此料目前庫存量：赤字紅／0 黃／少量淡黃／充足綠，一眼判斷要不要收。
預期量系統自動採購單上應收的數量。
實際量必填實際收到多少。
瑕疵數量選填其中有幾顆是瑕疵。
瑕疵類型選填瑕疵數量大於 0 時必填：外觀損壞／功能異常／規格不符／其他。
瑕疵描述選填瑕疵數量大於 0 時必填，說明狀況。
批號系統自動系統自動產（進貨年月＋流水），可留空。
保固到期日系統自動依進貨日＋保固月數自動算，可留空。

【重點】 過帳會一次做四件事：①庫存增加 ②更新移動平均成本 ③產生應付帳 ④更新該料件的「最後進貨時間」。

欄位性質規則／來源／說明
瑕疵必填選填瑕疵數量大於 0，就一定要填瑕疵類型與描述。
不可超收選填瑕疵數量不可超過實際量；實際量不可為負。

國外採購

國外採購大致和國內相同（需求 → 詢價 → 採購單 → 進貨驗收），差別在「物流與到貨」這段：要追船期、聯繫報關行、拿提貨單，而且進貨成本要把運費、關稅等進口費用攤分進去。國外進貨用「流程追蹤頁」以六個階段推進。

特殊採購

特殊採購（跳過詢價） 詳細頁 LITE

選單位置 進貨 → 採購單（特殊）

已經知道要跟誰買、不需要比價時，可以跳過詢價、直接開採購單。流程與一般採購單相同（送審 → 核准 → 寄廠商 → 廠商確認 → 進貨驗收），只是少了前面的詢價比價。

進貨延伸功能

保固申請單 詳細頁 LITE

選單位置 進貨 → 保固申請

料件壞掉要跟供應商主張保固時開保固申請單。分兩種來源：客戶反映的、或自己庫存發現的。

保固申請單欄位
欄位性質規則／來源／說明
單號系統自動保固單號。
類型必填客訴型（客戶反映壞掉、要連到銷貨單）／自用型（庫存自己發現、無客戶）。
來源銷貨單選填客訴型必填：是哪張銷貨的客戶反映的；自用型不顯示。
供應商必填這料件當初向哪家買的、要向誰主張保固。
零件必填壞掉的料件（料號＋品名）。
狀態系統自動申請的處理進度。
處理結果選填保固的判定結果。
退款方式選填退錢／換貨等處理方式。
附件選填佐證照片或文件。

業績指標

每顆料件會記錄「最後進貨時間」（驗收入庫時更新）與「最後銷售時間」（出貨過帳時更新），在產品主檔的採購分頁與銷貨分頁分別顯示，用來判斷哪些料件呆滯。完整說明見《核心主檔》操作手冊。

待釐清 / 待驗證

  • ① 在途量／預進量：採購單「已核准未入庫」的在途數量，系統是否記錄、是否計入「可用庫存」供下單參考。待 Hank 查現況（系統有沒有＋該不該有）。
  • ② 廠商確認自動產生應付：「廠商確認」即產生應付帳（先款後貨語意）——此過帳時點、科目、與驗收/發票的勾稽，連動財務 NX05，須與財務需求規格對齊。
  • ③ 採購核准流程：送審→核准依核心主檔「職務權限·核准」控制；哪些單據強制走核准（採購單、保固、盤點）需明列。
  • ④ 國外進貨追蹤六階段：各階段的觸發、應記欄位（船期、報關、稅費）與成本歸集規則待細列。
