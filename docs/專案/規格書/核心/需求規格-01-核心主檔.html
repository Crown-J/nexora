說明：核心主檔「該做成怎樣」的施工級需求——逐主檔列欄位、性質、規則、來源、關聯。操作步驟見《操作手冊-02 Ver 2.7》；工程慣例見《核心系統規格》。

核心主檔是所有單據的資料底座，進貨/庫存/銷貨/財務/報表全引用它。本模組含六大分區：組織架構、權限管理、據點倉庫、往來對象、產品與廠牌、字典主檔，外加所有主檔共通的通用需求。設計理念採「先建素材、再組裝」：各基本資料頁只負責建立實體本身，部門/組/職務/員工的指派關係統一在「組織架構圖」組裝。標記說明：本次 此版實作；伏筆 預留位置、另立任務；唯讀 使用者僅瀏覽不可改。

導覽銜接（DOCK）：本模組的六大分區即小星球「主檔」項的第二層選單——主檔導覽採三層：主檔 → 六大分區 → 各分區的主檔頁。各分區包含的主檔即下列各節，分區順序與小星球一致。DOCK 三層導覽的完整定義見 NX00。
每個畫面的寫法：有實際操作的畫面採兩段——「一、畫面欄位」說明這張畫面有哪些欄位（靜態）；「二、操作與結果」說明按了什麼、系統做什麼、出現什麼結果（動態）。純靜態的小型字典主檔（國家、幣別、地區等）只需新增/編輯/停用/啟用，不另列操作段。

通用需求（所有主檔共通）

無刪除、只停用：系統沒有實體刪除、只有「停用」。停用資料不消失、只是不再出現在日常清單與下拉，需要時可再「啟用」。權限矩陣對應欄位即名為「停用」（軟刪除）。停用方向永遠放行。
欄位性質定義（本文件用語）：
· 必填＝不填不能存　· 建立後不可改＝存檔後鎖定（多為代碼/主鍵類）　· 純顯示＝系統自動記錄、唯讀　· 進階＝列表預設隱藏、需要才展開　· 未標示＝選填。
  • 每個主檔提供單筆新增 / 編輯 / 停用 / 啟用。客戶端不提供批次匯入（大量資料轉移由 Innova 內部代建工具處理，沿用既有 importer 邏輯）。
  • 提供注音快搜：輸入注音聲母快速定位；查詢自動忽略空格、星號、點、大小寫差異。
  • 多數代碼類欄位自動轉大寫、建立後鎖定。
  • 客戶端介面/URL 只用業務中文名，不外露內部代碼或表名。
【說明】 本手冊每個主檔開頭都會標「選單位置」，照著點就能找到該畫面。
【重點】 NEXORA 沒有「刪除」、只有「停用」。停用的資料不會消失、只是不再出現在日常清單與下拉裡，需要時可再「啟用」。所以權限矩陣裡那一欄也叫「停用」不是「刪除」。

每個主檔標題旁標一個型態標籤，代表它套用哪一種頁面架構。以下定義各型態的版面結構與通用行為（只定架構與互動，視覺風格由設計系統供應）。後續各主檔只描述自己的欄位差異，頁面框架一律引用本章。

型態一：一般表格（基準型態）

最常見的型態，由「資料瀏覽（清單頁）」與「詳細資料（詳細頁）」兩個分頁構成，頂部以分頁列切換。全鍵盤可操作。

清單頁（資料瀏覽）— 由上而下的版面
區塊內容與行為
分頁列「資料瀏覽 / 詳細資料」兩個分頁，可鍵盤快捷切換。
工具列由左到右：翻頁鈕與頁次 → 更正（進編輯）→ 查詢（開搜尋條）→｜→ 停用／啟用（依選列狀態自動切換）→ 匯出（CSV／PDF／列印）→ 重新整理 →｜→ 欄位（顯示/隱藏欄、附隱藏數）→ 篩選（多條件，附條件數）→（撐開）→ 顯示停用（切換是否列出停用資料）→ 選取（進多選批次模式）。
浮動面板搜尋／欄位設定／篩選三個面板，在工具列下方就地展開，同時只開一個（互斥）。

頁尾顯示「共 X 筆 / 顯示 Y 筆」與「每頁 N 筆」選擇（傳統分頁，非無限捲動）。
詳細頁（詳細資料）— 由上而下的版面
區塊內容與行為
標題列狀態圓點＋主標題（該筆的代碼或名稱，新增時顯示「新增○○」）＋「編輯中／瀏覽」狀態字。
欄位區雙欄網格（手機單欄），欄位順序＝該主檔欄位定義順序；長欄位（多行文字、地址）自動跨欄。必填欄 label 加「*」。
動作（編輯模式）進編輯模式時工具列轉為「存檔／取消」；有未存變更時切走會跳三選確認（存檔後離開／放棄變更／取消）。
異動紀錄區底部顯示建立／最後修改的時間與人員（唯讀）。
【通用行為】 全鍵盤：分頁切換、工具列各鈕、表格上下、Enter 進詳細、編輯中 Enter 逐格跳、最後一格 Enter 觸發存檔確認。軟刪除：所有「刪除」一律是停用、可再啟用。唯讀欄：以唯讀樣式顯示、不可聚焦編輯（如代碼類、計算欄、推導欄）。

型態二：一般表格（多分頁）

架構同「一般表格」，差別在詳細頁分多個分頁，每個分頁裝一組相關欄位，頂部以分頁切換。清單頁與通用行為完全相同。例：員工基本資料分「基本資料／教育程度／職務部門／帳號狀況」四分頁。

型態三：一般表格（含子表）

架構同「一般表格」，詳細頁除主欄位外，下方再帶一個或多個子表（一對多明細）。子表通用範式：子表區有標題＋筆數＋「新增」鈕，主檔詳細頁上以唯讀明細列呈現；子表項目的新增／編輯走獨立的子頁面（非就地編輯）。例：往來對象的聯絡窗口／送貨地址、零件的替代料／照片。

型態四／五：一般表格（系統內建 / 半開放）

架構同「一般表格」，差別只在「能不能新增」：
· 系統內建：資料由系統預置，使用者只能改不能新增、不能停用（例：客戶分級 A／B／C／D）。
· 半開放：內建項鎖定（不能改代碼、不能停用），但使用者可另新增自訂項（例：供應商分級內建 A～D，可再加 VIP／列管）。

型態六：群組批次

左右兩欄面板，處理「一個主體配多個成員」的多對多關係。左欄＝主體清單（可搜尋、可選、部分可新建）；右欄＝選定主體的成員清單（每列一筆、可移除、右上有筆數與加入鈕）。成員可帶屬性的（如通用件群組成員有角色／替代設定），右欄每列可展開設定。供應商供貨對應另有「品牌＋群組＋產地」批次匯入視窗。全鍵盤操作。

型態七：圖像化指派

多層串接面板，由左至右逐層收斂，點左層節點、右層顯示其下層內容，用於組裝層級與指派關係。組織架構圖為四層（部門→組→職務→成員，含未指派成員池）；據點架構圖為三層（據點→倉庫→庫位，含員工據點指派）。各層的建立走各自基本資料頁，此型態只做「指派關係」的組裝。

型態八：權限矩陣

畫面 × 權限的二維勾選矩陣。每一列是一個畫面、每一欄是一種權限（瀏覽／新增／修改／停用／匯出／核准），交叉格打勾即授權。支援單格、整列（整個畫面）、整模組三層批次勾選；採「暫存後一次存檔」，未存離開會提醒。例：職務權限設定。

組織架構

建立組織的人事素材：員工、部門、組別、職務。本分區只負責「建立這些實體本身」；它們的指派關係（誰在哪個部門/組/職務）統一到「權限管理 → 組織架構圖」設定。員工基本資料的部門/組/職務欄位僅顯示、不可在此編輯。

操作與結果

動作結果
新增員工系統自動帶員工編號（可覆寫），填妥必填欄位後存檔。員工預設為「未啟用」，不占席次、不能登入。
啟用員工打開「是否啟用」→ 檢查啟用人數（含負責人）是否已達席次上限：未達則啟用、員工可登入；已達則擋下並提示「席次已滿」。
停用員工關閉「是否啟用」→ 永遠放行（停用方向不檢查上限），釋出一席。停用者資料保留、不能登入、不出現在日常下拉。離職員工以停用處理（資料保留、非刪除）。
重置密碼按「重置密碼」→ 確認視窗 → 密碼重設為預設密碼（員工編號）並自動開啟強制改密；員工下次登入改完密碼後該旗標自動關閉（見 NX00 登入流程）。
啟用雙重驗證打開開關前系統檢查：未填手機且未填 Email → 擋下並提示「請先填寫手機或 Email」；有任一管道才可開啟。
設離職填「離職日期」→ 標示已離職、資料保留（非刪除），建議一併停用以釋出席次。

【重點】 查詢任一顆零件，系統自動帶出同群組可替代品與各自庫存，缺貨時可改推替代品。查詢會自動忽略空格、星號、點、大小寫差異，對方料號各種寫法都找得到。
