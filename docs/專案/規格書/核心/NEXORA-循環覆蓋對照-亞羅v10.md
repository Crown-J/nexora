## 2. 四個發現

### 2.1 ✅ 亞羅補上 NEXORA 四條空循環，且每條都附過帳分錄樣板

**融資／固定資產／資訊／資金**——NEXORA 這四條是零 model，亞羅都落表了。

更關鍵的是 v10 有 **5 張「交易科目對映」分頁**（新增／資金／融資／人資／固資與資訊），
加上核心主檔 v1 那張 **131 列**的彙總表，格式一致：

```
交易代號 | 交易類型      | 序 | 借貸 | 科目   | 金額基礎 | 需部門 | 需往來對象
SO-CR   | 銷貨（賒銷）  | 1 | 借  | 1111  | 含稅總額 | 否    | 是    → 應收帳款
        |              | 2 | 貸  | 4101  | 未稅金額 | 是    | 是    → 銷貨收入
        |              | 3 | 貸  | 2121  | 稅額    | 否    | 否    → 銷項稅額
        |              | 4 | 借  | 5101  | 銷貨成本 | 是    | 否    → 結轉成本
        |              | 5 | 貸  | 1121  | 銷貨成本 | 是    | 否    → 存貨減少
```

⭐ **這就是 `NEXORA-循環圖與過帳事件-0724討論.md` §5 說「明天續填」的那張過帳事件表**，
而該檔 §7 列的下一步「逐事件定案借貸科目 → 這就是總帳脊椎的正式規格」，亞羅已經做完。
連 0724 該檔第 117 行「稅（營業稅/VAT）尚未畫入、刻意先擱著」都補上了（`2121 銷項稅額` 在內）。

**同時補上的還有 14 張 NEXORA 完全沒有的財會主檔**：
會計期間（含關帳三閘）、科目類別、交易科目對映、銀行帳戶、稅別、收付方式、
付款條件範本、定期費用排程、發票字軌、應收票據登錄、資產主檔、零件類型加成率、
代碼參數表（170 列）、會計政策（14 項）。

### 2.2 🔴 投資循環：雙方都空，而且沒有人決策過

策略骨架 §4 明講「**生產/研發**循環從 v1 砍掉」，**沒有提到投資**。亞羅八條也沒有。

這是唯一一條「兩邊都空、且無人明確拍板」的循環。對汽配經銷商可能真的不需要
（無轉投資、無金融資產部位），但**需要一次明確的砍除決策**——
策略骨架 §3 說「內控設計要能過 **COSO** 檢視」，缺一條循環而無說明，檢視時會被問。

✅ **已拍板（2026-08-01）→ 見 §3 決策 1️⃣：v1 砍掉，但留擴充位。**

### 2.3 ⚠ 「研發」的砍除判斷，可能要改成「保留為商品開發」

策略骨架 §4/§6 砍掉研發循環，理由是「恆迎不需生產/研發」。
但亞羅做了 **商品開發（選品）15 個行為**，設計理由是：

> 選品的後果**延遲一年**才顯現，而人不會記得自己一年前預期賣幾個。
> 恆迎的選品失敗不是「沒人做」（採購三十年天天在選），是**沒人回頭看**。

而恆迎實證把代價量化了：**超額庫存 1.13 億**（有在賣、但備了超過一年用量），
以及「選品命中率無人追蹤」。

⭐ **經銷商沒有 R&D，但有選品——選品就是通路業的研發。**
砍掉這條循環，等於把 1.13 億那個問題的解法一併砍掉。

✅ **已拍板（2026-08-01）→ 見 §3 決策 2️⃣：保留，正名為「商品開發／選品（法定：研發）」。**

### 2.4 ⚠ 亞羅把「資金」獨立成一條，與內控九大的切法不同

內控九大把收款拆在銷售循環、付款拆在採購循環。亞羅獨立成 27 個行為的一條，理由是
現金視角本來就跨循環：13 週現金預測、票據與開票警示、零用金、銀行對帳五道紀律、
🔴 現金預測必須**按帳戶**算（來自恆迎「支存負數」的教訓：活存 +1,250 萬、支存 −647 萬，
合計為正但甲存沒錢一樣跳票）。

**實務上更好用，但策略骨架 §3 要求「能過 COSO 檢視」**——對外檢視時循環切分最好對得上法定框架。

兩者不衝突，做法是：**內部用亞羅的切法，對外報告時映射回九大**。
但這個映射關係必須寫進規格，不能默默只做一邊。

✅ **已拍板（2026-08-01）→ 見 §3 決策 3️⃣：獨立保留，映射做在行為層（27 行）。**

### 決策 1️⃣ 投資循環：**v1 明確砍掉**，但留擴充位

| | |
|---|---|
| **決定** | v1 不設投資循環 |
| **理由** | ① 投資循環管的是有價證券／長期股權投資／衍生性商品的取得・保管・處分流程<br>② 🔴 **恆迎三十年沒有投資部位——因為錢全部拿去買貨了**（執行長 2026-08-01 確認）。這與診斷結論完全一致：庫存 2.9 億、其中 **1.13 億是超額庫存**。沒有閒置資金可投資，資金全變成架上的貨<br>③ 亞羅 1-a 現金最低點 **−429 萬**，連閒置資金都不存在<br>④ 套「外部紀律 × 人造紀律」框架，這條循環**收益為零**：投資循環的內控目的是防止經理人亂投資，而 1-a 的執行長就是老闆本人、錢全是自己的，**沒有對手方、也沒有要保護的第三方** |
| **⚠ 砍的方式** | 照策略骨架 §4「範圍砍掉 ≠ 架構焊死」：<br>· 會計科目表**留長短期投資科目位**（不啟用）<br>· 總帳脊椎**不得假設「不會有投資類分錄」**<br>· 本節即是「為什麼砍」的規格留痕——COSO 檢視時「評估過所以不設」與「沒想過」是兩回事 |

📌 **釐清（易混淆）**：投資循環 ≠ 業外收入。前者是**流程**分類（資產的取得/持有/處分），
後者是**損益科目**分類。亞羅**會有業外收入但沒有投資循環**——最現成的例子是 `8104 兌換損益`
（進口第一天就會用到），但它來自**採購循環＋資金循環**，與投資循環無關。

## 5. 轉譯進 NEXORA 要做的三件事（A 階段）
