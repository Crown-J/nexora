需求規格 03 — 庫存

檔案位置：docs/專案/規格書/核心/需求規格-03-庫存.html　|　版本：v1.0　|　維護：CTO（Alex）　|　NX 碼：NX03（核心 / LITE）
說明：庫存模組「該做成怎樣」的施工級需求——逐主檔/單據列欄位、狀態、規則、關聯。操作步驟見《操作手冊-04》；工程慣例見《核心系統規格》。

庫存模組涵蓋：庫存查詢與異動流水、產品庫存設定、倉位庫位、盤點、異常處置（六種，含特價售出）、重組分解、進貨工作站（驗貨上架）、撿包送出貨、開帳存（初次導入）。入庫源自進貨、出庫連動銷貨、特價售出與報廢連動財務。

通用操作

庫存的功能大多是各自獨立的作業（查庫存、盤點、處理異常、重組分解等），不像進貨那樣是一條長流程。這一章先講共通的操作。

怎麼進到庫存作業

按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「庫存」，或從下方工具列（dock）的「庫存」項展開進入。庫存底下就是各項作業：庫存查詢、產品庫存設定、倉位庫位、盤點、異常處置、重組分解、進貨工作站、撿包送、開帳存。

【說明】 庫存沒有中間的「庫存中心」頁；各項作業從星球選單或 dock 直接進。

欄位徽章說明

徽章意思
欄位性質規則／來源／說明
必填選填不填不能存檔。
建立後不可改選填存檔後就鎖住。
系統自動選填系統自動帶或自動算。

庫存查詢

庫存查詢 清單頁 LITE

選單位置 庫存 → 庫存查詢

查每個料件在各倉的庫存狀況。庫存帳由系統自動維護（進貨入庫加、出貨扣），這裡只看、不手改。

庫存查詢欄位
欄位性質規則／來源／說明
料件選填我方料號＋廠牌料號＋品名。
倉庫選填哪個倉。
庫存數量系統自動本倉目前現量。
調撥中系統自動正在跨倉調撥途中的數量。
預出量系統自動已開銷貨單、還沒出貨的預留數量。
平均進價系統自動成本參考。

庫存異動流水 清單頁 LITE

選單位置 庫存 → 庫存查詢 → 異動明細

每一筆讓庫存增減的動作都會留下一筆流水（進貨、出貨、調撥、盤點調整、報廢等），可追每顆料件的庫存怎麼變的。

異動流水欄位
欄位性質規則／來源／說明
異動日期 / 類型系統自動什麼時候、哪種異動（進／出／調整）。
來源單據系統自動由哪張單造成的。
數量 / 異動後餘額系統自動增減多少、異動後剩多少。

產品庫存設定

產品庫存設定 一般表格 LITE

選單位置 庫存 → 產品庫存設定

為每個料件、每個倉設定安全量、最高量與預設庫位。低於安全量時系統會列進缺貨簿、提醒補貨。

產品庫存設定欄位
欄位性質規則／來源／說明
料件必填哪個料件。
倉庫必填哪個倉（同一料件可在不同倉各設一組）。
安全量選填低於這個量就該補貨；系統依此列缺貨簿。
最高量選填庫存上限參考。
預設庫位選填這料件在本倉的預設擺放位置。

倉位與庫位

倉庫 一般表格 LITE

選單位置 庫存 → 倉位與庫位 → 倉庫

管理有哪些倉庫。倉庫綁著庫存的流向邏輯，是庫存帳的基本單位。

倉庫欄位
欄位性質規則／來源／說明
倉庫代碼必填 / 建立後不可改倉庫的代碼。
倉庫名稱必填倉庫名稱。
地址 / 聯絡進階倉庫所在與聯絡資訊。

庫位 一般表格 LITE

選單位置 庫存 → 倉位與庫位 → 庫位

倉庫底下細分的擺放位置（如 A 區 3 排 2 層）。料件可指定預設庫位，撿貨、上架時依庫位找貨。

庫位欄位
欄位性質規則／來源／說明
所屬倉庫必填這個庫位在哪個倉。
庫位代碼必填庫位編號。
說明選填位置描述。

盤點

盤點工作台 詳細頁（表頭＋明細） LITE

選單位置 庫存 → 盤點

實地清點庫存、把帳面量和實際量對齊。盤出差異後調整入帳，庫存帳就和現場一致。

盤點單表頭欄位
欄位性質規則／來源／說明
單號系統自動盤點單號。
倉庫必填盤哪個倉。
盤點日必填盤點的日期。
盤點人系統自動由建立人／操作人帶入。
狀態系統自動盤點的進度。
盤點明細欄位（逐筆料件）
欄位性質規則／來源／說明
料件選填盤點的料件。
庫位必填盤哪個庫位。
帳面量系統自動系統帳上的數量。
實盤量必填實際數到多少。
差異系統自動實盤量 − 帳面量。
單位成本系統自動計算差異金額用。

異常處置

庫存裡發現異常的件（損毀、過期、數量短缺、放錯庫位、其他）時，先開「異常回報」記錄下來，再依狀況選一種處置。異常回報本身只是記錄、不動庫存帳；真正的庫存增減，由你選的處置對應的單據去做。

異常回報 清單頁＋詳細頁 LITE

選單位置 庫存 → 異常處置
異常回報欄位
欄位性質規則／來源／說明
單號系統自動異常單號。
異常類型必填損毀／過期／數量短缺／放錯庫位／其他。
回報日期必填什麼時候發現的。
倉庫必填在哪個倉發現的。
料件 / 數量必填哪個料件、幾顆有問題。
庫位選填選「放錯庫位」時必填——錯放在哪個庫位。
來源選填從哪裡發現的（如銷貨檢貨、盤點時發現），系統可連回來源單據。
照片選填佐證照片。
處置方式選填選一種處置（見下方六種）。
狀態系統自動草稿 → 已回報 → 處理中 → 結案（可取消）。
【說明】 異常回報只記錄、不動庫存帳。選定處置後，庫存的實際增減由下游單據處理。

六種處置

處置方式（六選一）
欄位性質規則／來源／說明
退貨選填退回供應商，走《進貨》的退貨單。
保固選填向供應商主張保固，走《進貨》的保固申請單。
重組分解選填把件拆解或組合（見下一章），不進損益。
報廢選填報廢出庫（不自動進損益、由會計手動處理）。
特價售出選填把堪用的瑕疵／即期／中古件用特價賣掉、回收價值，系統會產生一張特價銷貨單。
未處置選填預設值。先記著、之後再處理。

報廢單 詳細頁 LITE

選單位置 庫存 → 報廢

確定要報廢的件開報廢單，過帳後從庫存扣掉。

報廢單欄位
欄位性質規則／來源／說明
單號系統自動報廢單號。
倉庫必填從哪個倉報廢。
報廢明細必填料件、庫位、數量、報廢原因（原因選「其他」時需填說明）。
狀態系統自動草稿 → 過帳 → （可作廢）。
【說明】 報廢過帳會出庫、扣庫存，但不自動進損益表——損失由會計手動入帳（這是刻意的邊界）。

特價售出 詳細頁 LITE

選單位置 庫存 → 異常處置（異常單詳細頁選「特價售出」）

異常件選「特價售出」處置時，系統會建一張特價銷貨單，填買家與特價售出，貨從庫存出、應收進財務。把瑕疵但堪用、即期、中古的件用特價賣掉回收價值，而不是直接報廢虧光。

特價售出（產生特價銷貨單）
欄位性質規則／來源／說明
買家必填賣給誰。
特價必填這次特價售出的單價（由你填）。
數量必填賣出數量。
成本系統自動用原平均成本計入；售價是特價，毛利會反映折損。
【重點】 特價售出走一般銷貨的流程（出庫、應收），只是標記為「特價」。怎麼定特價、即期／瑕疵／中古的優惠價規則，見《銷貨》操作手冊。

重組分解

重組分解 詳細頁 LITE

選單位置 庫存 → 重組分解

把庫存的料件「組合」或「拆解」。例如把零件組裝成套件（合併），或把整組拆成單品（分解）。系統會把投入的料件扣庫存、把產出的料件加庫存，並算好成本。

重組分解欄位
欄位性質規則／來源／說明
單號系統自動重組分解單號。
模式必填合併（多件組成一件）／分解（一件拆成多件）。
投入料件必填要消耗的料件與數量（扣庫存）。
產出料件必填產生的料件與數量（加庫存）。
成本系統自動合併：投入成本加總；分解：依 A 級建議售價比例攤分到各產出料件。
【說明】 重組分解只在倉庫內換料件型態、會動庫存帳，但不進損益（不是買賣）。

進貨工作站

進貨工作站（驗貨上架） 詳細頁 LITE

選單位置 庫存 → 進貨工作站

倉庫端收貨時的作業：核對到貨、把貨上架到庫位。概念上和《進貨》的進貨單搭配：進貨單記「收了什麼、驗收結果」，進貨工作站處理「實體貨怎麼上架到哪個庫位」。

進貨工作站欄位
欄位性質規則／來源／說明
料件 / 數量選填驗貨上架的料件與數量。
庫位選填上架到哪個庫位。

撿包送

出貨端的三步作業：撿貨、包裝、出貨。多在手機螢幕上操作，倉管邊走邊撿邊掃。

撿貨 詳細頁 LITE

選單位置 庫存 → 撿包送 → 撿貨
撿貨欄位
欄位性質規則／來源／說明
對應出貨單選填依哪張銷貨／出貨單撿。
料件 / 數量 / 庫位選填要撿的料件、數量、去哪個庫位撿。
已撿量選填撿了多少。

包裝 詳細頁 LITE

選單位置 庫存 → 撿包送 → 包裝
包裝欄位
欄位性質規則／來源／說明
撿好的料件選填撿貨完成的料件。
包裹選填裝成幾個包裹、各裝什麼。
包裹規格進階長寬高重。

出貨 詳細頁 LITE

選單位置 庫存 → 撿包送 → 出貨
出貨欄位
欄位性質規則／來源／說明
包裹選填要出的包裹。
配送方式選填怎麼送（自取／物流）。
出貨確認選填確認出貨、庫存正式扣掉。
【說明】 撿貨路徑最佳化、GPS、外送整合（Lalamove 等）屬加購套件，見對應的套件手冊。

開帳存

開帳存（初次導入） 詳細頁 LITE

選單位置 庫存 → 開帳存

系統剛上線時，把現有的庫存初值一次導入：每個料件在各倉有多少、成本多少。這是一次性的起始動作（通常由 Innova 代為匯入），導入後庫存帳就從這個初值開始跑。

開帳存欄位
欄位性質規則／來源／說明
單號系統自動開帳單號。
倉庫必填哪個倉的初值。
開帳日必填庫存初值的基準日。
明細必填料件、期初數量、期初成本。
【說明】 開帳存是一次性的起始導入，不是日常作業；新客戶上線時由 Innova 代為匯入。

待釐清 / 待驗證

  • ① 特價售出連動銷貨＋財務：處置選「特價售出」會產生一張特價銷貨單，售價脫離客戶分級毛利、低於成本屬正常。系統須「認得是瑕疵特價、不跳毛利警示」，且與正常銷貨分流、避免污染毛利報表。須與《需求規格-04 銷貨》《財務》對齊欄位與過帳。
  • ② 報廢過帳：報廢單過帳從庫存扣掉，但「不自動進損益、由會計手動處理」——此手動處理的科目與時點，連動財務 NX05。
  • ③ 在途量／可用庫存：採購已核准未入庫的在途量，是否計入可用庫存（與進貨 ① 同題）。
  • ④ 開帳存（初次導入）：與 Innova 代建匯入工具的關係——期初庫存由代建匯入或經開帳存單建立，須界定。
