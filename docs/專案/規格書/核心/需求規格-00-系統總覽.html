需求規格 00 — 系統總覽

檔案位置：docs/專案/規格書/核心/需求規格-00-系統總覽.html　|　版本：v1.0　|　維護：CTO（Alex）
說明：整個 ERP 有哪些模組功能、彼此怎麼串，以及各模組需求規格的索引。各模組細節見其需求規格。

NEXORA GRID 的功能分兩類：核心模組（LITE 內含、每家都用）與加購模組（按需選購）。每個核心模組各有一份需求規格，編號與《操作手冊》對齊（規格說「該做成怎樣」、手冊說「怎麼用」，成對）。

編號模組範疇對應需求規格 / 手冊

業務主流程（模組怎麼串）

核心主檔（零件/客戶/廠商… 貫穿全程，所有單據都引用）
  └ 進貨 → 庫存（盤點 / 異常處置）→ 銷貨（報價 → 銷貨單）
      → 撿包送 / 配送（屬庫存）→ 財務（應收 / 應付 / 折讓）→ 報表

員工啟用與席次（01）橫切全系統：決定誰能登入、佔幾席。

文件層次：本份（00 總覽）是大框架 → 各模組需求規格（01～07）逐一細談「該做成怎樣」→ 各模組《操作手冊》談「怎麼用」。三層由粗到細。
