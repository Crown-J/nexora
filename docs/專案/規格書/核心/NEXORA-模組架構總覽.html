模組架構總覽

整套系統有哪些畫面、使用者怎麼到達、各畫面對應哪一本規格書。 本份以使用者真正的入口 Top Bar 為核心展開——這顆元件能通往系統的每一個角落， 順著它就能看完整張系統地圖。

導讀

怎麼讀這套規格書

NEXORA 的規格書分三層、由粗到細。先看這張總覽抓全貌， 再依需要鑽進某個畫面的細分規格，最後對照手冊看怎麼操作。 本份只講「架構」——系統長什麼樣、畫面怎麼分、各自連到哪； 畫面的實際運作（欄位、流程、規則）一律在各自的細分規格書裡。
層級回答什麼問題文件
① 架構總覽系統有哪些畫面？我從哪進去？這畫面歸哪一本？本份
② 細分需求規格這一個畫面該做成怎樣？有哪些欄位、按了會怎樣？各畫面一本（見下）
③ 操作手冊使用者實際上怎麼操作這個畫面？各模組手冊
📐 一畫面一規格

系統的每一個畫面，都有一本專屬的細分需求規格書。本總覽的每個畫面名稱， 都連到它對應的那一本。命名規則：需求規格-[模組碼][序]-[畫面名] （例：需求規格-02-01-缺貨簿）。模組碼沿用 NX 編號，畫面顯示順序則依使用者習慣排列，兩者不衝突。

兩種模組分類

核心 LITE 即內含、每家都用； 　加購 按需選購的套件； 　待補 畫面已在版圖上、細分規格尚未撰寫。

核心元件

Top Bar 全貌

Top Bar 橫跨系統每一頁、不隨模組改變，是使用者到達任何畫面的唯一入口。 左側是導覽、右側是工具。整套系統地圖，就是把這條列上的每顆按鈕展開。
位元件通往
左 1小星球全域導覽——八大模組的單一入口（下方逐一展開）
左 2NEXORA 品牌點擊回首頁
左 3租戶名稱顯示登入公司（不可互動）
右 1使用者按鈕個人儀表板 / 修改密碼 / 登出
右 2設定齒輪環境設定（個人偏好）
右 3通知鈴鐺通知列表（待辦驅動）
右 4公告喇叭佈告欄
右 5日期時間顯示日期時間星期（不可互動）

※ Top Bar 與小星球本身的規格屬外殼層 NX00，見 需求規格-00-登入與首頁。

Top Bar · 其他入口

使用者 / 設定 / 通知 / 公告

除了小星球，Top Bar 右側四顆按鈕也各自通往畫面。這些都屬外殼層 NX00， 規格見 需求規格-00-登入與首頁。
入口展開的畫面
使用者按鈕個人儀表板（同小星球「個人」）/ 修改密碼 / 登出
設定齒輪環境設定：深淺主題 / 2FA / 語言 / 字級密度 / 快捷鍵 / 版本 / 關於
通知鈴鐺通知列表（待辦驅動，點一則跳對應單據）
公告喇叭佈告欄
⚙️ 設定齒輪只放「個人偏好」

齒輪只影響「我自己用起來的樣子」，不含任何會動到全公司的設定（稅率、單據編號規則、簽核流程等仍歸主檔與各模組）。
