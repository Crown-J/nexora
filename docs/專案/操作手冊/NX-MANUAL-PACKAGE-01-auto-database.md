## §1. 此套件涵蓋什麼

NEXORA 為汽車零件 ERP 領域特化的字典套件、把「料件 ↔ 車型 ↔ 廠牌料號規則」的細粒度對應自動化、目的：

- **業務員賣「Toyota Corolla 2018 1.8L CVT」的雨刷**時、系統能精準推薦適配料件。
- **採購員建料件**時、系統依品牌料號規則自動把料號切成 SEG1~SEG5 五段。
- **櫃台用注音快搜**時、打「ㄔㄜ」就找到所有「車」開頭的料件。

⭐ 適合「料件 SKU 數量大（5,000+）、需要精準車型對應」的中大型汽配批發 / 零售業者。LITE 版客戶用「料號 + 零件群組」（NX-MANUAL-02 §5.1 / §5.4）+ 「改號關聯」衛星表已能應付日常業務、不一定要加購此套件。

## §3. 品牌料號規則（從 NX-MANUAL-02 §5.5 搬入）

某些大廠牌的料號有規範格式（例：「3 碼類別 + 3 碼系列 + 3 碼變體」）。把規則登進系統、之後建料件時系統會自動切分段碼、方便檢索與篩選。

### 3.1 欄位

| 欄位 | 說明 |
|---|---|
| **規則名稱** | 自由命名（例：「Toyota 副廠標準碼」）|
| **零件品牌** | 這規則套用到哪個零件廠牌（從 NX-MANUAL-02 §5.3 零件廠牌主檔挑）|
| **說明** | 補充說明 |
| **SEG1 ~ SEG5 最大字數** | 5 段各自的最大字數（0 = 不使用）|
| **分段預覽** | 系統自動產出範例、確認規則對不對 |

### 3.2 操作

新增規則 → 建料件時、料件主檔的「編碼規則」欄選這條規則 → 系統會把料號自動切成 SEG1~SEG5 五段 / 帶到分段碼欄位。

⚠️ 此操作目前 LITE 看得到卡、未加購點下去會跳「需加購汽車資料庫套件」提示。

## §4. 零件關聯（從 NX-MANUAL-02 §5.6 搬入）

明確登記「兩個料件之間的關係」、讓系統幫您處理「改號」「同款」「組合 / 拆解」這類情境。

### 4.1 欄位

| 欄位 | 說明 |
|---|---|
| **來源零件** | 從零件主檔挑 A 件 |
| **目標零件** | 從零件主檔挑 B 件 |
| **關聯類型** | 1 改號 / 2 同款 / 3 改版 / 4 組合 / 5 拆解 |
| **排序** | 顯示順序 |

### 4.2 5 種關聯用途

- **改號**：A 是舊型號、B 是新型號、系統查庫存時把兩者合算。
- **同款**：A 和 B 在外觀 / 規格上幾乎相同、賣不到 A 時可以推 B。
- **改版**：A 是舊版、B 是新版（規格略改、用途相同）。
- **組合 / 拆解**：用於零件包（A 包裡有 B 零件、進貨入 A、賣的時候賣 B）。

## §5. 料件車型適配（從 NX-MANUAL-02 §5.7 搬入）

明確登記「這個料件可以裝在哪些車型」、業務員賣「Toyota Corolla 2018 的雨刷」時、系統直接告訴他哪些料件可用。

### 5.1 欄位

| 欄位 | 說明 |
|---|---|
| **零件** | 從料件主檔挑 |
| **車型** | 從車型主檔挑（§6.2）|
| **適配等級** | 1 原廠 / 2 副廠等效 / 3 通用 |
| **排序** | 顯示順序 |

### 5.2 為什麼用獨立主檔

一個料件可能適配 30 種車型、寫進料件主檔會炸表。獨立主檔以「一對多筆」方式管理、新增 / 移除某車型適配只動這張表。

## §6. 車型字典 5 卡（從 NX-MANUAL-02 §6 搬入）

⭐ 此分區 5 張卡都標套件徽章、給有需要做「精準車型對應」的客戶用。

### 6.1 是什麼分區

汽車零件 ERP 領域特化的字典、讓料件能精準綁定到「Toyota Corolla 2018 1.8L CVT 前驅 房車」這種具體車型。

### 6.2 車型基本資料

整套「車廠品牌 + 車型代號 + 年式 + 引擎 + 變速箱 + 傳動 + 車體類型」的組合字典。

| 欄位 | 說明 |
|---|---|
| **車型代碼** | 自由命名（例：`COROLLA-18`、`CIVIC-22`）|
| **車型名稱** | 中文名（例：「Corolla 11 代 1.8L」）|
| **車廠品牌** | 必填、從 NX-MANUAL-02 §5.2 挑 |
| **年式（起 / 迄）** | 適用的年份範圍 |
| **引擎** | 從 §6.3 挑 |
| **變速箱** | 從 §6.4 挑 |
| **傳動方式** | 從 §6.5 挑 |
| **車體類型** | 從 §6.6 挑 |

被「料件車型適配」（§5）引用、業務員賣具體車型零件時、系統能精準推薦。

### 6.3 引擎基本資料

| 欄位 | 說明 |
|---|---|
| **引擎代碼** | 自由命名 |
| **引擎名稱** | 中文名 |
| **燃料別** | 必填：1 汽油 / 2 柴油 / 3 油電 Hybrid / 4 純電 EV |
| **排氣量（cc）** | 數字、純電可空 |
| **進氣方式** | 1 自然進氣 NA / 2 渦輪 TC / 3 機械增壓 SC / 4 雙增壓 |
| **車廠品牌** | 可空、標這顆引擎是哪牌的 |

### 6.4 變速箱基本資料

| 欄位 | 說明 |
|---|---|
| **代碼** | 自由命名 |
| **名稱** | 中文名 |
| **變速型式** | 必填：1 手排 / 2 自排 / 3 雙離合 / 4 CVT / 5 AMT / 6 其他 |
| **檔位數** | 數字（例：6、8、10）|
| **英文名稱** | 選填 |
| **車廠品牌** | 可空、標這個變速箱常配的品牌 |

### 6.5 傳動方式基本資料

| 欄位 | 說明 |
|---|---|
| **代碼** | 自由命名（例：`FF`、`FR`、`AWD`、`4WD`）|
| **名稱** | 中文名（例：「前置前驅」「全時四驅」）|
| **英文名稱** | 例：「Front Engine Front Drive」|
| **排序** | 下拉排列順序 |

### 6.6 車體類型基本資料

| 欄位 | 說明 |
|---|---|
| **代碼** | 自由命名（例：`SEDAN`、`SUV`、`HATCH`）|
| **名稱** | 中文名（例：「房車」「休旅」「掀背」「跑車」「旅行車」）|
| **英文名稱** | 例：「Sedan」「SUV」|
| **排序** | 下拉排列順序 |

### 6.7 車型字典內部串接

```
車廠品牌（LITE 基本含、NX-MANUAL-02 §5.2）
    │
    ├─ 引擎、變速箱、傳動方式、車體類型（本套件）
    │       │
    │       └─ 全部被「車型」（本套件）引用
    │               │
    │               └─ 被「料件車型適配」（本套件 §5）引用
    │                       │
    │                       └─ 業務員賣某車型零件時、系統推薦適配料件
```

## §7. 注音字典 + F4 高速搜尋（從 NX-MANUAL-02 §9.4 搬入、規劃中）

⚠️ **此功能規劃中**、是櫃台高速搜尋的注音輔助、跟「自動產統一料號」「車型字典」屬同一個套件邏輯（汽配業特化）。

### 7.1 是什麼

櫃台快搜的中文注音對照表、加速「F4 快速搜尋」（例：打注音「ㄔㄜ」就找到所有「車」開頭的料件、不用全打中文）。

### 7.2 欄位

| 欄位 | 說明 |
|---|---|
| **字** | 中文字（一筆一字）|
| **主注音** | 該字的標準注音 |
| **主聲母** | 該字的聲母（用來建索引）|
| **使用頻率** | 數字、影響搜尋排序 |

### 7.3 為什麼歸這個套件

櫃台高速搜尋只對「員工流動率高、新人多、用注音輸入比較順」的中大型客戶有意義、小公司熟手通常直接打料號或打中文更快。歸「汽車資料庫套件」是因為跟車型 / 料號搜尋整合最緊。
