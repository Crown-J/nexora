通用操作（所有主檔共通）

NEXORA 的主檔都集中在「主檔中心」。本章先教共通操作與三種畫面版面，之後各章再依主檔中心的分區，逐一說明每個主檔的欄位與操作。

怎麼進到主檔

主檔的進入方式：按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「主檔」→ 選分區（帳號與權限／產品與料號／車型字典／組織架構／交易對象／系統設定）→ 點要進的主檔。也可以從下方工具列（dock）的「主檔」項展開進入。

【說明】本手冊每個主檔開頭都會標「選單位置」，照著點就能找到該畫面。

三種畫面版面

主檔依用途分成三種版面，操作方式不同。每個主檔開頭會標明它屬於哪一種：

A　一般表格

最常見的主檔（員工、零件、客戶、品牌…）。上半部是「資料列表」，下半部或另一分頁是「單筆詳細資料」。操作以「新增一筆／更正一筆／停用一筆」為主。

B　group 批次設定

用來「一次設定多筆」的批次工具（使用者職務設定、使用者據點設定）。畫面左右兩欄：左欄列實體（職務／倉庫），右欄列「該實體目前的成員」，可一次指派／撤銷多名員工。

C　權限矩陣

職務權限設定專用。一張大表：選一個職務，縱軸是各畫面、橫軸是六種權限（瀏覽／新增／修改／停用／匯出／核准），用打勾決定這個職務能對哪個畫面做什麼。

搜尋與注音快搜

每個主檔頂部都有搜尋框，打字後約 0.3 秒自動搜尋、不用按 Enter。除了打名稱，也可打「注音首碼」快速找到（例如找「永豐汽車」打注音首碼即可命中）。員工、客戶、零件都支援。

瀏覽、編輯、停用

  • 瀏覽模式：看資料，工具列可新增、更正、停用、匯出。
  • 編輯模式：新增或更正時進入，工具列變「儲存／取消」。
  • 批次選取：勾選多筆一起停用／啟用。
【重點】NEXORA 沒有「刪除」、只有「停用」。停用的資料不會消失、只是不再出現在日常清單與下拉裡，需要時可再「啟用」。所以權限矩陣裡那一欄也叫「停用」不是「刪除」。

欄位標記說明

  • 「必填」：一定要填，不填無法存檔。
  • 「建立後不可改」：存檔後鎖定、不能再改（通常是各種代碼）。
  • 「進階」：列表上預設不顯示，要進編輯視窗或詳細頁才看得到、才能填。

版本門檻

主檔中心的每個主檔都有適用版本（LITE／PLUS／PRO）。LITE 版進到 PLUS／PRO 才有的主檔會顯示灰階與升級提示。本手冊每個主檔開頭會標版本徽章，LITE 客戶可略過標 PLUS／PRO 者。

帳號與權限

這一區管理「人」與「能做什麼」：建立員工帳號、定義職務（組織職稱）、用權限等級控制每個人能用哪些畫面。共六個主檔。

【重點】權限怎麼運作（一句話版）：每位員工設一個「權限等級」，等級在「權限矩陣」勾選能用的畫面與動作——權限跟著等級走；「職務」是組織上的職稱標籤（誰是採購員、誰是業務），與權限分開管理。
使用者基本資料
一般表格LITE
選單位置主檔 → 帳號與權限 → 使用者基本資料

建立與維護每位員工的資料、帳號與權限。畫面分四個分頁：基本資料、帳號權限、帳號安全、人力資源。

操作步驟
  1. 在使用者列表點「新增」（或選一筆後點「更正」）。
  2. 在「基本資料」分頁填入姓名等資料；員工編號可留空由系統自動給號。
  3. 切到「帳號權限」分頁，勾選職務、設定是否啟用。
  4. 點「儲存」。新建帳號會顯示初始密碼，抄給員工，員工首次登入須改密碼。

職務基本資料
一般表格LITE
選單位置主檔 → 帳號與權限 → 職務基本資料

職務是組織上的職稱標籤（例如採購員、業務員、倉管、會計），供組織呈現、報表歸類與公告對象使用。員工能用哪些畫面由「權限等級」決定（見下一個主檔）。

操作步驟
  1. 在職務列表點「新增」。
  2. 填職務代碼（自動轉大寫）、職務名稱，可選填層級與隸屬部門。
  3. 點「儲存」。
  4. 到員工的帳號權限分頁把職務掛上（權限另在「權限等級」設定）。

使用者職務設定
group 批次LITE
選單位置主檔 → 帳號與權限 → 使用者職務設定

批次工具：以「職務」為單位，一次把多名員工指派到同一個職務（一般主檔是一人一筆，這裡是一個職務配多人）。畫面左右兩欄：左欄列職務、右欄列「該職務目前的成員」。

操作步驟
  1. 左欄點選一個職務（或用上下鍵移動）。
  2. 右欄會列出該職務目前的成員；點右上「指派成員（Alt+A）」開搜尋視窗。
  3. 在視窗用帳號或姓名搜尋、勾選要加入的員工（已是成員者會變灰不可重複選），確認加入。
  4. 要移除某成員，點該成員列的「× 撤銷」，確認後即軟刪除（保留紀錄）。
畫面區塊
左欄
全部職務清單，每列顯示職務名稱與代碼。上下鍵移動、右鍵進右欄。
右欄
選定職務目前的成員清單，每列顯示員工姓名與帳號，附「× 撤銷」鈕；右上有筆數與「指派成員」鈕。
指派成員視窗
搜尋帳號／姓名後多選加入；已是成員者不可重複選。
【說明】這是批次工具、各版本皆可用。也可在「使用者基本資料」的帳號權限分頁逐一替員工勾選職務（一次一人）；批次工具則適合一次處理多人。
使用者據點設定
group 批次LITE
選單位置主檔 → 帳號與權限 → 使用者據點設定

與「使用者職務設定」同一種批次畫面，只是軸換成「倉庫／據點」：以倉庫為單位，一次指派多名員工隸屬該倉。

操作步驟
  1. 左欄點選一個倉庫。
  2. 右欄列出該倉目前的成員；點「指派成員（Alt+A）」搜尋、多選員工加入。
  3. 要移除點該成員的「× 撤銷」並確認。
【說明】批次工具、各版本皆可用。也可在「使用者基本資料」的隸屬據點欄位逐一設定（一次一人）。

權限矩陣LITE
選單位置主檔 → 帳號與權限 → 職務權限設定

依「職務」勾畫面權限的矩陣：上方選一個職務，縱軸是各畫面（依模組分群），橫軸是六種權限，用打勾設定。

【說明】權限管理已改以「權限等級」為主（見上方權限等級主檔）；本頁是職務制時期的設定方式、過渡期間保留。日常設權限請優先使用權限等級的權限矩陣。
操作步驟
  1. 上方「職務」下拉選一個要設定的職務。
  2. 縱軸畫面依模組分群（手風琴，一次展開一個模組）；點模組標題展開該模組的畫面清單。
  3. 在每個畫面那一列，勾選要開放的權限（瀏覽／新增／修改／停用／匯出／核准）。
  4. 可用整列「全選／清除」或整模組「全選／清除」快速批次勾。
  5. 勾選只是暫存，務必點「存檔（Alt+S）」才會真正寫入；有未存檔變更時左上會顯示「● 有未存檔變更」。

  1. 在列表點「新增」，先選「對象類型」（決定顯示哪些分頁、編號開頭）。
  2. 「基本資料」分頁填公司全名等。
  3. 依對象類型切到銷貨／配送／財務分頁填對應資料。
  4. 進詳細頁可維護「聯絡窗口」與「地址」子表。點「儲存」。
