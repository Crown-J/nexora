## §1. 此套件涵蓋什麼

電子發票套件 = NEXORA 跟「**加值中心**」自動串接、能在銷貨單 INVOICED 狀態自動印出 / 寄電子發票給客戶。

| 項目 | 說明 |
|---|---|
| **典型加值中心** | ezPay / 綠界 / 藍新 等財政部認證加值中心 |
| **觸發點** | NX-MANUAL-05 §6.10 銷貨單 INVOICED 狀態 |
| **副產品** | 銷退單 R / D 過帳後可自動寄電子折讓單給客戶 |
| **業務邊界** | 發票專用、**不做物流通知**、**不做 LINE 訊息**、**不做催收**、**不做金流串接**（金流 / 訊息屬第三方串接套件、見 PACKAGE-07）|

⭐ 適合「開發票需求大、希望系統自動處理稅務發票流程、不想另設發票機 / 第三方系統手動標記」的客戶。

## §3. 加值中心串接設定（規劃中）

⚠️ 預計做法：

- 在「設定 → 套件設定 → 電子發票」分頁、選擇加值中心（ezPay / 綠界 / 藍新）、填 API Key 或上傳憑證、按「測試連線」確認可發測試發票。
- 一個租戶只能掛一家加值中心、之後可換、換時保留歷史發票紀錄。

## §4. 銷貨單 INVOICED 自動觸發（規劃中）

⚠️ 預計做法：

```
1. 業務員開銷貨單 → 出貨 → 應收掛帳 → 按「開發票」
   ↓
2. 狀態切 INVOICED → 系統呼叫加值中心 API、傳發票資料
   ↓
3. 加值中心回傳發票字軌號 → 系統存到銷貨單 invoiceNo 欄
   ↓
4. 加值中心按客戶設定（紙本 / Email / 簡訊）寄發票給客戶
```

⭐ 跟 LITE 預設流程的差別：LITE 流程在第 1 步「按開發票」之後、需要會計另外開發票機或第三方系統處理、再手動回 NEXORA 標 INVOICED；加購此套件後 1 ~ 4 全自動。

## §5. 銷退單自動寄電子折讓單（規劃中）

⚠️ 預計做法：

- NX-MANUAL-05 §7 銷退單 R（退回不換）或 D（折讓不退）過帳後、系統觸發加值中心 API、自動寄電子折讓單。
- 對應 NX-MANUAL-06 §6.1 折讓核可的 S 銷貨折讓路徑、加值中心同步處理。

## §6. 發票狀態回報 + 異常重發（規劃中）

⚠️ 預計做法：發票異常（買方拒收 / 加值中心 API 失敗）系統在銷貨單詳情頁顯示警示、提供「重發」按鈕、會計確認後重試。
