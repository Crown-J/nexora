## §1. 此套件涵蓋什麼

401 自動上傳套件 = 把 NEXORA LITE 的「401 TXT 兩檔」自動送到財政部 API、自動回標已上報、會計只要核對總數對不對。

| 項目 | 說明 |
|---|---|
| **觸發點** | NX-MANUAL-06 §7.6 ~ §7.7 月關帳 + 401 雙月一期預覽 → TXT 兩檔產生後自動傳 |
| **業務邊界** | 純「上傳國稅局」這一個動作、**不做別的稅務功能**（不算稅 / 不調帳 / 不串電子發票） |
| **回標** | 國稅局回應後、系統自動把月關帳的 reportFiledAt 欄位填上、狀態切「已上報」|

⭐ 適合「會計怕上傳麻煩、不熟悉財政部網站、希望系統一鍵搞定 401 申報」的客戶。

⚠️ ⭐ **重要邊界**：**401 預覽 + TXT 兩檔下載**功能屬 LITE 內含、就算不買套件、會計也能自己處理 401 申報、不影響合規。本套件只是「省一個手動上傳步驟」。

## §3. 財政部 API 串接設定（規劃中）

⚠️ 預計做法：

- 在「設定 → 套件設定 → 401 自動上傳」分頁、設定公司統編、上傳工商憑證、按「測試連線」。
- 雙月關帳完成後系統自動觸發、不用會計人工進入此設定頁。

## §4. TXT 兩檔自動傳檔（規劃中）

⚠️ 預計做法（對齊 NX-MANUAL-06 §7.7 LITE 流程的第 5 ~ 8 步：

```
LITE 預設（不買套件）：
   會計開瀏覽器 → 登入財政部 → 上傳媒體檔 + 主檔 → 等收件回應 → 回 NEXORA 標已上報

加購本套件後：
   雙月關帳完成 → 系統自動呼叫財政部 API、傳媒體檔 + 主檔
                → 等待國稅局回應 → 自動標已上報
```

## §5. 國稅局回應自動回標（規劃中）

⚠️ 預計做法：

- 國稅局 API 回應「收件成功」→ 系統填 reportFiledAt 為當下時間、狀態切「已上報」。
- 國稅局 API 回應「資料異常」→ 系統發內部通知給會計、提供「重傳」按鈕、會計可選擇修正後重傳或先轉人工處理。

## §6. 異常重傳 + 對帳通知（規劃中）

⚠️ 預計做法：每次自動上傳成功 / 失敗 / 重傳、系統皆寫到月關帳的「動作軌跡」欄、稽核可追溯。
