## §1. 這本手冊是什麼

這本講「員工每天第一件事」：

- 怎麼登入。
- 第一次登入要做什麼（強制改密碼）。
- 登入後看到的首頁有什麼、各個區塊是什麼用。

讀完之後您會知道每天打開 NEXORA 看到的畫面、每個按鈕是做什麼的。

## §2. 登入畫面

### 2.1 怎麼進到登入畫面

打開公司給您的登入網址（例：`https://your-company.nexora.com`）、瀏覽器會顯示登入畫面。

### 2.2 畫面長什麼樣

畫面左半邊（電腦版）顯示 NEXORA 品牌標誌、右半邊是登入表單。手機螢幕會自動把品牌放上面、表單放下面、不用左右捲。

### 2.3 要填的三個欄位

| 欄位 | 是什麼 | 從哪裡來 |
|---|---|---|
| **公司帳號** | 您公司在 NEXORA 的代號 | 開戶時伊諾瓦給您（例如 `TW-100001`、`ZT-100001`）|
| **員工編號** | 您個人在公司裡的工號 | 公司負責人或人事建您帳號時給您（例如 `E001`、`E007`）|
| **使用者密碼** | 個人密碼 | 首次登入用伊諾瓦給的預設密碼（目前是 `changeme`）、進去之後系統強制您改 |

⭐ 密碼欄右邊有一顆眼睛圖案、按下去可以暫時顯示密碼（確認沒打錯）、再按一下隱藏回去。

### 2.4 按「登入系統」之後

- 三欄填齊才會亮、可以按。
- 沒填齊會直接擋下、提示哪一欄沒填。
- 帳號或密碼錯、會跳橘色警示框、底下會顯示一組錯誤代碼（例：`AU-301`、`AU-999`）、把代碼跟伊諾瓦客服說、客服可以快速判斷狀況。
- 正確 → 系統依您身分跳兩種畫面：
  - **首次登入** → 跳「改密碼畫面」（見 §3）。
  - **已改過密碼** → 直接進首頁（見 §4）。

### 2.5 忘記密碼

登入按鈕上方有「忘記密碼？」按鈕。

⚠️ **此功能尚未開放**：目前點下去沒反應、請聯絡您公司的負責人或伊諾瓦客服協助重設。

### 2.6 登入頁底下的版本號

最底下有一行小字、像是「NEXORA GRID | v1.5.1 beta」、代表您現在用的是哪一版的系統。出問題時跟客服說這個版本號、客服比較好判斷。

## §3. 首次登入強制改密碼

### 3.1 為什麼會跳這個畫面

伊諾瓦給您的預設密碼很簡單（`changeme`）、誰拿到都能登入您的帳號。為了帳號安全、系統強制您第一次登入就改一組自己的密碼、改完才能用 NEXORA。

### 3.2 畫面長什麼樣

標題：「⚠️ 首次登入、請改密碼」、底下三個欄位：

| 欄位 | 怎麼填 |
|---|---|
| **舊密碼** | 首次登入可以**留空**（系統會自動略過驗證）、之後改密碼才會驗 |
| **新密碼** | 至少 6 個字、自由設定 |
| **確認新密碼** | 再打一次新密碼、確保沒打錯 |

### 3.3 按「改密 + 進入系統」

- 兩次新密碼不一樣 → 跳紅字「兩次新密碼不一致」。
- 新密碼少於 6 字 → 跳紅字「新密碼至少 6 字元」。
- 改成功 → 自動跳進首頁。

### 3.4 之後想再改密碼

之後想再改密碼、要從「使用者選單 → 個人設定」進入（不會再強制跳了）。

⚠️ **個人設定區塊細節尚未開放**：目前使用者選單的細項功能還在補、暫時只能用「登出」、之後補完會另發手冊更新。

## §4. 首頁全貌

登入成功（或改完密碼）後預設看到的畫面、整個首頁分三層：

```
┌─────────────────────────────────────────────────────┐
│  螢幕最上方那排（頂列）                              │ ← §5 講
├─────────────────────────────────────────────────────┤
│                                                     │
│  業務數據 5 個格子（自己挑要看什麼）                │ ← §6 講
│                                                     │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌──任務清單──┐ ┌──行事曆──┐ ┌──事件簿──┐         │ ← §7 講
│  │ 待辦事項    │ │ 本月日曆 │ │ 當日事件 │         │

```

⭐ 手機螢幕會自動變單欄堆疊：頂列 → 5 數據格（兩欄或三欄縮排）→ 任務 → 行事曆 → 事件簿。

## §5. 螢幕最上方那排（頂列）

由左到右、所有元素如下：

### 5.1 星球按鈕（左上角）

是一顆會轉的小行星圖案。

- **作用**：跳到 NEXORA 任何一區（最快的找功能方式）。
- **怎麼開**：滑鼠點一下、或按鍵盤 `Alt+X`。
- **開起來長什麼樣**：
  - 上方一個搜尋框（可以打主檔名字直接跳、例：打「職務」、「幣別」、「零件」就會跳對應主檔）。
  - 左邊一欄 7 個區（首頁 / 主檔 / 採購 / 銷貨 / 庫存 / 財務 / 報表）。
  - 滑鼠停在某個區、右邊會展開該區所有子頁面、點一下就跳。
  - 也可以全鍵盤操作：`↑↓` 選區、`→` 進子選單、`Enter` 跳頁、`Esc` 關閉。

### 5.2 分類 + 標題（中段）

顯示「您現在在哪個區、哪一頁」。

- 在首頁時顯示：「首頁 · 個人儀表板」。
- 走到報價單列表時顯示：「銷貨 · 報價單」。
- 等等。

讓您一眼知道自己在系統的哪裡。

### 5.3 公告（喇叭圖案、琥珀色徽章）

- **作用**：看公司公告。
- **徽章數字**：公司目前有幾則「已發布」的公告。
- **點開**：跳出小視窗、列前 10 則公告標題、按下方「查看全部公告」跳「主檔中心 → 公告」看完整列表。
- **資料來源**：主檔中心 → 公告（NX-MANUAL-02 §X 會講怎麼發公告）。

### 5.4 任務（剪貼板圖案、琥珀色徽章）

- **作用**：看您有幾件代辦事項。
- **徽章數字**：分配給您、還沒做完的待辦數。
- **點開**：跳出小視窗、列前 10 筆待辦標題、有到期日的標到期日。
- **資料來源**：任務管理（共用模組、所有單據都可以丟一條待辦進來、例如「這張採購單請王經理核可」）。

### 5.5 通知（鈴鐺圖案、紅色徽章）

- **作用**：看系統通知（跟公告不一樣、公告是公司主動發、通知是系統自動發）。
- **徽章數字**：未讀通知數。
- **點開**：跳出小視窗、目前顯示「有 N 則新通知 / 目前沒有新通知」。

⚠️ **通知詳細內容尚未開放**：目前通知小視窗只顯示總數、看不到單筆內容、之後會補通知中心。

### 5.6 使用者（最右邊、頭像 + 公司名 + 帳號 + 下拉箭頭）

- 頭像是您姓名的第一個字（中英文皆可）做成的圖案。
- 公司名顯示您所在的公司（伊諾瓦開戶時建的、見 NX-MANUAL-00 §4）。
- 帳號顯示您的姓名、後面可能會接您公司的方案（LITE / PLUS / PRO、見 NX-MANUAL-00 §3）。
- **點開有什麼**：
  - 上半顯示完整公司 + 帳號 + 方案。
  - 下方一個「登出」按鈕（紅色 hover 提示是要離開系統）。

⚠️ **個人設定、切換主題等功能尚未開放**：目前下拉選單只有「登出」、之後會補。

## §6. 業務數據 5 個格子

### 6.1 這 5 格是做什麼的

讓您把「最關心的 5 個數字」釘在首頁上、登入就看到、不用每天點進各個工作頁去查。每人自己挑、互不影響。

### 6.2 預設長什麼樣

剛開戶或剛建的帳號、5 格都是空的、寫「點擊設定數據」、像 5 個虛線框。

### 6.3 怎麼設一格

1. 點任一個空格。
2. 跳出選單視窗、列出所有可選的數據、分四類：**採購 / 庫存 / 銷售 / 財務**。
3. 點選一項、視窗關閉、該格自動換成那個數據。

### 6.4 可以選什麼

依您權限和方案而定、目前有 17 項可選：

| 類別 | 可選項目 |
|---|---|
| **採購** | 採購需求單筆數、詢價單筆數、採購單筆數、進貨單筆數、保固申請單筆數 |
| **庫存** | 產品庫存設定數、撿貨單筆數、包貨單筆數、盤點單筆數、異常回報單筆數 |
| **銷售** | 報價單筆數、銷貨單筆數、銷退單筆數、同行調貨筆數 |
| **財務** | 應收筆數、應付筆數、票據張數、已關帳期數 |

### 6.5 7 個 KPI 套件項目（顯示但鎖住）

⚠️ **此 7 項需加購「KPI 系統套件」、詳見 NX-MANUAL-PACKAGE-05**（PRO 跟打卡包送、LITE / PLUS 可單買）。未加購時、選單裡會看到名字標 🔒、點下去沒反應：

- 銷售目標達成率
- 毛利率走勢
- 採購節約率
- 帳實一致率
- 帳齡 / DSO 平均收款天數
- 報價成單率
- 銷售品類佔比

⭐ LITE 客戶（未加購）可直接跳過此節、6.4 的 17 項基本數據已夠日常用。

### 6.6 換或清掉某一格

滑鼠移到已設定的格上、右上角會浮出一顆小齒輪、點下去：

- 跳出原本的選單、可選別的數據覆蓋過去。
- 視窗下方有「清除」按鈕、可以把該格還原成「點擊設定數據」。

### 6.7 權限影響

- 您沒有「採購」權限、選單裡採購類整個分組會隱藏（看不到可選的採購數據）。
- 同理庫存 / 銷售 / 財務各類也是看權限。

### 6.8 資料更新時機

每次重新整理首頁或重新登入時、5 格的數字會自動重抓最新值。

### 6.9 引用關係（每格數字從哪來）

| 格類別 | 數字來源 |
|---|---|
| 採購 5 項 | 採購區的對應子頁面（詳見 NX-MANUAL-03）|
| 庫存 5 項 | 庫存區的對應子頁面（詳見 NX-MANUAL-04）|
| 銷售 4 項 | 銷貨區的對應子頁面（詳見 NX-MANUAL-05）|
| 財務 4 項 | 財務區的對應子頁面（詳見 NX-MANUAL-06）|

## §7. 下方三欄

### 7.1 左欄：任務清單

- **顯示什麼**：前 10 筆指派給您的待辦事項、依優先度排序。
- **每一筆顯示**：
  - 緊急程度標籤（**緊急** / **高**、其他不標）。
  - 任務標題（例：「請核可採購單 NX02PO00012」）。
  - 從哪個模組來（小灰字、例：「採購 / 銷貨」）。
  - 逾期：超過到期日會在右邊用紅色標「⚠️ 逾期」。
- **沒待辦時**：顯示「目前沒有待辦」。
- **想看全部**：到伊諾瓦平台後台或之後補的「任務中心」（⚠️ 目前首頁面板沒有「查看全部」按鈕、要從小星球 → 主檔 → 任務管理進去）。

### 7.2 中欄：行事曆

- **顯示什麼**：本月的月曆、6 週格子。
- **今天**：邊框會比較亮、容易找。
- **有事件的日子**：日期下方會有亮點（小圓點）標記、提示「這天有事」。
- **切月份**：標題列的左右箭頭（`<` `>`）切上個月、下個月。
- **選某一天**：滑鼠點該天的格子、右欄「事件簿」會自動換成那天的事件。

### 7.3 右欄：事件簿

- **顯示什麼**：左欄行事曆當前選取那天的所有事件。
- **每一筆事件顯示**：
  - 類型徽章：
    - **系統**（藍色、例：系統自動記的單據開單日）
    - **公司**（琥珀色、例：負責人手動加的休假、會議）
    - **提醒**（綠色、例：應收到期提醒）
  - 標題（例：「採購單 NX02PO00012 預計到貨」）。
  - 時間（全天事件顯示「全天」、有具體時間顯示 `HH:MM`）。
- **當天沒事件**：顯示「當日無事件」。
- **資料載入中**：顯示「載入中…」。

### 7.4 三欄資料來源

| 欄 | 資料來自 | 在哪管理 |
|---|---|---|
| 任務清單 | 任務管理模組 | 主檔中心 → 任務管理 |
| 行事曆 + 事件簿 | 日曆事件 | 主檔中心 → 公告 / 各業務單據自動寫入 |

## §8. 重新整理 / 切回首頁

任何時候想回首頁：

- 點頂列星球按鈕（或 `Alt+X`）→ 左欄選「首頁」→ Enter。
- 或者直接在網址列把網址尾端改成 `/dashboard`。

回到首頁後、任務 / 行事曆 / 事件簿 / 5 數據格都會自動重抓最新。
