NX-MANUAL-08

F2 即時零件查詢
版本Ver 1.0日期2026-07-11維護Hank（全端）

電話進來就查——任何畫面按 F2 開零件查詢，兩步到貨況：搜尋窗找料 → 主視窗看「公司到底有沒有貨」，再用 F3~F10 快捷鍵下鑽比價、看歷史、找替代。
全程鍵盤可完成、不需碰滑鼠。

概觀

F2 即時零件查詢是一組疊層視窗：視窗 1（搜尋窗）負責找到料件、視窗 2（主視窗）負責回答「這顆料公司有沒有貨、賣多少、跟誰買過」。設計原則是「一個模板、三種入口、銷售為錨」——同一套畫面，銷售、採購、倉管從不同地方進來，看到的重點各自貼合情境（見第 4 章）。

開啟與關閉

操作行為
任何畫面按 F2開搜尋窗（銷售入口、預設）
搜尋窗開著按 F2全部關閉
主視窗開著按 F2 或 Esc退回搜尋窗（搜尋條件與結果保留、可直接選下一筆）
主視窗右上 X兩窗全關
【說明】視窗開著時，背景畫面的鍵盤操作全部隔離，不會誤觸底下的頁面。

視窗 1：搜尋窗

左邊輸入條件、右邊即時出結果。三種查法用頁籤切換（Alt+1~Alt+3），切查法時輸入欄自動清空重來。

三種查法

查法快捷鍵欄位用途
料號（預設）Alt+1料號單欄最常用：知道公司料號直接打
品名+車型Alt+2品名（主）＋車型（縮小範圍）只知道是什麼零件、裝什麼車
進階Alt+3料號／品名／廠牌／族群／車型／系統別／用途別 七欄＋「含停用品」勾選多條件 AND 交集；查停用料也在這裡
【說明】進階的「系統別」九選（引擎／傳動／制動…）與「用途別」五選（保養件／維修件…）下拉，選項開頭帶數字——焦點在下拉時直接按數字鍵 1~9 即可選中。

鍵盤流（左輸入區 ⇄ 右結果區）

標準操作
  1. 打條件——欄位間 Enter 跳下一欄；最後一欄 Enter 或任意處 Alt+F 觸發搜尋。
  2. 觸發後焦點自動鎖到右邊結果區（左邊變灰、顯示「已鎖定 · Alt+F 回此區」）。
  3. ↑↓ 逐筆選、PageUpPageDown 整頁跳（一頁 8 筆）。
  4. Enter 選定 → 進主視窗。
  5. Esc 或 Alt+F 退回左邊改條件。

結果區怎麼看

每筆四項資訊：料號｜副廠料號｜廠牌｜品名，加「正廠」（金）／「副廠」（灰）徽章。屬於同一通用件群組的料會縮排分群——群組頭是主件、替代品縮排掛在底下，一眼看出誰跟誰互通。

  • 結果一次最多 500 筆，達上限會標紅字「⚠ 已達上限 500」——請加條件縮小。
  • 查無資料時提示「換個關鍵字、或勾『含停用品』（進階）」。

視窗 2：主視窗

選定料件後開啟，三欄一屏答完「這是什麼、有沒有貨、有什麼可替代」。

左欄：基本資料

基本資料欄位
產品圖
縮圖；按 Space 全螢幕放大，多張圖用 ←→ 切、再按 Space 或 Esc 關。
基準料號
公司主碼（金色強調）。
廠牌料號
該廠牌對此料的料號。
品名 / 廠牌 / 族群
名稱、零件品牌、所屬自訂群組。
正/副廠
正廠金徽章／副廠灰徽章。
規格備註 / 狀態
規格說明；停用料標紅「停用」。

中欄：公司總存貨

預設不分倉、只回答「公司到底有沒有貨」：

公司總存貨區塊
大狀態
三態：有貨可出（可出 ≥ 安全量）／低於安全／缺貨（可出 ≤ 0）。未設安全量時可出 > 0 即視為有貨。
三指標
總可出（主角、綠）／總庫存（白）／在途（橘、採購已下單未入庫）。
水位條
一條看懂：安全量刻線 ─ 現量填色 ─ 最高量刻度（安全/最高 = 各倉庫存設定加總；未設定則只畫現量並註記）。
各倉分布
預設收合、點「各倉分布」展開：每倉一條橫向長條（長度 ∝ 現有量、可出綠＋不可出紅分段、在途數字附註）；本倉（我的主要倉）pin 頂＋徽章；空倉折疊成「其他 N 倉無庫存」；超過 8 倉清單內捲動、資料不砍。

右欄：通用零件（焦點預設在這）

同群組的主件＋替代品清單，每筆顯示料號／品名／副廠料號／廠牌／即時庫存（缺貨標紅）。開窗後焦點直接落在第一筆，馬上可鍵盤操作：

按鍵行為
↑↓選通用件
Enter預覽：左欄、中欄切到該替代品的資料，但主件保留置頂高亮（比完價切回主件按 Enter 即可）
Alt+F跳搜：以該件為新主件整個重查（原主件不保留）
【重點】「預覽」跟「跳搜」的差別是靈魂：電話中客戶問替代品價格 → 用 Enter 預覽、看完切回；確定改賣那顆 → 用 Alt+F 換主件。

快捷面板 F3~F10

主視窗開著時按 F3~F10 下鑽。面板類（F3/F5/F6/F8/F9/F10）疊在主視窗上、同鍵再按或 Esc 關閉；換料件（預覽/跳搜）時面板自動收、資料重抓。F4/F7 是動作鍵、直接開報價/詢價視窗。

F3 可替代零件

通用件精簡表——只露料號／廠牌／庫存數量三欄（主件標「主」、庫存有貨綠/缺貨紅），電話中快速報「有沒有替代品」。

F4 即時報價

帶當前料件開「即時報價」（選客戶 → 報價）。選定客戶後主視窗會帶出該客戶的預設出貨倉（見第 4 章銷售情境）。

F5 周轉率分析

周轉率面板（六格指標）
近 30 / 90 天出庫、近 90 天入庫
出入量統計。
日均出庫（30天）
近 30 天出庫 ÷ 30。
現量可售天數
公司現量 ÷ 日均出庫。
年化周轉率（估）
近 90 天出庫年化 ÷ 現量。
【注意】F5 是估算值：以近 100 筆出入庫紀錄前端統計，面板底部標注估算基礎；紀錄達 100 筆上限時會警示「更早異動未計入」。

F6 出入庫紀錄

近 100 筆異動表：日期／類型（進貨、退貨、銷貨、開帳、盤點、調撥）／入／出／結存／倉位。

F8 銷貨比價

銷售報價的主力下鑽（寬版面板）：

銷貨比價三段
建議售價列
成本＋A／B／C／D 四級售價五格並排（未設定顯示 —）。
歷史銷貨
近 50 筆成交事實：日期／單號／客戶／數量／單價／金額／狀態。
歷史報價
近 50 筆含未成交：日期／單號／客戶／數量／報價／最低價／狀態／成交欄（✓＋已轉銷貨數量）——看得出這客戶談過什麼價。

F9 進貨比價

近 50 筆進貨明細（寬版面板）：日期／單號／供應商／數量／單位成本／實際成本（橘色強調、比價主看點）／金額／批號／狀態。

F10 相關零件

兩個頁籤（點按切換、各帶筆數）：

  • 對應料：改號、同款、改版周邊、組合包、拆解包等關聯料一表列出（不分子類型）：料號／品名／廠牌／庫存／備註。
  • 適用車型：這顆料裝什麼車：車型（代碼＋名稱）／品牌／年份（起–迄、現役顯示「現役」）／引擎（代碼＋排氣量）／適配等級（原廠／副廠等效／通用替代）／備註。

F7 即時詢價

帶當前料件開「即時詢價」（調貨側、挑同行問貨）。

三入口情境

同一套視窗、三種進法。差別在「倉別」——不做全域選倉，倉別由情境決定：

入口怎麼進情境行為
銷售（主入口、高頻）任何畫面 F2報價選定客戶後，主視窗頂部出現「客戶倉」徽章、各倉分布自動展開、該客戶的預設出貨倉 pin 到最頂（優先於本倉）——先看出貨倉有沒有貨。
採購（低頻）採購需求單工具列「料號查詢 F2」嵌在採購作業旁查料。
倉管（低頻）庫存查詢工具列「料號查詢 F2」主視窗各倉分布自動展開、本倉（自己的主要倉）pin 頂＋徽章。
【說明】情境記在外層：主視窗退回搜尋窗再進下一顆料，客戶倉等情境不會丟；整組關閉（X 或搜尋窗按 F2）才清除。

限制與注意

  • 筆數上限：搜尋結果 500 筆；F8 歷史銷貨/報價各近 50 筆、F9 近 50 筆、F6 近 100 筆——達上限面板會標警示、更早的紀錄不列。
  • F5 是估算：基礎為近 100 筆出入庫，低頻料可信、高頻料建議看報表模組的正式周轉分析。
  • 成本露出：F8 建議售價列含進貨成本，可見性走現有權限目錄（能開主視窗即能看）。
  • 水位條要有設定才完整：安全量／最高量來自「產品庫存設定」（見 NX-MANUAL-04）；沒設定只畫現量。
  • 本倉 pin 要有歸倉：倉管情境的本倉標記依「使用者隸屬倉」的主要倉設定；沒設定就不 pin。
