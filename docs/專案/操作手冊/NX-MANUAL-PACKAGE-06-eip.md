## §1. 此套件涵蓋什麼

EIP（Enterprise Information Portal）套件 = NEXORA 內部「**員工資訊入口 + 公司知識管理 + 跨模組通知中心**」、把分散在各模組的「該被員工看到的事」集中呈現、減少切換工作頁的成本。

⭐ 適合「員工 15+ 人、希望系統承載公司公告 / 文件 / 內部訊息 / 跨模組任務」的中大型客戶。

## §3. 完整公告系統（規劃中）

⚠️ LITE 公告主檔（NX-MANUAL-02 §9.1）只有「公司喇叭 + 行事曆」基礎呈現、加購本套件後擴充：

- 公告分類（系統公告 / 部門公告 / 全體公告 / 機密公告）。
- 必讀公告（員工未讀時首頁強制跳出、按已讀才能進工作頁）。
- 已讀統計（公告者看誰看了 / 誰沒看）。
- 公告附件（PDF / 圖片 / 影片）。

## §4. 公司知識管理（規劃中）

⚠️ 預計做法：建一個「公司文件庫」、按主題（產品手冊 / 內訓 SOP / 法規文件 / 安全資料）分類、員工可搜尋。

## §5. 內部社群 / 留言板（規劃中）

⚠️ 預計做法：類似精簡版 Yammer / Workplace、員工可發文、按讚、留言。

## §6. 跨模組通知中心（規劃中）

⚠️ 預計做法：把分散在各模組的「該員工看到的事」集中：

- 採購：「您的採購單 PO12345 廠商已確認」。
- 銷貨：「您的客戶 ABC 等級變更已通過核可」。
- 庫存：「您負責的庫位 A1-03 盤點差異需確認」。
- 財務：「您催收的客戶已付款」。

## §7. 員工自助（規劃中）

⚠️ 預計做法：員工自己改個人聯絡資料、下載電子名片、查薪資單（如有 PACKAGE-04 出勤的薪資聯動）。

## §8. 跟 PACKAGE-04 出勤套件的串接（規劃中）

⚠️ 預計做法：請假 / 加班申請從 EIP 入口進、跟 PACKAGE-04 共用後端、減少員工切換頁面。
