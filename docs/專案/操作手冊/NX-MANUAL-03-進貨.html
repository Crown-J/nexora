通用操作

進貨在 NEXORA 是一套有先後順序的流程：先看「採購需求」、再去「詢價」比價、選定供應商開「採購單」、送主管核准、寄給廠商確認、貨到開「進貨單」驗收入庫，過程中可能開「退貨單」或「保固申請」。這一章先講所有進貨作業共通的操作。

怎麼進到進貨作業

按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「進貨」，或從下方工具列（dock）的「進貨」項展開進入。進貨底下分四類作業：採購需求、詢價單、採購單、進貨單；另有退貨單、保固申請、國外進貨追蹤。

【說明】進貨沒有「採購中心」這種中間頁；每一種單據都是獨立入口，從星球選單或 dock 直接進。

三種畫面版面

進貨的畫面分三種版面，看到時就知道怎麼操作：

三種版面
清單頁
一張清單列出某類單據（例如所有採購單），上方可依狀態、日期、廠商過濾，點一筆進詳細頁。
單據詳細頁
一張單據分「表頭」（單號、廠商、日期等）＋「明細」（一筆筆料件）。表頭在上、明細表在下；依單據目前的狀態，畫面會顯示對應的動作按鈕（例如草稿才有「送審」）。
流程追蹤頁
國外進貨用。一張單據用「階段時間軸」呈現，從備貨到驗收一步步推進，每階段填當階段的資料（如船號、到港日）。

國內採購

國內採購是一條從「需求」到「驗收入庫」的流程。先看全貌：

第 1 步：採購需求單
清單頁＋詳細頁LITE
選單位置進貨 → 採購需求

先看哪些料件需要進貨。系統會依各料件的安全量，自動把低於安全量的缺料列進缺貨簿；也可能是客戶要的、或臨時手動要進的。

採購需求欄位
來源
缺貨補貨（系統依安全量）／客戶要的（從銷貨來）／手動新增，三種來源用顏色區分。
料件必填
要詢價進貨的料件。
需求數量必填
要進多少。
備註
說明用途、急不急。
操作步驟
  1. 在缺貨簿看系統依安全量列出的缺料。
  2. 挑要補的料件，一鍵「轉詢價」帶到詢價單。
  3. 客戶要的、或臨時要進的，也可以直接建詢價單。
第 2 步：詢價單・比價
詳細頁（並排比價）LITE
選單位置進貨 → 詢價單

針對要進的料件，跟「可供貨的廠商」詢價，多家報價並排比較，選最好的一家直接帶出採購單。

詢價單表頭欄位

詢價單號。

建立的日期與人。

草稿 → 已發出 → 已回覆 → 已關閉。
詢價明細與比價欄位
料件必填
要詢價的料件；系統依「供應商供貨對應」帶出可詢價的廠商。
數量必填
詢價數量。
各家報價
每家供應商一欄，填單價、交期，並排比較。
操作步驟
  1. 建立詢價單、加入要詢價的料件。
  2. 把單據標為「已發出」、向各供應商詢價。
  3. 在比價區，逐家填入報價（單價、交期）。
  4. 比較後，在某家供應商點「採用」→ 系統自動產生一張採購單草稿（並拒絕其他家、詢價單關閉）。
【重點】「採用」一鍵就把比價結果變成採購單草稿，料件、數量、單價自動帶過去，不用重打。
第 3 步：採購單

選單位置進貨 → 採購單

採購單是向廠商正式下單的單據。表頭記下單對象、付款與交貨安排，明細記要買的料件。建立後走「送審 → 核准 → 寄廠商 → 廠商確認」流程。

採購單表頭欄位
單號系統自動
採購單號。
開單日期 / 開單人員系統自動
建立的日期與人。

付款對象

指送對象
貨送給誰；留空＝跟供應商同（例如分店收貨）。

料件名稱（帶自主檔）。
數量必填
採購數量。
已進量 / 取消量系統自動
已收多少、取消多少（分批進貨時追蹤；缺貨剩餘可取消）。
單價 / 金額
單價與小計。
預交貨日
這一筆料件的預計到貨日（可逐筆設）。
操作步驟
  1. 在採購單填好表頭（供應商、付款／指送對象、交貨安排）與明細。
  2. 確認無誤，點「送審」→ 單據變「待核准」，送給主管。
  3. 主管在待核准的單上點「核准」（→已核准）或「退件」（填原因、退回草稿）。
  4. 核准後點「寄出廠商」→ 單據變「已寄廠商」。
  5. 廠商回覆接單後，點「廠商確認接單」→ 系統產生應付帳款。
  6. 廠商備好貨、依約付款後，點「轉進貨」產生進貨單，準備驗收。
【注意】「核准／退件」要有「核准」權限的職務才能按（在職務權限設定的「核准」欄開放）。這樣就能做到「採購員送審、主管才能核准」。

國外採購

國外採購大致和國內相同（需求 → 詢價 → 採購單 → 進貨驗收），差別在「物流與到貨」這段：要追船期、聯繫報關行、拿提貨單，而且進貨成本要把運費、關稅等進口費用攤分進去。國外進貨用「流程追蹤頁」以六個階段推進。

特殊採購

特殊採購（跳過詢價）
詳細頁LITE
選單位置進貨 → 採購單（特殊）

已經知道要跟誰買、不需要比價時，可以跳過詢價、直接開採購單。流程與一般採購單相同（送審 → 核准 → 寄廠商 → 廠商確認 → 進貨驗收），只是少了前面的詢價比價。

料件壞掉要跟供應商主張保固時開保固申請單。分兩種來源：客戶反映的、或自己庫存發現的。

保固申請單欄位
單號系統自動
保固單號。
類型必填
客訴型（客戶反映壞掉、要連到銷貨單）／自用型（庫存自己發現、無客戶）。
來源銷貨單
客訴型必填：是哪張銷貨的客戶反映的；自用型不顯示。
供應商必填
這料件當初向哪家買的、要向誰主張保固。
零件必填
壞掉的料件（料號＋品名）。
狀態系統自動
申請的處理進度。
處理結果
保固的判定結果。
退款方式
退錢／換貨等處理方式。
附件
佐證照片或文件。
