通用操作

庫存的功能大多是各自獨立的作業（查庫存、盤點、處理異常、重組分解等），不像進貨那樣是一條長流程。這一章先講共通的操作。

怎麼進到庫存作業

按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「庫存」，或從下方工具列（dock）的「庫存」項展開進入。庫存底下就是各項作業：庫存查詢、產品庫存設定、倉位庫位、盤點、異常處置、重組分解、進貨工作站、撿包送、開帳存。

【說明】庫存沒有中間的「庫存中心」頁；各項作業從星球選單或 dock 直接進。

撿包送

出貨端的三步作業：撿貨 → 包貨 → 出貨。撿貨分電腦版與手機版（手機邊走邊撿、電腦行內直接操作）；包貨、出貨用電腦。庫存與應收，等客人「簽收」那一刻才入帳——封箱出倉時還不扣，因為出貨前可能還要改單。

撿貨清單
庫位軸清單LITE
選單位置庫存 → 撿包送 → 撿貨（撿貨作業）

撿貨不是「新增一張撿貨單」，而是一張依庫位排的工作清單：所有要出貨、且現貨已備齊的貨，以庫位為軸自動出現在這裡。同一（倉×料件）跨多張銷貨單的需求會合併成一個總量，撿一次分配到各單；每項帶主圖與料號旁的廠牌徽章，倉管順著庫位走道一路撿。撿完，貨就傳到包貨。

撿貨清單怎麼看、怎麼操作
依庫位分組
同一庫位的料件排在一起、順著走道撿；每項顯示主圖、料號＋廠牌徽章、品名。
進度顯示
每項一條進度：已撿 X ／ 需 N ／ 剩 M，一眼看出這料件撿到哪。
全部撿取
一鍵把該料件剩餘量整批標已撿（最常用）。
部分撿
填數量 →「撿」，只撿一部分；剩餘量繼續掛待撿、可分次撿完。
異常
東西短缺／損毀，按「異常」對還沒撿到的剩餘量開一張異常回報單（接異常處置流程）；開完這料件的帳就平了、離開清單。
重置
撿錯了按「重置」把已撿量歸零重撿；已包貨或已開異常的不能重置。
行狀態系統自動
待撿 → 撿貨中 → 已撿完；一項全數帳平（已撿＋異常＝需求）才離開清單、傳到包貨。
【電腦／手機兩版】系統依螢幕寬度自動分版：電腦版每一行直接有「部分數量→撿／全部撿取／異常／重置」，滑鼠行內操作；手機版先點料件卡片、再按底部四個大鈕（部分撿／全部撿／異常／重置），字級放大、滿版好按，適合邊走邊撿。
【說明】缺貨的料件不會進撿貨清單；等調撥／調貨補到貨、現貨備齊後才自動出現。撿貨不扣庫存（扣庫存與開應收留到客人簽收那一刻）。
【請放回】撿到一半、若那張銷貨單被取消，系統會自動把它移出撿貨清單，並在撿貨頁頂端跳出「請放回 N 筆」提示（列出已撿下架的料號×數量）——把貨放回原庫位後按「已放回」即可清除。
包貨台
工作檯LITE
選單位置庫存 → 撿包送 → 包貨（包貨作業）

撿好的貨進包貨台，以客戶為單位呈現。預設一箱裝一張銷貨單；同一客戶如果有好幾張小單、東西都很小，可以併成一箱省包材。

包貨怎麼操作
建包貨單
點一個客戶，系統把他撿好的貨拉進來，預設每張銷貨單各自裝一箱、每箱自動產一個包裹號（BX 開頭）。
併箱
同客戶的小件，用「併入其他箱」把兩箱合成一箱（空箱自動刪）。限同倉、同出貨方式、同客戶。
列印 BX 標籤
每箱列印一張包裹標籤貼箱（含包裹號、客戶、料件清單）。
封箱
封箱＝包貨完成。這張銷貨單變「已出倉待簽收」、進出貨三區。封箱不扣庫存。
出貨三區
工作佇列LITE
選單位置庫存 → 撿包送 → 出貨三區

封箱後的包裹，依銷貨單的出貨方式自動分到三個工作佇列。各區收尾的簽收／寄出，就是正式扣庫存＋開應收的那一刻。

三區各自怎麼收尾
自取區
客人來取、核對後按「簽收」→ 完成、扣帳。
寄貨區
交黑貓／宅配，輸入物流公司＋物流單號按「寄出」→ 視同送達、完成、扣帳。
配送區
組長勾選多張要送的包貨單、選一位外務「配單成一趟」（一張配送單可含多張銷貨單）；外務送達、客人簽一次名，該趟所有銷貨單一起完成、扣帳。
整條動線
  1. 銷貨單確認 → 現貨自動進撿貨池。
  2. 手機撿貨：開始撿 → 逐項撿到／找不到。
  3. 包貨台：建包貨單 →（併箱）→ 列印 BX 標籤 → 封箱。
  4. 封箱後進出貨三區：自取簽收／寄貨寄出／配送配單派外務。
  5. 簽收（或寄貨輸單號）那一刻 → 正式扣庫存＋開應收、銷貨單完成。
【重點】庫存與應收在簽收後才入帳，不是封箱時。封箱到簽收之間貨雖已離倉，但系統用「保留量」鎖著、不會被別的單重複賣。
【說明】撿貨路徑最佳化、GPS、外送整合（Lalamove 等）屬加購套件，見對應的套件手冊。
