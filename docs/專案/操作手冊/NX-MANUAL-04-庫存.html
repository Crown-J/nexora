通用操作

庫存的功能大多是各自獨立的作業（查庫存、盤點、處理異常、重組分解等），不像進貨那樣是一條長流程。這一章先講共通的操作。

怎麼進到庫存作業

按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「庫存」，或從下方工具列（dock）的「庫存」項展開進入。庫存底下就是各項作業：庫存查詢、產品庫存設定、倉位庫位、盤點、異常處置、重組分解、進貨工作站、撿包送、開帳存。

【說明】庫存沒有中間的「庫存中心」頁；各項作業從星球選單或 dock 直接進。

異常處置

庫存裡發現異常的件（損毀、過期、數量短缺、放錯庫位、其他）時，先開「異常回報」記錄下來，再依狀況選一種處置。異常回報本身只是記錄、不動庫存帳；真正的庫存增減，由你選的處置對應的單據去做。

異常回報
清單頁＋詳細頁LITE
選單位置庫存 → 異常處置
異常回報欄位
單號系統自動
異常單號。
異常類型必填
損毀／過期／數量短缺／放錯庫位／其他。
回報日期必填
什麼時候發現的。
倉庫必填
在哪個倉發現的。
料件 / 數量必填
哪個料件、幾顆有問題。
庫位
選「放錯庫位」時必填——錯放在哪個庫位。
來源
從哪裡發現的（如銷貨檢貨、盤點時發現），系統可連回來源單據。
照片
佐證照片。
處置方式
選一種處置（見下方六種）。
狀態系統自動
草稿 → 已回報 → 處理中 → 結案（可取消）。
【說明】異常回報只記錄、不動庫存帳。選定處置後，庫存的實際增減由下游單據處理。
操作步驟
  1. 發現異常件，開異常回報，填異常類型、料件、數量。
  2. 標為「已回報」。
  3. 選一種處置（六選一，見下）。
  4. 下游單據處理完，異常單結案。

特價售出
詳細頁LITE
選單位置庫存 → 異常處置（異常單詳細頁選「特價售出」）

異常件選「特價售出」處置時，系統會建一張特價銷貨單，填買家與特價售出，貨從庫存出、應收進財務。把瑕疵但堪用、即期、中古的件用特價賣掉回收價值，而不是直接報廢虧光。

特價售出（產生特價銷貨單）
買家必填
賣給誰。
特價必填
這次特價售出的單價（由你填）。
數量必填
賣出數量。
成本系統自動
用原平均成本計入；售價是特價，毛利會反映折損。
【重點】特價售出走一般銷貨的流程（出庫、應收），只是標記為「特價」。怎麼定特價、即期／瑕疵／中古的優惠價規則，見《銷貨》操作手冊。

重組分解

重組分解
詳細頁LITE
選單位置庫存 → 重組分解

把庫存的料件「組合」或「拆解」。例如把零件組裝成套件（合併），或把整組拆成單品（分解）。系統會把投入的料件扣庫存、把產出的料件加庫存，並算好成本。

重組分解欄位
單號系統自動
重組分解單號。
模式必填
合併（多件組成一件）／分解（一件拆成多件）。
投入料件必填
要消耗的料件與數量（扣庫存）。
產出料件必填
產生的料件與數量（加庫存）。
成本系統自動
合併：投入成本加總；分解：依 A 級建議售價比例攤分到各產出料件。
【說明】重組分解只在倉庫內換料件型態、會動庫存帳，但不進損益（不是買賣）。

開帳存

【說明】開帳存是一次性的起始導入，不是日常作業；新客戶上線時由 Innova 代為匯入。
