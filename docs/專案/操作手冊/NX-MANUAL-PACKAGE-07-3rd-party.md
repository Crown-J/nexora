## §1. 此套件涵蓋什麼

第三方串接套件 = 一籃子「**跟外部 API 串接**」的通用套件、含 LINE / Lalamove / 簡訊 / 催收訊息 / GPS / 金流自動偵測款項到帳。

⭐ 適合「希望系統自動發訊息給客戶、自動派 Lalamove、自動匯入銀行流水、減少人工聯絡」的客戶。

⚠️ ⭐ **重要邊界**：

- 本套件**不**含電子發票（電發走 PACKAGE-02、跟加值中心串接是發票專用、不在這）。
- 本套件**不**算 401（401 走 PACKAGE-03、跟財政部 API 串接是稅務專用、不在這）。
- 金流自動串接銀行未來**可能拆獨立**第 9 套件（待總經理拍板）、目前暫歸本套件。
- Email 通道（自動寄催收 Email）目前**不在 8 套件**、待總經理拍板。

## §3. LINE / 簡訊通知（規劃中）

⚠️ 預計做法：

- 在「設定 → 套件設定 → 第三方串接」分頁、設定 LINE 官方帳號 Token + 簡訊服務商 API Key。
- 銷貨單出貨時自動發 LINE 給客戶「您的貨已出、單號 NX02SO12345、預計 6/10 送達」。
- 應收逾期 N 天自動發催收 LINE / 簡訊。
- 配送完成自動發 LINE「已送達、感謝您」。

⭐ 對應 LITE 預設：NX-MANUAL-06 §3.7 「催款 = 純內部 log、會計自己打電話」、加購後變自動發。

## §4. Lalamove API 整合（從 NX-MANUAL-04 §9.5 搬入）

⚠️ 規劃做法：配送方式選「Lalamove」時、直接呼叫 Lalamove API 叫車、API 回傳司機資訊 + 預計到達時間自動回填、司機位置接 GPS 追蹤、客戶用 LINE 通知拿追蹤連結。免去人工聯絡 Lalamove 客服 / 自行貼司機資訊。

⭐ 對應 LITE 預設：配送方式選「寄送」手動填 Lalamove 訂單編號即可。

## §5. GPS 即時追蹤（從 NX-MANUAL-04 §9.5 搬入）

⚠️ 規劃做法：司機開車送貨時、可在配送單詳情頁看到司機目前位置（即時 GPS 點）、客戶亦可拿到追蹤連結。配送完成 / 簽收落地後自動清除位置資訊。

⭐ 對應 LITE 預設：用配送員回報「已派車 / 已送達」+ 客戶電子簽收即可。

## §6. 金流自動串接銀行（規劃中、待總經理拍）

⚠️ **重要**：此功能未來**可能拆獨立**成第 9 套件（金流套件、待拍）、暫歸本套件。

⚠️ 預計做法：

- 串接客戶往來銀行（中信 / 玉山 / 國泰 / 第一 / 合作金庫）API。
- 每日自動匯入銀行流水。
- 跟 NEXORA 票據自動配對（金額 + 時間 + 客戶名）、自動沖銷應收。
- 異常配對（金額對不上 / 客戶無對應）標警示、會計手動處理。

⭐ 對應 LITE 預設：NX-MANUAL-06 §8.5 「會計人工核對月結單、手動更新自有帳戶餘額」、加購後自動匯入流水 + 自動沖銷。

## §7. 統一通知中心（規劃中）

⚠️ 預計做法：跟 PACKAGE-06 EIP 套件搭配、把第三方訊息（LINE / 簡訊）的回覆 / 已讀統計集中呈現。
