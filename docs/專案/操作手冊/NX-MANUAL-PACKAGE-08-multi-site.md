## §1. 此套件涵蓋什麼

多據點模組 = NEXORA 「**單據點 → 多據點**」升級包、解鎖跨倉 / 跨據點 / 跨幣別 / 跨國的完整營運能力。

⭐ 適合「公司有 2+ 倉 / 2+ 據點 / 做進口或出口 / 有多幣別需求 / 有部門結構」的中大型客戶。

⭐ 跟 PACKAGE-01 汽車資料庫的差別：本套件管「**地理 / 組織**」維度的擴張、PACKAGE-01 管「**產品分類 / 車型字典**」的細粒度。兩者獨立、可單買、可一起買。

## §3. 使用者據點設定（從 NX-MANUAL-02 §4.5 搬入）

多倉公司、每個員工要設定「**能操作哪幾個倉**」（**據點授權**）：

- LITE 預設單倉所以不需要這個設定。
- 加購「多據點模組」後：可以從使用者頁逐個設、或從「使用者據點設定」依倉庫批次匯入 / 移除成員。

## §4. 跨倉調撥單（從 NX-MANUAL-04 §10.2 搬入）

公司內部「A 倉的貨搬到 B 倉」的單據。常見場景：

- A 倉爆滿、B 倉空、把賣不動的料件搬過去。
- A 倉某料件缺、B 倉有多、移過來救急。
- 自動補貨：系統依「倉別」（總倉 / 中間倉 / 自助倉 / 寄賣倉、H/M/W/S）規則自動產調撥單。

入口：手機版工作站「調撥」分頁、桌機路由 `/dashboard/inventory/transfer`。

⚠️ 跟「同行調貨入庫」（NX-MANUAL-04 §10.1）是兩回事：同行調貨是**跨公司**向 O 同行調貨（LITE 基本內含）、跨倉調撥是**公司內**自家 A 倉搬 B 倉（本套件）。

## §5. 國外進貨 6 階段追蹤（從 NX-MANUAL-03 §10 搬入）

### 5.1 6 階段

| 階段 | 是什麼 | 圖示 |
|---|---|---|
| **1 備貨中** | 廠商正在備貨 | ✓ |
| **2 要求付款** | 廠商通知付款 | → |
| **3 待出貨** | 已付款、等廠商出貨 | → |
| **4 出貨上船** | 貨櫃已上船、船期確認 | 🚢 |
| **5 已到港** | 報關行通知到港 | ✈️ |
| **6 驗收完成** | 入庫驗收完成 | ✓ |

### 5.2 頁面長什麼樣

兩欄式佈局：

| 區 | 顯示 |
|---|---|
| **左欄：國外採購單列表** | 每筆顯示單號、目前階段徽章、開單日、狀態、總金額、船號、櫃號、ETA（預計到港日）|
| **右欄：選定 PO 的詳情 + 6 階段時間軸 + 推進按鈕** | 顯示 PO 號、目前階段、狀態、貿易條件、進口付款條件、明細表 |

### 5.3 跟一般採購單的差別

| 項目 | 國內採購 | 國外採購 |
|---|---|---|
| 狀態 | DRAFT → APPROVED → SUBMITTED → CONFIRMED → ... | 同左 + 多 **purchaseStage 1-6** 追蹤 |
| 應付認列點 | CONFIRMED 廠商確認 | 同左、外幣需多據點模組 |
| 額外欄位 | 不需要 | **船號、貨櫃號、ETA、貿易條件、進口付款條件** |
| 進口費用攤分 | 不需要 | **需要**（運費 / 關稅 / 報關費按比例攤到各料件成本）|
| 提貨單階段 | 不需要 | **需要**（本套件完整流程才有）|

### 5.4 資料來源 / 資料去向

- 來源：採購員建一般採購單時、標註 `purchaseType = 'I'`（進口）走國外流程。
- 去向：進口費用攤分後、寫進料件主檔的「進貨成本」；報表「進口報表 / 船期追蹤」用。

## §6. 出口（從 NX-MANUAL-05 §11 搬入）

| 功能 | 說明 |
|---|---|
| 國外銷貨單 | 含外幣、貿易條件（FOB/CIF/EXW/DDP）|
| 商業發票 | 給海關用 |
| 裝箱單 | 給物流用 |
| 報關文件 | 給報關行用 |

入口：銷售中心首頁 → 出口卡（加購後解鎖、路由 `/dashboard/sale/export`）。

國內為主的 LITE 客戶用不到、加購本套件後才開放完整國外流程。

## §7. 多幣別採購 / 銷貨單（規劃中）

⚠️ 預計做法：

- 採購單 / 銷貨單的「幣別」欄解鎖（LITE 預設鎖 TWD）。
- 外幣應付 / 應收按開單日匯率掛帳、收款 / 付款日按當日匯率沖、匯差自動計入損益。
- 多幣別月關帳支援。

## §8. 撿貨路徑最佳化（規劃中、從 NX-MANUAL-04 §9.3 標）

⚠️ 預計做法：依路徑最佳化（減少倉內走動）、適合多倉 / 大倉。

## §9. 盤點細範圍（規劃中、從 NX-MANUAL-04 §13.2 標）

⚠️ 預計做法：盤點單可設定範圍（全倉 / 特定區 / 特定料件）、LITE 預設全倉。

## §10. 部門結構 + 部門業績（規劃中、從 NX-MANUAL-07 §13.2 標）

⚠️ 預計做法：員工主檔加部門欄、銷售 / 採購單據按部門歸戶、報表「部門業績」可看。

## §11. SO 行的自倉調撥 T（規劃中、從 NX-MANUAL-05 §13.2 標）

⚠️ 預計做法：銷貨單明細的「自倉調撥」（transferSourceType=T）多倉支援、LITE 預設單倉、只有同行調貨（O）跟客訂（B）兩種。
