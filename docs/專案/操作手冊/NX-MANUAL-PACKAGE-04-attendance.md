## §1. 此套件涵蓋什麼

打卡出勤套件 = NEXORA 員工的「**上下班打卡 + 考勤管理**」基礎建設、為日後 KPI 系統套件（PACKAGE-05）的「準時上班 / 出勤率」指標提供原始數據。

| 項目 | 說明 |
|---|---|
| **打卡方式** | 手機 GPS 打卡（最低門檻）/ 桌機按按鈕 / IP 限定 |
| **班表管理** | 排班、輪班、跨日班、彈性上下班 |
| **加班 / 請假** | 員工自助申請、主管核可、累計到月關帳 |
| **薪資聯動** | 出勤統計提供原始時數、薪資計算（屬延伸功能、可能拆獨立模組）|

⭐ 適合「員工 5+ 人、有上下班時間管理需求、希望系統把出勤紀錄串到 KPI / 薪資」的客戶。

⚠️ **重要邊界**：
- 本套件**不**自動算薪資、只提供出勤時數給薪資模組（薪資模組規劃中、可能拆獨立模組）。
- 本套件**不**串信用卡 / 銀行（金流走 PACKAGE-07）。

## §3. 員工人資資料（規劃中）

⚠️ NX-MANUAL-02 §11.3 LITE 標明「員工主檔的『人資』分區看不到、屬打卡 + KPI 整合包」。本套件加購後、開放員工主檔的人資分區（部門 / 入職日 / 直屬主管 / 薪資基本資料 / 緊急聯絡人）。

## §4. 打卡規則設定（規劃中）

⚠️ 預計做法：負責人在「設定 → 套件設定 → 出勤」分頁設定：

- 上班時間（例 09:00）、下班時間（例 18:00）、午休時段。
- 遲到容差（例 5 分鐘以內算準時）。
- GPS 打卡範圍（公司座標 + 半徑 N 公尺）。
- 桌機 IP 限定（只允許辦公室 IP 打卡）。
- 跨日班 / 彈性上下班例外規則。

## §5. 員工打卡（規劃中）

⚠️ 預計做法：

- 手機：底部「打卡」按鈕、按下系統取 GPS、跟公司座標比、達範圍即記錄。
- 桌機：首頁右上「打卡」按鈕、按下記錄 IP + 時間。
- 雙打 / 漏打：員工可在「我的打卡紀錄」頁補申請、主管核可。

## §6. 班表管理（規劃中）

⚠️ 預計做法：負責人 / HR 在「出勤 → 班表」工作頁排班、每月固定排 / 自由排 / 跟員工換班。

## §7. 加班申請 / 請假申請（規劃中）

⚠️ 預計做法：員工自助申請、主管「等我核可」清單看到、按核可 / 駁回。累計時數寫入月關帳前的「出勤統計」。

## §8. 出勤統計 + KPI 餵料（規劃中）

⚠️ 預計做法：每月關帳前、出勤統計提供：

- 每位員工的「準時打卡率」「加班時數」「請假時數」「實際出勤天數」。
- 給 PACKAGE-05 KPI 系統套件的「準時上班」指標當原始數據。
