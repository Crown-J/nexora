通用操作

銷貨是「把貨賣給客戶」的完整流程，從報價到收款，再加上退貨。這一章先講共通操作。

怎麼進到銷貨作業

按左上角的星球選單鈕（快速鍵 Alt+X）→ 選「銷貨」，或從下方工具列（dock）的「銷貨」項展開進入。銷貨底下有：報價單、銷貨單、銷貨退回，以及一組「定價工具」（折扣代碼、促銷規則、組合套餐）。

【說明】銷貨沒有中間的「銷貨中心」頁；各項作業從星球選單或 dock 直接進。

銷貨主流程

目前只做內銷（外銷尚未開始）。一筆內銷生意從客戶來電查貨開始，到送達簽收、銷貨單顯示「已完成」。

操作步驟
  1. 客戶來電，先查庫存有沒有貨。
  2. 有貨直接報價；缺貨先向同行詢價、用同行價報。
  3. 客戶確定要就建銷貨單；缺貨先「同行調貨入庫」（見《庫存》）再建單。
  4. 銷貨單確認後，系統產生撿貨單、銷貨單狀態變「備貨中」。
  5. 撿完貨建包貨單、把貨拉進來、產生包裹編號。
  6. 配送方式為「配送」時，建配送單、指派誰送哪些包裹（自取則略過）。
  7. 送達客戶、客戶簽名後，銷貨單顯示「已完成」。
【說明】從「撿貨單」起（撿貨／包貨／配送／送達）屬庫存模組的撿包送＋配送，詳見《庫存》；銷貨單狀態會隨進度更新。開發票與收款屬財務、詳見《財務》。

銷貨退回

客戶退貨有兩種方式：業務先接到、建單再派人取回（計畫性）；或送貨員當場被告知、直接帶回檢查（臨時）。兩種最後都走「檢查能不能退 → 核准 → 過帳」。

方式 A：業務發起（計畫性退貨）

業務接到客戶要退貨 → 建銷退單 → 由庫存指派送貨員去取回（送貨員可能待命中、或正在配送中，屬庫存配送）→ 取回後檢查、核准、過帳。

方式 B：送貨員當場（臨時退貨）

客戶當場直接跟送貨員說這個要退 → 送貨員先把貨帶回 → 交給倉管或業務檢查能不能退 → 可退就建銷退單、核准、過帳。

優惠價子系統

優惠價是「針對特定商品（或套餐）給特定售價」，不是整張單打折。開銷貨單／報價時，系統會逐項商品算出該給的價、自動帶入。

定價分三層

商品的價分三層：基準價（商品本身的建議售價＋客戶等級）、促銷規則（臨時優惠：促銷／出清／即期）、個案特價（瑕疵／中古件個案，見《庫存》的特價售出）。系統開單時，把所有適用的價放進「候選價池」、取最低，就是這個商品給這個客戶的最終價。

第 1 層：基準售價

基準售價（既有，見《核心主檔》）
四級建議售價
每個料件有 A／B／C／D 四級建議價。
客戶分級
客戶分 A／B／C／D 級，對應挑哪一級建議價。
個別折數
個別客戶可覆寫分級、設專屬折數。

即期自動

系統會看每個批號快不快到期：批號的保固到期日距今小於「即期門檻天數」時，自動把它列為即期、套用即期類（出清）優惠價。新鮮的批不會被套出清價。

到期日來源系統自動

【說明】選了套餐，組內商品「不再各自套促銷」——套餐價就是整組的最終價（避免重複折）。套餐價會按各料件比例分攤回各明細、確保總和等於套餐價。

取最低與低於成本警示

開單時每個商品把候選價（客戶分級價＋所有適用的促銷／出清／即期）放一起，取最低，就是最終單價。

【說明】VIP 若分級價本來就比促銷低，他保有自己的低價（不會被促銷拉高）——客戶永遠拿到對他最划算的價。
【注意】最終單價低於成本（虧本賣，例如出清、即期）→ 系統警示、必填原因後放行（出清／即期本來就可能認賠）。
